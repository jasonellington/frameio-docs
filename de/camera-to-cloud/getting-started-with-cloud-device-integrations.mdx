## Camera To Cloud {#camera-to-cloud}

Die Camera to Cloud API bietet ein unkompliziertes Authentifizierungsprotokoll, das für Geräte mit eingeschränkten Anzeigemöglichkeiten konzipiert ist. Nach der Authentifizierung kann Ihr Gerät Daten vom Set direkt in die Cloud hochladen. Das System unterstützt die meisten gängigen Dateiformate für Video-, Audio-, LUT/CDL- und Timecode-Daten. Weitere Informationen zu C2C Certified Connections finden Sie auf unserer [Informationsseite](https://frame.io/c2c/certified).

## Erste Schritte {#getting-started}

Registrieren Sie sich auf unserer [Entwickler-Website](/de/#start-building), und wir nehmen Kontakt mit Ihnen auf, um Sie durch den Integrationsprozess für Cloud Devices zu begleiten.

## Entwicklerpaket {#developer-package}

Ihr Entwicklungspaket enthält:

**1. Client Secret**

Frame.io erstellt in unserem Backend ein Konfigurationsmodell für Ihr Gerät. Anschließend erhalten Sie ein `client_secret` für Ihr Gerät, das häufig als Gerätemodell-Kennung bezeichnet wird.

**2. Referenzimplementierung**

Sie erhalten eine Python-Referenzimplementierung mit Grundgerüst-Code, der Hardwaregeräte über ein CLI-Tool emuliert. Diese enthält kommentierten Code und eine Dokumentation, die die wichtigsten Integrationsschritte beschreibt.

**3. Validierungsprozess**

Vor dem Launch durchlaufen Sie gemeinsam mit Frame.io-Ingenieuren einen Qualitätssicherungsprozess, um sicherzustellen, dass Ihr Gerät wie erwartet funktioniert. Unser Ziel ist es, allen Integratoren zu helfen, einheitliche Qualitätsstandards für Endnutzer zu erreichen, die mit Ihrem cloudverbundenen Gerät arbeiten. So erhalten Sie vor der öffentlichen Veröffentlichung wertvolles Feedback. Wir stellen Ihnen eine Checkliste mit Prüfpunkten zur Verfügung, Sie können sich aber auch an unserer [C2C-Integrations-Checkliste](/de/camera-to-cloud/integrator-checklist) orientieren, um zu verstehen, was eine erfolgreiche Integration ausmacht.

**4. Supportmaterialien**

Sie erhalten Materialien, die Ihrem Team helfen, das Wertversprechen von Frame.io und Vorführtechniken zu verstehen, sowie Zugang zu einem eigenen Slack-Kanal für die Zusammenarbeit mit unserem Team. Wenn Sie zusätzliche Unterstützung benötigen – etwa eine Demo der Frame.io-Plattform oder einen Workshop zu Best Practices für Integrationen –, lassen Sie es uns wissen, und wir organisieren entsprechende Termine.

* Ein Logo im SVG-Format, vorzugsweise einfarbig

### Authentifizierungsmethode {#authentication-method}

Wir unterstützen jetzt ausschließlich den Authentifizierungsablauf mit 6-stelligem Code. Für Anwendungen bieten wir eine erweiterte Methode an, bei der beim Anfordern eines Gerätecodes ein spezieller Header-Parameter verwendet wird, um unseren URL-Pairing-Ablauf zu aktivieren. Dabei werden die Parameter `verification_uri_complete` oder `verification_uri` zurückgegeben, mit denen Sie eine URL als Hyperlink oder einen QR-Code generieren können, den Nutzer antippen oder scannen. Dadurch wird ein optimierter Pairing-Prozess gestartet, der eine direkte Verbindung zum vom Nutzer ausgewählten Projekt herstellt. Details zur Implementierung finden Sie im [Leitfaden zum Aktivieren des QR-Code-Pairings](/de/camera-to-cloud/implementing-c2c-authentication-and-authorization#h3-section-enabling-qr-code-pairing).
