## Einführung {#introduction}

Bevor Sie Ihr Camera to Cloud-Gerät implementieren, stellen wir sicher, dass Sie alles haben, was Sie für den Erfolg benötigen.

## Tools zum Nachvollziehen der Implementierungsanleitungen {#tools-for-following-implementation-guides}

Diese Tools sind zwar nicht zwingend erforderlich, helfen Ihnen aber dabei, unseren Tutorials zu folgen und API-Interaktionen direkt zu testen.

### cURL {#curl}

Diese Tutorials zeigen Frame.io-API-Anfragen mit `curl`. Diese weit verbreitete Bibliothek bietet eine hervorragende Befehlszeilenschnittstelle für HTTP-Anfragen. Bei der Implementierung Ihres Geräts müssen Sie diese HTTP-Aufrufe in Ihrer bevorzugten Programmiersprache nachbilden. Durch die Verwendung von `curl` in diesen Beispielen können Sie API-Interaktionen testen, indem Sie die Befehle einfach in Ihr Terminal kopieren.

Um zu prüfen, ob `curl` auf Ihrem System installiert ist, geben Sie diesen Befehl in Ihr Terminal ein:

```shell
curl --version
```

Sie sollten eine Ausgabe ähnlich der folgenden sehen:

```text
curl 7.64.1 (x86_64-apple-darwin20.0) libcurl/7.64.1 (SecureTransport) LibreSSL/2.8.3 zlib/1.2.11 nghttp2/1.41.0
Release-Date: 2019-03-27
Protocols: dict file ftp ftps gopher http https imap imaps ldap ldaps pop3 pop3s rtsp smb smbs smtp smtps telnet tftp 
Features: AsynchDNS GSS-API HTTP2 HTTPS-proxy IPv6 Kerberos Largefile libz MultiSSL NTLM NTLM_WB SPNEGO SSL UnixSockets
```

Falls es nicht installiert ist, finden Sie Installationsprogramme für die meisten Betriebssysteme [hier](https://curl.se/download.html). Benutzer von macOS oder Linux können es über [Homebrew](https://brew.sh/) installieren:

```shell
brew install curl
```

### Python {#python}

Wir verwenden Python, um JSON-Antworten zu formatieren, indem wir die Ergebnisse von `curl` weiterleiten:

```shell
curl https://api.frame.io/health | python -m json.tool
```

So prüfen Sie, ob Python installiert ist:

```shell
python --version
```

Erwartete Ausgabe:

```text
Python 2.7.16
```

Falls es nicht installiert ist, können Sie [Python hier herunterladen](https://www.python.org/downloads/). Für diese Beispiele funktionieren Python 2.6+ oder Python 3.x.

Python ist zwar nicht erforderlich, macht die Antworten aber besser lesbar. Alternativ bieten Tools wie [jq](https://stedolan.github.io/jq/) eine ähnliche Funktionalität.
