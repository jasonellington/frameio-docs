---
title: "Glitch verwenden"
---

Glitch ist ein Tool, mit dem Sie schnell und einfach Webanwendungen erstellen können. Sie können sie mit Glitch ausführen und testen, ohne sich die Mühe machen zu müssen, einen eigenen Server mit öffentlicher Webadresse einzurichten. 

Dieser Leitfaden bietet einige grundlegende Tipps und Tricks für die Arbeit mit Glitch. 

## Wie registriere ich mich bei Glitch? {#how-do-i-sign-up-for-glitch}
Klicken Sie auf **Sign In** und wählen Sie eine der angebotenen Methoden. Glitch unterstützt die Anmeldung über Facebook, GitHub, Google und E-Mail. Hier können Sie loslegen: [https://glitch.com](https://glitch.com).

## Wie arbeite ich mit einem Projekt in Glitch? {#how-do-i-work-with-a-project-on-glitch}
Um mit einem Projekt in Glitch zu arbeiten, gehen Sie wie folgt vor:

1. Rufen Sie die Projektseite des Projekts auf, die die Struktur `https://glitch.com/~word-otherword` hat

2. Klicken Sie auf **View Source**

3. Klicken Sie oben rechts auf dem Bildschirm auf **Remix to Edit**. Sie können das Projekt dann nach Belieben ändern. 

Sie können sich auch anmelden und dann oben rechts auf **New Project** klicken, wenn Sie an einem neuen Projekt arbeiten möchten. 

## Wie sehe ich Logs oder die Konsole in Glitch? {#how-do-i-see-logs-or-the-console-on-glitch}
Sie können Ihr Projekt über ein Terminal überprüfen, indem Sie unten auf der Seite auf **Tools** klicken. Dort können Sie wählen, ob Sie ein Audit-Log (Logs) oder eine Full Page Console anzeigen möchten. 

## Welche Sprachen kann ich verwenden? {#what-languages-can-i-use}
Glitch unterstützt offiziell nur JavaScript. Inoffiziell können Sie jedoch viele andere Sprachen verwenden. Glitch lässt sich mit folgenden Sprachen nutzen: 
* C/C++
* Haskell
* OCaml
* Perl
* Erlang
* Elixir
* Lua 5.2
* PHP 
* Ruby
* Java
* Python
* Go 
* Rust
* Racket 

## Glitch und Python {#glitch-and-python}
Sie können Ihrem Python-Projekt in Glitch Abhängigkeiten hinzufügen, indem Sie eine Datei **requirements.txt** mit den Modulen einfügen, die Sie importieren möchten. 

Manchmal lässt sich ein Modul, das Sie importieren möchten, nicht importieren. Sie können es über die Konsole von Glitch hinzufügen, achten Sie jedoch darauf, es mit dem Tag `--user` in Ihrem Benutzerbereich zu installieren. 

`pip install --user module_name`
