## Überblick {#overview}

Wenn Sie Dateien aus bestehenden cloudbasierten Apps oder von einer URL, die Assets bereitstellt, zu Frame.io hochladen möchten, ist Zapier in der Regel eine gute Lösung, da das Produkt viele Abweichungen im API-Design auflöst, die die Interaktion mit Cloud-Apps mühsam machen.  Dieser Leitfaden erläutert die wichtigsten Eigenschaften des Upload-Dienstes von Zapier, damit Sie genau wissen, was in Ihrer Integration passiert.

## Die Datei-Upload-Methode festlegen {#setting-the-file-upload-method}

Zapier versucht, für jede verbundene API automatisch die flexibelste Datei-Upload-Methode zu ermitteln.  Zapier versucht beispielsweise, eingeschränkte Links, auf die außerhalb der Domain einer App nicht zugegriffen werden kann, in öffentlich verfügbare Download-Links umzuwandeln:

Ursprünglicher, nicht lesbarer Link:
`https://www.dropbox.com/s/hriinb9w3a2107m/iPad%20intro.pdf`

Umgewandelter Link, nutzbar durch die Uploader-API von Frame.io:
`https://dl.dropboxusercontent.com/s/hriinb9w3a2107m/iPad%20intro.pdf`

### Dateibeschränkungen von Zapier {#zapier’s-file-limitations}

Wichtig: Wenn Zapier **keine** statische Download-URL ermitteln kann, die an die API von Frame.io übergeben werden kann, lädt der Zapier-Dienst die Dateien selbst on the fly herunter und übergibt sie an Frame.io.  Zapier beschränkt diese Methode auf Dateien mit **[weniger als 100 MB](https://zapier.com/help/doc/common-problems-dropbox)**.

Beachten Sie, dass die Oberfläche von Zapier Sie möglicherweise auch dann vor Dateigrößenbeschränkungen warnt, wenn Sie eine Direct URL übergeben (also wenn gar keine Beschränkung besteht).  Deshalb lohnt es sich, zu verstehen, wie File URL funktioniert.

## Upload-Methoden für gängige Apps und Dienste {#upload-methods-for-common-apps-and-services}

**Hinweis:** Integrationen vom Typ **File Upload** unterliegen den in der Zapier-Oberfläche angegebenen Dateigrößenbeschränkungen. Direct Links sind vorzuziehen, da sie keinen Größenbeschränkungen unterliegen und schneller sowie zuverlässiger verarbeitet werden.

| App | Typ | Tipps und Referenzen |
| --- | --- | --- |
| Gmail | File Upload | [Zapier-Hilfedokumentation](https://zapier.com/help/doc/common-problems-gmail#how-can-i-attach-a-file-to-my-email-that39s-not-in-my-trigger) |
| Google Drive | Direct Link | Fügen Sie `webContentLink` in die Dateiauswahl ein.  Das funktioniert für Dateien, die Sie in Google Drive hochladen, jedoch nicht für Dokumente oder Präsentationen, die in Drive erstellt wurden. [Zapier-Hilfedokumentation](https://zapier.com/help/doc/common-problems-google-drive#unable-to-get-a-value-when-looking-for-quotfilequot-is-it-missing), [Google Drive V3 API](https://developers.google.com/drive/api/v3/manage-downloads) |
| Dropbox | Direct Link | Dropbox-Dateien automatisch zu Frame.io hochladen |
| Box | Direct Link | Verwenden Sie `Info Shared Link Download URL` [Box-API-Leitfäden](https://developer.box.com/guides/downloads/shared-link/) |
| S3 | Direct Link | Zapier-Leitfaden: Häufige Probleme mit S3 |
