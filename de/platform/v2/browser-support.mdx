# Browserübergreifende Unterstützung für die Frame.io-Anmeldung {#cross-browser-support-for-frame-io-login}

Für vollständig API-gesteuerte Anwendungen ist dies zwar nicht relevant, doch die browserübergreifende Unterstützung von Frame.io spielt eine Rolle, wenn unsere [Accounts-App](https://accounts.frame.io/) während eines OAuth-Credential-Grant-Flows geladen wird.

Beachten Sie beim Entwickeln von OAuth-Anwendungen für Frame.io, dass für die im OAuth-Flow angezeigte Anmeldeseite dieselbe Browser-Unterstützung gilt wie für unsere Haupt-Webanwendung. Im Folgenden bedeutet „Teilweise“, dass alle wesentlichen Funktionen uneingeschränkt nutzbar sein sollten, jedoch kleinere Layoutprobleme auftreten können. „Minimal“ bedeutet, dass es möglicherweise funktioniert, wir es aber nicht mehr explizit testen oder unterstützen.

| Browser | Unterstützung |
| --- | --- |
| Chrome (neueste Version) | Vollständig |
| Safari (neueste Version) | Vollständig |
| Firefox (neueste Version) | Vollständig |
| Opera (neueste Version) | Vollständig |
| Edge (neueste Version) | Vollständig |
| IE (11+) | Minimal |
| IE (&lt;=10) | Keine |
| Mobile Safari (neueste Version) | Teilweise |
| Chrome für iOS (neueste Version) | Teilweise |
| Chrome für Android (neueste Version) | Teilweise |
| Android-Browser (neueste Version) | Teilweise |
