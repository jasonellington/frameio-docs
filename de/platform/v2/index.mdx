## Über Frame.io {#about-frame-io}

[Frame.io](https://frame.io) ist das Cloud-Collaboration-Tool für professionelle Videoteams – alles, was Sie brauchen, um den kreativen Prozess am Laufen zu halten, in einer einzigen Arbeitsumgebung, von überall aus zugänglich. Mit Frame.io können Sie Filmprojekte sicher hochladen, teilen und reviewen, sodass Ihr gesamter Betrieb im Tempo der Kreativität arbeiten kann.

### Frame.io Developer Platform {#frame-io-developer-platform}

Nicht jedes Kreativteam, jeder Prozess oder jeder Software-Stack ist gleich. Genau hier kommt unsere Developer Platform ins Spiel. Mit der Frame.io Developer Platform können Sie gängige Aufgaben über unsere API erledigen. Zu den beliebten Anwendungsfällen, für die Entwickler unsere API genutzt haben, gehören das automatische Hinzufügen vorhandener Dateien oder Ordner zur Frame.io-App, das Hochladen neuer Inhalte und die Verwaltung von Teams.

## Camera to Cloud (C2C)-Programm {#camera-to-cloud-c2c-program}

Camera to Cloud ist eine besondere Art der Integration. Diese Integrationen sind speziell für jedes Gerät und jede Anwendung konzipiert, die Daten erzeugt. Wenn Sie eine C2C-Integration entwickeln, sollten Sie die [C2C-Integrationsleitfäden](/de/camera-to-cloud/getting-started-with-cloud-device-integrations) verwenden. Dort finden Sie alle Informationen, die Sie benötigen, um sich mit Frame.io mit der Cloud zu verbinden!

## Schnellstartanleitung {#quick-start-guide}

Wenn Sie sofort loslegen möchten, klicken Sie einfach auf diese Schaltfläche, um unsere API in Postman zu importieren!

[![Run in Postman](/images/platform/v2/index/button.svg)](https://www.getpostman.com/collections/c2dfffb88990a9dc34c2)

Andernfalls lesen Sie weiter. Als Ausgangspunkt benötigen Sie ein Frame.io-Konto, mit dem Sie sich anmelden können.

Danach:

- [Melden Sie sich im Developer Portal an](/de/platform/v2) – mit Ihren Frame.io-Zugangsdaten
- [Erstellen Sie ein Developer Token](/de/platform/v2/authentication#developer-tokens)

Um zu überprüfen, ob Ihr Token funktioniert, führen Sie einen Testaufruf mit einer Sprache, einem Tool oder einem Proxy Ihrer Wahl durch:

<CodeGroup>

```bash title="cURL"
curl --request GET \
  --url https://api.frame.io/v2/me \
  --header 'authorization: Bearer <DEV_TOKEN>'
```

```python title="Python"
import requests

url = "https://api.frame.io/v2/me"
headers = {
 "Authorization": "Bearer <DEV_TOKEN>"
}

requests.GET(url,headers=headers)
```

</CodeGroup>

Als Antwort sollten Sie Ihre Benutzerinformationen sehen.

## Ereignisbasierte Workflows {#event-based-workflows}

Die Developer Platform von Frame.io bietet einige Möglichkeiten, Ihre Workflows auf andere Tools auszuweiten oder ganz neue Funktionen zu erstellen.

### Webhooks {#webhooks}

Webhooks bieten eine Möglichkeit, Ereignisse, die in Frame.io auftreten, in Benachrichtigungen umzuwandeln, die zur Verarbeitung, für API-Callbacks und zur Workflow-Automatisierung an externe Systeme gesendet werden können.

Es gibt eine Reihe von Möglichkeiten, unsere Webhooks zu nutzen. Sie können selbst etwas entwickeln oder ein No-Code-Automatisierungstool wie [Zapier](https://zapier.com), [Integromat](https://www.integromat.com), [Pabbly Connect](https://www.pabbly.com/) oder [Pipedream](https://pipedream.com) verwenden.

- [Webhooks](/de/platform/v2/webhooks-overview) – Webhooks stellen Frame.io-Ereignisse für externe URLs zur Nutzung und Verarbeitung bereit.
- [Zapier](/de/platform/v2/get-started-with-zapier) – Ein Online-Automatisierungstool, mit dem Sie über 1.000 gängige Apps und Tools verbinden können, ohne Code zu schreiben.

Wir haben eine [Webhooks-Beispiel-App](https://github.com/Frameio/webhooks-example-app) auf GitHub, die Sie als Ausgangspunkt verwenden können, wenn Sie Ihren eigenen Empfänger entwickeln möchten.

### Custom Actions {#custom-actions}

Mit [Custom Actions](/de/platform/v2/custom-actions-overview) können Sie Integrationen als programmierbare UI-Komponenten direkt in Frame.io einbauen. Technisch sind sie Webhooks sehr ähnlich und eine hervorragende Möglichkeit, Ihre Frame.io-Workflows zu erweitern.
