# Ressourcendaten durchsuchen {#navigating-resource-data}

Unsere API-Payloads sind ziemlich umfassend! Das bedeutet zum Beispiel, dass Sie beim Abfangen einer Änderung am Statuslabel-Feld eines Assets möglicherweise sehr viele Felder sehen, von denen nur wenige für Sie unmittelbar relevant sind.

![Field examples](/images/platform/v2/overview-frame-io-resources-in-zapier/96b556247084aa9ced664a076acc8e22da0c44c5def47b9147b2c0c968964aec.webp)

Die gute Nachricht: Alle Dateneingabefelder in Zapier verfügen über eine Suchfunktion, mit der Sie schnell zum benötigten Feld gelangen.

![Quick-search for asset approved](/images/platform/v2/overview-frame-io-resources-in-zapier/38f94d317a462a7caf7fdc781713c0040001d99ef441cd25507b215ca373f70e.webp)

Natürlich ist es auch hilfreich, wenn Sie wissen, wonach Sie suchen müssen.

## Worauf Sie achten sollten {#what-to-look-for}

Die folgende Tabelle ist nicht vollständig, sollte Ihnen aber einen Vorsprung beim Aufbau von Workflows mit der Zapier-Integration von Frame.io verschaffen.

<Info>

**Asset-URLs sind lang, und das ist in Ordnung**

Die Asset-URLs, die Sie in den API-Responses von Frame.io sehen, sind direkte Links zu Amazon S3. Diese URLs können und sollten in jedem Zapier-App-Kontext verwendet werden, in dem Sie ein Asset in ein anderes System übertragen möchten. Wenn Sie die Wahl zwischen „File Attachment“ und „File Attachment (URL)“ haben, wählen Sie bitte Letzteres, da URL-Uploads in Zapier in der Regel eine größere Bandbreite an Dateitypen und -größen unterstützen.

</Info>

| Ressourcentyp | Feld in Zapier | Beschreibung |
| --- | --- | --- |
| Asset(all) | Original | Das ursprünglich hochgeladene Video, unverändert. In den meisten Fällen ist dies der Schlüssel, den Sie in andere Systeme übertragen möchten. Es handelt sich jedoch immer um den ursprünglichen Dateityp, der daher möglicherweise nicht in allen anderen Kontexten abspielbar ist. |
| Asset (videos) | H264 *resolution* | Alle h.264-Proxys von Frame.io sind im Asset in Zapier verfügbar. |
| Asset (image) | Image *quality* | Ähnlich wie bei den h.264-Videoproxys sind auch alle für Bilder erstellten Proxys in Zapier verfügbar. |
| Asset (all) | Thumb | Das in Frame.io festgelegte Asset-Thumbnail. Dieses Feld eignet sich hervorragend, um Projekt-Tracking-Systeme wie Trello oder Airtable mit visuellen Elementen zu ergänzen. |
| Asset (all) | Label | Das Statuslabel. Dieses Feld wird in der Regel mit einer „Filter“-Aktion kombiniert (ähnlich wie im obigen Screenshot). |
| Asset (all) | Creator Email | Die E-Mail-Adresse der Person, die das Asset ursprünglich hochgeladen hat. |
| Asset (all) | Project ID | Die ID des übergeordneten Projects des Assets. Dieses Feld ist am nützlichsten in Kombination mit der Aktion „Find Project“, mit der Sie den Namen des Projects abrufen können. |
| Asset (all) | Parent ID | Die ID des übergeordneten Elements eines Assets. Dies ist immer ein Ordner, ein Version Stack oder das Project-Root. |
| Comment | Text | Der Text des Comments. |
| Comment | Asset ID | Die ID des übergeordneten Assets des Comments. Hilfreich, um sie für zusätzlichen Kontext an die Aktion „Find Asset“ zu übergeben oder um in externen Tracking-Tools darauf zu verlinken. |
| Comment | Owner Name | Vor- und Nachname des Benutzers, der den Comment hinterlassen hat. |
| Comment | Owner Email | Die E-Mail-Adresse des Benutzers, der den Comment hinterlassen hat. |
| Project | Name | Der Name des Projects. |
