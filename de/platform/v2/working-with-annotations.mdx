# Überblick {#overview}

Annotationen werden in Frame.io als serialisierter JSON-Blob aus Zeichenobjekten dargestellt, einschließlich Farben, Koordinaten und Größen. Im Blob sind alle Anführungszeichen außer dem äußeren umschließenden Paar mit Schrägstrichen maskiert (z. B. `\"key\":\"value\"`).

Es gibt drei Grundformen – **arrow**, **rect** und **line** – sowie das Freihandzeichnen, das über den Rahmen dieses Leitfadens hinausgeht, aber denselben Grundprinzipien serialisierter Koordinatendaten folgt.

## Das Koordinatensystem {#the-coordinate-system}

Alle Formen werden auf einem kartesischen Koordinatensystem mit Ursprung oben links und einer Skala von 0 bis 1 auf jeder Achse platziert.

![coordinate_plane.png](/images/platform/v2/working-with-annotations/099478340a4f8604fd4389c5d431ec9e9321f509f2d6055b0c92dd62e4e36147.webp)

## Grundlegende Formdaten {#basic-shape-data}

Alle Formen werden auf der oben gezeigten Ebene mit einer Kombination aus Koordinaten und Stildaten platziert. Jede Form hat einige gemeinsame Attribute und adressiert das Koordinatensystem dann auf leicht unterschiedliche Weise.

Alle Attribute für Abstand/Breite/Höhe verwenden dieselbe Skala von 0 bis 1 wie das Koordinatenraster selbst, werden aber in der Regel vom Ursprungspunkt der Form aus gemessen.

Mit anderen Worten: Wenn ein Video in einem 640x480-Viewport angezeigt wird, entspricht `x=1` in diesem Kontext absoluten 640px. Dadurch lassen sich Annotationen nahtlos skalieren und behalten ihre relative Position, auch wenn sich Bildschirm, Größe und Kontext ändern.

**Hinweis**: Der Ursprung eines *rect* ist immer die obere linke Ecke der Form, unabhängig vom Zeichenursprung.

### Gemeinsame Attribute {#common-attributes}

| Attribut | Beschreibung |
| --- | --- |
| `tool` | *arrow*, *rect* oder *line*. Gibt an, welche Form erstellt wird. |
| `color` | Sechsstellige Hex-Farbe für die Form. |
| `size` | Pixelgröße der Linie der Form. Bei Pfeilen bezieht sich dies nur auf den Anfang der Linie, da die Endbreite programmatisch bestimmt wird. |

### Arrow {#arrow}

| Attribut | Beschreibung |
| :--- | :--- |
| `x` | x-Koordinate des Pfeilursprungs. |
| `y` | y-Koordinate des Pfeilursprungs. |
| `w` | Differenz der Pfeilposition auf der y-Achse von Anfang bis Ende, relativ zum Pfeilursprung. |
| `h` | Differenz der Pfeilposition auf der x-Achse von Anfang bis Ende, relativ zum Pfeilursprung. |

### Rect {#rect}

| Attribut | Beschreibung |
| :--- | :--- |
| `x` | x-Koordinate der oberen linken Ecke des Rechtecks. |
| `y` | y-Koordinate der oberen linken Ecke des Rechtecks. |
| `w` | Breite des Rechtecks, relativ zum Ursprung oben links. |
| `h` | Höhe des Rechtecks, relativ zum Ursprung oben links. |
| `ix` | Der x-Zeichenursprung des Rechtecks. (Nicht erforderlich). |
| `iy` | Der y-Zeichenursprung des Rechtecks. (Nicht erforderlich). |
| `radius` | Radius der Eckenabrundung des Rechtecks. Muss positiv sein. Werte über 150 sind visuell nicht unterscheidbar. |

### Line {#line}

| Attribut | Beschreibung |
| :--- | :--- |
| `x1` | x-Koordinate des Linienursprungs. |
| `y1` | y-Koordinate des Linienursprungs. |
| `x2` | x-Koordinate des Linienendpunkts. Absoluter Wert auf der Bildebene. |
| `y2` | y-Koordinate des Linienendpunkts. Absoluter Wert auf der Bildebene. |
