<Note>
  Dies ist ein Demo-Endpunkt für die Mintlify-Automatisierung „Update from code changes“. Er ist nicht Teil der Frame.io API.
</Note>

Verwenden Sie diesen Endpunkt, um zu prüfen, ob die Verarbeitung eines Assets abgeschlossen ist.

## Status eines Assets abrufen {#get-an-asset’s-status}

```http
GET /v4/assets/{id}/status
```

### Pfadparameter {#path-parameters}

| Parameter | Typ    | Beschreibung      |
| --------- | ------ | ----------------- |
| `id`      | string | Die Asset-ID.     |

### Antwortfelder {#response-fields}

| Feld          | Typ    | Beschreibung                                         |
| ------------- | ------ | ---------------------------------------------------- |
| `data.id`     | string | Die Asset-ID.                                        |
| `data.status` | string | Der Verarbeitungsstatus: `processing` oder `ready`.  |
| `data.updated_at` | string | Der Zeitpunkt der letzten Aktualisierung des Assets als ISO-8601-Zeitstempel in UTC. |

### Beispiel {#example}

```bash
curl http://localhost:3001/v4/assets/a1b2c3/status
```

```json
{
  "data": {
    "id": "a1b2c3",
    "status": "ready",
    "updated_at": "2026-11-03T18:22:10Z"
  }
}
```

### Fehler {#errors}

| Status | Fehler            | Bedeutung                       |
| ------ | ----------------- | ------------------------------- |
| `404`  | `asset_not_found` | Kein Asset hat diese ID.        |
