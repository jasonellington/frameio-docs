### Verwendung {#usage}

Instanziieren und verwenden Sie den Client wie folgt:

```python
from frameio import (
    Frameio,
    SelectDefinitionParamsFieldConfiguration,
    SelectDefinitionParamsFieldConfigurationOptionsItem,
)
from frameio.metadata_fields import CreateFieldDefinitionParamsData_Select

client = Frameio(
    token="YOUR_TOKEN",
)
client.metadata_fields.metadata_field_definitions_create(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    data=CreateFieldDefinitionParamsData_Select(
        field_configuration=SelectDefinitionParamsFieldConfiguration(
            enable_add_new=False,
            options=[
                SelectDefinitionParamsFieldConfigurationOptionsItem(
                    display_name="Option 1",
                ),
                SelectDefinitionParamsFieldConfigurationOptionsItem(
                    display_name="Option 2",
                ),
            ],
        ),
        name="Fields definition name",
    ),
)
```

### Asynchroner Client {#async-client}

Das SDK exportiert außerdem einen asynchronen Client, mit dem Sie nicht blockierende Aufrufe an unsere API senden können. Hinweis: Wenn Sie eine asynchrone httpx-Client-Klasse erstellen, um sie an diesen Client zu übergeben, verwenden Sie httpx.AsyncClient() anstelle von httpx.Client() (z. B. für den Parameter httpx_client dieses Clients).

```python
import asyncio

from frameio import (
    AsyncFrameio,
    SelectDefinitionParamsFieldConfiguration,
    SelectDefinitionParamsFieldConfigurationOptionsItem,
)
from frameio.metadata_fields import CreateFieldDefinitionParamsData_Select

client = AsyncFrameio(
    token="YOUR_TOKEN",
)


async def main() -> None:
    await client.metadata_fields.metadata_field_definitions_create(
        account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
        data=CreateFieldDefinitionParamsData_Select(
            field_configuration=SelectDefinitionParamsFieldConfiguration(
                enable_add_new=False,
                options=[
                    SelectDefinitionParamsFieldConfigurationOptionsItem(
                        display_name="Option 1",
                    ),
                    SelectDefinitionParamsFieldConfigurationOptionsItem(
                        display_name="Option 2",
                    ),
                ],
            ),
            name="Fields definition name",
        ),
    )


asyncio.run(main())
```

### Fehlerbehandlung {#exception-handling}

Wenn die API einen Fehlerstatuscode zurückgibt (4xx- oder 5xx-Antwort), wird eine Unterklasse des folgenden Fehlers ausgelöst.

```python
from frameio.core.api_error import ApiError

try:
    client.metadata_fields.metadata_field_definitions_create(...)
except ApiError as e:
    print(e.status_code)
    print(e.body)
```

### Paginierung {#pagination}

Paginierte Anfragen geben einen SyncPager oder AsyncPager zurück, der als Generator für das zugrunde liegende Objekt verwendet werden kann.

```python
from frameio import Frameio

client = Frameio(
    token="YOUR_TOKEN",
)
response = client.project_permissions.index(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    project_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    page_size=10,
    include_total_count=False,
)
for item in response:
    yield item
# alternatively, you can paginate page-by-page
for page in response.iter_pages():
    yield page
```

### Erweitert {#advanced}

#### Zugriff auf Rohdaten der Antwort {#access-raw-response-data}

Das SDK bietet über die Eigenschaft .with_raw_response Zugriff auf die Rohdaten der Antwort, einschließlich der Header. Die Eigenschaft .with_raw_response gibt einen „Roh“-Client zurück, über den Sie auf die Attribute .headers und .data zugreifen können.

```python
from frameio import Frameio

client = Frameio(
    ...,
)
response = (
    client.metadata_fields.with_raw_response.metadata_field_definitions_create(
        ...
    )
)
print(response.headers)  # access the response headers
print(response.data)  # access the underlying object
pager = client.project_permissions.index(...)
print(pager.response.headers)  # access the response headers for the first page
for item in pager:
    print(item)  # access the underlying object(s)
for page in pager.iter_pages():
    print(page.response.headers)  # access the response headers for each page
    for item in page:
        print(item)  # access the underlying object(s)
```

#### Wiederholungsversuche {#retries}

Das SDK verfügt über automatische Wiederholungsversuche mit exponentiellem Backoff. Eine Anfrage wird wiederholt, solange sie als wiederholbar gilt und die Anzahl der Wiederholungsversuche das konfigurierte Limit (Standard: 2) nicht überschritten hat.<br />
Eine Anfrage gilt als wiederholbar, wenn einer der folgenden HTTP-Statuscodes zurückgegeben wird:

- 408 (Timeout)
- 429 (Too Many Requests – zu viele Anfragen)
- 5XX (Internal Server Errors – interne Serverfehler)

<br />

Verwenden Sie die Anfrageoption `max_retries`, um dieses Verhalten zu konfigurieren.

```python
client.metadata_fields.metadata_field_definitions_create(..., request_options={
    "max_retries": 1
})
```

---

#### Timeouts {#timeouts}

Das SDK verwendet standardmäßig ein Timeout von 60 Sekunden. Sie können dies mit einer Timeout-Option auf Client- oder Anfrageebene konfigurieren.

```python
from frameio import Frameio

client = Frameio(
    ...,
    timeout=20.0,
)


# Override timeout for a specific method
client.metadata_fields.metadata_field_definitions_create(..., request_options={
    "timeout_in_seconds": 1
})
```

#### Benutzerdefinierter Client {#custom-client}

Sie können den httpx-Client überschreiben, um ihn an Ihren Anwendungsfall anzupassen. Typische Anwendungsfälle sind die Unterstützung von Proxys und Transports.

```python
import httpx
from frameio import Frameio

client = Frameio(
    ...,
    httpx_client=httpx.Client(
        proxy="http://my.test.proxy.example.com",
        transport=httpx.HTTPTransport(local_address="0.0.0.0"),
    ),
)
```

#### Authentifizierung {#auth}

<AccordionGroup>

<Accordion title="frameio.auth.ServerToServerAuth(*, client_id, client_secret, ...)" defaultOpen={true}>

Authentifizierung über den OAuth-2.0-Grant client_credentials. Dieser Ablauf erfordert keinen Benutzer und gibt kein Refresh-Token zurück. Wenn das Zugriffstoken abläuft, fordert das SDK mithilfe der Client-Anmeldedaten automatisch ein neues an. Für die asynchrone Verwendung nutzen Sie `AsyncServerToServerAuth`.

```python title="usage"

from frameio import Frameio
from frameio.auth import ServerToServerAuth

auth = ServerToServerAuth(client_id="YOUR_CLIENT_ID", client_secret="YOUR_CLIENT_SECRET")
client = Frameio(token=auth.get_token)
```

**Parameters**

`client_id`: `str` — Adobe-IMS-OAuth-Client-ID.

`client_secret`: `str` — Adobe-IMS-OAuth-Client-Secret.

`scopes`: `str` — Durch Leerzeichen getrennte Scopes (OAuth 2.0 RFC 6749). Standardwert ist `openid AdobeID frame.s2s.all`.

`ims_base_url`: `str` — IMS-Basis-URL für Staging- bzw. alternative Umgebungen. Standardwert ist die Produktionsumgebung.

`http_client`: `typing.Optional[httpx.Client]` — Optionaler httpx.Client für Proxy, TLS oder Connection-Pooling.

`on_token_refreshed`: `typing.Optional[typing.Callable[[dict[str, Any]], None]]` — Optionaler Callback, der nach jedem Abruf eines Tokens ausgelöst wird.

`timeout`: `float` — Timeout für HTTP-Anfragen in Sekunden. Standardwert ist 30.

`max_retries`: `int` — Maximale Anzahl an Wiederholungsversuchen bei vorübergehenden Fehlern. Standardwert ist 2.

`refresh_buffer`: `int` — Sekunden vor Ablauf, zu denen eine proaktive Aktualisierung ausgelöst wird. Standardwert ist 60.

**Methods**

`get_token() -> str` — Gibt ein gültiges Zugriffstoken zurück und aktualisiert es bei Bedarf. Übergeben Sie dem SDK diese Methodenreferenz (keinen Aufruf): `Frameio(token=auth.get_token)`.

`authenticate() -> dict[str, Any]` — Ruft explizit ein neues Zugriffstoken ab. Gibt das Token-Antwort-Dict mit `access_token`, `expires_in` usw. zurück.

`revoke() -> None` — Widerruft beide Tokens serverseitig und löscht den lokalen Zustand.

`export_tokens() -> dict[str, Any]` — Exportiert den aktuellen Token-Zustand zur dauerhaften Speicherung.

`import_tokens(data: dict[str, Any]) -> None` — Stellt den Token-Zustand aus einem zuvor exportierten Dict wieder her.

</Accordion>

<Accordion title="frameio.auth.SPAAuth(*, client_id, redirect_uri, ...)">

`get_token() -> str` — Gibt ein gültiges Zugriffstoken zurück und aktualisiert es bei Bedarf. Übergeben Sie dem SDK diese Methodenreferenz: `Frameio(token=auth.get_token)`.

#### Authentifizierungsausnahmen {#auth-exceptions}

Alle Authentifizierungsausnahmen erben von `FrameioAuthError`.

| Ausnahme | Beschreibung |
| --- | --- |
| `FrameioAuthError` | Basisausnahme für alle `frameio.auth`-Fehler. |
| `AuthenticationError` | Token-Austausch oder -Aktualisierung fehlgeschlagen. Besitzt die Attribute `error_code` und `error_description`. |
| `TokenExpiredError` | Das Refresh-Token ist abgelaufen; eine erneute Authentifizierung ist erforderlich. |
| `ConfigurationError` | Eine erforderliche Konfiguration fehlt oder ist ungültig. |
| `NetworkError` | Netzwerkanfrage fehlgeschlagen (Timeout, Verbindungsfehler usw.). |
| `RateLimitError` | Die API hat 429 zurückgegeben und alle Wiederholungsversuche sind ausgeschöpft. Besitzt das Attribut `retry_after`. |
| `PKCEError` | PKCE-Verifizierung fehlgeschlagen. |

#### Upload {#upload}

<AccordionGroup>

<Accordion title="frameio.upload.FrameioUploader(asset, file, ...)" defaultOpen={true}>

Lädt eine lokale Datei mithilfe der von `client.files.create_local_upload(...)` zurückgegebenen vorsignierten URLs zu Frame.io hoch. `FrameioUploader` ist ein schlanker Wrapper, der `upload_urls`, `file_size` und `media_type` aus der `FileWithUploadUrls`-Antwort ausliest und einen in Chunks aufgeteilten, multithreaded S3-Upload durchführt.

```python title="usage"

from frameio import Frameio
from frameio.files import FileCreateLocalUploadParamsData
from frameio.upload import FrameioUploader

client = Frameio(
    token="YOUR_TOKEN",
)
response = client.files.create_local_upload(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    folder_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    data=FileCreateLocalUploadParamsData(
        file_size=1137444,
        name="asset.png",
    ),
)
with open("asset.png", "rb") as f:
    FrameioUploader(response.data, f).upload()
```

**Parameters**

`asset`: `FileWithUploadUrls` — Eine von `client.files.create_local_upload(...)` zurückgegebene `FileWithUploadUrls`-Instanz.

`file`: `typing.BinaryIO` — Ein dateiähnliches Objekt, das im binären Lesemodus (`"rb"`) geöffnet wurde.

`max_workers`: `int` — Parallelität des Thread-Pools, die an den zugrunde liegenden Uploader weitergegeben wird. Standardwert ist 5.

`headers`: `typing.Optional[typing.Dict[str, str]]` — Zusätzliche Header, die in jede S3-PUT-Anfrage übernommen werden. Standardwert ist `{"x-amz-acl": "private"}`, wie von Frame.io gefordert.

`max_retries`: `int` — Anzahl der Wiederholungsversuche pro Chunk. Standardwert ist 3.

`on_progress`: `typing.Optional[typing.Callable[[int, int], None]]` — Optionaler Callback, der nach jedem Chunk mit `(bytes_uploaded_so_far, total_bytes)` aufgerufen wird.

**Methods**

`upload() -> None` — Lädt die Datei hoch. Blockiert bis zum Abschluss oder löst bei einem Fehler eine Ausnahme aus.
