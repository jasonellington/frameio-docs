Make ist eine No-Code-Automatisierungsplattform, die Ihre Apps und Dienste miteinander verbindet. Sie bietet eine visuelle Oberfläche, in der Sie Workflows – sogenannte Szenarien – erstellen, indem Sie verschiedene Module aneinanderreihen.

Jedes Szenario hat einen Trigger (z. B. „neues Project in Frame.io erstellt“) und darauf folgende Aktionen (z. B. „eine Zeile zu Google Sheets hinzufügen“). Sie verbinden diese Module visuell, um festzulegen, was in welcher Reihenfolge passiert.

## Warum Frame.io mit Make verbinden? {#why-connect-frame-io-to-make}

Make erweitert Frame.io über Ihren gesamten Workflow hinweg. Synchronisieren Sie Dateien mit Speicherdiensten, aktualisieren Sie Projektmanagement-Tools, erstellen Sie Berichte, benachrichtigen Sie Ihr Team oder bauen Sie benutzerdefinierte Workflows auf Grundlage von Frame.io-Aktivitäten. Je mehr Sie Frame.io mit Ihrem Tech-Stack verbinden, desto leistungsfähiger wird es.

**Ideen für Automatisierungen:**

- Frame.io-Projects automatisch erstellen, wenn ein Kunde ein Aufnahmeformular absendet
- In Slack posten, wenn Kommentare zu einem Video in Frame.io hinzugefügt werden
- Ein Google Sheet aktualisieren, wenn ein neues Frame.io-Project erstellt wird

Dies sind nur einige Beispiele. Eine vollständige Liste der verfügbaren Frame.io-Module finden Sie auf dieser Seite bei [Make.com](https://www.make.com/en/integrations/frame-io#:~:text=All-,Modules,-(26)).

## Was Sie benötigen {#what-you-need}

- **Ein Frame.io-Konto** (Informationen zu Abonnements finden Sie [hier](https://frame.io/pricing))
- **Ein Make-Konto** (kostenlose Stufe verfügbar)

## Modultypen {#module-types}

Make kennt vier Arten von Modulen: Trigger, Suchen, Aktionen und universelle Module.

<CardGroup cols={2}>

<Card title="Trigger" icon="bell" iconType="solid" horizontal={true}>

Trigger überwachen Änderungen in einem Dienst und übertragen sie an Make, damit Sie diese Daten in Ihrem Szenario verwenden können. Sie können **ein** Trigger-Modul pro Szenario hinzufügen.

<br />

Details zu Polling- und Instant-Triggern finden Sie im Abschnitt **Trigger-Typen** weiter unten.

<br />

- Wie oft ein Trigger-Modul ausgeführt wird, legen Sie fest, indem Sie in der Szenario-Symbolleiste auf **Schedule settings** klicken
- Make empfiehlt dringend, Szenarien mit einem Trigger-Modul zu beginnen.

</Card>

<Card title="Suchen" icon="magnifying-glass" iconType="solid" horizontal={true}>

Suchmodule rufen bestimmte Daten aus einem Dienst ab. Sie können mehrere Suchmodule an beliebiger Stelle in Ihrem Szenario hinzufügen. Die meisten Suchen geben bis zu 3.200 Objekte pro Ausführung zurück.

<br />

**Arten von Suchmodulen:**

<br />

- **Suchmodule** ermöglichen das Filtern und die Verwendung von Abfragen, um bestimmte Daten zu finden
  (Search Records, Search Rows usw.)
- **Listenmodule** rufen alle Daten ohne Filterung ab. (List Projects, List Sheets usw.)

</Card>

<Card title="Aktionen" icon="bolt" iconType="solid" horizontal={true}>

Aktionsmodule verarbeiten die aus einem Dienst abgerufenen Daten. Sie können beliebig viele Aktionen an beliebiger Stelle in Ihrem Szenario hinzufügen.

<br />

**Arten von Aktionen:**

<br />

- GET
- CREATE
- UPDATE
- DELETE

<br />

</Card>

<Card title="Universelle Module" icon="code" iconType="solid" horizontal={true}>

Universelle Module (meist **Make an API Call** genannt) ermöglichen benutzerdefinierte API-Aufrufe, wenn Make kein vorgefertigtes Modul für Ihren Bedarf bereitstellt.

<br />

Sie können beliebig viele universelle Module hinzufügen und an beliebiger Stelle in Ihrem Szenario platzieren.

</Card>

</CardGroup>

## Trigger-Typen {#trigger-types}

Make verwendet zwei Arten von Triggern: Polling und Instant.

**Polling-Trigger** prüfen Ihr Dienstkonto nach einem Zeitplan auf neue Daten. Sie heißen meist etwa „Watch Records“ oder „Watch Rows“. Wenn das Szenario ausgeführt wird, fragt Make den Dienst, ob es etwas Neues gibt. Ist das der Fall, verarbeitet das Szenario die Daten.

**Instant-Trigger** funktionieren anders. Sie verwenden Webhooks, sodass der Dienst Make sofort benachrichtigt, wenn etwas passiert. Ihr Szenario wird umgehend ausgeführt. Sie erkennen diese am Blitzsymbol und an der Kennzeichnung „Instant“ am Modul.

Das Frame.io-Modul Watch Events ist ein Instant-Trigger, sodass das Szenario, das wir später erstellen, in Echtzeit ausgeführt wird.

Weitere Details dazu, wie verschiedene Modultypen ausgeführt werden, finden Sie in [diesem Abschnitt des Make Help Centers](https://help.make.com/types-of-modules).

# Die Make-Oberfläche {#the-make-interface}

Ihr Make-Dashboard zeigt alle Ihre Szenarien. Hier überwachen Sie aktive Szenarien, die Szenario-Performance und den Credit-Verbrauch. Klicken Sie in der Kopfzeile auf **Create scenario**, um den Builder zu öffnen.

### Anwendungen und Module hinzufügen {#adding-applications-+-modules}

Um Ihrem Szenario Module hinzuzufügen, klicken Sie auf die Plus-Schaltfläche in der Mitte des Builders. Dadurch öffnet sich ein Bereich, in dem Sie nach der benötigten App suchen können, z. B. Frame.io oder Google Sheets, und dann das gewünschte Modul auswählen (etwa „Watch Events“ oder „Add a Row“). Ziehen Sie Module im Builder per Drag-and-drop, um sie zu verbinden und Ihr Szenario aufzubauen.

### Apps verwalten und erneut verbinden {#managing-+-reconnecting-apps}

Über die linke Seitenleiste erreichen Sie Szenarien, Verbindungen, Webhooks und weitere Make-Funktionen.

Wenn Sie Frame.io oder eine andere App erneut verbinden müssen, klicken Sie in der linken Seitenleiste auf **Connections**. Dort sehen Sie alle verbundenen Apps, jeweils mit einer Schaltfläche **Reauthorize**. Klicken Sie darauf, um den Authentifizierungsablauf erneut zu durchlaufen.

### Testen {#testing}

Um Ihr Szenario zu testen, klicken Sie in der Symbolleiste auf **Run once**. Nach Abschluss des Tests erscheinen über jedem Modul Operations-Blasen, die anzeigen, wie viele Operationen ausgeführt wurden. Klicken Sie auf eine Blase, um die Eingabe- und Ausgabedaten dieses Schritts anzuzeigen.

**Testen mit vorhandenen Daten:**

Standardmäßig verarbeiten Trigger nur neue Ereignisse. Um mit vorhandenen Daten zu testen, klicken Sie auf den Dropdown-Pfeil neben der Schaltfläche **Run once**. Dadurch öffnet sich ein Dialog, in dem Sie Daten aus einem früher empfangenen Webhook-Ereignis erneut ausführen können.

# Ihr erstes Szenario erstellen: Neue Projects in Google Sheets protokollieren {#building-your-first-scenario-log-new-projects-to-google-sheets}

Erstellen Sie vor dem Start ein Google Sheet mit diesen Spaltenüberschriften:

**Event Type**, **Resource ID**, **Workspace ID**, **User ID**. In diesem Beispiel nennen wir das Sheet „Frame Projects“.

<Steps>

<Step title="Mit Frame.io verbinden und Trigger hinzufügen">

Klicken Sie im Make-Builder auf das Pluszeichen, um ein Modul hinzuzufügen. Suchen Sie nach „Frame.io“ und wählen Sie **Watch Events**. Dadurch wird ein Webhook erstellt, der ausgelöst wird, wenn bestimmte Ereignisse in Frame.io eintreten.

**Frame.io verbinden:**

- Klicken Sie neben dem Verbindungsfeld auf **Add**
- Behalten Sie den Standardnamen der Verbindung bei oder benennen Sie sie um
- Sie werden aufgefordert, sich bei Ihrem Adobe-Konto anzumelden und Make zu autorisieren
- Sobald die Verbindung hergestellt ist, sehen Sie alle verfügbaren Frame.io-Konten und Workspaces in den Dropdown-Menüs

**Webhook konfigurieren:**

- Wählen Sie Ihr Konto und den Workspace aus, den Sie überwachen möchten. In diesem Beispiel verwenden wir „New Workspace“
- Wählen Sie unter den Ereignissen **Project Created** (weitere Informationen zu unterstützten Ereignissen finden Sie in unserer [Webhooks-Dokumentation](https://developer.adobe.com/frameio/guides/Webhooks/#webhook-event-subscriptions))
- Benennen Sie Ihren Webhook und speichern Sie Ihre Änderungen

</Step>

<Step title="Google Sheets hinzufügen">

Klicken Sie auf das Pluszeichen, um den nächsten Schritt hinzuzufügen. Suchen Sie die App Google Sheets, wählen Sie sie aus und klicken Sie auf das Modul **Add a Row**.

**Google Sheets verbinden:**

- Klicken Sie auf **Add**, um eine neue Verbindung zu erstellen
- Klicken Sie auf **Sign in with Google** und autorisieren Sie Make für den Zugriff auf Ihr Google-Konto
- Sobald die Verbindung hergestellt ist, sollten Sie die Sheets Ihres Kontos in den Dropdown-Menüs sehen
- Wählen Sie den Namen des Sheets/Tabs aus (in unserem Fall „Frame Projects“)

**Daten zuordnen:**
Ordnen Sie nun die Frame.io-Daten den Spalten Ihrer Tabelle zu. Klicken Sie in jedes Feld und wählen Sie die entsprechenden Daten aus dem Frame.io-Trigger aus:

- **Event Type** → Frame.io Event Type zuordnen
- **Resource ID** → Frame.io Resource zuordnen
- **Workspace ID** → Frame.io Workspace ID zuordnen
- **User ID** → Frame.io User ID zuordnen

</Step>

<Step title="Testen und aktivieren">

Klicken Sie auf **Run once**, um das Szenario zu testen, und erstellen Sie dann ein neues Projekt in Ihrem ausgewählten Frame.io-Workspace. Wenn alles korrekt eingerichtet ist, sollte in Ihrer Tabelle eine neue Zeile erscheinen.

![Sheet](/images/platform/docs/guides/make/frame_sheet_example.gif)

Wenn Sie bereit für den Live-Betrieb sind, stellen Sie den Schalter auf **Active**, und das Szenario wird automatisch ausgeführt.

</Step>

</Steps>

Sie haben soeben Ihre erste Automatisierung erstellt. Von hier aus können Sie diesem Szenario weitere Schritte hinzufügen oder mit den anderen verfügbaren Frame.io-Modulen auf [Make.com](https://www.make.com/en/integrations/frame-io#:~:text=All-,Modules,-(26)) neue Szenarien erstellen.

Wenn Sie auf Probleme stoßen, Fragen haben oder zeigen möchten, was Sie gebaut haben, besuchen Sie das [Community-Forum](https://forum.frame.io/).
