## Acerca de Frame.io {#about-frame-io}

[Frame.io](https://frame.io) es la herramienta de colaboración en la nube para equipos profesionales de video: todo lo que necesitas para mantener en marcha el proceso creativo, en un único espacio de trabajo, accesible desde cualquier lugar. Con Frame.io, puedes subir, compartir y revisar proyectos audiovisuales de forma segura, lo que permite que toda tu operación funcione a la velocidad de la creatividad.

### Plataforma para desarrolladores de Frame.io {#frame-io-developer-platform}

No todos los equipos creativos, procesos o conjuntos de software son exactamente iguales. Ahí es donde entra nuestra Plataforma para desarrolladores. La Plataforma para desarrolladores de Frame.io te permite realizar tareas comunes mediante nuestra API. Algunos de los casos de uso más populares para los que los desarrolladores han utilizado nuestra API incluyen agregar automáticamente archivos o carpetas existentes a la aplicación de Frame.io, subir contenido nuevo y administrar equipos.

## Programa Camera to Cloud (C2C) {#camera-to-cloud-c2c-program}

Camera to Cloud es un tipo de integración único. Estas integraciones están diseñadas específicamente para cualquier dispositivo o aplicación que genere datos. Si estás creando una integración C2C, te conviene usar las [guías de integración C2C](/es/camera-to-cloud/getting-started-with-cloud-device-integrations). ¡Allí encontrarás toda la información que necesitas para empezar a conectarte a la nube con Frame.io!

## Guía de inicio rápido {#quick-start-guide}

Si quieres empezar de inmediato, ¡solo haz clic en este botón para llevar nuestra API a Postman!

[![Run in Postman](/images/platform/v2/index/button.svg)](https://www.getpostman.com/collections/c2dfffb88990a9dc34c2)

De lo contrario, sigue leyendo. Como punto de partida, debes asegurarte de tener una cuenta de Frame.io con la que puedas iniciar sesión.

A partir de ahí:

- [Inicia sesión en el Portal para desarrolladores](/es/platform/v2) con tus credenciales de Frame.io
- [Crea un token de desarrollador](/es/platform/v2/authentication#developer-tokens)

Para confirmar que tu token funciona, realiza una llamada de prueba con el lenguaje, la herramienta o el proxy que prefieras:

<CodeGroup>

```bash title="cURL"
curl --request GET \
  --url https://api.frame.io/v2/me \
  --header 'authorization: Bearer <DEV_TOKEN>'
```

```python title="Python"
import requests

url = "https://api.frame.io/v2/me"
headers = {
 "Authorization": "Bearer <DEV_TOKEN>"
}

requests.GET(url,headers=headers)
```

</CodeGroup>

En la respuesta, deberías ver la información de tu usuario.

## Flujos de trabajo basados en eventos {#event-based-workflows}

La Plataforma para desarrolladores de Frame.io ofrece algunas opciones que puedes usar para extender tus flujos de trabajo a otras herramientas o para crear funciones completamente nuevas.

### Webhooks {#webhooks}

Los webhooks ofrecen una forma de aprovechar los eventos que ocurren dentro de Frame.io y convertirlos en notificaciones que pueden enviarse a sistemas externos para su procesamiento, devoluciones de llamada de API y automatización de flujos de trabajo.

Hay varias formas de usar nuestros webhooks. Puedes crear algo por tu cuenta o aprovechar una herramienta de automatización sin código como [Zapier](https://zapier.com), [Integromat](https://www.integromat.com), [Pabbly Connect](https://www.pabbly.com/) o [Pipedream](https://pipedream.com).

- [Webhooks](/es/platform/v2/webhooks-overview): los webhooks exponen los eventos de Frame.io a URL externas para su consumo y procesamiento.
- [Zapier](/es/platform/v2/get-started-with-zapier): una herramienta de automatización en línea que te permite conectar más de 1000 aplicaciones y herramientas comunes sin escribir código.

Tenemos una [aplicación de ejemplo de webhooks](https://github.com/Frameio/webhooks-example-app) en GitHub que puedes usar como punto de partida si quieres crear tu propio receptor.

### Acciones personalizadas {#custom-actions}

Las [acciones personalizadas](/es/platform/v2/custom-actions-overview) te permiten crear integraciones directamente en Frame.io como componentes de interfaz programables. Técnicamente son muy similares a los webhooks y son una excelente forma de extender tus flujos de trabajo de Frame.io.
