# Navegar por los datos de los recursos {#navigating-resource-data}

¡Los payloads de nuestra API son bastante completos! Eso significa que (por ejemplo), cuando capturas un cambio en el campo Status Label de un Asset, es posible que termines viendo una gran cantidad de campos, de los cuales muy pocos serán relevantes de inmediato para ti.

![Ejemplos de campos](/images/platform/v2/overview-frame-io-resources-in-zapier/96b556247084aa9ced664a076acc8e22da0c44c5def47b9147b2c0c968964aec.webp)

La buena noticia es que todos los campos de entrada de datos de Zapier tienen una función de búsqueda y, con ella, puedes llegar rápidamente al campo que necesitas.

![Búsqueda rápida de asset aprobado](/images/platform/v2/overview-frame-io-resources-in-zapier/38f94d317a462a7caf7fdc781713c0040001d99ef441cd25507b215ca373f70e.webp)

Por supuesto, también ayuda saber qué buscar.

## Qué buscar {#what-to-look-for}

La siguiente tabla no es exhaustiva, pero debería darte una ventaja para crear flujos de trabajo con la integración de Frame.io con Zapier.

<Info>

**Las URL de los Assets son largas, y no pasa nada**

Las URL de los Assets que ves en las respuestas de la API de Frame.io son enlaces directos a Amazon S3. Estas URL pueden y deben usarse en cualquier contexto de aplicación de Zapier en el que quieras mover un Asset a otro sistema. Si puedes elegir entre “File Attachment” y “File Attachment (URL)”, elige la segunda opción, ya que las subidas mediante URL en Zapier suelen admitir una gama más amplia de tipos y tamaños de archivo.

</Info>

| Tipo de recurso | Campo en Zapier | Descripción |
| --- | --- | --- |
| Asset (todos) | Original | El video original subido, sin modificar. En la mayoría de los casos, esta será la clave que querrás enviar a otros sistemas; pero siempre tendrá el tipo de archivo original, por lo que es posible que no se pueda reproducir en todos los demás contextos. |
| Asset (videos) | H264 *resolution* | Todos los proxies h.264 de Frame.io están disponibles en el Asset en Zapier. |
| Asset (imagen) | Image *quality* | Al igual que los proxies de video h.264, todos los proxies generados para imágenes también están disponibles en Zapier. |
| Asset (todos) | Thumb | La miniatura del Asset tal como está configurada en Frame.io. Este campo es ideal para agregar elementos visuales a sistemas de seguimiento de proyectos como Trello o Airtable. |
| Asset (todos) | Label | La Status Label. Este campo normalmente se combinará con una acción “Filter” (similar a la captura de pantalla anterior). |
| Asset (todos) | Creator Email | La dirección de correo electrónico de quien subió el archivo original. |
| Asset (todos) | Project ID | El ID del Project principal del Asset. Este campo es más útil cuando se combina con la acción “Find Project”, que puedes usar para obtener el nombre del Project. |
| Asset (todos) | Parent ID | El ID del elemento principal de un Asset, que siempre será una carpeta, un version stack o la raíz del Project. |
| Comment | Text | El texto del comentario. |
| Comment | Asset ID | El ID del Asset principal del Comment. Es útil para pasarlo a la acción Find Asset y obtener contexto adicional, o para enlazarlo en herramientas de seguimiento externas. |
| Comment | Owner Name | El nombre y el apellido del usuario que dejó el Comment. |
| Comment | Owner Email | La dirección de correo electrónico del usuario que dejó el Comment. |
| Project | Name | El nombre del Project. |
