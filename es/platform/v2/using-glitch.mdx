---
title: "Usar Glitch"
---

Glitch es una herramienta que te permite crear aplicaciones web de forma rápida y sencilla. Puedes ejecutarlas con Glitch para probarlas sin la molestia de tener que configurar tu propio servidor con una dirección web pública. 

Esta guía ofrece algunos consejos y trucos básicos para trabajar con Glitch. 

## ¿Cómo me registro en Glitch? {#how-do-i-sign-up-for-glitch}
Haz clic en **Sign In** y elige uno de los métodos disponibles. Glitch admite el inicio de sesión con Facebook, GitHub, Google y correo electrónico. Puedes empezar aquí: [https://glitch.com](https://glitch.com).

## ¿Cómo trabajo con un proyecto en Glitch? {#how-do-i-work-with-a-project-on-glitch}
Para trabajar con un proyecto en Glitch, haz lo siguiente:

1. Ve a la página del proyecto, que tendrá la estructura `https://glitch.com/~word-otherword`

2. Haz clic en **View Source**

3. En la parte superior derecha de la pantalla, haz clic en **Remix to Edit**. Podrás modificar el proyecto como quieras. 

También puedes iniciar sesión y luego hacer clic en **New Project** en la esquina superior derecha si quieres trabajar en un proyecto nuevo. 

## ¿Cómo veo los registros o la consola en Glitch? {#how-do-i-see-logs-or-the-console-on-glitch}
Puedes revisar tu proyecto desde una terminal haciendo clic en **Tools** en la parte inferior de la página. Podrás elegir ver un registro de auditoría (Logs) y una consola de página completa (Full Page Console). 

## ¿Qué lenguajes puedo usar? {#what-languages-can-i-use}
Oficialmente, Glitch solo admite javascript. Pero puedes usar muchos otros lenguajes de forma no oficial. Se puede hacer que Glitch funcione con: 
* C/C++
* Haskell
* OCaml
* Perl
* Erlang
* Elixir
* Lua 5.2
* PHP 
* Ruby
* Java
* Python
* Go 
* Rust
* Racket 

## Glitch y Python {#glitch-and-python}
Puedes agregar dependencias a tu proyecto de Python en Glitch incluyendo un archivo **requirements.txt** que contenga los módulos que quieres importar. 

A veces, un módulo que quieres importar no se importa. Puedes agregarlo mediante la consola de Glitch, pero asegúrate de instalarlo en tu área de usuario usando la etiqueta `--user`. 

`pip install --user module_name`
