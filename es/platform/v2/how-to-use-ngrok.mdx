Ngrok es una herramienta fácil de usar que te permite crear un túnel seguro en tu máquina local junto con una URL pública que puedes usar para probar tu proyecto local o para compartir tu trabajo con un cliente o un compañero de equipo para que lo revise. Puedes configurar HTTP o HTTPS y, debido a la popularidad de esta herramienta, si algo falla, hay un montón de artículos que describen distintas formas de resolver el problema. Este artículo explica un par de formas sencillas de instalar ngrok y qué hacer si no consigues que tu aplicación web se comunique con ngrok.

## Instalar ngrok {#install-ngrok}

Puedes usar ngrok de un par de formas diferentes

### Instalar con el instalador de ngrok {#install-via-the-ngrok-installer}

1. Ve al sitio web de ngrok y sigue las instrucciones que allí se indican: [https://ngrok.com/download](https://ngrok.com/download)
2. Si quieres las funcionalidades que ofrece conectar una cuenta, sigue estas instrucciones para obtener una cuenta y un token.

No es obligatorio obtener una cuenta ni añadir el token, pero sin duda consulta la página de descarga para ver si es algo que quieres o necesitas.

<Info>

**Nota:**

Si usas este método, ngrok se ejecuta desde la ubicación en la que lo guardes, a menos que lo pongas a disposición de todo tu sistema.

</Info>

### Instalar con Homebrew {#install-with-homebrew}

Este es mi método favorito para instalar ngrok. Si tienes Homebrew instalado, solo tienes que escribir `homebrew cask install ngrok`. ¡ngrok se instala automáticamente y puedes usarlo desde cualquier lugar! Y lo mejor de todo es que no tienes que escribir `./ngrok` en el terminal al principio de cada comando; basta con escribir `ngrok`. Puedes leer más sobre esta opción [aquí](https://gist.github.com/wosephjeber/aa174fb851dfe87e644e).

## Usar ngrok {#use-ngrok}

Después de configurar ngrok, elige un puerto como `3000` y ponlo en marcha desde la línea de comandos del terminal con el comando ngrok http `3000`. No es obligatorio usar el puerto `3000`, pero es un puerto que se elige habitualmente en la configuración.

Si configuraste ngrok para que se ejecute desde una carpeta concreta, debes estar en la carpeta donde colocaste ngrok y usar el comando `./ngrok http 3000`.

Inicia el servidor de tu proyecto para que escuche en el mismo puerto y podrás acceder a tu trabajo usando la dirección pública que proporciona ngrok.

### Solucionar problemas de ngrok con tu aplicación web: barra final {#troubleshooting-ngrok-with-your-web-app-trailing-slash}

Un problema que puedes encontrarte con ngrok es que no consigas conectarte a tu servidor al configurar una URL de ngrok para usarla con tu aplicación web. Lo frustrante de este problema es que ngrok no registrará que le has enviado nada. Puedes abrir localhost:4040 para ver qué ocurre, y no te mostrará nada. (ngrok proporciona localhost:4040 para que puedas supervisar las solicitudes entrantes a tu servidor). Ngrok parece hacer coincidir las direcciones con /(.*) en lugar de con (/.*), así que si no incluyes una barra final al final de tu dirección y no ves nada en las herramientas de supervisión de ngrok, es porque ngrok no encuentra ninguna coincidencia para la dirección indicada.

Este es un ejemplo de cómo añadir una barra final: `http://something.ngrok.io/`

También puedes escribir tus aplicaciones de ejemplo para que resuelvan a un endpoint que incluya una barra. Solo recuerda que, para que la aplicación de Frame.io llegue a tu servidor, si tu aplicación de ejemplo usa el endpoint `/actions`, tienes que añadir el endpoint /actions al final de tu dirección de ngrok. Por ejemplo, si la dirección de ngrok es `http://something.ngrok.io`, tendrías que indicarla en la configuración de tu Custom Action como `http://something.ngrok.io/actions`. Esto puede ser diferente en otras aplicaciones web, así que prueba distintas variantes al final de la dirección de ngrok si no consigues que funcione de inmediato.

### ¿Puedo usar algo distinto de ngrok? ¡Prueba Glitch! {#can-i-use-something-besides-ngrok-try-glitch}

Glitch es una alternativa muy interesante a ngrok y es más rápida de configurar. Glitch te permite crear una cuenta y, después, crear tus propias aplicaciones en sus servidores con una URL accesible públicamente. Puedes colaborar con otras personas, hacer tu código público o privado y elegir entre una gran variedad de lenguajes y plataformas. Consulta [https://glitch.com/create](https://glitch.com/create) para ver qué hay disponible.

Al configurar tu proyecto en Glitch, el problema de la barra final se aplica a algunas aplicaciones web. En el caso de Frame.io, al configurar una Custom Action en [developer.frame.io](/es/platform/v2), tienes que incluir la barra final al final de la URL proporcionada por Glitch. No necesitas añadir nada más, ni siquiera para el endpoint /actions.

### ¿Hay algo ya configurado que pueda probar ahora? {#is-there-something-set-up-i-could-try-now}

Sí. Si no quieres usar ngrok ni crear tu propio proyecto en Glitch, hemos configurado una aplicación de ejemplo para que la pruebes aquí: [https://frameio-custom-action.glitch.me](https://frameio-custom-action.glitch.me). Recuerda incluir una barra final al añadir esta dirección en la sección Custom Actions de \[/).
