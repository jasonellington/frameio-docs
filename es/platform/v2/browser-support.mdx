# Compatibilidad entre navegadores para el inicio de sesión en Frame.io {#cross-browser-support-for-frame-io-login}

Aunque esto no será relevante para aplicaciones totalmente basadas en la API, la compatibilidad entre navegadores de Frame.io entra en juego al cargar nuestra [aplicación Accounts](https://accounts.frame.io/) durante un flujo de concesión de credenciales OAuth.

Al escribir aplicaciones OAuth para Frame.io, ten en cuenta que la página de inicio de sesión que mostramos en el flujo OAuth tendrá la misma compatibilidad con navegadores que nuestra aplicación web principal. A efectos de la tabla siguiente, la compatibilidad "Parcial" significa que todas las funciones principales deberían funcionar sin impedimentos, aunque puede haber algunos problemas menores de diseño. La compatibilidad "Mínima" significa que podría funcionar, pero ya no lo probamos ni lo admitimos explícitamente.

| Navegador | Compatibilidad |
| --- | --- |
| Chrome (última versión) | Completa |
| Safari (última versión) | Completa |
| Firefox (última versión) | Completa |
| Opera (última versión) | Completa |
| Edge (última versión) | Completa |
| IE (11+) | Mínima |
| IE (&lt;=10) | Ninguna |
| Safari para móviles (última versión) | Parcial |
| Chrome para iOS (última versión) | Parcial |
| Chrome para Android (última versión) | Parcial |
| Navegador de Android (última versión) | Parcial |
