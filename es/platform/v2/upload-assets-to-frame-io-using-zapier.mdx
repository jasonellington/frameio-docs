## Descripción general {#overview}

Si quieres subir archivos a Frame.io desde aplicaciones en la nube existentes o desde una URL que sirva assets, Zapier suele ser una buena solución, ya que su producto resuelve muchas divergencias de diseño entre API que hacen que interactuar con aplicaciones en la nube sea un dolor de cabeza.  Esta guía aclara los atributos clave del servicio de subida de Zapier para que sepas exactamente qué ocurre en tu integración.

## Configurar el método de subida de archivos {#setting-the-file-upload-method}

Zapier intenta descubrir automáticamente el método de subida de archivos más flexible para cada API a la que se conecta.  Por ejemplo, Zapier intentará convertir los enlaces restringidos a los que no se puede acceder fuera del dominio de una aplicación en enlaces de descarga disponibles públicamente:

Enlace original ilegible:
`https://www.dropbox.com/s/hriinb9w3a2107m/iPad%20intro.pdf`

Enlace convertido, utilizable por la API Uploader de Frame.io:
`https://dl.dropboxusercontent.com/s/hriinb9w3a2107m/iPad%20intro.pdf`

### Limitaciones de archivos de Zapier {#zapier’s-file-limitations}

Es importante saber que, si Zapier **no puede** descubrir una URL de descarga estática para pasarla a la API de Frame.io, el propio servicio de Zapier descargará los archivos sobre la marcha y los pasará a Frame.io.  Zapier restringe este método a archivos de **[menos de 100MB](https://zapier.com/help/doc/common-problems-dropbox)**.

Ten en cuenta que la interfaz de Zapier puede advertirte sobre restricciones de tamaño de archivo incluso cuando pasas una URL directa (es decir, cuando no hay ninguna restricción).  Por eso vale la pena entender cómo funciona File URL.

## Métodos de subida para aplicaciones y servicios comunes {#upload-methods-for-common-apps-and-services}

**Nota:** las integraciones del tipo **File Upload** están sujetas a los límites de tamaño de archivo indicados en la interfaz de Zapier. Son preferibles los enlaces directos, ya que no están sujetos a limitaciones de tamaño y se procesan de forma más rápida y fiable.

| Aplicación | Tipo | Consejos y referencias |
| --- | --- | --- |
| Gmail | File Upload | [Documentación de ayuda de Zapier](https://zapier.com/help/doc/common-problems-gmail#how-can-i-attach-a-file-to-my-email-that39s-not-in-my-trigger) |
| Google Drive | Enlace directo | Debes pegar `webContentLink` en el selector File.  Esto funciona para los archivos que subes a Google Drive, pero no para documentos o presentaciones creados dentro de Drive. [Documentación de ayuda de Zapier](https://zapier.com/help/doc/common-problems-google-drive#unable-to-get-a-value-when-looking-for-quotfilequot-is-it-missing), [API V3 de Google Drive](https://developers.google.com/drive/api/v3/manage-downloads) |
| Dropbox | Enlace directo | Subir automáticamente archivos de Dropbox a Frame.io |
| Box | Enlace directo | Usa `Info Shared Link Download URL` [Guías de la API de Box](https://developer.box.com/guides/downloads/shared-link/) |
| S3 | Enlace directo | Guía de Zapier: problemas comunes con S3 |
