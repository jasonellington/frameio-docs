## Acceso para todas las cuentas {#all-account-access}

Todas las cuentas de Frame V4 —no solo las gestionadas a través de la Adobe Admin Console— pueden crear tokens y acceder a la API V4. Clientes y partners pueden probar, crear y perfeccionar sus flujos de trabajo con nuestras funciones de API más recientes.

<Steps>

<Step title="Crear un token de autenticación de usuario">

Visita la Adobe Developer Console para crear un token de autenticación de usuario. El usuario debe usar el mismo Adobe ID que utiliza para iniciar sesión en Frame para validar el acceso al token de API.

</Step>

<Step title="Crear credenciales de API">

Una vez que tengas acceso a las API, el siguiente paso es crear credenciales de API, o un token de API, para comunicarte con Frame. Crea tus credenciales de API en developer.adobe.com.

</Step>

</Steps>

![Account Access](/images/platform/docs/guides/accounts-projects-and-workspaces/706a4eb9324bc24a3465388a838455baf58384f128882a185dad2d1900f728a3.webp)

<Info>

Todas las cuentas V4, ya sean gestionadas por Frame (V4F) o por Adobe (V4A), pueden crear un proyecto en la Adobe Developer Console y, a continuación, crear credenciales. Una vez que tengas un conjunto de credenciales (OAuth Client ID/Client Secret), podrás integrarte con el flujo OAuth de tres vías de la Adobe Developer Platform. ¡Inicia sesión con tu Adobe Identity para recibir un token de autenticación y un refresh token válidos y hacer solicitudes a la Frame.io V4 Developer API!

</Info>

## Proyectos y workspaces {#projects-and-workspaces}

### Novedades de los workspaces {#workspace-updates}

La página de inicio de Frame.io es nueva y se llama página Workspace. Los usuarios pueden explorar los workspaces y proyectos a los que tienen acceso en una cuenta. Gracias a este nuevo diseño, es más fácil ver quién pertenece a un workspace determinado e invitar rápidamente a nuevas personas.

<Note>

En Frame V3, los workspaces se conocían como Teams.

</Note>

En V4, los workspaces son solo por invitación, por lo que los usuarios solo verán los workspaces a los que se les haya invitado explícitamente. Además, no existe una página Team Directory en la configuración de la cuenta.

Para gestionar permisos y operaciones relacionadas, usa los endpoints Create, List, Delete y Update Workspace.

- Listar los roles de usuario de un workspace determinado.
- Eliminar a un usuario de un workspace determinado.
- Actualizar los roles de usuario del workspace indicado si el usuario ya se ha añadido al workspace. Si el usuario no se ha añadido al workspace, se añadirá con el rol indicado.

### Novedades de los proyectos {#project-updates}

El flujo de creación de proyectos ha cambiado en V4. Ahora, al iniciar un nuevo proyecto, eliges entre un proyecto en blanco o una plantilla de proyecto. Hay doce plantillas para elegir, diseñadas para flujos de trabajo creativos habituales. También puedes optar por incluir los assets de demostración de la plantilla o empezar solo con la estructura de la plantilla. Al elegir una plantilla de proyecto, se crea inmediatamente un nuevo proyecto en tu workspace.

Para gestionar permisos y operaciones relacionadas, usa los endpoints Create, List, Delete y Update Project.

- Eliminar a un usuario de un proyecto determinado.
- Actualizar los roles de usuario del proyecto indicado si el usuario ya se ha añadido al proyecto. Si el usuario no se ha añadido al proyecto, se añadirá con el rol indicado.

</Card>

</CardGroup>
