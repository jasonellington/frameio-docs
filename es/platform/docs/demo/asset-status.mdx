<Note>
  Este es un endpoint de demostración para la automatización Update from code changes de Mintlify. No forma parte de la API de Frame.io.
</Note>

Usa este endpoint para comprobar si un asset ha terminado de procesarse.

## Obtener el estado de un asset {#get-an-asset’s-status}

```http
GET /v4/assets/{id}/status
```

### Parámetros de ruta {#path-parameters}

| Parámetro | Tipo   | Descripción        |
| --------- | ------ | ------------------ |
| `id`      | string | El ID del asset.   |

### Campos de respuesta {#response-fields}

| Campo         | Tipo   | Descripción                                                  |
| ------------- | ------ | ------------------------------------------------------------ |
| `data.id`     | string | El ID del asset.                                             |
| `data.status` | string | El estado de procesamiento: `processing` o `ready`.          |

### Ejemplo {#example}

```bash
curl http://localhost:3001/v4/assets/a1b2c3/status
```

```json
{
  "data": {
    "id": "a1b2c3",
    "status": "ready"
  }
}
```

### Errores {#errors}

| Estado | Error             | Significado                       |
| ------ | ----------------- | --------------------------------- |
| `404`  | `asset_not_found` | Ningún asset tiene este ID.       |
