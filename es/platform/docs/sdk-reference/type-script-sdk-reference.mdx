### Instalación {#installation}

```bash
npm i -s frameio
```

---

### Uso {#usage}

Crea una instancia del cliente y úsalo de la siguiente manera:

```typescript
import { FrameioClient } from "frameio";

const client = new FrameioClient({ token: "YOUR_TOKEN" });
await client.metadataFields.metadataFieldDefinitionsCreate("b2702c44-c6da-4bb6-8bbd-be6e547ccf1b", {
    data: {
        field_type: "select",
        field_configuration: {
            enable_add_new: false,
            options: [
                {
                    display_name: "Option 1",
                },
                {
                    display_name: "Option 2",
                },
            ],
        },
        name: "Fields definition name",
    },
});
```

---

### Tipos de solicitud y respuesta {#request-and-response-types}

El SDK exporta todos los tipos de solicitud y respuesta como interfaces de TypeScript. Solo tienes que importarlos con el siguiente espacio de nombres:

```typescript
import { Frameio } from "frameio";

const request: Frameio.UpdateFieldDefinitionParams = {
    ...
};
```

---

### Manejo de excepciones {#exception-handling}

Cuando la API devuelve un código de estado de error (respuesta 4xx o 5xx), se lanza una subclase del siguiente error.

```typescript
import { FrameioError } from "frameio";

try {
    await client.metadataFields.metadataFieldDefinitionsCreate(...);
} catch (err) {
    if (err instanceof FrameioError) {
        console.log(err.statusCode);
        console.log(err.message);
        console.log(err.body);
        console.log(err.rawResponse);
    }
}
```

### Avanzado {#advanced}

#### Encabezados adicionales {#additional-headers}

Si quieres enviar encabezados adicionales como parte de la solicitud, usa la opción de solicitud headers.

```typescript
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    headers: {
        'X-Custom-Header': 'custom value'
    }
});
```

#### Parámetros adicionales de cadena de consulta {#additional-query-string-parameters}

Si quieres enviar parámetros adicionales de cadena de consulta como parte de la solicitud, usa la opción de solicitud queryParams.

```typescript
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    queryParams: {
        'customQueryParamKey': 'custom query param value'
    }
});
```

---

#### Reintentos {#retries}

El SDK incorpora reintentos automáticos con retroceso exponencial. Una solicitud se reintentará siempre que se considere reintentable y que el número de reintentos no haya superado el límite configurado (valor predeterminado: 2).

Una solicitud se considera reintentable cuando se devuelve cualquiera de los siguientes códigos de estado HTTP:

- 408 (Tiempo de espera agotado)
- 429 (Demasiadas solicitudes)
- 5XX (Errores internos del servidor)

<br />

Usa la opción de solicitud `maxRetries` para configurar este comportamiento.

```typescript
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    maxRetries: 0 // override maxRetries at the request level
});
```

---

#### Tiempos de espera {#timeouts}

De forma predeterminada, el SDK usa un tiempo de espera de 60 segundos. Usa la opción timeoutInSeconds para configurar este comportamiento.

```typescript
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    timeoutInSeconds: 30 // override timeout to 30s
});
```

#### Cancelar solicitudes {#aborting-requests}

El SDK permite a los usuarios cancelar solicitudes en cualquier momento pasando una señal de cancelación.

```typescript
const controller = new AbortController();
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    abortSignal: controller.signal
});
controller.abort(); // aborts the request
```

---

#### Acceder a los datos sin procesar de la respuesta {#access-raw-response-data}

El SDK proporciona acceso a los datos sin procesar de la respuesta, incluidos los encabezados, mediante el método `.withRawResponse()`. El método `.withRawResponse()` devuelve una promesa que se resuelve en un objeto con las propiedades `data` y `rawResponse`.

```typescript
const { data, rawResponse } = await client.metadataFields.metadataFieldDefinitionsCreate(...).withRawResponse();

console.log(data);
console.log(rawResponse.headers['X-My-Header']);
```

#### Compatibilidad con entornos de ejecución {#runtime-compatibility}

El SDK funciona en los siguientes entornos de ejecución:

- Node.js 18+
- Vercel
- Cloudflare Workers
- Deno v1.25+
- Bun 1.0+
- React Native

#### Personalizar el cliente Fetch {#customizing-fetch-client}

El SDK te permite personalizar el cliente HTTP / la función Fetch subyacente. Si trabajas en un entorno no compatible, esto te ofrece una solución de último recurso para garantizar que el SDK funcione.

```typescript
import { FrameioClient } from "frameio";

const client = new FrameioClient({
    ...
    fetcher: // provide your implementation here
});
```

#### Autenticación {#auth}

<AccordionGroup>

<Accordion title="new ServerToServerAuth({ clientId, clientSecret, ... })">

Autentica mediante la concesión OAuth 2.0 `client_credentials`. Este flujo no implica a ningún usuario y no devuelve un token de actualización. Cuando el token de acceso caduca, el SDK solicita automáticamente uno nuevo con las credenciales del cliente.

```typescript title="usage"
import { FrameioClient, ServerToServerAuth } from "frameio";

const auth = new ServerToServerAuth({
    clientId: "YOUR_CLIENT_ID",
    clientSecret: "YOUR_CLIENT_SECRET",
});
const client = new FrameioClient({ token: () => auth.getToken() });
```

**Parámetros**

`clientId`: `string` — ID de cliente OAuth de Adobe IMS.

`clientSecret`: `string` — Secreto de cliente OAuth de Adobe IMS.

`scopes`: `string` — Ámbitos separados por espacios (OAuth 2.0 RFC 6749). De forma predeterminada, los ámbitos de servidor a servidor.

`imsBaseUrl`: `string` — URL base de IMS para entornos de staging o alternativos. De forma predeterminada, producción.

`fetch`: `typeof fetch` — Implementación personalizada de fetch (para proxy, TLS, etc.).

`onTokenRefreshed`: `OnTokenRefreshed` — Callback opcional que se ejecuta después de cada obtención de token.

`timeout`: `number` — Tiempo de espera de las solicitudes HTTP en milisegundos. Valor predeterminado: 30000.

`maxRetries`: `number` — Número máximo de reintentos ante fallos transitorios. Valor predeterminado: 2.

`refreshBuffer`: `number` — Segundos antes de la caducidad para activar una actualización proactiva. Valor predeterminado: 60.

`logger`: `Logger` — Instancia de logger para la salida de diagnóstico.

**Métodos**

`getToken(): Promise<string>` — Devuelve un token de acceso válido y lo actualiza si es necesario. Pásalo al cliente: `new FrameioClient({ token: () => auth.getToken() })`.

`authenticate(): Promise<TokenResponse>` — Obtiene explícitamente un nuevo token de acceso.

`revoke(): Promise<void>` — Revoca los tokens en el servidor y borra el estado local.

`exportTokens(): ExportedTokens` — Exporta el estado actual de los tokens para conservarlo.

`importTokens(data: ExportedTokens): void` — Restaura el estado de los tokens a partir de un objeto exportado previamente.

</Accordion>

<Accordion title="new WebAppAuth({ clientId, clientSecret, redirectUri, ... })">

Autentica mediante la concesión OAuth 2.0 `authorization_code`. Úsala en aplicaciones del lado del servidor que puedan almacenar un secreto de cliente de forma segura.

```typescript title="usage"
import { randomBytes } from "crypto";
import { FrameioClient, WebAppAuth } from "frameio";

const auth = new WebAppAuth({
    clientId: "YOUR_CLIENT_ID",
    clientSecret: "YOUR_CLIENT_SECRET",
    redirectUri: "https://myapp.com/callback",
});
const url = auth.getAuthorizationUrl({ state: randomBytes(24).toString("hex") });
// redirect the user to url ...
await auth.exchangeCode("CODE_FROM_CALLBACK");
const client = new FrameioClient({ token: () => auth.getToken() });
```

**Parámetros**

`clientId`: `string` — ID de cliente OAuth de Adobe IMS.

`clientSecret`: `string` — Secreto de cliente OAuth de Adobe IMS.

`redirectUri`: `string` — URI de redirección registrado.

`scopes`: `string` — Ámbitos separados por espacios (OAuth 2.0 RFC 6749).

`imsBaseUrl`: `string` — URL base de IMS para entornos de staging o alternativos. De forma predeterminada, producción.

`fetch`: `typeof fetch` — Implementación personalizada de fetch (para proxy, TLS, etc.).

`onTokenRefreshed`: `OnTokenRefreshed` — Callback opcional que se ejecuta después de cada actualización de token.

`timeout`: `number` — Tiempo de espera de las solicitudes HTTP en milisegundos. Valor predeterminado: 30000.

`maxRetries`: `number` — Número máximo de reintentos ante fallos transitorios. Valor predeterminado: 2.

`refreshBuffer`: `number` — Segundos antes de la caducidad para activar una actualización proactiva. Valor predeterminado: 60.

`logger`: `Logger` — Instancia de logger para la salida de diagnóstico.

**Métodos**

`getToken(): Promise<string>` — Devuelve un token de acceso válido y lo actualiza si es necesario.

`getAuthorizationUrl({ state }): string` — Construye la URL de autorización de Adobe IMS. Pasa un valor CSRF/state opaco que se te devolverá.

`exchangeCode(code: string): Promise<TokenResponse>` — Intercambia un código de autorización por tokens de acceso y de actualización.

`refresh(): Promise<TokenResponse>` — Activa manualmente una actualización del token.

`revoke(): Promise<void>` — Revoca los tokens en el servidor y borra el estado local.

`exportTokens(): ExportedTokens` — Exporta el estado actual de los tokens para conservarlo.

`importTokens(data: ExportedTokens): void` — Restaura el estado de los tokens a partir de un objeto exportado previamente.

</Accordion>

<Accordion title="new SPAAuth({ clientId, redirectUri, ... })">

Autentica mediante `authorization_code` + PKCE (sin secreto de cliente). Úsalo en aplicaciones de una sola página basadas en navegador que no pueden almacenar un secreto de cliente de forma segura.

```typescript title="usage"
import { randomBytes } from "crypto";
import { FrameioClient, SPAAuth } from "frameio";

const auth = new SPAAuth({
    clientId: "YOUR_CLIENT_ID",
    redirectUri: "https://myapp.com/cb",
});
const result = await auth.getAuthorizationUrl({ state: randomBytes(24).toString("hex") });
// redirect the user to result.url, store result.codeVerifier ...
await auth.exchangeCode({ code: "CODE_FROM_CALLBACK", codeVerifier: result.codeVerifier });
const client = new FrameioClient({ token: () => auth.getToken() });
```

**Parámetros**

`clientId`: `string` — ID de cliente OAuth de Adobe IMS.

`redirectUri`: `string` — URI de redirección registrado.

`scopes`: `string` — Ámbitos separados por espacios (OAuth 2.0 RFC 6749).

`imsBaseUrl`: `string` — URL base de IMS para entornos de staging o alternativos. De forma predeterminada, producción.

`fetch`: `typeof fetch` — Implementación personalizada de fetch (para proxy, TLS, etc.).

`onTokenRefreshed`: `OnTokenRefreshed` — Callback opcional que se ejecuta después de cada actualización de token.

`timeout`: `number` — Tiempo de espera de las solicitudes HTTP en milisegundos. Valor predeterminado: 30000.

`maxRetries`: `number` — Número máximo de reintentos ante fallos transitorios. Valor predeterminado: 2.

`refreshBuffer`: `number` — Segundos antes de la caducidad para activar una actualización proactiva. Valor predeterminado: 60.

`logger`: `Logger` — Instancia de logger para la salida de diagnóstico.

**Métodos**

`getToken(): Promise<string>` — Devuelve un token de acceso válido y lo actualiza si es necesario.

`getAuthorizationUrl({ state }): Promise<AuthorizationUrlResult>` — Construye la URL de autorización de Adobe IMS con un desafío PKCE. Devuelve un `AuthorizationUrlResult` con `url` y `codeVerifier`.

`exchangeCode({ code, codeVerifier }): Promise<TokenResponse>` — Intercambia un código de autorización + verificador PKCE por tokens.

`refresh(): Promise<TokenResponse>` — Activa manualmente una actualización del token.

`revoke(): Promise<void>` — Revoca los tokens en el servidor y borra el estado local.

`exportTokens(): ExportedTokens` — Exporta el estado actual de los tokens para conservarlo.

`importTokens(data: ExportedTokens): void` — Restaura el estado de los tokens a partir de un objeto exportado previamente.

</Accordion>

<Accordion title="new NativeAppAuth({ clientId, redirectUri, ... })">

Autentica mediante `authorization_code` + PKCE en aplicaciones de escritorio y móviles. Comparte la misma API que `SPAAuth`; usa un URI de redirección con esquema personalizado (p. ej., `myapp://callback`).

```typescript title="usage"
import { randomBytes } from "crypto";
import { FrameioClient, NativeAppAuth } from "frameio";

const auth = new NativeAppAuth({
    clientId: "YOUR_CLIENT_ID",
    redirectUri: "myapp://callback",
});
const result = await auth.getAuthorizationUrl({ state: randomBytes(24).toString("hex") });
// open result.url in the system browser, store result.codeVerifier ...
await auth.exchangeCode({ code: "CODE_FROM_CALLBACK", codeVerifier: result.codeVerifier });
const client = new FrameioClient({ token: () => auth.getToken() });
```

**Parámetros**

`clientId`: `string` — ID de cliente OAuth de Adobe IMS.

`redirectUri`: `string` — URI de redirección registrado (se admite un esquema personalizado).

`scopes`: `string` — Ámbitos separados por espacios (OAuth 2.0 RFC 6749).

`imsBaseUrl`: `string` — URL base de IMS para entornos de staging o alternativos. De forma predeterminada, producción.

`fetch`: `typeof fetch` — Implementación personalizada de fetch (para proxy, TLS, etc.).

`onTokenRefreshed`: `OnTokenRefreshed` — Callback opcional que se ejecuta después de cada actualización de token.

`timeout`: `number` — Tiempo de espera de las solicitudes HTTP en milisegundos. Valor predeterminado: 30000.

`maxRetries`: `number` — Número máximo de reintentos ante fallos transitorios. Valor predeterminado: 2.

`refreshBuffer`: `number` — Segundos antes de la caducidad para activar una actualización proactiva. Valor predeterminado: 60.

`logger`: `Logger` — Instancia de logger para la salida de diagnóstico.

**Métodos**

Los mismos que `SPAAuth`: `getToken()`, `getAuthorizationUrl({ state })`, `exchangeCode({ code, codeVerifier })`, `refresh()`, `revoke()`, `exportTokens()`, `importTokens(data)`.

</Accordion>

<Accordion title="AuthorizationUrlResult">

Objeto devuelto por `SPAAuth.getAuthorizationUrl()` y `NativeAppAuth.getAuthorizationUrl()`. Contiene la URL de autorización y el verificador de código PKCE.

**Propiedades**

`url`: `string` — La URL de autorización completa a la que redirigir al usuario.

`codeVerifier`: `string` — El verificador de código PKCE que se debe almacenar y pasar a `exchangeCode()`.

</Accordion>

#### Excepciones de autenticación {#auth-exceptions}

Todos los errores de autenticación extienden `FrameioAuthError` y se pueden importar desde `frameio`.

| Excepción | Descripción |
| --- | --- |
| `FrameioAuthError` | Error base para todos los errores del SDK de autenticación. |
| `AuthenticationError` | Error en el intercambio o la actualización del token. Tiene las propiedades `errorCode` y `errorDescription`. |
| `TokenExpiredError` | El token de actualización ha caducado; es necesario volver a autenticarse. |
| `NetworkError` | Error en una solicitud de red (tiempo de espera, error de conexión, etc.). |
| `RateLimitError` | Adobe IMS devolvió 429 y se agotaron los reintentos. Tiene la propiedad `retryAfter`. |
| `PKCEError` | Error en la verificación PKCE. |
| `ConfigurationError` | Falta la configuración obligatoria o no es válida. |

Usa el parámetro de consulta include para incluir de forma selectiva propiedades adicionales en la respuesta.

<Note>

Si incluyes `media_links.original` y el usuario no tiene permiso para descargar archivos en el proyecto correspondiente, este endpoint responderá con un error `403 Forbidden`. Si el contenido no es accesible porque se requiere una marca de agua para este usuario y los media_links solicitados no la admiten, la solicitud se completará correctamente, pero los enlaces multimedia no admitidos se establecerán en null. Del mismo modo, si un enlace de transcodificación solicitado no existe para un archivo concreto (p. ej., `including media_links.video_h264_180` en un archivo de imagen estática) o el proceso de transcodificación no ha finalizado (es decir, el estado del archivo es “uploaded” en lugar de “transcoded”), el enlace multimedia también se establecerá en null en la carga útil de la respuesta. En resumen, el cliente debe gestionar correctamente los enlaces multimedia nulos.

</Note>

Límites de frecuencia: 100 llamadas por 1.00 minuto(s) por account_user

await client.versionStacks.index("b2702c44-c6da-4bb6-8bbd-be6e547ccf1b", "b2702c44-c6da-4bb6-8bbd-be6e547ccf1b", {

    after: "<opaque_cursor>",
    page_size: 10,
    include_total_count: false,
});

    console.log(item);
}

// Or you can manually iterate page-by-page
let page = await client.workspaces.index("b2702c44-c6da-4bb6-8bbd-be6e547ccf1b", {
    include: "creator",
    sort: "name_asc",
    after: "<opaque_cursor>",
    page_size: 10,
    include_total_count: false,
});
while (page.hasNextPage()) {
    page = page.getNextPage();
}
