### Uso {#usage}

Crea una instancia del cliente y úsalo de la siguiente manera:

```python
from frameio import (
    Frameio,
    SelectDefinitionParamsFieldConfiguration,
    SelectDefinitionParamsFieldConfigurationOptionsItem,
)
from frameio.metadata_fields import CreateFieldDefinitionParamsData_Select

client = Frameio(
    token="YOUR_TOKEN",
)
client.metadata_fields.metadata_field_definitions_create(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    data=CreateFieldDefinitionParamsData_Select(
        field_configuration=SelectDefinitionParamsFieldConfiguration(
            enable_add_new=False,
            options=[
                SelectDefinitionParamsFieldConfigurationOptionsItem(
                    display_name="Option 1",
                ),
                SelectDefinitionParamsFieldConfigurationOptionsItem(
                    display_name="Option 2",
                ),
            ],
        ),
        name="Fields definition name",
    ),
)
```

### Cliente asíncrono {#async-client}

El SDK también exporta un cliente asíncrono para que puedas realizar llamadas no bloqueantes a nuestra API. Ten en cuenta que, si construyes una clase de cliente httpx asíncrono para pasarla a este cliente, debes usar httpx.AsyncClient() en lugar de httpx.Client() (por ejemplo, para el parámetro httpx_client de este cliente).

```python
import asyncio

from frameio import (
    AsyncFrameio,
    SelectDefinitionParamsFieldConfiguration,
    SelectDefinitionParamsFieldConfigurationOptionsItem,
)
from frameio.metadata_fields import CreateFieldDefinitionParamsData_Select

client = AsyncFrameio(
    token="YOUR_TOKEN",
)


async def main() -> None:
    await client.metadata_fields.metadata_field_definitions_create(
        account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
        data=CreateFieldDefinitionParamsData_Select(
            field_configuration=SelectDefinitionParamsFieldConfiguration(
                enable_add_new=False,
                options=[
                    SelectDefinitionParamsFieldConfigurationOptionsItem(
                        display_name="Option 1",
                    ),
                    SelectDefinitionParamsFieldConfigurationOptionsItem(
                        display_name="Option 2",
                    ),
                ],
            ),
            name="Fields definition name",
        ),
    )


asyncio.run(main())
```

### Manejo de excepciones {#exception-handling}

Cuando la API devuelve un código de estado de error (respuesta 4xx o 5xx), se lanzará una subclase del siguiente error.

```python
from frameio.core.api_error import ApiError

try:
    client.metadata_fields.metadata_field_definitions_create(...)
except ApiError as e:
    print(e.status_code)
    print(e.body)
```

### Paginación {#pagination}

Las solicitudes paginadas devolverán un SyncPager o un AsyncPager, que pueden usarse como generadores del objeto subyacente.

```python
from frameio import Frameio

client = Frameio(
    token="YOUR_TOKEN",
)
response = client.project_permissions.index(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    project_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    page_size=10,
    include_total_count=False,
)
for item in response:
    yield item
# alternatively, you can paginate page-by-page
for page in response.iter_pages():
    yield page
```

### Avanzado {#advanced}

#### Acceder a los datos de respuesta sin procesar {#access-raw-response-data}

El SDK proporciona acceso a los datos de respuesta sin procesar, incluidos los encabezados, a través de la propiedad .with_raw_response. La propiedad .with_raw_response devuelve un cliente “sin procesar” que puede usarse para acceder a los atributos .headers y .data.

```python
from frameio import Frameio

client = Frameio(
    ...,
)
response = (
    client.metadata_fields.with_raw_response.metadata_field_definitions_create(
        ...
    )
)
print(response.headers)  # access the response headers
print(response.data)  # access the underlying object
pager = client.project_permissions.index(...)
print(pager.response.headers)  # access the response headers for the first page
for item in pager:
    print(item)  # access the underlying object(s)
for page in pager.iter_pages():
    print(page.response.headers)  # access the response headers for each page
    for item in page:
        print(item)  # access the underlying object(s)
```

#### Reintentos {#retries}

El SDK incluye reintentos automáticos con retroceso exponencial. Una solicitud se reintentará siempre que se considere reintentable y el número de reintentos no haya superado el límite de reintentos configurado (valor predeterminado: 2).<br />
Una solicitud se considera reintentable cuando se devuelve cualquiera de los siguientes códigos de estado HTTP:

- 408 (Tiempo de espera agotado)
- 429 (Demasiadas solicitudes)
- 5XX (Errores internos del servidor)

<br />

Usa la opción de solicitud `max_retries` para configurar este comportamiento.

```python
client.metadata_fields.metadata_field_definitions_create(..., request_options={
    "max_retries": 1
})
```

---

#### Tiempos de espera {#timeouts}

El SDK usa de forma predeterminada un tiempo de espera de 60 segundos. Puedes configurarlo con la opción timeout a nivel de cliente o de solicitud.

```python
from frameio import Frameio

client = Frameio(
    ...,
    timeout=20.0,
)


# Override timeout for a specific method
client.metadata_fields.metadata_field_definitions_create(..., request_options={
    "timeout_in_seconds": 1
})
```

---

#### Cliente personalizado {#custom-client}

Puedes reemplazar el cliente httpx para personalizarlo según tu caso de uso. Algunos casos de uso habituales incluyen la compatibilidad con proxies y transportes.

```python
import httpx
from frameio import Frameio

client = Frameio(
    ...,
    httpx_client=httpx.Client(
        proxy="http://my.test.proxy.example.com",
        transport=httpx.HTTPTransport(local_address="0.0.0.0"),
    ),
)
```

#### Autenticación {#auth}

<AccordionGroup>

<Accordion title="frameio.auth.ServerToServerAuth(*, client_id, client_secret, ...)" defaultOpen={true}>

Autentícate mediante la concesión client_credentials de OAuth 2.0. Este flujo no involucra a un usuario y no devuelve un token de actualización. Cuando el token de acceso caduca, el SDK solicita automáticamente uno nuevo con las credenciales del cliente. Para uso asíncrono, usa `AsyncServerToServerAuth`.

```python title="usage"

from frameio import Frameio
from frameio.auth import ServerToServerAuth

auth = ServerToServerAuth(client_id="YOUR_CLIENT_ID", client_secret="YOUR_CLIENT_SECRET")
client = Frameio(token=auth.get_token)
```

**Parámetros**

`client_id`: `str` — ID de cliente OAuth de Adobe IMS.

`client_secret`: `str` — Secreto de cliente OAuth de Adobe IMS.

`scopes`: `str` — Ámbitos separados por espacios (OAuth 2.0 RFC 6749). El valor predeterminado es `openid AdobeID frame.s2s.all`.

`ims_base_url`: `str` — URL base de IMS para entornos de staging o alternativos. El valor predeterminado es producción.

`http_client`: `typing.Optional[httpx.Client]` — httpx.Client opcional para proxy, TLS o agrupación de conexiones.

`on_token_refreshed`: `typing.Optional[typing.Callable[[dict[str, Any]], None]]` — Callback opcional que se ejecuta después de cada obtención del token.

`timeout`: `float` — Tiempo de espera de la solicitud HTTP en segundos. El valor predeterminado es 30.

`max_retries`: `int` — Número máximo de reintentos ante errores transitorios. El valor predeterminado es 2.

`refresh_buffer`: `int` — Segundos antes de la caducidad para activar la actualización proactiva. El valor predeterminado es 60.

**Métodos**

`get_token() -> str` — Devuelve un token de acceso válido y lo actualiza si es necesario. Pasa la referencia a este método (no una llamada) al SDK: `Frameio(token=auth.get_token)`.

`authenticate() -> dict[str, Any]` — Obtiene explícitamente un nuevo token de acceso. Devuelve el dict de respuesta del token con `access_token`, `expires_in`, etc.

`revoke() -> None` — Revoca ambos tokens en el servidor y borra el estado local.

`export_tokens() -> dict[str, Any]` — Exporta el estado actual de los tokens para su persistencia.

`import_tokens(data: dict[str, Any]) -> None` — Restaura el estado de los tokens a partir de un dict exportado previamente.

</Accordion>

<Accordion title="frameio.auth.WebAppAuth(*, client_id, client_secret, redirect_uri, ...)">

Autentícate mediante la concesión authorization_code de OAuth 2.0. Úsala para aplicaciones del lado del servidor que puedan almacenar de forma segura un secreto de cliente. Para uso asíncrono, usa `AsyncWebAppAuth`.

```python title="usage"

import secrets
from frameio import Frameio
from frameio.auth import WebAppAuth

auth = WebAppAuth(

# redirect user to url ...
```

<Accordion title="frameio.auth.SPAAuth(*, client_id, redirect_uri, ...)">

Autentícate mediante authorization_code + PKCE (sin secreto de cliente). Úsalo para aplicaciones basadas en navegador o nativas que no puedan almacenar de forma segura un secreto de cliente. Para uso asíncrono, usa `AsyncSPAAuth`.

```python title="usage"

import secrets
from frameio import Frameio
from frameio.auth import SPAAuth

auth = SPAAuth(client_id="YOUR_CLIENT_ID", redirect_uri="https://myapp.com/cb")
result = auth.get_authorization_url(state=secrets.token_urlsafe(32))
# redirect user to result.url, store result.code_verifier
auth.exchange_code(code="CODE_FROM_CALLBACK", code_verifier=result.code_verifier)
client = Frameio(token=auth.get_token)
```

**Parámetros**

`client_id`: `str` — ID de cliente OAuth de Adobe IMS.

`redirect_uri`: `str` — URI de redirección registrada.

`scopes`: `str` — Ámbitos separados por espacios (OAuth 2.0 RFC 6749).

`ims_base_url`: `str` — URL base de IMS para entornos de staging o alternativos. El valor predeterminado es producción.

`http_client`: `typing.Optional[httpx.Client]` — httpx.Client opcional para proxy, TLS o agrupación de conexiones.

`on_token_refreshed`: `typing.Optional[typing.Callable[[dict[str, Any]], None]]` — Callback opcional que se ejecuta después de cada actualización del token.

`timeout`: `float` — Tiempo de espera de la solicitud HTTP en segundos. El valor predeterminado es 30.

`max_retries`: `int` — Número máximo de reintentos ante errores transitorios. El valor predeterminado es 2.

`refresh_buffer`: `int` — Segundos antes de la caducidad para activar la actualización proactiva. El valor predeterminado es 60.

**Métodos**

`get_token() -> str` — Devuelve un token de acceso válido y lo actualiza si es necesario. Pasa la referencia a este método al SDK: `Frameio(token=auth.get_token)`.

`get_authorization_url(state: str) -> AuthorizationUrlResult` — Construye la URL de autorización de Adobe IMS con el desafío PKCE. Devuelve un `AuthorizationUrlResult` con los atributos `url` y `code_verifier`.

`refresh() -> dict[str, Any]` — Activa manualmente una actualización del token.

`revoke() -> None` — Revoca ambos tokens en el servidor y borra el estado local.

`export_tokens() -> dict[str, Any]` — Exporta el estado actual de los tokens para su persistencia.

`import_tokens(data: dict[str, Any]) -> None` — Restaura el estado de los tokens a partir de un dict exportado previamente.

Dataclass inmutable devuelta por `SPAAuth.get_authorization_url()` y `AsyncSPAAuth.get_authorization_url()`. Contiene la URL de autorización y el verificador de código PKCE.

#### Excepciones de autenticación {#auth-exceptions}

Todas las excepciones de autenticación heredan de `FrameioAuthError`.

| Excepción | Descripción |
| --- | --- |
| `FrameioAuthError` | Excepción base para todos los errores de `frameio.auth`. |
| `AuthenticationError` | Falló el intercambio o la actualización del token. Tiene los atributos `error_code` y `error_description`. |
| `TokenExpiredError` | El token de actualización ha caducado; es necesario volver a autenticarse. |
| `ConfigurationError` | Falta una configuración obligatoria o no es válida. |
| `NetworkError` | Falló la solicitud de red (tiempo de espera agotado, error de conexión, etc.). |
| `RateLimitError` | La API devolvió 429 y se agotaron los reintentos. Tiene el atributo `retry_after`. |
| `PKCEError` | Falló la verificación PKCE. |

#### Carga {#upload}

<AccordionGroup>

<Accordion title="frameio.upload.FrameioUploader(asset, file, ...)" defaultOpen={true}>

Carga un archivo local en Frame.io mediante las URL prefirmadas que devuelve `client.files.create_local_upload(...)`. `FrameioUploader` es un contenedor ligero que lee `upload_urls`, `file_size` y `media_type` de la respuesta `FileWithUploadUrls` y realiza una carga a S3 por fragmentos y multihilo.

```python title="usage"

from frameio import Frameio
from frameio.files import FileCreateLocalUploadParamsData
from frameio.upload import FrameioUploader

client = Frameio(
    token="YOUR_TOKEN",
)
response = client.files.create_local_upload(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    folder_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    data=FileCreateLocalUploadParamsData(
        file_size=1137444,
        name="asset.png",
    ),
)
with open("asset.png", "rb") as f:
    FrameioUploader(response.data, f).upload()
```

**Parámetros**

`asset`: `FileWithUploadUrls` — Una instancia de `FileWithUploadUrls` devuelta por `client.files.create_local_upload(...)`.

`file`: `typing.BinaryIO` — Un objeto de tipo archivo abierto en modo de lectura binaria (`"rb"`).

`max_workers`: `int` — Concurrencia del grupo de hilos que se transmite al cargador subyacente. El valor predeterminado es 5.

`headers`: `typing.Optional[typing.Dict[str, str]]` — Encabezados adicionales que se combinan en cada solicitud PUT a S3. El valor predeterminado es `{"x-amz-acl": "private"}`, tal como exige Frame.io.

`max_retries`: `int` — Número de reintentos por fragmento. El valor predeterminado es 3.

`on_progress`: `typing.Optional[typing.Callable[[int, int], None]]` — Callback opcional que se invoca después de cada fragmento con `(bytes_uploaded_so_far, total_bytes)`.

**Métodos**

`upload() -> None` — Carga el archivo. Bloquea la ejecución hasta completarse o lanza una excepción si se produce un error.
