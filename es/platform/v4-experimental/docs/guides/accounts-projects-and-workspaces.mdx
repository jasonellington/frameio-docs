## Acceso para todas las cuentas {#all-account-access}

Todas las cuentas de Frame V4 —no solo las gestionadas a través de Adobe Admin Console— pueden crear tokens y acceder a la API V4. Los clientes y partners pueden probar, crear y perfeccionar sus flujos de trabajo con nuestras funciones de API más recientes.

<Steps>

<Step title="Crear un token de autenticación de usuario">

Visita Adobe Developer Console para crear un token de autenticación de usuario. El usuario debe usar el mismo Adobe ID que utiliza para iniciar sesión en Frame para validar el acceso del token de API.

</Step>

<Step title="Crear credenciales de API">

Una vez que tengas acceso a las API, el siguiente paso es crear credenciales de API, o un token de API, para comunicarte con Frame. Crea tus credenciales de API en developer.adobe.com.

</Step>

</Steps>

![Acceso a la cuenta](/images/platform/docs/guides/accounts-projects-and-workspaces/706a4eb9324bc24a3465388a838455baf58384f128882a185dad2d1900f728a3.webp)

<Info>

Todas las cuentas V4, ya estén gestionadas por Frame (V4F) o por Adobe (V4A), pueden crear un Project en Adobe Developer Console y, después, crear credenciales. Una vez que tengas un conjunto de credenciales (Client ID/Client Secret de OAuth), puedes integrarte con el flujo OAuth de tres vías (three-legged) de Adobe Developer Platform. ¡Inicia sesión con tu Adobe Identity para recibir un token de autenticación y un token de actualización válidos y realizar solicitudes a la API para desarrolladores de Frame.io V4!

</Info>

## Proyectos y workspaces {#projects-and-workspaces}

### Novedades de los workspaces {#workspace-updates}

La página de inicio de Frame.io es nueva y se llama página de Workspace. Los usuarios pueden explorar los Workspaces y Projects a los que tienen acceso en una cuenta. Gracias a este nuevo diseño, es más fácil ver quién pertenece a un Workspace determinado e invitar rápidamente a nuevas personas.

<Note>

En Frame V3, los Workspaces se conocían como Teams.

</Note>

En V4, los Workspaces están configurados como "solo por invitación", por lo que los usuarios solo verán los Workspaces a los que se les haya invitado explícitamente. Además, no hay ninguna página de directorio de Teams en la configuración de la cuenta.

Para gestionar los permisos y las operaciones relacionadas, usa los endpoints Create, List, Delete y Update de Workspace.

- Actualizar los roles de usuario del workspace indicado si el usuario ya se ha añadido al workspace. Si el usuario no se ha añadido al workspace, se añadirá con el rol indicado.

### Novedades de los proyectos {#project-updates}

El flujo de creación de Projects ha cambiado en V4. Ahora, al iniciar un nuevo Project, puedes elegir entre un Project en blanco o una plantilla de Project. Hay doce plantillas para elegir, diseñadas para flujos de trabajo creativos habituales. También puedes optar por incluir los assets de demostración de la plantilla o empezar solo con la estructura de la plantilla. Al elegir una plantilla de Project, se crea inmediatamente un nuevo Project en tu Workspace.

Para gestionar los permisos y las operaciones relacionadas, usa los endpoints Create, List, Delete y Update de Project.
