## Camera To Cloud {#camera-to-cloud}

La API Camera to Cloud ofrece un protocolo de autenticación sencillo diseñado para dispositivos con capacidades de pantalla limitadas. Una vez autenticado, tu dispositivo puede subir los datos del rodaje directamente a la nube. El sistema admite la mayoría de los formatos de archivo estándar de vídeo, audio, LUT/CDL y datos de código de tiempo. Para obtener más información sobre las conexiones con certificación C2C, visita nuestra [página informativa](https://frame.io/c2c/certified).

## Paquete para desarrolladores {#developer-package}

Tu paquete de desarrollo incluirá:

**1. Client Secret**

Frame.io creará un modelo de configuración para tu dispositivo en nuestro backend. Una vez completado, recibirás un `client_secret` para tu dispositivo, habitualmente denominado identificador del modelo de dispositivo.

**2. Implementación de referencia**

Recibirás una implementación de referencia en Python con código esqueleto que emula dispositivos de hardware mediante una herramienta de CLI. Incluye código comentado y documentación que describe los pasos clave de la integración.

**3. Proceso de validación**

Antes del lanzamiento, participarás en un proceso de control de calidad con ingenieros de Frame.io para garantizar que tu dispositivo funciona como se espera. Nuestro objetivo es ayudar a todos los integradores a alcanzar estándares de calidad coherentes para los usuarios finales que trabajan con tu dispositivo conectado a la nube. Esto te proporciona comentarios valiosos antes del lanzamiento público. Te proporcionaremos una lista de elementos que revisar, pero también puedes consultar nuestra [lista de comprobación de integración C2C](/es/camera-to-cloud/integrator-checklist) para entender qué hace que una integración tenga éxito.

**4. Materiales de soporte**

Recibirás materiales que ayudarán a tu equipo a comprender la propuesta de valor de Frame.io y las técnicas de demostración, además de acceso a un canal de Slack dedicado para trabajar con nuestro equipo. Si necesitas asistencia adicional (como una demostración de la plataforma Frame.io o un taller sobre prácticas recomendadas de integración), avísanos y organizaremos las sesiones adecuadas.

## Planificar tu integración {#planning-your-integration}

Antes o durante tus conversaciones con nuestro equipo, habrá que abordar varios detalles técnicos. No es necesario que tengas toda esta información preparada antes de contactarnos: esta descripción general tiene como objetivo ayudarte a empezar a pensar en estos aspectos.

### Información del dispositivo {#device-information}

Necesitaremos cierta información básica sobre tu dispositivo:

* El nombre exacto de tu dispositivo
* Un logotipo en formato SVG, preferiblemente monocromático

### Método de autenticación {#authentication-method}

Ahora solo admitimos el flujo de autenticación con código de 6 dígitos. Para las aplicaciones, ofrecemos un método mejorado que utiliza un parámetro de encabezado especial al solicitar un código de dispositivo para habilitar nuestro flujo de emparejamiento por URL. Este devuelve los parámetros `verification_uri_complete` o `verification_uri`, que puedes usar para generar una URL mediante un hipervínculo o un código QR que los usuarios puedan tocar o escanear. Esto inicia un proceso de emparejamiento simplificado que se conecta directamente al proyecto seleccionado por el usuario. Para conocer los detalles de implementación, consulta la [guía para habilitar el emparejamiento mediante código QR](/es/camera-to-cloud/implementing-c2c-authentication-and-authorization#h3-section-enabling-qr-code-pairing).

## Colaboración de marketing {#marketing-collaboration}

Cada nueva integración de Cloud Devices ofrece soluciones innovadoras a los desafíos de los flujos de trabajo creativos. Valoramos la importante inversión que supone desarrollar y lanzar tu integración.

Para fomentar su adopción, trabajaremos contigo para crear recursos destinados a nuestros clientes y al mercado en general. Aunque los enfoques de marketing se adaptan a cada integración, las actividades habituales incluyen:

* Trabajar con nuestro equipo de Soluciones para diseñar y documentar casos de uso y flujos de trabajo óptimos
* Colaborar con clientes comunes para desarrollar casos de éxito que muestren tu integración en producción
* Crear materiales de ventas para que nuestro equipo pueda poner en contacto a los usuarios con tu dispositivo y tus soluciones de flujo de trabajo
