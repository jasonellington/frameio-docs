## Introducción {#introduction}

Antes de implementar tu dispositivo Camera to Cloud, asegurémonos de que tienes todo lo necesario para tener éxito.

## Registrarse como desarrollador {#register-as-a-developer}

Necesitarás un `client_secret` para tu dispositivo para poder seguir las guías de implementación. Si aún no lo has hecho, revisa nuestra [guía de introducción](/es/camera-to-cloud/getting-started-with-cloud-device-integrations) para obtener información sobre cómo registrarte como desarrollador de C2C. Nuestro equipo te proporcionará las credenciales necesarias para interactuar con la API.

## Herramientas para seguir las guías de implementación {#tools-for-following-implementation-guides}

Aunque no son estrictamente necesarias, tener estas herramientas disponibles te ayudará a seguir nuestros tutoriales y a probar directamente las interacciones con la API.

### cURL {#curl}

Estos tutoriales muestran solicitudes a la API de Frame.io mediante `curl`. Esta biblioteca de uso generalizado proporciona una excelente interfaz de línea de comandos para realizar solicitudes HTTP. Al implementar tu dispositivo, tendrás que replicar estas llamadas HTTP en tu lenguaje de programación preferido. Usar `curl` en estos ejemplos te permite probar las interacciones con la API simplemente copiando los comandos en tu terminal.

Para verificar que `curl` está instalado en tu sistema, introduce este comando en tu terminal:

```shell
curl --version
```

Deberías ver una salida similar a esta:

```text
curl 7.64.1 (x86_64-apple-darwin20.0) libcurl/7.64.1 (SecureTransport) LibreSSL/2.8.3 zlib/1.2.11 nghttp2/1.41.0
Release-Date: 2019-03-27
Protocols: dict file ftp ftps gopher http https imap imaps ldap ldaps pop3 pop3s rtsp smb smbs smtp smtps telnet tftp 
Features: AsynchDNS GSS-API HTTP2 HTTPS-proxy IPv6 Kerberos Largefile libz MultiSSL NTLM NTLM_WB SPNEGO SSL UnixSockets
```

Si no está instalado, puedes encontrar instaladores para la mayoría de los sistemas operativos [aquí](https://curl.se/download.html). Los usuarios de MacOS o Linux pueden instalarlo mediante [Homebrew](https://brew.sh/):

```shell
brew install curl
```

### Python {#python}

Usaremos Python para formatear los payloads de respuesta JSON, canalizando los resultados de `curl` de esta forma:

```shell
curl https://api.frame.io/health | python -m json.tool
```

Para comprobar si Python está instalado:

```shell
python --version
```

Salida esperada:

```text
Python 2.7.16
```

Si no está instalado, puedes [descargar Python aquí](https://www.python.org/downloads/). Python 2.6+ o Python 3.x funcionarán para estos ejemplos.

Aunque Python no es obligatorio, ayuda a que las respuestas sean más legibles. Como alternativa, herramientas como [jq](https://stedolan.github.io/jq/) ofrecen una funcionalidad similar.
