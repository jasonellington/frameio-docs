## Wprowadzenie {#introduction}

Zanim zaimplementujesz swoje urządzenie Camera to Cloud, upewnijmy się, że masz wszystko, czego potrzebujesz do osiągnięcia sukcesu.

## Zarejestruj się jako deweloper {#register-as-a-developer}

Aby korzystać z przewodników implementacji, Twoje urządzenie będzie potrzebować `client_secret`. Jeśli jeszcze tego nie zrobiłeś, zapoznaj się z naszym [przewodnikiem wprowadzającym](/pl/camera-to-cloud/getting-started-with-cloud-device-integrations), aby uzyskać informacje o rejestracji jako deweloper C2C. Nasz zespół dostarczy dane uwierzytelniające niezbędne do interakcji z API.

## Narzędzia do pracy z przewodnikami implementacji {#tools-for-following-implementation-guides}

Choć nie są one bezwzględnie wymagane, te narzędzia pomogą Ci śledzić nasze samouczki i bezpośrednio testować interakcje z API.

### cURL {#curl}

Te samouczki demonstrują żądania do API Frame.io z użyciem `curl`. Ta powszechnie używana biblioteka zapewnia doskonały interfejs wiersza poleceń do wykonywania żądań HTTP. Podczas implementacji urządzenia musisz odtworzyć te wywołania HTTP w wybranym przez siebie języku programowania. Użycie `curl` w tych przykładach pozwala testować interakcje z API przez proste skopiowanie poleceń do terminala.

Aby sprawdzić, czy `curl` jest zainstalowany w Twoim systemie, wpisz w terminalu następujące polecenie:

```shell
curl --version
```

Powinieneś zobaczyć wynik podobny do tego:

```text
curl 7.64.1 (x86_64-apple-darwin20.0) libcurl/7.64.1 (SecureTransport) LibreSSL/2.8.3 zlib/1.2.11 nghttp2/1.41.0
Release-Date: 2019-03-27
Protocols: dict file ftp ftps gopher http https imap imaps ldap ldaps pop3 pop3s rtsp smb smbs smtp smtps telnet tftp 
Features: AsynchDNS GSS-API HTTP2 HTTPS-proxy IPv6 Kerberos Largefile libz MultiSSL NTLM NTLM_WB SPNEGO SSL UnixSockets
```

Jeśli nie jest zainstalowany, instalatory dla większości systemów operacyjnych znajdziesz [tutaj](https://curl.se/download.html). Użytkownicy macOS lub Linuksa mogą zainstalować go za pomocą [Homebrew](https://brew.sh/):

```shell
brew install curl
```

### Python {#python}

Będziemy używać Pythona do formatowania ładunków odpowiedzi JSON, przekierowując do niego wyniki `curl`:

```shell
curl https://api.frame.io/health | python -m json.tool
```

Aby sprawdzić, czy Python jest zainstalowany:

```shell
python --version
```

Oczekiwany wynik:

```text
Python 2.7.16
```

Jeśli nie jest zainstalowany, możesz [pobrać Pythona tutaj](https://www.python.org/downloads/). W tych przykładach zadziała Python 2.6+ lub Python 3.x.

Choć Python nie jest wymagany, pomaga w uczynieniu odpowiedzi bardziej czytelnymi. Alternatywnie podobną funkcjonalność zapewniają narzędzia takie jak [jq](https://stedolan.github.io/jq/).
