### Użycie {#usage}

Utwórz instancję klienta i używaj go w następujący sposób:

```python
from frameio import (
    Frameio,
    SelectDefinitionParamsFieldConfiguration,
    SelectDefinitionParamsFieldConfigurationOptionsItem,
)
from frameio.metadata_fields import CreateFieldDefinitionParamsData_Select

client = Frameio(
    token="YOUR_TOKEN",
)
client.metadata_fields.metadata_field_definitions_create(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    data=CreateFieldDefinitionParamsData_Select(
        field_configuration=SelectDefinitionParamsFieldConfiguration(
            enable_add_new=False,
            options=[
                SelectDefinitionParamsFieldConfigurationOptionsItem(
                    display_name="Option 1",
                ),
                SelectDefinitionParamsFieldConfigurationOptionsItem(
                    display_name="Option 2",
                ),
            ],
        ),
        name="Fields definition name",
    ),
)
```

### Klient asynchroniczny {#async-client}

SDK eksportuje również klienta asynchronicznego, dzięki któremu możesz wykonywać nieblokujące wywołania naszego API. Pamiętaj, że jeśli tworzysz klasę asynchronicznego klienta httpx, aby przekazać ją do tego klienta, użyj httpx.AsyncClient() zamiast httpx.Client() (np. dla parametru httpx_client tego klienta).

```python
import asyncio

from frameio import (
    AsyncFrameio,
    SelectDefinitionParamsFieldConfiguration,
    SelectDefinitionParamsFieldConfigurationOptionsItem,
)
from frameio.metadata_fields import CreateFieldDefinitionParamsData_Select

client = AsyncFrameio(
    token="YOUR_TOKEN",
)


async def main() -> None:
    await client.metadata_fields.metadata_field_definitions_create(
        account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
        data=CreateFieldDefinitionParamsData_Select(
            field_configuration=SelectDefinitionParamsFieldConfiguration(
                enable_add_new=False,
                options=[
                    SelectDefinitionParamsFieldConfigurationOptionsItem(
                        display_name="Option 1",
                    ),
                    SelectDefinitionParamsFieldConfigurationOptionsItem(
                        display_name="Option 2",
                    ),
                ],
            ),
            name="Fields definition name",
        ),
    )


asyncio.run(main())
```

### Obsługa wyjątków {#exception-handling}

Gdy API zwróci kod statusu oznaczający niepowodzenie (odpowiedź 4xx lub 5xx), zostanie zgłoszony wyjątek będący podklasą poniższego błędu.

```python
from frameio.core.api_error import ApiError

try:
    client.metadata_fields.metadata_field_definitions_create(...)
except ApiError as e:
    print(e.status_code)
    print(e.body)
```

### Paginacja {#pagination}

Żądania z paginacją zwracają obiekt SyncPager lub AsyncPager, którego można używać jako generatora bazowych obiektów.

```python
from frameio import Frameio

client = Frameio(
    token="YOUR_TOKEN",
)
response = client.project_permissions.index(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    project_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    page_size=10,
    include_total_count=False,
)
for item in response:
    yield item
# alternatively, you can paginate page-by-page
for page in response.iter_pages():
    yield page
```

### Zaawansowane {#advanced}

#### Dostęp do surowych danych odpowiedzi {#access-raw-response-data}

SDK zapewnia dostęp do surowych danych odpowiedzi, w tym nagłówków, za pośrednictwem właściwości .with_raw_response. Właściwość .with_raw_response zwraca „surowego” klienta, za pomocą którego można uzyskać dostęp do atrybutów .headers i .data.

```python
from frameio import Frameio

client = Frameio(
    ...,
)
response = (
    client.metadata_fields.with_raw_response.metadata_field_definitions_create(
        ...
    )
)
print(response.headers)  # access the response headers
print(response.data)  # access the underlying object
pager = client.project_permissions.index(...)
print(pager.response.headers)  # access the response headers for the first page
for item in pager:
    print(item)  # access the underlying object(s)
for page in pager.iter_pages():
    print(page.response.headers)  # access the response headers for each page
    for item in page:
        print(item)  # access the underlying object(s)
```

#### Ponawianie żądań {#retries}

SDK ma wbudowane automatyczne ponawianie żądań z wykładniczym wydłużaniem odstępów (exponential backoff). Żądanie będzie ponawiane, dopóki zostanie uznane za kwalifikujące się do ponowienia, a liczba prób nie przekroczy skonfigurowanego limitu ponowień (domyślnie: 2).<br />
Żądanie jest uznawane za kwalifikujące się do ponowienia, gdy zostanie zwrócony którykolwiek z poniższych kodów statusu HTTP:

- 408 (Przekroczenie limitu czasu)
- 429 (Zbyt wiele żądań)
- 5XX (Wewnętrzne błędy serwera)

<br />

Aby skonfigurować to zachowanie, użyj opcji żądania `max_retries`.

```python
client.metadata_fields.metadata_field_definitions_create(..., request_options={
    "max_retries": 1
})
```

---

#### Limity czasu {#timeouts}

Domyślny limit czasu w SDK wynosi 60 sekund. Możesz go skonfigurować za pomocą opcji timeout na poziomie klienta lub żądania.

```python
from frameio import Frameio

client = Frameio(
    ...,
    timeout=20.0,
)


# Override timeout for a specific method
client.metadata_fields.metadata_field_definitions_create(..., request_options={
    "timeout_in_seconds": 1
})
```

---

#### Klient niestandardowy {#custom-client}

Możesz zastąpić klienta httpx, aby dostosować go do swoich potrzeb. Typowe zastosowania obejmują obsługę serwerów proxy i niestandardowych transportów.

```python
import httpx
from frameio import Frameio

client = Frameio(
    ...,
    httpx_client=httpx.Client(
        proxy="http://my.test.proxy.example.com",
        transport=httpx.HTTPTransport(local_address="0.0.0.0"),
    ),
)
```

<Accordion title="frameio.auth.ServerToServerAuth(*, client_id, client_secret, ...)" defaultOpen={true}>

Uwierzytelnianie z użyciem przepływu OAuth 2.0 client_credentials. Ten przepływ nie angażuje użytkownika i nie zwraca tokenu odświeżania. Gdy token dostępu wygaśnie, SDK automatycznie zażąda nowego, używając danych uwierzytelniających klienta. W przypadku użycia asynchronicznego użyj `AsyncServerToServerAuth`.

```python title="usage"

from frameio import Frameio
from frameio.auth import ServerToServerAuth

auth = ServerToServerAuth(client_id="YOUR_CLIENT_ID", client_secret="YOUR_CLIENT_SECRET")
client = Frameio(token=auth.get_token)
```

**Parametry**

`client_id`: `str` — Identyfikator klienta OAuth Adobe IMS.

`client_secret`: `str` — Klucz tajny klienta OAuth Adobe IMS.

`scopes`: `str` — Zakresy oddzielone spacjami (OAuth 2.0 RFC 6749). Domyślnie `openid AdobeID frame.s2s.all`.

`ims_base_url`: `str` — Bazowy adres URL IMS dla środowisk testowych/alternatywnych. Domyślnie środowisko produkcyjne.

`http_client`: `typing.Optional[httpx.Client]` — Opcjonalny httpx.Client do obsługi proxy, TLS lub puli połączeń.

`on_token_refreshed`: `typing.Optional[typing.Callable[[dict[str, Any]], None]]` — Opcjonalne wywołanie zwrotne uruchamiane po każdym pobraniu tokenu.

`timeout`: `float` — Limit czasu żądania HTTP w sekundach. Domyślnie 30.

`max_retries`: `int` — Maksymalna liczba ponowień w przypadku przejściowych błędów. Domyślnie 2.

`refresh_buffer`: `int` — Liczba sekund przed wygaśnięciem, po której następuje proaktywne odświeżenie. Domyślnie 60.

**Metody**

`get_token() -> str` — Zwraca ważny token dostępu, odświeżając go w razie potrzeby. Przekaż do SDK referencję do tej metody (a nie jej wywołanie): `Frameio(token=auth.get_token)`.

`authenticate() -> dict[str, Any]` — Jawnie pobiera nowy token dostępu. Zwraca słownik odpowiedzi tokenu zawierający `access_token`, `expires_in` itd.

`revoke() -> None` — Unieważnia oba tokeny po stronie serwera i czyści stan lokalny.

`export_tokens() -> dict[str, Any]` — Eksportuje bieżący stan tokenów w celu jego trwałego zapisania.

`import_tokens(data: dict[str, Any]) -> None` — Przywraca stan tokenów z wcześniej wyeksportowanego słownika.

</Accordion>

<Accordion title="frameio.auth.SPAAuth(*, client_id, redirect_uri, ...)">

Uwierzytelnianie z użyciem authorization_code + PKCE (bez klucza tajnego klienta). Używaj go w aplikacjach przeglądarkowych lub natywnych, które nie mogą bezpiecznie przechowywać klucza tajnego klienta. W przypadku użycia asynchronicznego użyj `AsyncSPAAuth`.

```python title="usage"

import secrets
from frameio import Frameio
from frameio.auth import SPAAuth

auth = SPAAuth(client_id="YOUR_CLIENT_ID", redirect_uri="https://myapp.com/cb")
result = auth.get_authorization_url(state=secrets.token_urlsafe(32))
# redirect user to result.url, store result.code_verifier
auth.exchange_code(code="CODE_FROM_CALLBACK", code_verifier=result.code_verifier)
client = Frameio(token=auth.get_token)
```

**Parametry**

`client_id`: `str` — Identyfikator klienta OAuth Adobe IMS.

`redirect_uri`: `str` — Zarejestrowany identyfikator URI przekierowania.

`scopes`: `str` — Zakresy oddzielone spacjami (OAuth 2.0 RFC 6749).

`ims_base_url`: `str` — Bazowy adres URL IMS dla środowisk testowych/alternatywnych. Domyślnie środowisko produkcyjne.

`http_client`: `typing.Optional[httpx.Client]` — Opcjonalny httpx.Client do obsługi proxy, TLS lub puli połączeń.

`on_token_refreshed`: `typing.Optional[typing.Callable[[dict[str, Any]], None]]` — Opcjonalne wywołanie zwrotne uruchamiane po każdym odświeżeniu tokenu.

`timeout`: `float` — Limit czasu żądania HTTP w sekundach. Domyślnie 30.

`max_retries`: `int` — Maksymalna liczba ponowień w przypadku przejściowych błędów. Domyślnie 2.

`refresh_buffer`: `int` — Liczba sekund przed wygaśnięciem, po której następuje proaktywne odświeżenie. Domyślnie 60.

**Metody**

`get_token() -> str` — Zwraca ważny token dostępu, odświeżając go w razie potrzeby. Przekaż do SDK referencję do tej metody: `Frameio(token=auth.get_token)`.

`get_authorization_url(state: str) -> AuthorizationUrlResult` — Tworzy adres URL autoryzacji Adobe IMS z wyzwaniem PKCE. Zwraca obiekt `AuthorizationUrlResult` z atrybutami `url` i `code_verifier`.

`exchange_code(code: str, code_verifier: str) -> dict[str, Any]` — Wymienia kod autoryzacji + weryfikator PKCE na tokeny.

`refresh() -> dict[str, Any]` — Ręcznie wyzwala odświeżenie tokenu.

`revoke() -> None` — Unieważnia oba tokeny po stronie serwera i czyści stan lokalny.

`export_tokens() -> dict[str, Any]` — Eksportuje bieżący stan tokenów w celu jego trwałego zapisania.

`import_tokens(data: dict[str, Any]) -> None` — Przywraca stan tokenów z wcześniej wyeksportowanego słownika.

</Accordion>

<Accordion title="frameio.auth.AuthorizationUrlResult">

Niemutowalna klasa danych (frozen dataclass) zwracana przez `SPAAuth.get_authorization_url()` i `AsyncSPAAuth.get_authorization_url()`. Przechowuje adres URL autoryzacji i weryfikator kodu PKCE.

**Atrybuty**

`url`: `str` — Pełny adres URL autoryzacji, na który należy przekierować użytkownika.

`code_verifier`: `str` — Weryfikator kodu PKCE, który należy zapisać i przekazać do `exchange_code()`.

</Accordion>

#### Wyjątki uwierzytelniania {#auth-exceptions}

Wszystkie wyjątki uwierzytelniania dziedziczą po `FrameioAuthError`.

| Wyjątek | Opis |
| --- | --- |
| `FrameioAuthError` | Bazowy wyjątek dla wszystkich błędów `frameio.auth`. |
| `AuthenticationError` | Wymiana lub odświeżenie tokenu nie powiodło się. Ma atrybuty `error_code` i `error_description`. |
| `TokenExpiredError` | Token odświeżania wygasł; wymagane jest ponowne uwierzytelnienie. |
| `ConfigurationError` | Brak wymaganej konfiguracji lub jest ona nieprawidłowa. |
| `NetworkError` | Żądanie sieciowe nie powiodło się (przekroczenie limitu czasu, błąd połączenia itp.). |
| `RateLimitError` | API zwróciło kod 429, a limit ponowień został wyczerpany. Ma atrybut `retry_after`. |
| `PKCEError` | Weryfikacja PKCE nie powiodła się. |
