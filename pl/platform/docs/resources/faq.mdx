## Pytania dotyczące zgodności {#compatibility-questions}

<AccordionGroup>

<Accordion title="Czy API Frame.io V4 jest wstecznie zgodne?">

<Warning>

Nie. Produkt Frame.io wydany podczas Adobe MAX działa w zasadniczo inny sposób i kładzie nacisk na inne przepływy pracy niż starsza wersja. Ze względu na te różnice nowe API nie jest wstecznie zgodne.

</Warning>

</Accordion>

<Accordion title="Jak w przyszłości będzie zapewniana zgodność wsteczna?">

Zdając sobie sprawę, że zgodność wsteczna jest kluczowa dla klientów zarządzających produkcyjnymi integracjami o wysokich wymaganiach dotyczących dostępności, projektujemy API V4 tak, aby obsługiwało dodatkowy poziom wersjonowania za pomocą niestandardowego nagłówka HTTP. Pozwoli to klientom świadomie korzystać z eksperymentalnych endpointów, unikać zmian powodujących niezgodność i zapewni gwarancje zgodności wstecznej w przestrzeni nazw API `/v4`.

</Accordion>

<Accordion title="Czy po ogólnym udostępnieniu API V4 automatyzacje skonfigurowane w starszym produkcie będą nadal działać? Tzn. czy zostaną one automatycznie przeniesione do V4?">

<Warning>

Żadne automatyzacje korzystające ze starszych tokenów deweloperskich nie będą już działać na kontach V4. **Nie mamy** żadnej możliwości ich migracji do V4.

</Warning>

</Accordion>

</AccordionGroup>

<AccordionGroup>

API V4 jest obecnie dostępne dla nowych klientów Enterprise oraz wybranych klientów i partnerów za pośrednictwem kont testowych.

</Info>

</Accordion>

</AccordionGroup>

## Multimedia i pliki {#media-&-files}

<AccordionGroup>

<Accordion title="Jak długo ważne są adresy URL linków do multimediów?">

Adresy URL zwracane w `media_links` (takie jak `download_url`, `inline_url` i `url`) to **tymczasowe podpisane adresy URL** — wygasają i nie można ich używać w nieskończoność.

| Typ adresu URL | Wygaśnięcie |
| --- | --- |
| Adresy URL do pobierania i wyświetlania inline (`original`, `high_quality`, `efficient`, `video_h264_180`) | Do 24 godzin |
| Adresy URL miniatur i podglądów (`thumbnail`) | Do 24 godzin |

W praktyce wygaśnięcie jest wyrównane do południa lub północy UTC, więc rzeczywisty pozostały czas w chwili otrzymania adresu URL może wynosić od kilku minut do 24 godzin, w zależności od momentu wysłania żądania.

**Nie przechowuj tych adresów URL ani nie zapisuj ich w pamięci podręcznej.** Za każdym razem, gdy musisz udostępnić plik lub uzyskać do niego dostęp, pobieraj nowy zestaw `media_links`. Próba użycia wygasłego adresu URL spowoduje błąd `403` z CDN.

</Accordion>

</AccordionGroup>
