<Note>
  To jest demonstracyjny endpoint dla automatyzacji Mintlify Update from code changes. Nie jest częścią API Frame.io.
</Note>

Użyj tego endpointu, aby sprawdzić, czy przetwarzanie zasobu zostało zakończone.

## Pobieranie stanu zasobu {#get-an-asset’s-status}

```http
GET /v4/assets/{id}/status
```

### Parametry ścieżki {#path-parameters}

| Parametr | Typ    | Opis               |
| -------- | ------ | ------------------ |
| `id`     | string | Identyfikator zasobu. |

### Pola odpowiedzi {#response-fields}

| Pole          | Typ    | Opis                                              |
| ------------- | ------ | ------------------------------------------------- |
| `data.id`     | string | Identyfikator zasobu.                             |
| `data.status` | string | Stan przetwarzania: `processing` lub `ready`.     |

### Przykład {#example}

```bash
curl http://localhost:3001/v4/assets/a1b2c3/status
```

```json
{
  "data": {
    "id": "a1b2c3",
    "status": "ready"
  }
}
```

### Błędy {#errors}

| Status | Błąd              | Znaczenie                               |
| ------ | ----------------- | --------------------------------------- |
| `404`  | `asset_not_found` | Nie istnieje zasób o tym identyfikatorze. |
