## Podstawy odświeżania tokenów {#basics-of-token-refresh}

Zakładając, że w żądaniu danych uwierzytelniających OAuth2.0 uwzględniono zakres ***offline***, pomyślne uwierzytelnienie za pośrednictwem aplikacji Accounts Frame.io zwróci ładunek podobny do poniższego:

```json
{
  "access_token":"BEARER_TOKEN",
  "expires_in":3600,
  "refresh_token":"REFRESH_TOKEN",
  "scope":"account.read offline",
  "token_type":"bearer"
}
```

`access_token` to token typu bearer, za pomocą którego można działać w imieniu uwierzytelnionego użytkownika; wygasa on po 3600 sekundach (jednej godzinie), a po tym czasie można użyć `refresh_token`, aby pobrać nowy `access_token`. Token odświeżania wygasa z kolei po 30 dniach — wtedy użytkownik musi zalogować się od nowa, co generuje nową parę tokenów dostępu i odświeżania; i tak dalej.

Jeśli nie zażądasz jawnie zakresu *offline*, nie otrzymasz `refresh_token`, w związku z czym po godzinie konieczne będzie pełne ponowne uwierzytelnienie użytkownika.

### Przechwytywanie tokenu odświeżania po pomyślnym uwierzytelnieniu {#capturing-the-refresh-token-on-successful-authentication}

Rzecz jasna nie możesz użyć `refresh_token`, którego nie masz, więc upewnij się, że Twoja aplikacja:

- Żąda zakresu **offline**
- Przechwytuje `refresh_token` zwracany w pomyślnym wywołaniu zwrotnym.

Dla wygody poniżej przytaczamy wywołanie zwrotne z naszych [przewodników po aplikacjach OAuth 2](https://developer.frame.io/oauth-2-applications/building-an-oauth-2-app), uzupełnione o wywołanie `os` zapisujące token odświeżania. Zwróć uwagę, że podano dwa przykłady: jeden ze skonfigurowanym PKCE (bez nagłówka uwierzytelniania podstawowego) i jeden bez niego (z nagłówkiem uwierzytelniania podstawowego).

### Bez PKCE {#without-pkce}

```python title="Python"
def callback():
  # Where `request` refers to our initial call to the auth URL
  state = request.args.get('state')
  scope = request.args.get('scope')
  code = request.args.get('code')
  error = request.args.get('error')

  if error:
    return "Error: " + error

  # Set up for client authorization and set up the data you need to send.
  client_auth = requests.auth.HTTPBasicAuth(CLIENT_ID, CLIENT_SECRET)

  post_data = {
    "grant_type": "authorization_code",
    "code": code,
    "redirect_uri": REDIRECT_URI,
    "state": state,
    "scope": SCOPE
  }

  # Send a POST request with the data you need to receive an access token. 
  response = requests.post(TOKEN, auth=client_auth, data=post_data)    
	# Stash the refresh token for later
  os.environ['REFRESH_TOKEN'] = response.json()["refresh_token"]

  return response.text
```

### Z PKCE {#with-pkce}

```python title="Python"
def callback():
  # Where `request` refers to our initial call to the auth URL
  state = request.args.get('state')
  scope = request.args.get('scope')
  code = request.args.get('code')
  error = request.args.get('error')

  if error:
    return "Error: " + error

  # If using PKCE, you must include the CLIENT_ID in your request body  
  post_data = {
    "grant_type": "authorization_code",
    "code": code,
    "redirect_uri": REDIRECT_URI,
    "state": state,
    "scope": SCOPE
    "client_id": CLIENT_ID 
  }

  # Send a POST request with the data you need to receive an access token.
  # If using PKCE, use the below request with no auth
  response = requests.post(TOKEN_URL, data=post_data)
  # Stash the refresh token for later
  os.environ['REFRESH_TOKEN'] = response.json()["refresh_token"]

  return response.text
```

## Wykonywanie odświeżania {#executing-a-refresh}

Samo odświeżenie to pojedyncze wywołanie adresu URL tokenu Frame.io:

- Metoda: POST
- URL: **[https://applications.frame.io/oauth2/token](https://applications.frame.io/oauth2/token)**
- `Content-Type`: *application/x-www-form-urlencoded*

Żądanie odświeżenia zawsze zawiera w danych formularza co najmniej trzy następujące atrybuty:

- `grant_type`: *refresh_token*
- `scope`: &lt;SCOPES>
- `refresh_token`: &lt;REFRESH_TOKEN>

Jeśli używasz PKCE, musisz dołączyć do danych formularza `client_id` swojej aplikacji; jeśli nie, musisz dołączyć nagłówek uwierzytelniania podstawowego (Basic), w którym `client_id` i `client_secret` aplikacji pełnią odpowiednio rolę nazwy użytkownika i hasła.

### Bez PKCE {#without-pkce-1}

Podobnie jak w przypadku [wykonywania początkowego wywołania zwrotnego uwierzytelniania](https://developer.frame.io/oauth-2-applications/building-an-oauth-2-app#the-callback) bez PKCE, to standardowe odświeżenie wymaga podania `client_id` i `client_secret` jako nazwy użytkownika i hasła w nagłówku Basic Authentication.

```python title="Python"
def refresh():
  # Fetch the refresh token, assuming we have it
  REFRESH_TOKEN = os.environ.get('REFRESH_TOKEN')

  client_auth = requests.auth.HTTPBasicAuth(CLIENT_ID,CLIENT_SECRET)
  post_data = {
    "grant_type": "refresh_token",
    "scope": SCOPE,
    "refresh_token": REFRESH_TOKEN
    # if using PKCE, you will need to include your client_id as below
    # "client_id": CLIENT_ID 
  }

  response = requests.post(TOKEN_URL, auth=client_auth, data=post_data)
  # Catch + stash a new Refresh Token
  os.environ['REFRESH_TOKEN'] = response.json()["refresh_token"]

  return response.text
```

### Z PKCE {#with-pkce-1}

Ponownie odwzorowujemy zasady naszego początkowego cyklu `/callback`:

- Nie dołączamy nagłówka `Authorization`
- Musimy dołączyć `client_id` do ładunku

```python title="Python"
def refresh():
  # Fetch the refresh token, assuming we have it
  REFRESH_TOKEN = os.environ.get('REFRESH_TOKEN')

  post_data = {
    "grant_type": "refresh_token",
    "scope": SCOPE,
    "refresh_token": REFRESH_TOKEN
    "client_id": CLIENT_ID 
  }

  response = requests.post(TOKEN_URL, data=post_data)
  # Catch + stash a new Refresh Token
  os.environ['REFRESH_TOKEN'] = response.json()["refresh_token"]

  return response.text
```
