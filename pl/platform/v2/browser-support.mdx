# Obsługa różnych przeglądarek przy logowaniu do Frame.io {#cross-browser-support-for-frame-io-login}

Choć nie ma to znaczenia w przypadku aplikacji w pełni opartych na API, obsługa różnych przeglądarek przez Frame.io ma znaczenie podczas ładowania naszej [aplikacji Accounts](https://accounts.frame.io/) w trakcie przepływu przyznawania poświadczeń OAuth.

Pisząc aplikacje OAuth dla Frame.io, pamiętaj, że strona logowania wyświetlana w przepływie OAuth podlega tym samym zasadom obsługi przeglądarek co nasza główna aplikacja internetowa. Na potrzeby poniższej tabeli obsługa „Częściowa” oznacza, że wszystkie główne funkcje powinny działać bez przeszkód, ale mogą występować drobne problemy z układem. Obsługa „Minimalna” oznacza, że rozwiązanie może działać, ale nie testujemy go już ani nie wspieramy w sposób jawny.

| Przeglądarka | Obsługa |
| --- | --- |
| Chrome (najnowsza) | Pełna |
| Safari (najnowsza) | Pełna |
| Firefox (najnowsza) | Pełna |
| Opera (najnowsza) | Pełna |
| Edge (najnowsza) | Pełna |
| IE (11+) | Minimalna |
| IE (&lt;=10) | Brak |
| Mobile Safari (najnowsza) | Częściowa |
| Chrome na iOS (najnowsza) | Częściowa |
| Chrome na Androida (najnowsza) | Częściowa |
| Android Browser (najnowsza) | Częściowa |
