## O Frame.io {#about-frame-io}

[Frame.io](https://frame.io) to narzędzie do współpracy w chmurze dla profesjonalnych zespołów wideo — wszystko, czego potrzebujesz, aby proces twórczy przebiegał sprawnie, w jednym miejscu pracy, dostępnym z dowolnego miejsca. Dzięki Frame.io możesz bezpiecznie przesyłać, udostępniać i recenzować projekty filmowe, dzięki czemu cała Twoja działalność może toczyć się w tempie kreatywności.

### Frame.io Developer Platform {#frame-io-developer-platform}

Nie każdy zespół kreatywny, proces czy zestaw oprogramowania jest taki sam. Właśnie tu z pomocą przychodzi nasza platforma deweloperska. Frame.io Developer Platform pozwala wykonywać typowe zadania za pomocą naszego API. Do popularnych zastosowań naszego API należą m.in. automatyczne dodawanie istniejących plików lub folderów do aplikacji Frame.io, przesyłanie nowych treści oraz zarządzanie zespołami.

## Przewodnik szybkiego startu {#quick-start-guide}

Jeśli chcesz zacząć od razu, kliknij ten przycisk, aby zaimportować nasze API do Postmana!

[![Run in Postman](/images/platform/v2/index/button.svg)](https://www.getpostman.com/collections/c2dfffb88990a9dc34c2)

W przeciwnym razie czytaj dalej. Na początek upewnij się, że masz konto Frame.io, na które możesz się zalogować.

Następnie:

- [Zaloguj się do Developer Portal](/pl/platform/v2) przy użyciu swoich danych logowania Frame.io
- [Utwórz token deweloperski](/pl/platform/v2/authentication#developer-tokens)

Aby sprawdzić, czy token działa, wykonaj wywołanie testowe przy użyciu wybranego języka, narzędzia lub proxy:

<CodeGroup>

```bash title="cURL"
curl --request GET \
  --url https://api.frame.io/v2/me \
  --header 'authorization: Bearer <DEV_TOKEN>'
```

```python title="Python"
import requests

url = "https://api.frame.io/v2/me"
headers = {
 "Authorization": "Bearer <DEV_TOKEN>"
}

requests.GET(url,headers=headers)
```

</CodeGroup>

W odpowiedzi powinny pojawić się informacje o Twoim użytkowniku.

## Przepływy pracy oparte na zdarzeniach {#event-based-workflows}

Frame.io Developer Platform oferuje kilka opcji, dzięki którym możesz rozszerzyć swoje przepływy pracy na inne narzędzia lub tworzyć zupełnie nowe funkcje.

### Webhooki {#webhooks}

Webhooki pozwalają przekształcać zdarzenia zachodzące w Frame.io w powiadomienia, które można wysyłać do systemów zewnętrznych w celu przetwarzania, wywołań zwrotnych API i automatyzacji przepływów pracy.

Z naszych webhooków można korzystać na wiele sposobów. Możesz zbudować coś samodzielnie albo skorzystać z narzędzia do automatyzacji bez kodu, takiego jak [Zapier](https://zapier.com), [Integromat](https://www.integromat.com), [Pabbly Connect](https://www.pabbly.com/) lub [Pipedream](https://pipedream.com).

- [Webhooki](/pl/platform/v2/webhooks-overview) — Webhooki udostępniają zdarzenia Frame.io zewnętrznym adresom URL do odbioru i przetwarzania.
- [Zapier](/pl/platform/v2/get-started-with-zapier) — Internetowe narzędzie do automatyzacji, które pozwala połączyć ponad 1000 popularnych aplikacji i narzędzi bez pisania kodu.

Na GitHubie udostępniamy [przykładową aplikację do webhooków](https://github.com/Frameio/webhooks-example-app), której możesz użyć jako punktu wyjścia, jeśli chcesz zbudować własny odbiornik.

### Akcje niestandardowe {#custom-actions}

[Akcje niestandardowe (Custom Actions)](/pl/platform/v2/custom-actions-overview) pozwalają budować integracje bezpośrednio w Frame.io jako programowalne komponenty interfejsu użytkownika. Pod względem technicznym są bardzo podobne do webhooków i stanowią świetny sposób na rozszerzenie przepływów pracy w Frame.io.
