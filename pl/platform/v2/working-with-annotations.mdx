# Przegląd {#overview}

Adnotacje we Frame.io są reprezentowane jako zserializowany blob JSON zawierający obiekty rysunkowe wraz z ich kolorami, współrzędnymi i rozmiarami. W tym blobie wszystkie cudzysłowy poza zewnętrzną parą są poprzedzone ukośnikami (np. `\"key\":\"value\"`).

Istnieją trzy podstawowe kształty — **arrow**, **rect** i **line** — a także rysunek odręczny, który wykracza poza zakres tego przewodnika, ale opiera się na tych samych podstawowych zasadach zserializowanych danych współrzędnych.

## Układ współrzędnych {#the-coordinate-system}

Wszystkie kształty są umieszczane w kartezjańskim układzie współrzędnych z początkiem w lewym górnym rogu i skalą od 0 do 1 na każdej osi.

![coordinate_plane.png](/images/platform/v2/working-with-annotations/099478340a4f8604fd4389c5d431ec9e9321f509f2d6055b0c92dd62e4e36147.webp)

## Podstawowe dane kształtów {#basic-shape-data}

Wszystkie kształty są umieszczane na powyższej płaszczyźnie za pomocą kombinacji współrzędnych i danych stylu. Każdy kształt ma pewne wspólne atrybuty, a ponadto każdy w nieco inny sposób korzysta z układu współrzędnych.

Wszystkie atrybuty odległości/szerokości/wysokości używają tej samej skali od 0 do 1 co główna siatka współrzędnych, ale zazwyczaj są mierzone od punktu początkowego kształtu.

Innymi słowy, jeśli wideo jest wyświetlane w obszarze 640x480, `x=1` będzie w tym kontekście odpowiadać bezwzględnej wartości 640 px. Dzięki temu adnotacje płynnie się skalują, zachowując swoją względną pozycję przy zmianie ekranu, rozmiaru i kontekstu wyświetlania.

**Uwaga**: początkiem kształtu *rect* jest zawsze lewy górny róg kształtu, niezależnie od punktu, od którego rozpoczęto rysowanie.

### Wspólne atrybuty {#common-attributes}

| Atrybut | Opis |
| --- | --- |
| `tool` | *arrow*, *rect* lub *line*. Określa, jaki kształt jest tworzony. |
| `color` | Sześciocyfrowy kolor szesnastkowy kształtu. |
| `size` | Grubość linii kształtu w pikselach. W przypadku strzałek dotyczy to tylko początku linii, ponieważ szerokość końcowa jest ustalana programowo. |

### Arrow {#arrow}

| Atrybut | Opis |
| :--- | :--- |
| `x` | Współrzędna x początku strzałki. |
| `y` | Współrzędna y początku strzałki. |
| `w` | Różnica położenia strzałki na osi y od początku do końca, względem początku strzałki. |
| `h` | Różnica położenia strzałki na osi x od początku do końca, względem początku strzałki. |

### Rect {#rect}

| Atrybut | Opis |
| :--- | :--- |
| `x` | Współrzędna x lewego górnego rogu prostokąta. |
| `y` | Współrzędna y lewego górnego rogu prostokąta. |
| `w` | Szerokość prostokąta względem jego lewego górnego rogu. |
| `h` | Wysokość prostokąta względem jego lewego górnego rogu. |
| `ix` | Współrzędna x punktu, od którego rozpoczęto rysowanie prostokąta. (Opcjonalne). |
| `iy` | Współrzędna y punktu, od którego rozpoczęto rysowanie prostokąta. (Opcjonalne). |
| `radius` | Promień zaokrąglenia narożników prostokąta. Musi być dodatni. Wartości powyżej 150 są wizualnie nierozróżnialne. |

### Line {#line}

| Atrybut | Opis |
| :--- | :--- |
| `x1` | Współrzędna x początku linii. |
| `y1` | Współrzędna y początku linii. |
| `x2` | Współrzędna x końca linii. Wartość bezwzględna na płaszczyźnie obrazu. |
| `y2` | Współrzędna y końca linii. Wartość bezwzględna na płaszczyźnie obrazu. |
