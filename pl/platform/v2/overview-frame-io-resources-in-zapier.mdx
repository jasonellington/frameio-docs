# Poruszanie się po danych zasobów {#navigating-resource-data}

Ładunki naszego API są bardzo rozbudowane! Oznacza to (na przykład), że gdy przechwytujesz zmianę w polu Status Label zasobu, możesz zobaczyć mnóstwo pól, z których tylko nieliczne będą dla Ciebie od razu istotne.

![Przykłady pól](/images/platform/v2/overview-frame-io-resources-in-zapier/96b556247084aa9ced664a076acc8e22da0c44c5def47b9147b2c0c968964aec.webp)

Dobra wiadomość jest taka, że wszystkie pola wprowadzania danych w Zapier mają funkcję wyszukiwania, dzięki której możesz szybko dotrzeć do potrzebnego pola.

![Szybkie wyszukiwanie zatwierdzonego zasobu](/images/platform/v2/overview-frame-io-resources-in-zapier/38f94d317a462a7caf7fdc781713c0040001d99ef441cd25507b215ca373f70e.webp)

Oczywiście warto też wiedzieć, czego szukać.

## Czego szukać {#what-to-look-for}

Poniższa tabela nie jest wyczerpująca, ale powinna ułatwić Ci start w budowaniu przepływów pracy z integracją Frame.io z Zapier.

<Info>

**Adresy URL zasobów są długie i to jest w porządku**

Adresy URL zasobów widoczne w odpowiedziach API Frame.io to bezpośrednie linki do Amazon S3. Można i należy ich używać w każdym kontekście aplikacji Zapier, w którym chcesz przenieść zasób do innego systemu. Jeśli masz do wyboru „File Attachment” i „File Attachment (URL)”, wybierz to drugie, ponieważ przesyłanie przez URL w Zapier zazwyczaj obsługuje szerszy zakres typów i rozmiarów plików.

</Info>

| Typ zasobu | Pole w Zapier | Opis |
| --- | --- | --- |
| Asset (wszystkie) | Original | Oryginalnie przesłany, nienaruszony film. W większości przypadków jest to klucz, który warto przekazywać do innych systemów; zawsze będzie to jednak oryginalny typ pliku, więc może nie dać się odtworzyć we wszystkich innych kontekstach. |
| Asset (filmy) | H264 *resolution* | Wszystkie proxy h.264 Frame.io są dostępne w zasobie w Zapier. |
| Asset (obrazy) | Image *quality* | Podobnie jak w przypadku proxy wideo h.264, wszystkie proxy wygenerowane dla obrazów są również dostępne w Zapier. |
| Asset (wszystkie) | Thumb | Miniatura zasobu ustawiona w Frame.io. To pole świetnie nadaje się do dodawania elementów wizualnych do systemów śledzenia projektów, takich jak Trello czy Airtable. |
| Asset (wszystkie) | Label | Status Label. To pole zazwyczaj łączy się z akcją „Filter” (podobnie jak na powyższym zrzucie ekranu). |
| Asset (wszystkie) | Creator Email | Adres e-mail osoby, która pierwotnie przesłała zasób. |
| Asset (wszystkie) | Project ID | Identyfikator projektu nadrzędnego zasobu. To pole jest najbardziej przydatne w połączeniu z akcją „Find Project”, za pomocą której możesz pobrać nazwę projektu. |
| Asset (wszystkie) | Parent ID | Identyfikator elementu nadrzędnego zasobu, którym zawsze jest folder, stos wersji lub katalog główny projektu. |
| Comment | Text | Treść komentarza. |
| Comment | Asset ID | Identyfikator zasobu nadrzędnego komentarza. Przydatny do przekazania do akcji Find Asset w celu uzyskania dodatkowego kontekstu lub do linkowania w zewnętrznych narzędziach do śledzenia. |
| Comment | Owner Name | Imię i nazwisko użytkownika, który dodał komentarz. |
| Comment | Owner Email | Adres e-mail użytkownika, który dodał komentarz. |
| Project | Name | Nazwa projektu. |
