## Przegląd {#overview}

Jeśli chcesz przesyłać pliki do Frame.io z istniejących aplikacji chmurowych lub z adresu URL udostępniającego zasoby, Zapier jest zazwyczaj dobrym rozwiązaniem, ponieważ ich produkt niweluje wiele rozbieżności w projektach API, które sprawiają, że praca z aplikacjami chmurowymi przyprawia o ból głowy.  Ten przewodnik wyjaśnia kluczowe cechy usługi przesyłania Zapier, dzięki czemu będziesz dokładnie wiedzieć, co dzieje się w Twojej integracji.

## Ustawianie metody przesyłania plików {#setting-the-file-upload-method}

Zapier próbuje automatycznie wykryć najbardziej elastyczną metodę przesyłania plików dla każdego API, z którym się łączy.  Na przykład Zapier spróbuje przekonwertować linki z ograniczonym dostępem, do których nie można uzyskać dostępu spoza domeny aplikacji, na publicznie dostępne linki do pobrania:

Oryginalny, nieczytelny link:
`https://www.dropbox.com/s/hriinb9w3a2107m/iPad%20intro.pdf`

Przekonwertowany link, którego może użyć API Uploader Frame.io:
`https://dl.dropboxusercontent.com/s/hriinb9w3a2107m/iPad%20intro.pdf`

### Ograniczenia plików w Zapier {#zapier’s-file-limitations}

Co ważne, jeśli Zapier **nie może** wykryć statycznego adresu URL do pobrania, który można przekazać do API Frame.io, usługa Zapier sama pobiera pliki na bieżąco i przekazuje je do Frame.io.  Zapier ogranicza tę metodę do plików **[mniejszych niż 100 MB](https://zapier.com/help/doc/common-problems-dropbox)**.

Pamiętaj, że interfejs Zapier może ostrzegać o ograniczeniach rozmiaru pliku nawet wtedy, gdy przekazujesz bezpośredni adres URL (tj. gdy żadne ograniczenie nie obowiązuje).  Dlatego warto zrozumieć, jak działa File URL.

## Metody przesyłania dla popularnych aplikacji i usług {#upload-methods-for-common-apps-and-services}

**Uwaga:** integracje typu **File Upload** podlegają limitom rozmiaru plików wskazanym w interfejsie Zapier. Bezpośrednie linki są lepszym wyborem, ponieważ nie podlegają ograniczeniom rozmiaru, a przetwarzanie przebiega szybciej i bardziej niezawodnie.

| Aplikacja | Typ | Wskazówki i materiały |
| --- | --- | --- |
| Gmail | File Upload | [Dokumentacja pomocy Zapier](https://zapier.com/help/doc/common-problems-gmail#how-can-i-attach-a-file-to-my-email-that39s-not-in-my-trigger) |
| Google Drive | Direct Link | Wklej `webContentLink` w selektorze pliku.  Działa to w przypadku plików przesłanych na Dysk Google, ale nie zadziała w przypadku dokumentów ani prezentacji utworzonych na Dysku. [Dokumentacja pomocy Zapier](https://zapier.com/help/doc/common-problems-google-drive#unable-to-get-a-value-when-looking-for-quotfilequot-is-it-missing), [Google Drive V3 API](https://developers.google.com/drive/api/v3/manage-downloads) |
| Dropbox | Direct Link | Automatyczne przesyłanie plików z Dropbox do Frame.io |
| Box | Direct Link | Użyj `Info Shared Link Download URL` [Przewodniki po Box API](https://developer.box.com/guides/downloads/shared-link/) |
