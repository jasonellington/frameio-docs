## すべてのアカウントでのアクセス {#all-account-access}

Adobe Admin Console で管理されているアカウントに限らず、すべての Frame V4 アカウントでトークンを作成し、V4 API にアクセスできます。お客様やパートナーは、最新の API 機能を使ってワークフローをテスト、構築、改善できます。

<Steps>

<Step title="ユーザー認証トークンを作成する">

Adobe Developer Console にアクセスして、ユーザー認証トークンを作成します。API トークンのアクセスを検証するには、ユーザーは Frame へのログインと同じ Adobe ID を使用する必要があります。

</Step>

<Step title="API 認証情報を作成する">

API にアクセスできるようになったら、次のステップとして、Frame と通信するための API 認証情報（API トークン）を作成します。API 認証情報は developer.adobe.com で作成してください。

</Step>

</Steps>

![アカウントのアクセス](/images/platform/docs/guides/accounts-projects-and-workspaces/706a4eb9324bc24a3465388a838455baf58384f128882a185dad2d1900f728a3.webp)

<Info>

Frame 管理（V4F）か Adobe 管理（V4A）かにかかわらず、すべての V4 アカウントは Adobe Developer Console でプロジェクトを作成し、認証情報を作成できます。認証情報一式（OAuth クライアント ID／クライアントシークレット）を取得したら、Adobe Developer Platform の 3-legged OAuth フローと連携できます。Adobe Identity にサインインして有効な認証トークンとリフレッシュトークンを受け取り、Frame.io V4 Developer API にリクエストを送信しましょう！

</Info>

## プロジェクトとワークスペース {#projects-and-workspaces}

### ワークスペースの更新 {#workspace-updates}

Frame.io のランディングページが新しくなり、「ワークスペース」ページという名前になりました。ユーザーは、アカウント内でアクセス権を持つワークスペースとプロジェクトを閲覧できます。この新しいデザインにより、特定のワークスペースに誰が所属しているかを確認しやすくなり、新しいメンバーをすばやく招待できるようになりました。

<Note>

Frame V3 では、ワークスペースはチームと呼ばれていました。

</Note>

V4 ではワークスペースは招待制に設定されているため、ユーザーには明示的に招待されたワークスペースのみが表示されます。また、アカウント設定にチームディレクトリページはありません。

権限や関連する操作を管理するには、ワークスペースの Create、List、Delete、Update エンドポイントを使用します。

<CardGroup cols={1}>

<Card title="ワークスペース管理の操作" icon="users" iconType="solid" horizontal={true}>

- 指定したワークスペースのユーザーロールを一覧表示します。
- 指定したワークスペースからユーザーを削除します。
- ユーザーがすでにワークスペースに追加されている場合、指定したワークスペースのユーザーロールを更新します。ユーザーがワークスペースに追加されていない場合は、指定したロールでユーザーが追加されます。

</Card>

</CardGroup>

### プロジェクトの更新 {#project-updates}

V4 ではプロジェクトの作成フローが変更されました。新しいプロジェクトを開始する際に、空のプロジェクトかプロジェクトテンプレートかを選択します。一般的なクリエイティブワークフロー向けに設計された 12 種類のテンプレートから選択できます。テンプレートのデモアセットを含めるか、テンプレートの構造のみで開始するかを選ぶこともできます。プロジェクトテンプレートを選択すると、ワークスペースに新しいプロジェクトがすぐに作成されます。

権限や関連する操作を管理するには、プロジェクトの Create、List、Delete、Update エンドポイントを使用します。

<Card title="プロジェクト管理の操作" icon="folder" iconType="solid" horizontal={true}>

- 指定したプロジェクトのユーザーロールを一覧表示します。
- 指定したプロジェクトからユーザーを削除します。
- ユーザーがすでにプロジェクトに追加されている場合、指定したプロジェクトのユーザーロールを更新します。ユーザーがプロジェクトに追加されていない場合は、指定したロールでユーザーが追加されます。

</Card>

</CardGroup>
