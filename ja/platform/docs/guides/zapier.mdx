技術的な専門知識がなくても、誰でも数分で設定できるシンプルなノーコードの自動化で、Frame.io のワークフローを変革しましょう。

## Zapier とは {#what-is-zapier}

**Zapier は、お気に入りのアプリを自動的につなぐデジタルアシスタントです。** 手作業を一切することなく、アプリ同士が「会話」できるようにする橋渡し役と考えてください。

この魔法は、[**Zap**](https://help.zapier.com/hc/en-us/articles/8496309697421-What-is-a-Zap) と呼ばれるシンプルな「これが起きたら、あれをする」というルールによって実現されます。たとえば、「Frame.io に新しい動画がアップロードされたら、チームに送る共有リンクを自動的に作成する」といったものです。それだけです。コーディングも複雑なセットアップも不要で、ポイント&クリックだけの簡単さです。

[7,000 以上のアプリ](https://zapier.com/apps)が利用可能な Zapier は、反復的で単調なタスクを自動化されたワークフローに変え、あなたとチームが最も重要な仕事に集中できる時間を増やします。

## Frame.io を Zapier と組み合わせて使う理由 {#why-use-frame-io-with-zapier}

Frame.io の [Zapier 連携](https://zapier.com/apps/frameio-v4/integrations)は、ファイルのワークフローに自動化の力をもたらします。新しいアップロードを手動で確認したり、リンクをコピーしたり、ステータスの更新を送信したりする代わりに、これらのタスクを処理する自動化されたワークフローを設定できます。

**よく使われる自動化の例:**

- **新規アップロードの通知**: 誰かが新しい動画をアップロードしたら、Slack でチームに自動的に通知する
- **プロジェクト管理の同期**: 新しい Frame.io プロジェクトが作成されたら、Airtable にタスクを作成する
- **クライアントとのコミュニケーション**: レビューの準備ができたら、クライアントにメールで最新情報を送る
- **ファイルの整理**: 承認されたアセットを Google Drive や Dropbox に自動的に保存する
- **ステータスの追跡**: コメントが解決されたら、CRM のプロジェクトステータスを更新する

## 始めるのは思ったより簡単です {#getting-started-is-easier-than-you-think}

**コーディングの知識は不要です。** Zapier のビジュアルインターフェースが各ステップをガイドします。

<Steps>

<Step title="トリガーを選択する">

「Frame.io でこれが起きたら…」(新しいアップロードなど)

</Step>

<Step title="アクションを選択する">

「別のアプリでこれを実行する…」(Slack メッセージの送信など)

</Step>

<Step title="データをマッピングする">

アプリ間で共有する情報を選択します

</Step>

<Step title="テストして有効化する">

Zapier は、本番稼働の前に何が起きるかを正確に示してくれます

</Step>

</Steps>

全体のプロセスはわずか数分で完了します。また、Zapier にはさらに早く始めるのに役立つ[テンプレート](https://zapier.com/apps/frameio-v4/integrations#integrations)が用意されています。

## Zapier のセットアップ {#setting-up-zapier}

Zapier 連携を使い始めて、Frame.io を数百ものアプリに接続しましょう。

### セットアップ {#setup}

<Steps>

<Step title="Zapier に登録する">

[無料の Zapier アカウント](https://zapier.com/apps/frameio-v4/integrations)に登録します

</Step>

<Step title="Frame.io を接続する">

Zapier にログインして Zap を作成し、Zap に Frame.io アプリを追加します。追加すると、Zapier を Frame.io アカウントに接続するよう求められます。

</Step>

</Steps>

### 探索する {#explore}

- [Zapier の例とテンプレート](https://zapier.com/apps/frameio-v4/integrations)を閲覧する
- Zapier 連携にさらに機能を追加してほしい場合は、[コミュニティチャット](https://forum.frame.io/)でご要望をお聞かせください。Zapier 連携は他のネイティブ連携と同様に当社が保守しており、常に改善の方法を模索しています。

### パートナーになる {#partner-with-us}

- 貴社のソフトウェアを Zapier のミドルウェアを介さずに Frame.io と直接連携させたい場合は、[Frame.io パートナーになりましょう](https://frame.io/integrations)。

### テンプレートの使い方 {#how-to-use-templates}

テンプレートの使い方は簡単で、セットアップにかかる時間を大幅に節約できます。

<Steps>

<Step title="テンプレートを選択する">

ワークフローのニーズに合った構築済みテンプレートを選択します

</Step>

<Step title="各ステップを設定する">

Zap 内の各ステップで、設定セクションに直接進みます *(セットアップはテンプレートによってすでに完了しています)*

</Step>

<Step title="情報を追加する">

アカウントの認証情報、Workspace 名、プロジェクト名、フォルダーの場所など、必要な詳細を入力します。

</Step>

<Step title="Zap をテストする(オプション)">

テストを実行して、すべてが正しく動作することを確認します

<Warning>

特に Webhook ベースのトリガーの場合、テストが難しいことがあります。テストステップではサンプルデータが表示される場合がありますが、実際に Zap を使用すると実際のデータに置き換えられます。

</Warning>

</Step>

<Step title="公開する">

設定に問題がなければ、「Publish」をクリックして Zap を有効化しましょう!

</Step>

</Steps>

## Zapier における Frame.io のリソースフィールド {#frame-io-resource-fields-in-zapier}

「File Created」や「Comment Created」などのトリガーを使用すると、イベントやリソースに関する豊富なコンテキストを提供する多数のフィールドが表示されます。

### File のフィールド {#file-fields}

<Info>

**ファイルの URL は安全かつ直接的です**: V4 連携では、Frame.io のアセットストレージへの直接リンクが提供されます。他のアプリで「File Attachment」と「File Attachment (URL)」のどちらかを選択できる場合は、一般により大きなファイルやより多くのファイルタイプをサポートしている URL のオプションを選択してください。

</Info>

主な File のフィールドは次のとおりです。

- `Original Download URL` - アップロードされた元のファイルへの直接ダウンロードリンク
- `High Quality Download URL` - 高品質プロキシバージョンのダウンロードリンク
- `Thumbnail Download URL` - ファイルのサムネイルのダウンロードリンク
- `File Name` - 拡張子を含む完全なファイル名
- `File Type Category` - 分類されたタイプ: "video"、"image"、"audio"、"document"、または "other"
- `Creator Name` と `Creator Email` - ファイルをアップロードしたユーザーに関する情報
- `Project Name` と `Project ID` - プロジェクトのコンテキスト情報

### Comment のフィールド {#comment-fields}

主なコメントのフィールドは次のとおりです。

- `Comment Text` - コメントのテキスト内容
- `Comment Author Name` と `Comment Author Email` - コメントを残したユーザー
- `Timestamp` - 時間ベースのコメント(動画の場合)のフレーム番号
- `File ID` - コメントが残されたファイルの ID
- `Project Name` と `Project ID` - プロジェクトのコンテキスト

### Project のフィールド {#project-fields}

主な Project のフィールドは次のとおりです。

- `Project Name` と `Project ID` - Project の基本情報
- `Root Folder ID` - Project のルートフォルダーの ID
- `Storage Usage` - Project が使用しているストレージ(バイト単位)
- `View URL` - Frame.io で Project を表示するための直接リンク
- `Workspace ID` と `Account ID` - 組織のコンテキスト

## カスタム Zap の作成 {#building-custom-zaps}

カスタムワークフローを一から作成したい場合や、テンプレートで提供されているものよりも具体的なものが必要な場合は、次の手順に従います。

<Steps>

<Step title="新しい Zap を開始する">

Zapier のホームページに移動し、「Create」、「New Zap」の順にクリックします

</Step>

<Step title="トリガーを選択する">

トリガーアクションを選択します。Frame.io でも、その他の Zapier 連携でも構いません

</Step>

<Step title="ワークフローを完成させる">

アクションを追加し、特定のニーズに応じてステップを設定します

</Step>

<Step title="Zap を共有する">

Zap はチームメンバーやコラボレーターと共有でき、組織全体で一貫したワークフローを実現できることを覚えておいてください

</Step>

</Steps>

## Legacy から V4 への移行 {#migrating-from-legacy-to-v4}

Frame.io の V4 Zapier 連携は、Legacy バージョンとの機能の同等性を維持しながら、大幅な改善をもたらします。

### 切り替え {#making-the-switch}

<Warning>

**既存のユーザーの方へ**: 現在 Legacy の Frame.io Zapier 連携を使用している場合、既存の Zap は Legacy バージョンの Frame.io でのみ動作します。Frame.io の Account を V4 にアップグレードした後は、Frame.io V4 Zapier 連携を使用して連携を再構築する必要があります。

</Warning>

<Info>

**新規ユーザーの方へ**: 新しい Zap を作成する際は、常に **Frame.io V4** 連携を選択してください。これは、最新の改善がすべて含まれた、現在積極的に保守されているバージョンです。

</Info>

### 主な用語の変更 {#key-terminology-changes}

最も目立つ変更は、コンテンツの整理に関する用語です。

| Legacy の用語 | V4 の用語 |
| --- | --- |
| "Asset" | "File" または "File & Folder" |
| "Asset Created" | "File Created" |
| "Asset Ready" | "File Ready" |
| "Asset Upload Completed" | "File Upload Completed" |

**なぜ変更したのか?** 「File」という用語のほうが広く理解されており、動画、画像、ドキュメント、その他のファイルタイプなど、扱っているものを正確に表しているためです。

## さらにサポートが必要な場合 {#need-more-help}

<Warning>

**不足している機能が必要ですか?** 当社は Legacy と V4 のすべての機能を揃えることを目標としていますが、不足しているものに気付いた場合や追加の機能が必要な場合は、お気軽にお問い合わせください。

</Warning>

### お問い合わせ方法 {#how-to-reach-out}

- **コミュニティフォーラム**: 機能のリクエストは [Frame.io コミュニティ](https://forum.frame.io/)に投稿してください
- **サポートチーム**: Frame.io アプリからサポートチームに直接お問い合わせください

機能のリクエストや問題の報告を行う際は、次の内容をお知らせください。

- 実現しようとしている具体的なワークフロー
- 表示されているエラーや、行き詰まっている箇所
- Legacy バージョンでは動作していたのか、それとも V4 固有の新機能なのか

## 自動化の準備はできましたか? {#ready-to-automate}

自動化の最も良いところは、小さく始めてそこから拡大していけることです。誰かがプロジェクトにコメントしたときに通知を受け取るといったシンプルなワークフローから始め、時間の節約効果を実感しながら拡大していきましょう。

あなたのアプリはすでに素晴らしい仕事をしています。今度はそれらを連携させて、さらに多くのことを実現しましょう。

<Note>

さっそく始めてみませんか? [テンプレート](https://zapier.com/apps/frameio-v4/integrations)を使えば、10 分もかからずに最初の自動化を作成できます。

</Note>
