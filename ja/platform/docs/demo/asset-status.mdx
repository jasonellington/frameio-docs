このエンドポイントを使用して、アセットの処理が完了したかどうかを確認します。

## アセットのステータスを取得する {#get-an-asset’s-status}

```http
GET /v4/assets/{id}/status
```

### パスパラメーター {#path-parameters}

| パラメーター | 型     | 説明          |
| ------------ | ------ | ------------- |
| `id`         | string | アセット ID。 |

### レスポンスフィールド {#response-fields}

| フィールド    | 型     | 説明                                         |
| ------------- | ------ | -------------------------------------------- |
| `data.id`     | string | アセット ID。                                |
| `data.status` | string | 処理ステータス：`processing` または `ready`。 |
| `data.updated_at` | string | アセットが最後に更新された日時（ISO 8601 形式の UTC タイムスタンプ）。 |

### 例 {#example}

```bash
curl http://localhost:3001/v4/assets/a1b2c3/status
```

```json
{
  "data": {
    "id": "a1b2c3",
    "status": "ready",
    "updated_at": "2026-11-03T18:22:10Z"
  }
}
```

### エラー {#errors}

| ステータス | エラー            | 意味                                  |
| ---------- | ----------------- | ------------------------------------- |
| `404`      | `asset_not_found` | この ID を持つアセットは存在しません。 |
