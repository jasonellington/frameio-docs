### 使い方 {#usage}

次のようにクライアントをインスタンス化して使用します。

```python
from frameio import (
    Frameio,
    SelectDefinitionParamsFieldConfiguration,
    SelectDefinitionParamsFieldConfigurationOptionsItem,
)
from frameio.metadata_fields import CreateFieldDefinitionParamsData_Select

client = Frameio(
    token="YOUR_TOKEN",
)
client.metadata_fields.metadata_field_definitions_create(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    data=CreateFieldDefinitionParamsData_Select(
        field_configuration=SelectDefinitionParamsFieldConfiguration(
            enable_add_new=False,
            options=[
                SelectDefinitionParamsFieldConfigurationOptionsItem(
                    display_name="Option 1",
                ),
                SelectDefinitionParamsFieldConfigurationOptionsItem(
                    display_name="Option 2",
                ),
            ],
        ),
        name="Fields definition name",
    ),
)
```

### 非同期クライアント {#async-client}

SDK は非同期クライアントもエクスポートしているため、API に対してノンブロッキングな呼び出しを行えます。このクライアントに渡す非同期 httpx クライアントクラスを構築する場合は、httpx.Client() ではなく httpx.AsyncClient() を使用してください(例: このクライアントの httpx_client パラメーター)。

```python
import asyncio

from frameio import (
    AsyncFrameio,
    SelectDefinitionParamsFieldConfiguration,
    SelectDefinitionParamsFieldConfigurationOptionsItem,
)
from frameio.metadata_fields import CreateFieldDefinitionParamsData_Select

client = AsyncFrameio(
    token="YOUR_TOKEN",
)


async def main() -> None:
    await client.metadata_fields.metadata_field_definitions_create(
        account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
        data=CreateFieldDefinitionParamsData_Select(
            field_configuration=SelectDefinitionParamsFieldConfiguration(
                enable_add_new=False,
                options=[
                    SelectDefinitionParamsFieldConfigurationOptionsItem(
                        display_name="Option 1",
                    ),
                    SelectDefinitionParamsFieldConfigurationOptionsItem(
                        display_name="Option 2",
                    ),
                ],
            ),
            name="Fields definition name",
        ),
    )


asyncio.run(main())
```

### 例外処理 {#exception-handling}

API が成功以外のステータスコード(4xx または 5xx レスポンス)を返すと、次のエラーのサブクラスがスローされます。

```python
from frameio.core.api_error import ApiError

try:
    client.metadata_fields.metadata_field_definitions_create(...)
except ApiError as e:
    print(e.status_code)
    print(e.body)
```

### ページネーション {#pagination}

ページネーションされたリクエストは SyncPager または AsyncPager を返します。これらは基になるオブジェクトのジェネレーターとして使用できます。

```python
from frameio import Frameio

client = Frameio(
    token="YOUR_TOKEN",
)
response = client.project_permissions.index(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    project_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    page_size=10,
    include_total_count=False,
)
for item in response:
    yield item
# alternatively, you can paginate page-by-page
for page in response.iter_pages():
    yield page
```

### 高度な使い方 {#advanced}

#### 生のレスポンスデータへのアクセス {#access-raw-response-data}

SDK では、.with_raw_response プロパティを通じて、ヘッダーを含む生のレスポンスデータにアクセスできます。.with_raw_response プロパティは「生」のクライアントを返し、これを使用して .headers 属性と .data 属性にアクセスできます。

```python
from frameio import Frameio

client = Frameio(
    ...,
)
response = (
    client.metadata_fields.with_raw_response.metadata_field_definitions_create(
        ...
    )
)
print(response.headers)  # access the response headers
print(response.data)  # access the underlying object
pager = client.project_permissions.index(...)
print(pager.response.headers)  # access the response headers for the first page
for item in pager:
    print(item)  # access the underlying object(s)
for page in pager.iter_pages():
    print(page.response.headers)  # access the response headers for each page
    for item in page:
        print(item)  # access the underlying object(s)
```

#### リトライ {#retries}

SDK には、指数バックオフによる自動リトライが組み込まれています。リクエストがリトライ可能と判断され、リトライ回数が設定されたリトライ上限(デフォルト: 2)を超えていない限り、リクエストはリトライされます。<br />
次のいずれかの HTTP ステータスコードが返された場合、リクエストはリトライ可能と判断されます。

- 408 (タイムアウト)
- 429 (リクエスト過多)
- 5XX (内部サーバーエラー)

<br />

この動作を設定するには、`max_retries` リクエストオプションを使用します。

```python
client.metadata_fields.metadata_field_definitions_create(..., request_options={
    "max_retries": 1
})
```

---

#### タイムアウト {#timeouts}

SDK のデフォルトのタイムアウトは 60 秒です。クライアントレベルまたはリクエストレベルの timeout オプションで設定できます。

```python
from frameio import Frameio

client = Frameio(
    ...,
    timeout=20.0,
)


# Override timeout for a specific method
client.metadata_fields.metadata_field_definitions_create(..., request_options={
    "timeout_in_seconds": 1
})
```

---

#### カスタムクライアント {#custom-client}

httpx クライアントをオーバーライドして、ユースケースに合わせてカスタマイズできます。一般的なユースケースとして、プロキシやトランスポートのサポートがあります。

```python
import httpx
from frameio import Frameio

client = Frameio(
    ...,
    httpx_client=httpx.Client(
        proxy="http://my.test.proxy.example.com",
        transport=httpx.HTTPTransport(local_address="0.0.0.0"),
    ),
)
```

#### 認証 {#auth}

<AccordionGroup>

<Accordion title="frameio.auth.ServerToServerAuth(*, client_id, client_secret, ...)" defaultOpen={true}>

OAuth 2.0 の client_credentials グラントを使用して認証します。このフローにはユーザーが関与せず、リフレッシュトークンも返されません。アクセストークンの有効期限が切れると、SDK はクライアント認証情報を使用して新しいトークンを自動的にリクエストします。非同期で使用する場合は `AsyncServerToServerAuth` を使用してください。

```python title="usage"

from frameio import Frameio
from frameio.auth import ServerToServerAuth

auth = ServerToServerAuth(client_id="YOUR_CLIENT_ID", client_secret="YOUR_CLIENT_SECRET")
client = Frameio(token=auth.get_token)
```

**パラメーター**

`client_id`: `str` — Adobe IMS OAuth クライアント ID。

`client_secret`: `str` — Adobe IMS OAuth クライアントシークレット。

`scopes`: `str` — スペース区切りのスコープ(OAuth 2.0 RFC 6749)。デフォルトは `openid AdobeID frame.s2s.all` です。

`ims_base_url`: `str` — ステージング環境や代替環境用の IMS ベース URL。デフォルトは本番環境です。

`http_client`: `typing.Optional[httpx.Client]` — プロキシ、TLS、またはコネクションプーリング用のオプションの httpx.Client。

`on_token_refreshed`: `typing.Optional[typing.Callable[[dict[str, Any]], None]]` — トークンを取得するたびに呼び出されるオプションのコールバック。

`timeout`: `float` — HTTP リクエストのタイムアウト(秒)。デフォルトは 30 です。

`max_retries`: `int` — 一時的な障害に対するリトライの最大回数。デフォルトは 2 です。

`refresh_buffer`: `int` — 有効期限の何秒前に事前リフレッシュを実行するか。デフォルトは 60 です。

**メソッド**

`get_token() -> str` — 有効なアクセストークンを返します。必要に応じてリフレッシュします。このメソッドの参照(呼び出しではなく)を SDK に渡します: `Frameio(token=auth.get_token)`。

`authenticate() -> dict[str, Any]` — 新しいアクセストークンを明示的に取得します。`access_token`、`expires_in` などを含むトークンレスポンスの dict を返します。

`revoke() -> None` — サーバー側で両方のトークンを失効させ、ローカルの状態をクリアします。

`export_tokens() -> dict[str, Any]` — 永続化のために現在のトークンの状態をエクスポートします。

`import_tokens(data: dict[str, Any]) -> None` — 以前にエクスポートした dict からトークンの状態を復元します。

</Accordion>

<Accordion title="frameio.auth.WebAppAuth(*, client_id, client_secret, redirect_uri, ...)">

OAuth 2.0 の authorization_code グラントを使用して認証します。クライアントシークレットを安全に保存できるサーバーサイドアプリケーションで使用します。非同期で使用する場合は `AsyncWebAppAuth` を使用してください。

```python title="usage"

import secrets
from frameio import Frameio
from frameio.auth import WebAppAuth

auth = WebAppAuth(
    client_id="YOUR_CLIENT_ID",
    client_secret="YOUR_CLIENT_SECRET",
    redirect_uri="https://myapp.com/callback",
)
url = auth.get_authorization_url(state=secrets.token_urlsafe(32))
# redirect user to url ...
auth.exchange_code(code="CODE_FROM_CALLBACK")
client = Frameio(token=auth.get_token)
```

**パラメーター**

`client_id`: `str` — Adobe IMS OAuth クライアント ID。

`client_secret`: `str` — Adobe IMS OAuth クライアントシークレット。

`redirect_uri`: `str` — 登録済みのリダイレクト URI。

`scopes`: `str` — スペース区切りのスコープ(OAuth 2.0 RFC 6749)。

`ims_base_url`: `str` — ステージング環境や代替環境用の IMS ベース URL。デフォルトは本番環境です。

`http_client`: `typing.Optional[httpx.Client]` — プロキシ、TLS、またはコネクションプーリング用のオプションの httpx.Client。

`on_token_refreshed`: `typing.Optional[typing.Callable[[dict[str, Any]], None]]` — トークンをリフレッシュするたびに呼び出されるオプションのコールバック。

`timeout`: `float` — HTTP リクエストのタイムアウト(秒)。デフォルトは 30 です。

`max_retries`: `int` — 一時的な障害に対するリトライの最大回数。デフォルトは 2 です。

`refresh_buffer`: `int` — 有効期限の何秒前に事前リフレッシュを実行するか。デフォルトは 60 です。

**メソッド**

`refresh() -> dict[str, Any]` — トークンのリフレッシュを手動で実行します。

`revoke() -> None` — サーバー側で両方のトークンを失効させ、ローカルの状態をクリアします。

`export_tokens() -> dict[str, Any]` — 永続化のために現在のトークンの状態をエクスポートします。

`import_tokens(data: dict[str, Any]) -> None` — 以前にエクスポートした dict からトークンの状態を復元します。

</Accordion>

<Accordion title="frameio.auth.SPAAuth(*, client_id, redirect_uri, ...)">

authorization_code + PKCE(クライアントシークレットなし)を使用して認証します。クライアントシークレットを安全に保存できないブラウザーベースのアプリやネイティブアプリで使用します。非同期で使用する場合は `AsyncSPAAuth` を使用してください。

```python title="usage"

import secrets

auth = SPAAuth(client_id="YOUR_CLIENT_ID", redirect_uri="https://myapp.com/cb")
result = auth.get_authorization_url(state=secrets.token_urlsafe(32))
# redirect user to result.url, store result.code_verifier
auth.exchange_code(code="CODE_FROM_CALLBACK", code_verifier=result.code_verifier)
client = Frameio(token=auth.get_token)
```

**パラメーター**

`client_id`: `str` — Adobe IMS OAuth クライアント ID。

`redirect_uri`: `str` — 登録済みのリダイレクト URI。

`scopes`: `str` — スペース区切りのスコープ(OAuth 2.0 RFC 6749)。

`ims_base_url`: `str` — ステージング環境や代替環境用の IMS ベース URL。デフォルトは本番環境です。

`http_client`: `typing.Optional[httpx.Client]` — プロキシ、TLS、またはコネクションプーリング用のオプションの httpx.Client。

`on_token_refreshed`: `typing.Optional[typing.Callable[[dict[str, Any]], None]]` — トークンをリフレッシュするたびに呼び出されるオプションのコールバック。

`timeout`: `float` — HTTP リクエストのタイムアウト(秒)。デフォルトは 30 です。

`max_retries`: `int` — 一時的な障害に対するリトライの最大回数。デフォルトは 2 です。

`refresh_buffer`: `int` — 有効期限の何秒前に事前リフレッシュを実行するか。デフォルトは 60 です。

**メソッド**

`get_token() -> str` — 有効なアクセストークンを返します。必要に応じてリフレッシュします。このメソッドの参照を SDK に渡します: `Frameio(token=auth.get_token)`。

`get_authorization_url(state: str) -> AuthorizationUrlResult` — PKCE チャレンジ付きの Adobe IMS 認可 URL を構築します。`url` 属性と `code_verifier` 属性を持つ `AuthorizationUrlResult` を返します。

`exchange_code(code: str, code_verifier: str) -> dict[str, Any]` — 認可コードと PKCE ベリファイアをトークンに交換します。

`refresh() -> dict[str, Any]` — トークンのリフレッシュを手動で実行します。

`revoke() -> None` — サーバー側で両方のトークンを失効させ、ローカルの状態をクリアします。

`export_tokens() -> dict[str, Any]` — 永続化のために現在のトークンの状態をエクスポートします。

`import_tokens(data: dict[str, Any]) -> None` — 以前にエクスポートした dict からトークンの状態を復元します。

</Accordion>

<Accordion title="frameio.auth.AuthorizationUrlResult">

`SPAAuth.get_authorization_url()` および `AsyncSPAAuth.get_authorization_url()` が返すイミュータブル(frozen)なデータクラスです。認可 URL と PKCE コードベリファイアを保持します。

**属性**

`url`: `str` — ユーザーのリダイレクト先となる完全な認可 URL。

`code_verifier`: `str` — 保存して `exchange_code()` に渡す PKCE コードベリファイア。

</Accordion>

<Accordion title="frameio.auth.close_clients() / aclose_clients()">

auth モジュールが使用するモジュールレベルの HTTP クライアントを閉じます。アプリケーションのシャットダウン時に、同期コードでは `close_clients()` を、非同期コードでは `await aclose_clients()` を呼び出して接続を解放してください。

```python title="usage"

from frameio.auth import close_clients

# During application shutdown
close_clients()
```

#### 認証の例外 {#auth-exceptions}

すべての認証例外は `FrameioAuthError` を継承します。

| 例外 | 説明 |
| --- | --- |
| `FrameioAuthError` | すべての `frameio.auth` エラーの基底例外です。 |
| `AuthenticationError` | トークンの交換またはリフレッシュに失敗しました。`error_code` 属性と `error_description` 属性を持ちます。 |
| `TokenExpiredError` | リフレッシュトークンの有効期限が切れています。再認証が必要です。 |
| `ConfigurationError` | 必要な設定が欠落しているか、無効です。 |
| `NetworkError` | ネットワークリクエストに失敗しました(タイムアウト、接続エラーなど)。 |
| `RateLimitError` | API が 429 を返し、リトライ回数を使い切りました。`retry_after` 属性を持ちます。 |
| `PKCEError` | PKCE の検証に失敗しました。 |
