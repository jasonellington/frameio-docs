## 互換性に関する質問 {#compatibility-questions}

<AccordionGroup>

<Accordion title="Frame.io V4 API には後方互換性がありますか？">

<Warning>

いいえ。Adobe MAX でリリースされた Frame.io 製品は、レガシーバージョンとは根本的に異なる方法で動作し、異なるワークフローを重視しています。これらの違いにより、新しい API には後方互換性がありません。

</Warning>

</Accordion>

<Accordion title="今後、後方互換性はどのように扱われますか？">

高い稼働率が求められる本番品質のインテグレーションを管理するお客様にとって、後方互換性が大きな関心事であることを踏まえ、V4 API では、カスタム HTTP ヘッダーによる追加のバージョニングレベルをサポートするよう設計を進めています。これにより、クライアントは実験的なエンドポイントの使用をオプトインでき、破壊的変更を回避し、`/v4` API 名前空間内で後方互換性の保証を受けられます。

</Accordion>

<Accordion title="V4 API が一般提供されたら、レガシー製品で設定したオートメーションは引き続き動作しますか？つまり、それらは自動的に V4 に移行されますか？">

<Warning>

レガシーの開発者トークンを使用しているすべてのオートメーションは、V4 アカウントでは動作しなくなります。それらを V4 に移行する方法は**ありません**。

</Warning>

</Accordion>

</AccordionGroup>

## メディアとファイル {#media-&-files}

<AccordionGroup>

<Accordion title="メディアリンクの URL はどのくらいの期間有効ですか？">

`media_links` に含まれて返される URL（`download_url`、`inline_url`、`url` など）は**一時的な署名付き URL** であり、有効期限があるため、無期限に再利用することはできません。

| URL の種類 | 有効期限 |
| --- | --- |
| ダウンロード URL とインライン URL（`original`、`high_quality`、`efficient`、`video_h264_180`） | 最大 24 時間 |
| サムネイル URL とプレビュー URL（`thumbnail`） | 最大 24 時間 |

実際には、有効期限は UTC の正午または午前 0 時に揃えられるため、URL を受け取った時点での実際の残り時間は、リクエストを行うタイミングによって数分から 24 時間までの間で変動します。

**これらの URL を保存またはキャッシュしないでください。** ファイルを配信またはアクセスする必要があるたびに、常に新しい `media_links` をリクエストしてください。期限切れの URL を使用しようとすると、CDN から `403` エラーが返されます。

</Accordion>

</AccordionGroup>
