### Frame.io について {#about-frame-io}

Frame.io は、クリエイティブチームとその関係者が制作途中のアセットを整理、レビュー、管理し、それを支える人とプロセスを調整できる、柔軟で高速かつ直感的なプラットフォームを提供します。強力なメタデータフレームワークを基盤としているため、チームは Frame.io を使用して、メディアアセットを中心としたあらゆるクリエイティブワークフローをカスタマイズできるようになりました。

### Frame.io V4 開発者プラットフォームについて {#about-frame-io-v4-developer-platform}

Frame.io 開発者プラットフォームは、クリエイティブコラボレーションを明快かつシンプルにするために、ゼロから再設計されました。クリエイティブな作業をより簡単にする新しいコンセプトとして、リレーションシップベースのアクセス制御、チームの働き方に合わせたカスタムフィールド、そして Shares の簡素化などがあります。皆さんが操作し、構築に使用するまったく新しい API は、お客様とパートナーのニーズに最も適するよう設計されています。

このドキュメントには、コアコンセプトを順を追って説明し、V4 API の全体像を詳しく解説する包括的な Getting Started ガイドが含まれており、レガシー API から移行する方向けの相違点にも特に注意を払っています。また、人間にも機械にも読みやすい *API リファレンス* も用意しています。Open API 仕様を使用して生成されており、開発者は Frame.io の *API リファレンス* を参照して、エラー情報を含むサンプルリクエストとレスポンス付きで、サポートされているエンドポイントの完全な一覧を確認できます。現在開発中の新しいエンドポイントには、Web サイト上部のナビゲーションバーからアクセスできます。これらの *experimental*（実験的）バージョンを試したい開発者は、ここでバージョンを切り替えることができます。このセクションのエンドポイントは、サポート対象のバージョンヘッダーで正式にリリースされる前にルートやレスポンスボディが変更される可能性があるため、あくまで方向性の参考としてのみご利用ください。
