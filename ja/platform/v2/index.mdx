## Frame.io について {#about-frame-io}

[Frame.io](https://frame.io) は、プロフェッショナルな映像制作チームのためのクラウドコラボレーションツールです。クリエイティブプロセスを前に進めるために必要なものすべてを 1 つのワークベンチに集約し、どこからでもアクセスできます。Frame.io を使えば、映像プロジェクトを安全にアップロード、共有、レビューでき、業務全体をクリエイティビティのスピードで進めることができます。

### Frame.io 開発者プラットフォーム {#frame-io-developer-platform}

クリエイティブチーム、プロセス、ソフトウェアスタックは、どれ一つとしてまったく同じではありません。そこで役立つのが開発者プラットフォームです。Frame.io 開発者プラットフォームでは、API を使って一般的なタスクを処理できます。開発者による API の代表的な活用例としては、既存のファイルやフォルダーを Frame.io アプリに自動で追加すること、新しいコンテンツをアップロードすること、チームを管理することなどがあります。

## Camera to Cloud (C2C) プログラム {#camera-to-cloud-c2c-program}

Camera to Cloud は、独自のタイプのインテグレーションです。これらのインテグレーションは、データを生成するあらゆるデバイスやアプリケーション向けに特化して設計されています。C2C インテグレーションを構築する場合は、[C2C インテグレーションガイド](/ja/camera-to-cloud/getting-started-with-cloud-device-integrations)を参照してください。Frame.io でクラウドへの接続を始めるために必要な情報がすべて揃っています。

## クイックスタートガイド {#quick-start-guide}

今すぐ始めたい場合は、このボタンをクリックして API を Postman に取り込んでください。

[![Run in Postman](/images/platform/v2/index/button.svg)](https://www.getpostman.com/collections/c2dfffb88990a9dc34c2)

そうでない場合は、このまま読み進めてください。まず、サインインできる Frame.io アカウントを用意しておく必要があります。

その後、次の手順を行います。

- Frame.io の認証情報を使って[開発者ポータルにサインイン](/ja/platform/v2)する
- [開発者トークンを作成](/ja/platform/v2/authentication#developer-tokens)する

トークンが機能していることを確認するには、お好みの言語、ツール、またはプロキシを使ってテスト呼び出しを行ってください。

<CodeGroup>

```bash title="cURL"
curl --request GET \
  --url https://api.frame.io/v2/me \
  --header 'authorization: Bearer <DEV_TOKEN>'
```

```python title="Python"
import requests

url = "https://api.frame.io/v2/me"
headers = {
 "Authorization": "Bearer <DEV_TOKEN>"
}

requests.GET(url,headers=headers)
```

</CodeGroup>

レスポンスとして、ユーザー情報が表示されるはずです。

## イベントベースのワークフロー {#event-based-workflows}

Frame.io 開発者プラットフォームには、ワークフローを他のツールに拡張したり、まったく新しい機能を作成したりするためのオプションがいくつか用意されています。

### Webhooks {#webhooks}

Webhooks を使うと、Frame.io 内で発生したイベントを通知に変換し、外部システムに送信して、処理、API コールバック、ワークフローの自動化に活用できます。

Webhooks の活用方法はいくつかあります。自分で何かを構築することも、[Zapier](https://zapier.com)、[Integromat](https://www.integromat.com)、[Pabbly Connect](https://www.pabbly.com/)、[Pipedream](https://pipedream.com) などのノーコード自動化ツールを利用することもできます。

- [Webhooks](/ja/platform/v2/webhooks-overview) - Webhooks は、Frame.io のイベントを外部 URL に公開し、受信と処理を可能にします。
- [Zapier](/ja/platform/v2/get-started-with-zapier)  - コードを書かずに 1,000 以上の一般的なアプリやツールを接続できるオンライン自動化ツールです。

独自のレシーバーを構築したい場合の出発点として使える [Webhooks サンプルアプリ](https://github.com/Frameio/webhooks-example-app)を Github で公開しています。

### カスタムアクション {#custom-actions}

[カスタムアクション](/ja/platform/v2/custom-actions-overview)を使うと、プログラム可能な UI コンポーネントとして Frame.io に直接インテグレーションを組み込むことができます。技術的には Webhooks と非常によく似ており、Frame.io のワークフローを拡張するのに最適な方法です。

## 開発者コミュニティに参加する {#join-the-developer-community}

すぐに構築を始めるかどうか迷っている場合は、[開発者フォーラム](https://forum.frame.io)をご覧ください。コミュニティには、Frame.io の API とさまざまなワークフローツールを組み合わせて優れたインテグレーションを構築した、あるいは現在構築中の開発者、ものづくり好き、クリエイティブのプロフェッショナルが多数参加しています。
