# Frame.io ログインのクロスブラウザサポート {#cross-browser-support-for-frame-io-login}

完全に API 駆動のアプリケーションには関係ありませんが、OAuth 認証情報付与フローの中で [Accounts アプリ](https://accounts.frame.io/)を読み込む際には、Frame.io のクロスブラウザサポートが関係してきます。

Frame.io 向けの OAuth アプリケーションを作成する際は、OAuth フローで表示されるログインページが、メインの Web アプリケーションと同じブラウザサポートに準拠することにご注意ください。以下の表において、「Partial」（部分的）サポートとは、主要な機能はすべて問題なく動作するものの、軽微なレイアウトの問題が発生する可能性があることを意味します。「Minimal」（最小限）サポートとは、動作する可能性はあるものの、明示的なテストやサポートはすでに行っていないことを意味します。

| ブラウザ | サポート |
| --- | --- |
| Chrome（最新版） | Full（完全） |
| Safari（最新版） | Full（完全） |
| Firefox（最新版） | Full（完全） |
| Opera（最新版） | Full（完全） |
| Edge（最新版） | Full（完全） |
| IE (11+) | Minimal（最小限） |
| IE (&lt;=10) | なし |
| Mobile Safari（最新版） | Partial（部分的） |
| Chrome for iOS（最新版） | Partial（部分的） |
| Chrome for Android（最新版） | Partial（部分的） |
| Android Browser（最新版） | Partial（部分的） |
