---
title: "Glitch を使う"
---

Glitch は、Web アプリケーションをすばやく簡単に作成できるツールです。公開 Web アドレスを持つ独自のサーバーを用意する手間をかけずに、Glitch でアプリケーションを実行してテストできます。 

このガイドでは、Glitch を使うための基本的なヒントとコツを紹介します。 

## Glitch に登録するには? {#how-do-i-sign-up-for-glitch}
**Sign In** をクリックし、表示される方法のいずれかを選びます。Glitch は Facebook、GitHub、Google、メールでのサインインに対応しています。こちらから始められます: [https://glitch.com](https://glitch.com)。

## Glitch でプロジェクトを操作するには? {#how-do-i-work-with-a-project-on-glitch}
Glitch でプロジェクトを操作するには、次の手順を行います。

1. プロジェクトのプロジェクトページに移動します。ページは `https://glitch.com/~word-otherword` という構造になっています

2. **View Source** をクリックします

3. 画面右上の **Remix to Edit** をクリックします。プロジェクトを自由に変更できるようになります。 

新しいプロジェクトで作業したい場合は、サインインしてから右上の **New Project** をクリックすることもできます。 

## Glitch でログやコンソールを確認するには? {#how-do-i-see-logs-or-the-console-on-glitch}
ページ下部の **Tools** をクリックすると、ターミナルからプロジェクトを確認できます。監査ログ(Logs)とフルページのコンソール(Full Page Console)のどちらを表示するかを選べます。 

## どの言語を使用できますか? {#what-languages-can-i-use}
Glitch が公式にサポートしているのは javascript のみです。ただし、非公式には他の多くの言語も使用できます。Glitch は次の言語でも動作させることができます。 
* C/C++
* Haskell
* OCaml
* Perl
* Erlang
* Elixir
* Lua 5.2
* PHP 
* Ruby
* Java
* Python
* Go 
* Rust
* Racket 

## Glitch と Python {#glitch-and-python}
Glitch 上の Python プロジェクトに依存関係を追加するには、インポートしたいモジュールを記載した **requirements.txt** ファイルを含めます。 

インポートしたいモジュールがインポートされない場合があります。その場合は Glitch のコンソールを使って追加できますが、必ず `--user` タグを使ってユーザー領域にインストールしてください。 

`pip install --user module_name`
