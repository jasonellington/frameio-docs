# リソースデータをたどる {#navigating-resource-data}

Frame.io の API ペイロードは非常に包括的です。つまり(たとえば)Asset の Status Label フィールドの変更を検知した場合、大量のフィールドを目にすることになりますが、その中で直接関係するものはごくわずかかもしれません。

![Field examples](/images/platform/v2/overview-frame-io-resources-in-zapier/96b556247084aa9ced664a076acc8e22da0c44c5def47b9147b2c0c968964aec.webp)

幸い、Zapier のデータ入力フィールドにはすべて検索機能があり、それを使えば必要なフィールドにすばやくたどり着けます。

![Quick-search for asset approved](/images/platform/v2/overview-frame-io-resources-in-zapier/38f94d317a462a7caf7fdc781713c0040001d99ef441cd25507b215ca373f70e.webp)

もちろん、何を探せばよいかがわかっていると便利です。

## 探すべきもの {#what-to-look-for}

次の表は網羅的なものではありませんが、Frame.io の Zapier インテグレーションでワークフローを構築する際の足がかりになるはずです。

<Info>

**Asset の URL は長いですが、問題ありません**

Frame.io の API レスポンスに含まれる Asset の URL は、Amazon S3 への直接リンクです。これらの URL は、Asset を別のシステムに移動したいあらゆる Zapier アプリのコンテキストで使用でき、また使用すべきです。「File Attachment」と「File Attachment (URL)」のどちらかを選べる場合は、後者を選んでください。Zapier の URL アップロードは、一般により幅広いファイル形式とサイズをサポートしています。

</Info>

| リソースタイプ | Zapier のフィールド | 説明 |
| --- | --- | --- |
| Asset(すべて) | Original | アップロードされた元の動画で、手が加えられていないものです。ほとんどの場合、他のシステムに送りたいのはこのキーです。ただし、常に元のファイル形式であるため、他のすべてのコンテキストで再生できるとは限りません。 |
| Asset(動画) | H264 *resolution* | Frame.io のすべての h.264 プロキシが、Zapier の Asset で利用できます。 |
| Asset(画像) | Image *quality* | h.264 動画プロキシと同様に、画像用に作成されたすべてのプロキシも Zapier で利用できます。 |
| Asset(すべて) | Thumb | Frame.io で設定された Asset のサムネイルです。このフィールドは、Trello や Airtable などのプロジェクト管理システムにビジュアルを追加するのに最適です。 |
| Asset(すべて) | Label | Status Label です。このフィールドは通常、「Filter」アクションと組み合わせて使用します(上のスクリーンショットと同様)。 |
| Asset(すべて) | Creator Email | 元のアップロード者のメールアドレスです。 |
| Asset(すべて) | Project ID | Asset の親 Project の ID です。このフィールドは、Project の名前を取得できる「Find Project」アクションと組み合わせると最も便利です。 |
| Asset(すべて) | Parent ID | Asset の親の ID で、常にフォルダー、バージョンスタック、Project ルートのいずれかです。 |
| Comment | Text | コメントのテキストです。 |
| Comment | Asset ID | Comment の親 Asset の ID です。追加のコンテキストを得るために Find Asset アクションに渡したり、外部のトラッキングツールでリンクしたりするのに便利です。 |
| Comment | Owner Name | Comment を残したユーザーの姓名です。 |
| Comment | Owner Email | Comment を残したユーザーのメールアドレスです。 |
| Project | Name | Project の名前です。 |
