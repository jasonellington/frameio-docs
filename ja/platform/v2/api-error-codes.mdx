---
title: "API エラーコード"
---

Frame.io API は、次の一般的なエラーを返す場合があります。

| コード | 詳細 | 理由 |
| --- | --- | --- |
| `401` | **Unauthorized** — API トークンが無効です。Bearer Token 認証を使用しているか、Authorization ヘッダーでトークンを渡しているかを確認してください。 |  |
| `402` | **Usage exceeded** — Frame.io プランの上限を超えています。 |  |
| `403` | **Forbidden** — そのリソースへのアクセス権がありません。ユーザーのアクセス権とトークンのスコープのどちらの場合にも返されます。 |  |
| `404` | **Not Found** — リソースが見つかりません。 | リソースが移動または削除されています。 |
| `422` | **Invalid arguments** — 指定された 1 つ以上のパラメーターが無効です。 |  |
| `429` | **Rate Limited** — API のレート制限に達しました。 |  |
| `500` | **Server Error** — サーバーがリクエストを解釈できなかったか、利用可能な時間枠（30 秒）内にリクエストを完了できませんでした。 | リクエスト URL やボディの形式が正しくないか、その他の理由で完了できませんでした。 |

# 一般的なエラーのトラブルシューティング {#troubleshooting-common-errors}

有効な API トークンを使用して一般的なタスクを実行する場合、最もよく発生するエラーは `403`、`404`、`500` です。

**403** エラーは通常、次の 3 つのいずれかの状況を示します。

1. リクエストで使用されたトークン、またはトークンの所有者であるユーザー（あるいはその両方）が、リソースがリクエストされた Frame.io アカウントの領域に対して十分なアクセス権を持っていない。
2. リクエストされたリソースに対して、トークンに十分なスコープがない。例：`comments.read` スコープなしで `GET /comments/` を呼び出す。
3. ネットワークトラフィックの問題により、Frame.io API がリクエストを処理できない。*ネットワークトラフィックの問題によってリクエストがブロックされている疑いがある場合は、カスタマーサポートにお問い合わせください。*

**404** エラーは通常、リソースがもう存在しない（移動または削除された）ことを示します。

**500** エラーは通常、リクエスト URL やボディの形式が正しくないことを示しますが、利用可能な時間枠（30 秒）内にリクエストを完了できなかった場合にも発生することがあります。

# レート制限 {#rate-limiting}

Frame.io API は、トークンごとにレート制限を適用します。トークンのデフォルトの制限は、1 秒あたり 50 回の呼び出しです。一部のメソッドにはより低い制限があります（例：POST `/assets/:id/children` のレート制限は 1 秒あたり 5 アセットです）。

すべての制限は変更される可能性があり、制限に達すると 429 HTTP エラーが返されます。レート制限への対処には、指数バックオフ方式の使用をお勧めします。

詳しくは、レート制限に関する[ガイド](/ja/platform/v2/rate-limits)をご覧ください。
