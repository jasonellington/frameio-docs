## すべてのアカウントでのアクセス {#all-account-access}

Adobe Admin Console で管理されているアカウントに限らず、すべての Frame V4 アカウントでトークンを作成し、V4 API にアクセスできます。顧客とパートナーは、最新の API 機能を使ってワークフローをテスト、構築、改善できます。

<Steps>

<Step title="ユーザー認証トークンを作成する">

Adobe Developer Console にアクセスして、ユーザー認証トークンを作成します。API トークンのアクセスを検証するため、ユーザーは Frame へのログインと同じ Adobe ID を使用する必要があります。

</Step>

<Step title="API 認証情報を作成する">

API にアクセスできるようになったら、次のステップとして、Frame と通信するための API 認証情報 (API トークン) を作成します。API 認証情報は developer.adobe.com で作成します。

</Step>

</Steps>

![Account Access](/images/platform/docs/guides/accounts-projects-and-workspaces/706a4eb9324bc24a3465388a838455baf58384f128882a185dad2d1900f728a3.webp)

<Info>

Frame で管理されている (V4F) か Adobe で管理されている (V4A) かにかかわらず、すべての V4 アカウントで Adobe Developer Console に Project を作成し、認証情報を作成できます。認証情報一式 (OAuth Client ID/Client Secret) を取得したら、Adobe Developer Platform の 3-legged OAuth フローと連携できます。Adobe ID でサインインして有効な認証トークンとリフレッシュトークンを受け取り、Frame.io V4 Developer API にリクエストを送信しましょう。

</Info>

## プロジェクトとワークスペース {#projects-and-workspaces}

### ワークスペースの更新内容 {#workspace-updates}

Frame.io のランディングページが新しくなり、ワークスペースページという名前になりました。ユーザーは、アカウント内でアクセス権を持つワークスペースとプロジェクトを閲覧できます。この新しいデザインにより、特定のワークスペースに誰が所属しているかを把握しやすくなり、新しいメンバーをすばやく招待できるようになりました。

<Note>

Frame V3 では、ワークスペースはチーム (Teams) と呼ばれていました。

</Note>

V4 ではワークスペースは招待制に設定されているため、ユーザーには明示的に招待されたワークスペースのみが表示されます。また、アカウント設定にはチームディレクトリのページはありません。

権限の管理や関連する操作を行うには、ワークスペースの Create、List、Delete、Update の各エンドポイントを使用します。

<CardGroup cols={1}>

<Card title="ワークスペースの管理操作" icon="users" iconType="solid" horizontal={true}>

- 特定のワークスペースのユーザーロールを一覧表示します。
- 特定のワークスペースからユーザーを削除します。
- ユーザーがすでにワークスペースに追加されている場合は、そのワークスペースのユーザーロールを更新します。ユーザーがワークスペースに追加されていない場合は、指定したロールでユーザーが追加されます。

</Card>

</CardGroup>

### プロジェクトの更新内容 {#project-updates}

V4 では、プロジェクトの作成フローが変更されました。新しいプロジェクトを開始する際に、空のプロジェクトとプロジェクトテンプレートのいずれかを選択します。一般的なクリエイティブワークフロー向けに設計された 12 種類のテンプレートから選択できます。また、テンプレートのデモアセットを含めるか、テンプレートの構造のみで開始するかを選択することもできます。プロジェクトテンプレートを選択すると、ワークスペースに新しいプロジェクトがすぐに作成されます。

権限の管理や関連する操作を行うには、プロジェクトの Create、List、Delete、Update の各エンドポイントを使用します。

<CardGroup cols={1}>

<Card title="プロジェクトの管理操作" icon="folder" iconType="solid" horizontal={true}>

- 特定のプロジェクトのユーザーロールを一覧表示します。
- 特定のプロジェクトからユーザーを削除します。
- ユーザーがすでにプロジェクトに追加されている場合は、そのプロジェクトのユーザーロールを更新します。ユーザーがプロジェクトに追加されていない場合は、指定したロールでユーザーが追加されます。

</Card>

</CardGroup>
