## Camera To Cloud {#camera-to-cloud}

Camera to Cloud API は、表示機能が限られたデバイス向けに設計された、シンプルな認証プロトコルを提供します。認証が完了すると、デバイスは撮影現場のデータをクラウドへ直接アップロードできます。このシステムは、動画、音声、LUT/CDL、タイムコードデータの標準的なファイル形式のほとんどをサポートしています。C2C 認定コネクションの詳細については、[情報ページ](https://frame.io/c2c/certified)をご覧ください。

## はじめに {#getting-started}

[開発者サイト](/ja/#start-building)でサインアップしていただくと、Cloud Devices インテグレーションのプロセスをご案内するために当社からご連絡します。

デバイスを確認した後、共有の Slack チャンネルを設定し、お客様と協力してインテグレーション計画とタイムラインを作成します。インテグレーションを成功させるために必要なすべての資料が含まれた開発パッケージをお渡しします。

## ドキュメントリソース {#documentation-resources}

この記事は、C2C インテグレーションを支援する一連のガイドの最初の記事です。これらのガイドは出発点です。ドキュメントや API の改善についてご質問やご提案があれば、ぜひ私たちのチームにご連絡ください。これらは網羅的なリファレンスではなく、インテグレーションを進めるための土台と考えてください。

## 開発者パッケージ {#developer-package}

開発パッケージには次のものが含まれます。

**1. クライアントシークレット**

Frame.io は、お客様のデバイス用の設定モデルを当社のバックエンドに作成します。完了すると、デバイス用の `client_secret` (一般にデバイスモデル識別子と呼ばれます) が発行されます。

**2. リファレンス実装**

CLI ツールを通じてハードウェアデバイスをエミュレートするスケルトンコードを含む、Python のリファレンス実装が提供されます。これには、インテグレーションの主要な手順を説明するコメント付きのコードとドキュメントが含まれています。

**3. 検証プロセス**

リリース前に、Frame.io のエンジニアとともに品質保証プロセスに参加し、デバイスが期待どおりに動作することを確認します。私たちの目標は、クラウド接続されたお客様のデバイスを使用するエンドユーザーのために、すべてのインテグレーターが一貫した品質基準を達成できるよう支援することです。これにより、一般公開前に貴重なフィードバックを得ることができます。レビュー項目のチェックリストをお渡ししますが、インテグレーションを成功させるための要素を理解するために、[C2C インテグレーションチェックリスト](/ja/camera-to-cloud/integrator-checklist)を参照することもできます。

**4. サポート資料**

Frame.io の価値提案やデモの手法をチームが理解するための資料が提供され、当社チームと連携するための専用 Slack チャンネルにアクセスできます。Frame.io プラットフォームのデモやインテグレーションのベストプラクティスに関するワークショップなど、追加のサポートが必要な場合はお知らせください。適切なセッションを手配します。

## インテグレーションの計画 {#planning-your-integration}

当社チームとの打ち合わせの前または最中に、いくつかの技術的な詳細について検討する必要があります。ご連絡いただく前にこれらの情報をすべて準備しておく必要はありません。この概要は、これらの点について考え始めるためのものです。

### デバイス情報 {#device-information}

デバイスに関する基本的な情報が必要です。

* デバイスの正式な名称
* SVG 形式のロゴ (モノクロが望ましい)

### 認証方法 {#authentication-method}

現在、6 桁のコードによる認証フローのみをサポートしています。アプリケーション向けには、デバイスコードをリクエストする際に特別なヘッダーパラメーターを使用して URL ペアリングフローを有効にする拡張方式を提供しています。これにより `verification_uri_complete` または `verification_uri` パラメーターが返されるので、それを使ってハイパーリンクや QR コードとして URL を生成し、ユーザーがタップまたはスキャンできるようにします。これにより、ユーザーが選択したプロジェクトに直接接続する簡素化されたペアリングプロセスが開始されます。実装の詳細については、[QR コードペアリングの有効化ガイド](/ja/camera-to-cloud/implementing-c2c-authentication-and-authorization#h3-section-enabling-qr-code-pairing)を参照してください。

## マーケティングでの協力 {#marketing-collaboration}

新しい Cloud Devices インテグレーションはそれぞれ、クリエイティブワークフローの課題に対する革新的なソリューションを提供します。インテグレーションの開発とリリースに必要な多大な投資に感謝いたします。

普及を後押しするため、お客様と協力して当社の顧客や幅広い市場に向けたリソースを作成します。マーケティングのアプローチはインテグレーションごとに調整されますが、一般的な活動には次のようなものがあります。

* 当社の Solutions チームと協力して、最適なユースケースとワークフローを設計し、文書化する
* 共通のクライアントと協力して、本番環境でのインテグレーションの活用を示す事例を作成する
* ユーザーをお客様のデバイスやワークフローソリューションにつなげるための、当社チーム向けの営業資料を作成する
