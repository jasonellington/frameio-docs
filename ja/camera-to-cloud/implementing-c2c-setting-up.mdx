## はじめに {#introduction}

Camera to Cloud デバイスを実装する前に、成功に必要なものがすべて揃っているか確認しましょう。

## 開発者として登録する {#register-as-a-developer}

実装ガイドに沿って作業するには、デバイス用の `client_secret` が必要です。まだお済みでない場合は、C2C 開発者としての登録方法について[はじめにガイド](/ja/camera-to-cloud/getting-started-with-cloud-device-integrations)をご確認ください。API とのやり取りに必要な認証情報は、私たちのチームが提供します。

## 実装ガイドに沿って作業するためのツール {#tools-for-following-implementation-guides}

必須ではありませんが、以下のツールを用意しておくと、チュートリアルに沿って作業したり、API とのやり取りを直接テストしたりする際に役立ちます。

### cURL {#curl}

これらのチュートリアルでは、`curl` を使って Frame.io API リクエストを示します。広く使われているこのライブラリは、HTTP リクエストを行うための優れたコマンドラインインターフェースを提供します。デバイスを実装する際には、これらの HTTP 呼び出しをお好みのプログラミング言語で再現する必要があります。これらの例で `curl` を使用することで、コマンドをターミナルにコピーするだけで API とのやり取りをテストできます。

お使いのシステムに `curl` がインストールされているか確認するには、ターミナルで次のコマンドを入力します。

```shell
curl --version
```

次のような出力が表示されるはずです。

```text
curl 7.64.1 (x86_64-apple-darwin20.0) libcurl/7.64.1 (SecureTransport) LibreSSL/2.8.3 zlib/1.2.11 nghttp2/1.41.0
Release-Date: 2019-03-27
Protocols: dict file ftp ftps gopher http https imap imaps ldap ldaps pop3 pop3s rtsp smb smbs smtp smtps telnet tftp 
Features: AsynchDNS GSS-API HTTP2 HTTPS-proxy IPv6 Kerberos Largefile libz MultiSSL NTLM NTLM_WB SPNEGO SSL UnixSockets
```

インストールされていない場合は、ほとんどのオペレーティングシステム向けのインストーラーを[こちら](https://curl.se/download.html)から入手できます。macOS または Linux をお使いの場合は、[Homebrew](https://brew.sh/) でインストールできます。

```shell
brew install curl
```

### Python {#python}

`curl` の結果をパイプで渡し、Python を使って JSON レスポンスのペイロードを整形します。

```shell
curl https://api.frame.io/health | python -m json.tool
```

Python がインストールされているか確認するには、次のコマンドを実行します。

```shell
python --version
```

期待される出力:

```text
Python 2.7.16
```

インストールされていない場合は、[こちらから Python をダウンロード](https://www.python.org/downloads/)できます。これらの例は Python 2.6 以降または Python 3.x で動作します。

Python は必須ではありませんが、レスポンスを読みやすくするのに役立ちます。代わりに、[jq](https://stedolan.github.io/jq/) のようなツールでも同様の機能を利用できます。

## リファレンス実装 {#reference-implementation}

開発者パッケージには、C2C 接続としてメディアを Frame.io にアップロードするサンプル CLI アプリケーションを含む、Python のリファレンス実装が含まれています。これらのガイドの各セクションを読み進めた後、リファレンス実装を確認すると、各概念が実際に動作するコードでどのように適用されているかがわかり、役立つでしょう。
