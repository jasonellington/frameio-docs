## About Frame.io

[Frame.io](https://frame.io) is the cloud collaboration tool for professional video teams — everything you need to keep the creative process moving, all in a single workbench, accessible from anywhere. With Frame.io, you can securely upload, share, and review film projects, enabling your full operation to run at the speed of creativity.

### Frame.io Developer Platform

Not every creative team, process, or software stack is exactly the same. That’s where our Developer Platform comes in. The Frame.io Developer Platform allows you to handle common tasks using our API. Some popular use cases developers have used our API for include automatically adding existing files or folders to the Frame.io app, uploading new content, and managing teams.

## Camera to Cloud (C2C) Program

Camera to Cloud is a unique type of integration. These integrations are purpose built for any device or application that is generating data. If you are building a C2C integration then you will want to use the [C2C Integration guides](/camera-to-cloud/getting-started-with-cloud-device-integrations). There you can find all the information you need to get started connecting to the cloud with Frame.io!

## Quick Start Guide

If you want to get started right away, just click this button to bring our API into Postman!

[![Run in Postman](/images/platform/v2/index/button.svg)](https://www.getpostman.com/collections/c2dfffb88990a9dc34c2)

Otherwise, read on. As a starting point, you’ll need to ensure that you have a Frame.io account that you can sign in with.

From there:

- [Sign into the Developer Portal](/platform/v2) using your Frame.io credentials
- [Create a Developer Token](/platform/v2/authentication#developer-tokens)

To confirm that your token is working, go ahead and make a test call using a language, tool, or proxy of your choice:

<CodeGroup>

```bash title="cURL"
curl --request GET \
  --url https://api.frame.io/v2/me \
  --header 'authorization: Bearer <DEV_TOKEN>'
```

```python title="Python"
import requests

url = "https://api.frame.io/v2/me"
headers = {
 "Authorization": "Bearer <DEV_TOKEN>"
}

requests.GET(url,headers=headers)
```

</CodeGroup>

In response, you should see your user information.

## Event-based Workflows

Frame.io’s Developer Platform offers a few options you can use to extend your workflows into other tools, or to create whole new features.

### Webhooks

Webhooks provide a way to leverage events that occur inside of Frame.io into notifications that can be sent to external systems for processing, API callback, and workflow automation.

There a number of ways to use our webhooks. You can build something yourself or you can take advantage of a no-code automation tool like [Zapier](https://zapier.com), [Integromat](https://www.integromat.com), [Pabbly Connect](https://www.pabbly.com/), or [Pipedream](https://pipedream.com).

- [Webhooks](/platform/v2/webhooks-overview) - Webhooks expose Frame.io events to external URLs for consumption and processing.
- [Zapier](/platform/v2/get-started-with-zapier)  - An online automation tool that allows you to connect over 1,000 common apps and tools without writing code.

We have a [Webhooks Example App](https://github.com/Frameio/webhooks-example-app) on Github that you can use as a starting point if you’d like to build your own receiver.

### Custom Actions

[Custom Actions](/platform/v2/custom-actions-overview) allow you to build integrations directly into Frame.io as programmable UI components. They’re technically very similar to Webhooks, and are a great way to extend your Frame.io workflows.
