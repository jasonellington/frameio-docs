<Note>
  This is a demo endpoint for Mintlify's Update from code changes automation. It isn't part of the Frame.io API.
</Note>

Use this endpoint to check whether an asset has finished processing.

## Get an asset's status

```http
GET /v4/assets/{id}/status
```

### Path parameters

| Parameter | Type   | Description   |
| --------- | ------ | ------------- |
| `id`      | string | The asset ID. |

### Response fields

| Field             | Type   | Description                                                  |
| ----------------- | ------ | ------------------------------------------------------------ |
| `data.id`         | string | The asset ID.                                                |
| `data.status`     | string | The processing status: `processing` or `ready`.              |
| `data.updated_at` | string | When the asset was last updated, as an ISO 8601 UTC timestamp. |

### Example

```bash
curl http://localhost:3001/v4/assets/a1b2c3/status
```

```json
{
  "data": {
    "id": "a1b2c3",
    "status": "ready",
    "updated_at": "2026-11-03T18:22:10Z"
  }
}
```

### Errors

| Status | Error             | Meaning               |
| ------ | ----------------- | --------------------- |
| `404`  | `asset_not_found` | No asset has this ID. |
