## Introdução {#introduction}

Antes de implementar seu dispositivo Camera to Cloud, vamos garantir que você tenha tudo o que precisa para ter sucesso.

## Registre-se como desenvolvedor {#register-as-a-developer}

Você precisará de um `client_secret` para o seu dispositivo para acompanhar os guias de implementação. Se ainda não o fez, leia nosso [guia de primeiros passos](/pt-BR/camera-to-cloud/getting-started-with-cloud-device-integrations) para obter informações sobre como se registrar como desenvolvedor C2C. Nossa equipe fornecerá as credenciais necessárias para interagir com a API.

## Ferramentas para acompanhar os guias de implementação {#tools-for-following-implementation-guides}

Embora não sejam estritamente obrigatórias, ter estas ferramentas disponíveis ajudará você a acompanhar nossos tutoriais e testar as interações com a API diretamente.

### cURL {#curl}

Estes tutoriais demonstram solicitações à API do Frame.io usando `curl`. Essa biblioteca amplamente utilizada oferece uma excelente interface de linha de comando para fazer solicitações HTTP. Ao implementar seu dispositivo, você precisará reproduzir essas chamadas HTTP na linguagem de programação de sua preferência. Usar `curl` nestes exemplos permite testar as interações com a API simplesmente copiando os comandos para o seu terminal.

Para verificar se o `curl` está instalado no seu sistema, digite este comando no terminal:

```shell
curl --version
```

Você deverá ver uma saída semelhante a:

```text
curl 7.64.1 (x86_64-apple-darwin20.0) libcurl/7.64.1 (SecureTransport) LibreSSL/2.8.3 zlib/1.2.11 nghttp2/1.41.0
Release-Date: 2019-03-27
Protocols: dict file ftp ftps gopher http https imap imaps ldap ldaps pop3 pop3s rtsp smb smbs smtp smtps telnet tftp 
Features: AsynchDNS GSS-API HTTP2 HTTPS-proxy IPv6 Kerberos Largefile libz MultiSSL NTLM NTLM_WB SPNEGO SSL UnixSockets
```

Se não estiver instalado, você encontra instaladores para a maioria dos sistemas operacionais [aqui](https://curl.se/download.html). Usuários de macOS ou Linux podem instalá-lo via [Homebrew](https://brew.sh/):

```shell
brew install curl
```

### Python {#python}

Usaremos o Python para formatar os payloads de resposta JSON, redirecionando os resultados do `curl` por meio dele:

```shell
curl https://api.frame.io/health | python -m json.tool
```

Para verificar se o Python está instalado:

```shell
python --version
```

Saída esperada:

```text
Python 2.7.16
```

Se não estiver instalado, você pode [baixar o Python aqui](https://www.python.org/downloads/). Python 2.6+ ou Python 3.x funcionarão para estes exemplos.

Embora o Python não seja obrigatório, ele ajuda a tornar as respostas mais legíveis. Como alternativa, ferramentas como o [jq](https://stedolan.github.io/jq/) oferecem funcionalidade semelhante.
