## Camera To Cloud {#camera-to-cloud}

A API Camera to Cloud oferece um protocolo de autenticação simples, projetado para dispositivos com recursos de exibição limitados. Depois de autenticado, seu dispositivo pode fazer upload dos dados do set diretamente para a nuvem. O sistema é compatível com a maioria dos formatos de arquivo padrão para vídeo, áudio, LUT/CDL e dados de timecode. Para mais detalhes sobre as conexões certificadas C2C, visite nossa [página de informações](https://frame.io/c2c/certified).

## Primeiros passos {#getting-started}

Cadastre-se em nosso [site para desenvolvedores](/pt-BR/#start-building) e entraremos em contato para orientar você no processo de integração de Cloud Devices.

Depois de analisar seu dispositivo, criaremos um canal compartilhado no Slack e trabalharemos com você para elaborar um plano e um cronograma de integração. Você receberá um pacote de desenvolvimento com todos os materiais necessários para construir uma integração bem-sucedida.

## Pacote para desenvolvedores {#developer-package}

Seu pacote de desenvolvimento incluirá:

**1. Client Secret**

O Frame.io criará um modelo de configuração em nosso backend para o seu dispositivo. Depois de concluído, você receberá um `client_secret` para o seu dispositivo, comumente chamado de identificador de modelo do dispositivo.

**2. Implementação de referência**

Você receberá uma implementação de referência em Python com código esqueleto que emula dispositivos de hardware por meio de uma ferramenta CLI. Ela inclui código comentado e documentação descrevendo as principais etapas da integração.

**3. Processo de validação**

Antes do lançamento, você participará de um processo de garantia de qualidade com engenheiros do Frame.io para garantir que seu dispositivo funcione conforme o esperado. Nosso objetivo é ajudar todos os integradores a alcançar padrões de qualidade consistentes para os usuários finais que trabalham com seu dispositivo conectado à nuvem. Isso fornece um feedback valioso antes do lançamento público. Forneceremos uma checklist de itens de revisão, mas você também pode consultar nossa [checklist de integração C2C](/pt-BR/camera-to-cloud/integrator-checklist) para entender o que torna uma integração bem-sucedida.

**4. Materiais de suporte**

Você receberá materiais para ajudar sua equipe a entender a proposta de valor do Frame.io e técnicas de demonstração, além de acesso a um canal dedicado no Slack para trabalhar com nossa equipe. Se precisar de suporte adicional — como uma demonstração da plataforma Frame.io ou um workshop de boas práticas de integração — avise-nos e organizaremos as sessões apropriadas.

## Planejando sua integração {#planning-your-integration}

Antes ou durante suas conversas com nossa equipe, vários detalhes técnicos precisarão ser tratados. Você não precisa ter todas essas informações prontas antes de entrar em contato conosco — esta visão geral serve para ajudar você a começar a pensar nesses aspectos.

### Informações do dispositivo {#device-information}

Precisaremos de algumas informações básicas sobre o seu dispositivo:

* O nome exato do seu dispositivo
* Um logotipo em formato SVG, de preferência monocromático

### Método de autenticação {#authentication-method}

Agora oferecemos suporte exclusivamente ao fluxo de autenticação com código de 6 dígitos. Para aplicativos, oferecemos um método aprimorado que usa um parâmetro de header especial ao solicitar um código de dispositivo, para habilitar nosso fluxo de pareamento por URL. Isso retorna os parâmetros `verification_uri_complete` ou `verification_uri`, que você pode usar para gerar uma URL por meio de um hiperlink ou de um QR code para que os usuários toquem ou escaneiem. Isso inicia um processo de pareamento simplificado que se conecta diretamente ao projeto selecionado pelo usuário. Para detalhes de implementação, consulte o [guia de habilitação do pareamento por QR code](/pt-BR/camera-to-cloud/implementing-c2c-authentication-and-authorization#h3-section-enabling-qr-code-pairing).

## Colaboração de marketing {#marketing-collaboration}

Cada nova integração de Cloud Devices oferece soluções inovadoras para desafios de fluxos de trabalho criativos. Reconhecemos o investimento significativo necessário para desenvolver e lançar sua integração.

Para apoiar a adoção, trabalharemos com você para criar recursos para nossos clientes e para o mercado em geral. Embora as abordagens de marketing sejam adaptadas a cada integração, as atividades típicas incluem:

* Trabalhar com nossa equipe de Soluções para projetar e documentar casos de uso e fluxos de trabalho ideais
* Colaborar com clientes em comum para desenvolver estudos de caso que mostrem sua integração em produção
* Criar materiais de vendas para que nossa equipe conecte os usuários ao seu dispositivo e às suas soluções de fluxo de trabalho
