## Acesso para todas as contas {#all-account-access}

Todas as contas do Frame V4 — não apenas aquelas gerenciadas pelo Adobe Admin Console — podem criar tokens e acessar a API V4. Clientes e parceiros podem testar, criar e refinar seus fluxos de trabalho usando os recursos mais recentes da nossa API.

<Steps>

<Step title="Criar token de autenticação de usuário">

Acesse o Adobe Developer Console para criar um token de autenticação de usuário. O usuário deve usar o mesmo Adobe ID do seu login no Frame para validar o acesso com o token da API.

</Step>

<Step title="Criar credenciais da API">

Depois de ter acesso às APIs, o próximo passo é criar credenciais da API, ou um token da API, para se comunicar com o Frame. Crie suas credenciais da API em developer.adobe.com.

</Step>

</Steps>

![Acesso à conta](/images/platform/docs/guides/accounts-projects-and-workspaces/706a4eb9324bc24a3465388a838455baf58384f128882a185dad2d1900f728a3.webp)

<Info>

Todas as contas V4, sejam gerenciadas pelo Frame (V4F) ou pela Adobe (V4A), podem criar um Project no Adobe Developer Console e, em seguida, criar credenciais. Depois de obter um conjunto de credenciais (OAuth Client ID/Client Secret), você pode fazer a integração com o fluxo OAuth de três etapas (three-legged) da Adobe Developer Platform. Faça login com sua Adobe Identity para receber um token de autenticação e um refresh token válidos e fazer requisições à Frame.io V4 Developer API!

</Info>

## Projetos e workspaces {#projects-and-workspaces}

### Novidades dos workspaces {#workspace-updates}

A página inicial do Frame.io é nova e se chama página Workspace. Os usuários podem navegar pelos Workspaces e Projects aos quais têm acesso em uma conta. Graças a esse novo design, ficou mais fácil ver quem pertence a um determinado Workspace e convidar novas pessoas rapidamente.

<Note>

No Frame V3, os Workspaces eram conhecidos como Teams.

</Note>

Os Workspaces são configurados como somente por convite (Invite Only) no V4, portanto os usuários verão apenas os Workspaces para os quais foram explicitamente convidados. Além disso, não há uma página Team Directory nas configurações da conta.

Para gerenciar permissões e operações relacionadas, use os endpoints Create, List, Delete e Update de Workspace.

### Novidades dos projetos {#project-updates}

O fluxo de criação de Projects mudou no V4. Agora, ao iniciar um novo Project, você escolhe entre um Project em branco ou um Project Template. Há doze templates para escolher, projetados para fluxos de trabalho criativos comuns. Você também pode optar por incluir os assets de demonstração do template ou começar apenas com a estrutura do template. Escolher um Project Template cria imediatamente um novo Project no seu Workspace.

Para gerenciar permissões e operações relacionadas, use os endpoints Create, List, Delete e Update de Project.
