O Make é uma plataforma de automação sem código que conecta seus aplicativos e serviços. Ele usa uma interface visual na qual você cria workflows chamados cenários, encadeando diferentes módulos.

Todo cenário tem um gatilho (como “novo Projeto criado no Frame.io”) e ações que vêm em seguida (como “adicionar uma linha ao Google Sheets”). Você conecta esses módulos visualmente para definir o que acontece e em que ordem.

## Por que conectar o Frame.io ao Make? {#why-connect-frame-io-to-make}

O Make estende o Frame.io por todo o seu workflow. Sincronize arquivos com o armazenamento, atualize ferramentas de gerenciamento de projetos, gere relatórios, notifique sua equipe ou crie workflows personalizados com base na atividade do Frame.io. Quanto mais você conecta o Frame.io ao seu conjunto de ferramentas, mais poderoso ele se torna.

**Ideias de automação:**

- Criar automaticamente Projetos no Frame.io quando um cliente envia um formulário de entrada
- Publicar no Slack quando comentários forem adicionados a um vídeo no Frame.io
- Atualizar uma planilha do Google Sheets quando um novo Projeto do Frame.io for criado

Esses são apenas alguns exemplos. Para ver a lista completa de módulos do Frame.io disponíveis, confira esta página no [Make.com](https://www.make.com/en/integrations/frame-io#:~:text=All-,Modules,-(26)).

## O que você precisa {#what-you-need}

- **Uma conta do Frame.io** (veja as informações de assinatura [aqui](https://frame.io/pricing))
- **Uma conta do Make** (plano gratuito disponível)

## Tipos de módulos {#module-types}

O Make tem quatro tipos de módulos: gatilhos, pesquisas, ações e módulos universais.

<CardGroup cols={2}>

<Card title="Gatilhos" icon="bell" iconType="solid" horizontal={true}>

Os gatilhos monitoram alterações em um serviço e as trazem para o Make, para que você possa usar esses dados no seu cenário. Você pode adicionar **um** módulo de gatilho por cenário.

<br />

Consulte a seção **Tipos de gatilhos** abaixo para obter detalhes sobre gatilhos de polling e instantâneos.

<br />

- Você pode definir com que frequência um módulo de gatilho é executado clicando em **Schedule settings** na barra de ferramentas do cenário
- O Make recomenda fortemente iniciar os cenários com um módulo de gatilho.

</Card>

<Card title="Pesquisas" icon="magnifying-glass" iconType="solid" horizontal={true}>

Os módulos de pesquisa recuperam dados específicos de um serviço. Você pode adicionar vários módulos de pesquisa em qualquer lugar do seu cenário. A maioria das pesquisas retorna até 3.200 objetos por execução.

<br />

**Tipos de módulos de pesquisa:**

<br />

- **Módulos de pesquisa** permitem filtrar e usar consultas para encontrar dados específicos
  (Search Records, Search Rows etc.)
- **Módulos de listagem** recuperam todos os dados sem filtragem. (List Projects, List Sheets etc.)

</Card>

<Card title="Ações" icon="bolt" iconType="solid" horizontal={true}>

Os módulos de ação processam os dados recuperados de um serviço. Você pode adicionar quantas ações forem necessárias, em qualquer lugar do seu cenário.

<br />

**Tipos de ações:**

<br />

- GET
- CREATE
- UPDATE
- DELETE

<br />

</Card>

Os módulos universais (geralmente chamados de **Make an API Call**) permitem fazer chamadas de API personalizadas quando o Make não oferece um módulo pronto para o que você precisa.

<br />

Você pode adicionar quantos módulos universais forem necessários e posicioná-los em qualquer lugar do seu cenário.

## Tipos de gatilhos {#trigger-types}

O Make usa dois tipos de gatilhos: de polling e instantâneos.

**Gatilhos de polling** verificam periodicamente a conta do serviço em busca de novos dados. Eles geralmente têm nomes como “Watch Records” ou “Watch Rows”. Quando o cenário é executado, o Make pergunta ao serviço se há algo novo. Se houver, o cenário processa os dados.

**Gatilhos instantâneos** funcionam de forma diferente. Eles usam webhooks, então o serviço avisa o Make imediatamente quando algo acontece. Seu cenário é executado na hora. Você pode identificá-los pelo ícone de raio e pela etiqueta “Instant” no módulo.

O módulo Watch Events do Frame.io é um gatilho instantâneo, portanto o cenário que vamos criar mais adiante será executado em tempo real.

O Make traz mais detalhes sobre como os diferentes tipos de módulos são executados [nesta seção da Central de Ajuda deles](https://help.make.com/types-of-modules).

# A interface do Make {#the-make-interface}

O painel do Make mostra todos os seus cenários. É aqui que você monitora os cenários ativos, o desempenho dos cenários e o uso de créditos. Clique em **Create scenario** no cabeçalho para abrir o editor.

### Adicionando aplicativos e módulos {#adding-applications-+-modules}

Para adicionar módulos ao seu cenário, clique no botão de mais no centro do editor. Isso abre um painel no qual você pode pesquisar o aplicativo de que precisa, como Frame.io ou Google Sheets, e selecionar o módulo específico desejado (como “Watch Events” ou “Add a Row”). Arraste e solte os módulos no editor para conectá-los e montar seu cenário.

### Gerenciando e reconectando aplicativos {#managing-+-reconnecting-apps}

A barra lateral esquerda dá acesso a cenários, conexões, webhooks e outros recursos do Make.

Se precisar reconectar o Frame.io ou qualquer outro aplicativo, clique em **Connections** na barra lateral esquerda. Você verá todos os aplicativos conectados com um botão **Reauthorize** ao lado de cada um. Clique nele para passar novamente pelo fluxo de autenticação.

### Testes {#testing}

Para testar seu cenário, clique em **Run once** na barra de ferramentas. Quando o teste terminar, bolhas de operação aparecerão acima de cada módulo mostrando quantas operações foram executadas. Clique em uma bolha para ver os dados de entrada e saída dessa etapa.

**Testando com dados existentes:**

Por padrão, os gatilhos processam apenas eventos novos. Para testar com dados existentes, clique na seta suspensa ao lado do botão **Run once**. Isso abre uma caixa de diálogo na qual você pode executar novamente os dados de um evento de webhook recebido anteriormente.

# Criando seu primeiro cenário: registrar novos projetos no Google Sheets {#building-your-first-scenario-log-new-projects-to-google-sheets}

Antes de começar, crie uma planilha do Google Sheets com estes cabeçalhos de coluna:

**Event Type**, **Resource ID**, **Workspace ID**, **User ID**. Neste exemplo, chamaremos a planilha de “Frame Projects”.

<Steps>

<Step title="Conecte o Frame.io e adicione o gatilho">

Clique no sinal de mais no editor do Make para adicionar um módulo. Pesquise “Frame.io” e selecione **Watch Events**. Isso cria um webhook que é acionado quando eventos específicos acontecem no Frame.io.

**Conectando o Frame.io:**

- Clique em **Add** ao lado do campo de conexão
- Mantenha o nome de conexão padrão ou renomeie-o
- Você será solicitado a fazer login na sua conta Adobe e autorizar o Make
- Depois de conectado, você verá todas as suas contas e workspaces do Frame.io disponíveis nos menus suspensos

**Configure o webhook:**

- Selecione sua conta e o workspace que deseja monitorar. Neste exemplo, usaremos “New Workspace”
- Em eventos, escolha **Project Created** (para saber mais sobre os eventos compatíveis, consulte nossa [documentação de webhooks](https://developer.adobe.com/frameio/guides/Webhooks/#webhook-event-subscriptions))
- Dê um nome ao seu webhook e salve as alterações

</Step>

<Step title="Adicione o Google Sheets">

Clique no sinal de mais para adicionar a próxima etapa. Pesquise e selecione o aplicativo Google Sheets e clique no módulo **Add a Row**.

**Conecte o Google Sheets:**

- Clique em **Add** para criar uma nova conexão
- Clique em **Sign in with Google** e autorize o Make a acessar sua conta do Google
- Depois de conectado, você deverá ver as planilhas da sua conta nos menus suspensos
- Selecione o nome da planilha/aba (no nosso caso, “Frame Projects”)

**Mapeie os dados:**
Agora mapeie os dados do Frame.io para as colunas da sua planilha. Clique em cada campo e selecione os dados correspondentes do gatilho do Frame.io:

- **Event Type** → mapeie para Frame.io Event Type
- **Resource ID** → mapeie para Frame.io Resource
- **Workspace ID** → mapeie para Frame.io Workspace ID
- **User ID** → mapeie para Frame.io User ID

</Step>

<Step title="Teste e ative">

Clique em **Run once** para testar o cenário e, em seguida, crie um novo projeto no workspace do Frame.io selecionado. Se tudo estiver configurado corretamente, uma nova linha deverá aparecer na sua planilha.

![Planilha](/images/platform/docs/guides/make/frame_sheet_example.gif)

Quando estiver pronto para colocar em produção, mude a chave para **Active** e o cenário será executado automaticamente.

</Step>

</Steps>

Você acabou de criar sua primeira automação. A partir daqui, você pode adicionar mais etapas a este cenário ou criar novos usando os outros módulos do Frame.io disponíveis no [Make.com](https://www.make.com/en/integrations/frame-io#:~:text=All-,Modules,-(26))

Se tiver problemas, dúvidas ou quiser compartilhar o que você criou, acesse o [Fórum da Comunidade](https://forum.frame.io/).
