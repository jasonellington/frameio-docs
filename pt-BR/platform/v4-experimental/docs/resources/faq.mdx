## Perguntas sobre compatibilidade {#compatibility-questions}

<AccordionGroup>

<Accordion title="A API do Frame.io V4 é retrocompatível?">

<Warning>

Não. O produto Frame.io lançado no Adobe MAX funciona de maneiras fundamentalmente diferentes e prioriza workflows diferentes dos da versão legada. Devido a essas diferenças, a nova API não é retrocompatível.

</Warning>

</Accordion>

<Accordion title="Como a retrocompatibilidade será tratada daqui para frente?">

Reconhecendo que a retrocompatibilidade é uma grande preocupação para clientes que mantêm integrações de nível de produção com altos requisitos de disponibilidade, estamos projetando a API V4 para oferecer suporte a um nível adicional de versionamento por meio de um cabeçalho HTTP personalizado, permitindo que os clientes optem por usar endpoints experimentais, evitem alterações incompatíveis e tenham garantias de retrocompatibilidade dentro do namespace da API `/v4`.

</Accordion>

<Accordion title="Quando a API V4 estiver disponível para todos, as automações que configurei com o produto legado continuarão funcionando? Ou seja, elas serão migradas automaticamente para a V4?">

<Warning>

Nenhuma automação que use tokens de desenvolvedor legados funcionará com contas V4. **Não** temos nenhuma forma de migrá-las para a V4.

</Warning>

</Accordion>

</AccordionGroup>

## Mídia e arquivos {#media-&-files}

<AccordionGroup>

<Accordion title="Por quanto tempo as URLs de links de mídia são válidas?">

As URLs retornadas em `media_links` (como `download_url`, `inline_url` e `url`) são **URLs assinadas temporárias** — elas expiram e não podem ser reutilizadas indefinidamente.

| Tipo de URL | Expiração |
| --- | --- |
| URLs de download e inline (`original`, `high_quality`, `efficient`, `video_h264_180`) | Até 24 horas |
| URLs de miniatura e pré-visualização (`thumbnail`) | Até 24 horas |

Na prática, a expiração é alinhada ao meio-dia ou à meia-noite UTC, portanto o tempo restante real quando você recebe uma URL pode variar de alguns minutos a 24 horas, dependendo de quando a requisição é feita.

**Não armazene nem faça cache dessas URLs.** Sempre solicite um novo conjunto de `media_links` cada vez que precisar disponibilizar ou acessar um arquivo. Tentar usar uma URL expirada resultará em um erro `403` da CDN.

</Accordion>

</AccordionGroup>
