title: "Como usar o ngrok"
---

O ngrok é uma ferramenta fácil de usar que permite criar um túnel seguro na sua máquina local, junto com uma URL pública que você pode usar para testar seu projeto local ou para compartilhar seu trabalho para revisão com um cliente ou colega de equipe. Você pode configurar HTTP ou HTTPS e, graças à popularidade dessa ferramenta, se algo der errado, há muitos artigos descrevendo diferentes formas de resolver o problema. Este artigo aborda algumas maneiras fáceis de instalar o ngrok e o que fazer se você não conseguir fazer seu aplicativo web se comunicar com o ngrok.

## Instale o ngrok {#install-ngrok}

Você pode usar o ngrok de algumas maneiras diferentes

### Instale pelo instalador do ngrok {#install-via-the-ngrok-installer}

1. Acesse o site do ngrok e siga as instruções: [https://ngrok.com/download](https://ngrok.com/download)
2. Se você quiser os recursos oferecidos ao conectar uma conta, siga estas instruções para obter uma conta e um token.

Você não precisa criar uma conta nem adicionar o token, mas vale a pena conferir a página de download para ver se isso é algo que você quer ou precisa.

<Info>

**Observação:**

Se você usar esse método, o ngrok será executado a partir do local onde você o armazenou, a menos que você o disponibilize em todo o sistema.

</Info>

### Instale com o Homebrew {#install-with-homebrew}

Este é o meu método favorito para instalar o ngrok. Se você tiver o Homebrew instalado, basta digitar `homebrew cask install ngrok`. O ngrok será instalado e você poderá usá-lo de qualquer lugar! O melhor de tudo é que você não precisa digitar `./ngrok` no terminal no início de cada comando; basta digitar `ngrok`. Você pode ler mais sobre essa opção [aqui](https://gist.github.com/wosephjeber/aa174fb851dfe87e644e).

## Use o ngrok {#use-ngrok}

Depois de configurar o ngrok, escolha uma porta, como `3000`, e execute-o pela linha de comando do terminal com o comando ngrok http `3000`. Você não precisa usar a porta `3000`, mas ela é uma escolha comum na configuração.

Se você configurou o ngrok para ser executado a partir de uma pasta específica, precisa estar na pasta onde colocou o ngrok e usar o comando `./ngrok http 3000`.

Inicie o servidor do seu projeto para escutar na mesma porta, e você poderá acessar seu trabalho usando o endereço público fornecido pelo ngrok.

### Solução de problemas do ngrok com seu app web: barra final {#troubleshooting-ngrok-with-your-web-app-trailing-slash}

Um problema que você pode encontrar com o ngrok é não conseguir se conectar ao seu servidor ao configurar uma URL do ngrok para uso com seu app web. O que é frustrante nesse problema é que o ngrok não registra que você enviou algo para ele. Você pode abrir localhost:4040 para ver o que está acontecendo, e nada será exibido. (O localhost:4040 é fornecido pelo ngrok para que você possa monitorar todas as solicitações recebidas pelo seu servidor.) O ngrok parece associar os endereços a /(.*) em vez de (/.*), então, se você não incluir uma barra no final do endereço e não vir nada nas ferramentas de monitoramento do ngrok, é porque o ngrok não está encontrando uma correspondência para o endereço informado.

Aqui está um exemplo com a barra final adicionada: `http://something.ngrok.io/`

Você também pode escrever seus aplicativos de exemplo para resolver para um endpoint que inclua uma barra. Só lembre que, para o app do Frame.io alcançar seu servidor, se o seu app de exemplo usar o endpoint `/actions`, você precisará adicionar o endpoint /actions ao final do seu endereço do ngrok. Por exemplo, se o endereço do ngrok for `http://something.ngrok.io`, você precisará informá-lo na configuração da sua Custom Action como `http://something.ngrok.io/actions`. Isso pode ser diferente para outros aplicativos web, então experimente variações no final do endereço do ngrok se não conseguir fazer tudo funcionar de imediato.

### Posso usar algo além do ngrok? Experimente o Glitch! {#can-i-use-something-besides-ngrok-try-glitch}

O Glitch é uma alternativa bem interessante ao ngrok e é mais rápido de configurar. O Glitch permite criar uma conta e depois desenvolver seus próprios apps usando os servidores deles, com uma URL acessível publicamente. Você pode colaborar com outras pessoas, deixar seu código público ou privado e escolher entre uma grande variedade de linguagens e plataformas. Acesse [https://glitch.com/create](https://glitch.com/create) para ver o que está disponível.

Ao configurar seu projeto no Glitch, o problema da barra final se aplica a alguns aplicativos web. No caso do Frame.io, ao configurar uma Custom Action no [developer.frame.io](/pt-BR/platform/v2), você precisa incluir a barra final no fim da URL fornecida pelo Glitch. Não é necessário adicionar mais nada, nem mesmo para o endpoint /actions.

### Existe algo já configurado que eu possa testar agora? {#is-there-something-set-up-i-could-try-now}

Sim. Se você não quiser usar o ngrok nem criar seu próprio projeto no Glitch, configuramos um aplicativo de exemplo para você testar aqui: [https://frameio-custom-action.glitch.me](https://frameio-custom-action.glitch.me). Lembre-se de incluir a barra final ao adicionar esse endereço na área Custom Actions de \[/).
