# Compatibilidade entre navegadores para o login do Frame.io {#cross-browser-support-for-frame-io-login}

Embora isso não seja relevante para aplicativos totalmente baseados em API, a compatibilidade do Frame.io com diferentes navegadores entra em jogo ao carregar nosso [aplicativo Accounts](https://accounts.frame.io/) durante um fluxo de concessão de credenciais OAuth.

Ao criar aplicativos OAuth para o Frame.io, saiba que a página de login que apresentamos no fluxo OAuth segue a mesma compatibilidade com navegadores do nosso aplicativo web principal. Para os fins da tabela abaixo, compatibilidade “Parcial” significa que todas as funcionalidades principais devem funcionar sem impedimentos, mas podem ocorrer alguns pequenos problemas de layout. Compatibilidade “Mínima” significa que pode funcionar, mas não testamos nem oferecemos mais suporte explicitamente.

| Navegador | Compatibilidade |
| --- | --- |
| Chrome (mais recente) | Total |
| Safari (mais recente) | Total |
| Firefox (mais recente) | Total |
| Opera (mais recente) | Total |
| Edge (mais recente) | Total |
| IE (11+) | Mínima |
| IE (&lt;=10) | Nenhuma |
| Mobile Safari (mais recente) | Parcial |
| Chrome para iOS (mais recente) | Parcial |
| Chrome para Android (mais recente) | Parcial |
| Navegador do Android (mais recente) | Parcial |
