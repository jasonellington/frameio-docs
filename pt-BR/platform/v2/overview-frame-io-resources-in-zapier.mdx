# Navegar pelos dados dos recursos {#navigating-resource-data}

Os payloads da nossa API são bem completos! Isso significa (por exemplo) que, ao capturar uma alteração no campo Status Label de um Asset, você pode acabar vendo uma grande quantidade de campos, dos quais pouquíssimos serão imediatamente relevantes para você.

![Exemplos de campos](/images/platform/v2/overview-frame-io-resources-in-zapier/96b556247084aa9ced664a076acc8e22da0c44c5def47b9147b2c0c968964aec.webp)

A boa notícia é que todos os campos de entrada de dados do Zapier têm uma função de busca e, com ela, você pode chegar rapidamente ao campo de que precisa.

![Busca rápida por asset aprovado](/images/platform/v2/overview-frame-io-resources-in-zapier/38f94d317a462a7caf7fdc781713c0040001d99ef441cd25507b215ca373f70e.webp)

Claro que também ajuda saber o que procurar.

## O que procurar {#what-to-look-for}

A tabela a seguir não é exaustiva, mas deve ajudar você a começar a criar workflows com a integração do Frame.io com o Zapier.

<Info>

**As URLs de Assets são longas, e tudo bem**

As URLs de Assets que você vê nas respostas da API do Frame.io são links diretos para o Amazon S3. Essas URLs podem e devem ser usadas em qualquer contexto de app do Zapier em que você queira mover um Asset para outro sistema. Se puder escolher entre "File Attachment" e "File Attachment (URL)", escolha a segunda opção, pois os envios por URL no Zapier geralmente oferecem suporte a uma variedade maior de tipos e tamanhos de arquivo.

</Info>

| Tipo de recurso | Campo no Zapier | Descrição |
| --- | --- | --- |
| Asset (todos) | Original | O vídeo original enviado, sem alterações. Na maioria dos casos, essa será a chave que você vai querer enviar para outros sistemas; mas ela sempre estará no tipo de arquivo original, portanto pode não ser reproduzível em todos os outros contextos. |
| Asset (vídeos) | H264 *resolution* | Todos os proxies h.264 do Frame.io estão disponíveis no Asset no Zapier. |
| Asset (imagem) | Image *quality* | Assim como os proxies de vídeo h.264, todos os proxies gerados para imagens também estão disponíveis no Zapier. |
| Asset (todos) | Thumb | A miniatura do Asset, conforme definida no Frame.io. Esse campo é ótimo para adicionar elementos visuais a sistemas de acompanhamento de projetos como Trello ou Airtable. |
| Asset (todos) | Label | O Status Label. Esse campo geralmente será combinado com uma ação "Filter" (semelhante à captura de tela acima). |
| Asset (todos) | Creator Email | O endereço de e-mail de quem fez o envio original. |
| Asset (todos) | Project ID | O ID do Project pai do Asset. Esse campo é mais útil quando combinado com a ação "Find Project", que você pode usar para obter o nome do Project. |
| Asset (todos) | Parent ID | O ID do pai de um Asset, que sempre será uma pasta, um version stack ou a raiz do Project. |
| Comment | Text | O texto do comentário. |
| Comment | Asset ID | O ID do Asset pai do Comment. Útil para passar à ação Find Asset para obter contexto adicional ou para criar links em ferramentas externas de acompanhamento. |
| Comment | Owner Name | O nome e o sobrenome do usuário que deixou o Comment. |
| Comment | Owner Email | O endereço de e-mail do usuário que deixou o Comment. |
| Project | Name | O nome do Project. |
