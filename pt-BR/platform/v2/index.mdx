## Sobre o Frame.io {#about-frame-io}

O [Frame.io](https://frame.io) é a ferramenta de colaboração em nuvem para equipes profissionais de vídeo — tudo o que você precisa para manter o processo criativo em andamento, reunido em uma única bancada de trabalho, acessível de qualquer lugar. Com o Frame.io, você pode enviar, compartilhar e revisar projetos audiovisuais com segurança, permitindo que toda a sua operação funcione na velocidade da criatividade.

### Plataforma de desenvolvedores do Frame.io {#frame-io-developer-platform}

Nem toda equipe criativa, processo ou conjunto de softwares é exatamente igual. É aí que entra a nossa Plataforma de desenvolvedores. A Plataforma de desenvolvedores do Frame.io permite que você realize tarefas comuns usando a nossa API. Alguns casos de uso populares para os quais os desenvolvedores já usaram nossa API incluem adicionar automaticamente arquivos ou pastas existentes ao app Frame.io, enviar novos conteúdos e gerenciar equipes.

## Programa Camera to Cloud (C2C) {#camera-to-cloud-c2c-program}

O Camera to Cloud é um tipo único de integração. Essas integrações são criadas especificamente para qualquer dispositivo ou aplicativo que gere dados. Se você estiver criando uma integração C2C, use os [guias de integração C2C](/pt-BR/camera-to-cloud/getting-started-with-cloud-device-integrations). Lá você encontra todas as informações necessárias para começar a se conectar à nuvem com o Frame.io!

## Guia de início rápido {#quick-start-guide}

Se quiser começar imediatamente, basta clicar neste botão para levar a nossa API para o Postman!

[![Run in Postman](/images/platform/v2/index/button.svg)](https://www.getpostman.com/collections/c2dfffb88990a9dc34c2)

Caso contrário, continue lendo. Como ponto de partida, você precisa ter uma conta do Frame.io com a qual possa fazer login.

A partir daí:

- [Faça login no Portal do desenvolvedor](/pt-BR/platform/v2) usando suas credenciais do Frame.io
- [Crie um token de desenvolvedor](/pt-BR/platform/v2/authentication#developer-tokens)

Para confirmar que seu token está funcionando, faça uma chamada de teste usando a linguagem, ferramenta ou proxy de sua preferência:

<CodeGroup>

```bash title="cURL"
curl --request GET \
  --url https://api.frame.io/v2/me \
  --header 'authorization: Bearer <DEV_TOKEN>'
```

```python title="Python"
import requests

url = "https://api.frame.io/v2/me"
headers = {
 "Authorization": "Bearer <DEV_TOKEN>"
}

requests.GET(url,headers=headers)
```

</CodeGroup>

Na resposta, você deverá ver as informações do seu usuário.

## Workflows baseados em eventos {#event-based-workflows}

A Plataforma de desenvolvedores do Frame.io oferece algumas opções que você pode usar para estender seus workflows a outras ferramentas ou para criar recursos totalmente novos.

### Webhooks {#webhooks}

Os webhooks oferecem uma forma de transformar eventos que ocorrem dentro do Frame.io em notificações que podem ser enviadas a sistemas externos para processamento, callback de API e automação de workflows.

Há várias maneiras de usar nossos webhooks. Você pode criar algo por conta própria ou aproveitar uma ferramenta de automação sem código como [Zapier](https://zapier.com), [Integromat](https://www.integromat.com), [Pabbly Connect](https://www.pabbly.com/) ou [Pipedream](https://pipedream.com).

- [Webhooks](/pt-BR/platform/v2/webhooks-overview) - Os webhooks expõem eventos do Frame.io a URLs externas para consumo e processamento.
- [Zapier](/pt-BR/platform/v2/get-started-with-zapier)  - Uma ferramenta de automação on-line que permite conectar mais de 1.000 apps e ferramentas comuns sem escrever código.

Temos um [app de exemplo de webhooks](https://github.com/Frameio/webhooks-example-app) no Github que você pode usar como ponto de partida se quiser criar seu próprio receptor.

### Custom Actions {#custom-actions}

As [Custom Actions](/pt-BR/platform/v2/custom-actions-overview) permitem criar integrações diretamente no Frame.io como componentes de interface programáveis. Tecnicamente, elas são muito semelhantes aos webhooks e são uma ótima maneira de estender seus workflows do Frame.io.
