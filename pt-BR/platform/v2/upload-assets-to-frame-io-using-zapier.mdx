## Visão geral {#overview}

Se você quiser enviar arquivos para o Frame.io a partir de apps em nuvem existentes ou de uma URL que disponibiliza assets, o Zapier geralmente é uma boa solução, pois o produto resolve muitas divergências de design de API que tornam a interação com apps em nuvem uma dor de cabeça.  Este guia esclarece os principais atributos do serviço de envio do Zapier para que você saiba exatamente o que está acontecendo na sua integração.

## Definir o método de envio de arquivos {#setting-the-file-upload-method}

O Zapier tenta descobrir automaticamente o método de envio de arquivos mais flexível para cada API à qual se conecta.  Por exemplo, o Zapier tentará converter links restritos, que não podem ser acessados fora do domínio de um app, em links de download publicamente disponíveis:

Link original ilegível:
`https://www.dropbox.com/s/hriinb9w3a2107m/iPad%20intro.pdf`

Link convertido, utilizável pela API Uploader do Frame.io:
`https://dl.dropboxusercontent.com/s/hriinb9w3a2107m/iPad%20intro.pdf`

### Limitações de arquivos do Zapier {#zapier’s-file-limitations}

É importante saber que, se o Zapier **não conseguir** descobrir uma URL de download estática para passar à API do Frame.io, o próprio serviço do Zapier baixará os arquivos em tempo real e os passará ao Frame.io.  O Zapier restringe esse método a arquivos com **[menos de 100 MB](https://zapier.com/help/doc/common-problems-dropbox)**.

Observe que a interface do Zapier pode alertar você sobre restrições de tamanho de arquivo mesmo ao passar uma URL direta (ou seja, quando não há restrição).  Por isso vale a pena entender como o File URL funciona.

## Métodos de envio para apps e serviços comuns {#upload-methods-for-common-apps-and-services}

**Observação:** integrações do tipo **File Upload** estão sujeitas aos limites de tamanho de arquivo indicados na interface do Zapier. Links diretos são preferíveis, pois não estão sujeitos a limitações de tamanho e são processados de forma mais rápida e confiável.

| App | Tipo | Dicas e referências |
| --- | --- | --- |
| Gmail | File Upload | [Documentação de ajuda do Zapier](https://zapier.com/help/doc/common-problems-gmail#how-can-i-attach-a-file-to-my-email-that39s-not-in-my-trigger) |
| Google Drive | Direct Link | Você deve colar `webContentLink` no seletor File.  Isso funciona para arquivos que você envia ao Google Drive, mas não funciona para documentos ou apresentações criados dentro do Drive. [Documentação de ajuda do Zapier](https://zapier.com/help/doc/common-problems-google-drive#unable-to-get-a-value-when-looking-for-quotfilequot-is-it-missing), [API do Google Drive V3](https://developers.google.com/drive/api/v3/manage-downloads) |
| Dropbox | Direct Link | Enviar automaticamente arquivos do Dropbox para o Frame.io |
| Box | Direct Link | Use `Info Shared Link Download URL` [Guias da API do Box](https://developer.box.com/guides/downloads/shared-link/) |
| S3 | Direct Link | Guia do Zapier: problemas comuns com o S3 |
