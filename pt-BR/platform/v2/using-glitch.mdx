---
title: "Usar o Glitch"
---

O Glitch é uma ferramenta que permite criar aplicativos web de forma rápida e fácil. Você pode executá-los no Glitch para testá-los sem o trabalho de configurar seu próprio servidor com um endereço web público. 

Este guia traz algumas dicas e truques básicos para trabalhar com o Glitch. 

## Como faço para me cadastrar no Glitch? {#how-do-i-sign-up-for-glitch}
Clique em **Sign In** e escolha um dos métodos oferecidos. O Glitch oferece suporte a login com Facebook, GitHub, Google e e-mail. Você pode começar aqui: [https://glitch.com](https://glitch.com).

## Como trabalho com um projeto no Glitch? {#how-do-i-work-with-a-project-on-glitch}
Para trabalhar com um projeto no Glitch, faça o seguinte:

1. Acesse a página do projeto, que terá a estrutura `https://glitch.com/~word-otherword`

2. Clique em **View Source**

3. No canto superior direito da tela, clique em **Remix to Edit**. Você poderá alterar o projeto como quiser. 

Você também pode fazer login e clicar em **New Project** no canto superior direito se quiser trabalhar em um novo projeto. 

## Como vejo os logs ou o console no Glitch? {#how-do-i-see-logs-or-the-console-on-glitch}
Você pode acompanhar seu projeto a partir de um terminal clicando em **Tools** na parte inferior da página. Você poderá optar por ver um log de auditoria (Logs) e um Full Page Console. 

## Quais linguagens posso usar? {#what-languages-can-i-use}
Oficialmente, o Glitch oferece suporte apenas a javascript. Mas você pode usar muitas outras linguagens de forma não oficial. É possível fazer o Glitch funcionar com: 
* C/C++
* Haskell
* OCaml
* Perl
* Erlang
* Elixir
* Lua 5.2
* PHP 
* Ruby
* Java
* Python
* Go 
* Rust
* Racket 

## Glitch e Python {#glitch-and-python}
Você pode adicionar dependências ao seu projeto Python no Glitch incluindo um arquivo **requirements.txt** com os módulos que deseja importar. 

Às vezes, um módulo que você deseja importar não é importado. Você pode adicioná-lo usando o console do Glitch, mas certifique-se de instalá-lo na sua área de usuário usando a flag `--user`. 

`pip install --user module_name`
