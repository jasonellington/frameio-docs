## Perguntas sobre compatibilidade {#compatibility-questions}

<AccordionGroup>

<Accordion title="A API Frame.io V4 é retrocompatível?">

<Warning>

Não. O produto Frame.io lançado no Adobe MAX funciona de maneiras fundamentalmente diferentes e prioriza fluxos de trabalho diferentes da versão legada. Devido a essas diferenças, a nova API não é retrocompatível.

</Warning>

</Accordion>

<Accordion title="Como a retrocompatibilidade será tratada daqui em diante?">

Reconhecendo que a retrocompatibilidade é uma grande preocupação para clientes que gerenciam integrações de qualidade de produção com altos requisitos de disponibilidade, estamos projetando a API V4 para oferecer um nível adicional de versionamento por meio de um cabeçalho HTTP personalizado, a fim de permitir que os clientes optem por usar endpoints experimentais, evitem alterações incompatíveis e contem com garantias de retrocompatibilidade dentro do namespace da API `/v4`.

</Accordion>

<Accordion title="Quando a API V4 estiver disponível para todos, as automações que configurei com o produto legado continuarão funcionando? Ou seja, elas serão migradas automaticamente para a V4?">

<Warning>

Todas as automações que usam tokens de desenvolvedor legados deixarão de funcionar em contas V4. **Não** temos nenhuma forma de migrá-las para a V4.

</Warning>

</Accordion>

</AccordionGroup>

## Mídia e arquivos {#media-&-files}

<AccordionGroup>

<Accordion title="Por quanto tempo as URLs de links de mídia são válidas?">

As URLs retornadas em `media_links` (como `download_url`, `inline_url` e `url`) são **URLs assinadas temporárias**: elas expiram e não podem ser reutilizadas indefinidamente.

| Tipo de URL | Expiração |
| --- | --- |
| URLs de download e inline (`original`, `high_quality`, `efficient`, `video_h264_180`) | Até 24 horas |
| URLs de miniatura e prévia (`thumbnail`) | Até 24 horas |

Na prática, a expiração é alinhada ao meio-dia ou à meia-noite UTC; portanto, o tempo restante real quando você recebe uma URL pode variar de alguns minutos a 24 horas, dependendo de quando a solicitação é feita.

**Não armazene nem coloque essas URLs em cache.** Sempre solicite um novo conjunto de `media_links` sempre que precisar disponibilizar ou acessar um arquivo. Tentar usar uma URL expirada resultará em um erro `403` da CDN.

</Accordion>

</AccordionGroup>
