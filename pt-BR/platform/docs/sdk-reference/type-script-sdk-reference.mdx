title: "Referência do SDK de TypeScript"

### Instalação {#installation}

```bash
npm i -s frameio
```

---

### Uso {#usage}

Crie uma instância do cliente e use-o da seguinte forma:

```typescript
import { FrameioClient } from "frameio";

const client = new FrameioClient({ token: "YOUR_TOKEN" });
await client.metadataFields.metadataFieldDefinitionsCreate("b2702c44-c6da-4bb6-8bbd-be6e547ccf1b", {
    data: {
        field_type: "select",
        field_configuration: {
            enable_add_new: false,
            options: [
                {
                    display_name: "Option 1",
                },
                {
                    display_name: "Option 2",
                },
            ],
        },
        name: "Fields definition name",
    },
});
```

---

### Tipos de solicitação e resposta {#request-and-response-types}

O SDK exporta todos os tipos de solicitação e resposta como interfaces TypeScript. Basta importá-los com o seguinte namespace:

```typescript
import { Frameio } from "frameio";

const request: Frameio.UpdateFieldDefinitionParams = {
    ...
};
```

---

### Tratamento de exceções {#exception-handling}

Quando a API retorna um código de status de falha (resposta 4xx ou 5xx), uma subclasse do seguinte erro será lançada.

```typescript
import { FrameioError } from "frameio";

try {
    await client.metadataFields.metadataFieldDefinitionsCreate(...);
} catch (err) {
    if (err instanceof FrameioError) {
        console.log(err.statusCode);
        console.log(err.message);
        console.log(err.body);
        console.log(err.rawResponse);
    }
}
```

### Avançado {#advanced}

#### Cabeçalhos adicionais {#additional-headers}

Se quiser enviar cabeçalhos adicionais como parte da solicitação, use a opção de solicitação headers.

```typescript
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    headers: {
        'X-Custom-Header': 'custom value'
    }
});
```

#### Parâmetros adicionais de query string {#additional-query-string-parameters}

Se quiser enviar parâmetros adicionais de query string como parte da solicitação, use a opção de solicitação queryParams.

```typescript
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    queryParams: {
        'customQueryParamKey': 'custom query param value'
    }
});
```

---

#### Novas tentativas {#retries}

O SDK conta com novas tentativas automáticas com backoff exponencial. Uma solicitação será tentada novamente desde que seja considerada passível de nova tentativa e o número de tentativas não ultrapasse o limite configurado (padrão: 2).

Uma solicitação é considerada passível de nova tentativa quando qualquer um dos seguintes códigos de status HTTP é retornado:

- 408 (Tempo esgotado)
- 429 (Solicitações em excesso)
- 5XX (Erros internos do servidor)

<br />

Use a opção de solicitação `maxRetries` para configurar esse comportamento.

```typescript
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    maxRetries: 0 // override maxRetries at the request level
});
```

---

#### Tempos limite {#timeouts}

Por padrão, o SDK usa um tempo limite de 60 segundos. Use a opção timeoutInSeconds para configurar esse comportamento.

```typescript
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    timeoutInSeconds: 30 // override timeout to 30s
});
```

#### Cancelamento de solicitações {#aborting-requests}

O SDK permite cancelar solicitações a qualquer momento passando um sinal de cancelamento (abort signal).

```typescript
const controller = new AbortController();
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    abortSignal: controller.signal
});
controller.abort(); // aborts the request
```

---

#### Acesso aos dados brutos da resposta {#access-raw-response-data}

O SDK fornece acesso aos dados brutos da resposta, incluindo os cabeçalhos, por meio do método `.withRawResponse()`. O método `.withRawResponse()` retorna uma promise que resulta em um objeto com as propriedades `data` e `rawResponse`.

```typescript
const { data, rawResponse } = await client.metadataFields.metadataFieldDefinitionsCreate(...).withRawResponse();

console.log(data);
console.log(rawResponse.headers['X-My-Header']);
```

#### Compatibilidade de runtime {#runtime-compatibility}

O SDK funciona nos seguintes runtimes:

- Node.js 18+
- Vercel
- Cloudflare Workers
- Deno v1.25+
- Bun 1.0+
- React Native

---

#### Personalização do cliente Fetch {#customizing-fetch-client}

O SDK oferece uma forma de personalizar o cliente HTTP / a função Fetch subjacente. Se você estiver executando em um ambiente sem suporte, essa é uma alternativa de emergência para garantir que o SDK funcione.

```typescript
import { FrameioClient } from "frameio";

const client = new FrameioClient({
    ...
    fetcher: // provide your implementation here
});
```

#### Autenticação {#auth}

<AccordionGroup>

<Accordion title="new ServerToServerAuth({ clientId, clientSecret, ... })">

Autentica usando a concessão `client_credentials` do OAuth 2.0. Esse fluxo não envolve um usuário e não retorna um refresh token. Quando o token de acesso expira, o SDK solicita automaticamente um novo usando as credenciais do cliente.

```typescript title="usage"
import { FrameioClient, ServerToServerAuth } from "frameio";

const auth = new ServerToServerAuth({
    clientId: "YOUR_CLIENT_ID",
    clientSecret: "YOUR_CLIENT_SECRET",
});
const client = new FrameioClient({ token: () => auth.getToken() });
```

**Parâmetros**

`clientId`: `string` — ID do cliente OAuth do Adobe IMS.

`clientSecret`: `string` — Segredo do cliente OAuth do Adobe IMS.

`scopes`: `string` — Escopos separados por espaço (OAuth 2.0 RFC 6749). O padrão são os escopos server-to-server.

`imsBaseUrl`: `string` — URL base do IMS para ambientes de staging/alternativos. O padrão é produção.

`fetch`: `typeof fetch` — Implementação personalizada de fetch (para proxy, TLS etc.).

`onTokenRefreshed`: `OnTokenRefreshed` — Callback opcional disparado após cada obtenção de token.

`timeout`: `number` — Tempo limite da solicitação HTTP em milissegundos. O padrão é 30000.

`maxRetries`: `number` — Número máximo de novas tentativas para falhas transitórias. O padrão é 2.

`refreshBuffer`: `number` — Segundos antes da expiração para acionar a renovação proativa. O padrão é 60.

`logger`: `Logger` — Instância de logger para saída de diagnóstico.

**Métodos**

`getToken(): Promise<string>` — Retorna um token de acesso válido, renovando-o se necessário. Passe-o para o cliente: `new FrameioClient({ token: () => auth.getToken() })`.

`authenticate(): Promise<TokenResponse>` — Obtém explicitamente um novo token de acesso.

`revoke(): Promise<void>` — Revoga os tokens no servidor e limpa o estado local.

`exportTokens(): ExportedTokens` — Exporta o estado atual dos tokens para persistência.

`importTokens(data: ExportedTokens): void` — Restaura o estado dos tokens a partir de um objeto exportado anteriormente.

</Accordion>

<Accordion title="new WebAppAuth({ clientId, clientSecret, redirectUri, ... })">

Autentica usando a concessão `authorization_code` do OAuth 2.0. Use para aplicações do lado do servidor que podem armazenar um segredo do cliente com segurança.

```typescript title="usage"
import { randomBytes } from "crypto";
import { FrameioClient, WebAppAuth } from "frameio";

const auth = new WebAppAuth({
    clientId: "YOUR_CLIENT_ID",
    clientSecret: "YOUR_CLIENT_SECRET",
    redirectUri: "https://myapp.com/callback",
});
const url = auth.getAuthorizationUrl({ state: randomBytes(24).toString("hex") });
// redirect the user to url ...
await auth.exchangeCode("CODE_FROM_CALLBACK");
const client = new FrameioClient({ token: () => auth.getToken() });
```

**Parâmetros**

`clientId`: `string` — ID do cliente OAuth do Adobe IMS.

`clientSecret`: `string` — Segredo do cliente OAuth do Adobe IMS.

`redirectUri`: `string` — URI de redirecionamento registrado.

`scopes`: `string` — Escopos separados por espaço (OAuth 2.0 RFC 6749).

`imsBaseUrl`: `string` — URL base do IMS para ambientes de staging/alternativos. O padrão é produção.

`fetch`: `typeof fetch` — Implementação personalizada de fetch (para proxy, TLS etc.).

`onTokenRefreshed`: `OnTokenRefreshed` — Callback opcional disparado após cada renovação de token.

`timeout`: `number` — Tempo limite da solicitação HTTP em milissegundos. O padrão é 30000.

`maxRetries`: `number` — Número máximo de novas tentativas para falhas transitórias. O padrão é 2.

`refreshBuffer`: `number` — Segundos antes da expiração para acionar a renovação proativa. O padrão é 60.

`logger`: `Logger` — Instância de logger para saída de diagnóstico.

**Métodos**

`getToken(): Promise<string>` — Retorna um token de acesso válido, renovando-o se necessário.

`getAuthorizationUrl({ state }): string` — Monta a URL de autorização do Adobe IMS. Passe um valor opaco de CSRF/state que será devolvido na resposta.

`exchangeCode(code: string): Promise<TokenResponse>` — Troca um código de autorização por tokens de acesso e de renovação.

`refresh(): Promise<TokenResponse>` — Aciona manualmente a renovação do token.

`revoke(): Promise<void>` — Revoga os tokens no servidor e limpa o estado local.

`exportTokens(): ExportedTokens` — Exporta o estado atual dos tokens para persistência.

`importTokens(data: ExportedTokens): void` — Restaura o estado dos tokens a partir de um objeto exportado anteriormente.

</Accordion>

<Accordion title="new SPAAuth({ clientId, redirectUri, ... })">

Autentica usando `authorization_code` + PKCE (sem segredo do cliente). Use para aplicações de página única (SPA) executadas no navegador que não podem armazenar um segredo do cliente com segurança.

```typescript title="usage"
import { randomBytes } from "crypto";
import { FrameioClient, SPAAuth } from "frameio";

const auth = new SPAAuth({
    clientId: "YOUR_CLIENT_ID",
    redirectUri: "https://myapp.com/cb",
});
const result = await auth.getAuthorizationUrl({ state: randomBytes(24).toString("hex") });
// redirect the user to result.url, store result.codeVerifier ...
await auth.exchangeCode({ code: "CODE_FROM_CALLBACK", codeVerifier: result.codeVerifier });
const client = new FrameioClient({ token: () => auth.getToken() });
```

**Parâmetros**

`clientId`: `string` — ID do cliente OAuth do Adobe IMS.

`redirectUri`: `string` — URI de redirecionamento registrado.

`scopes`: `string` — Escopos separados por espaço (OAuth 2.0 RFC 6749).

`imsBaseUrl`: `string` — URL base do IMS para ambientes de staging/alternativos. O padrão é produção.

`fetch`: `typeof fetch` — Implementação personalizada de fetch (para proxy, TLS etc.).

`onTokenRefreshed`: `OnTokenRefreshed` — Callback opcional disparado após cada renovação de token.

`timeout`: `number` — Tempo limite da solicitação HTTP em milissegundos. O padrão é 30000.

`maxRetries`: `number` — Número máximo de novas tentativas para falhas transitórias. O padrão é 2.

`refreshBuffer`: `number` — Segundos antes da expiração para acionar a renovação proativa. O padrão é 60.

`logger`: `Logger` — Instância de logger para saída de diagnóstico.

**Métodos**

`getToken(): Promise<string>` — Retorna um token de acesso válido, renovando-o se necessário.

`getAuthorizationUrl({ state }): Promise<AuthorizationUrlResult>` — Monta a URL de autorização do Adobe IMS com um desafio PKCE. Retorna um `AuthorizationUrlResult` com `url` e `codeVerifier`.

`exchangeCode({ code, codeVerifier }): Promise<TokenResponse>` — Troca um código de autorização + verificador PKCE por tokens.

`refresh(): Promise<TokenResponse>` — Aciona manualmente a renovação do token.

`revoke(): Promise<void>` — Revoga os tokens no servidor e limpa o estado local.

`exportTokens(): ExportedTokens` — Exporta o estado atual dos tokens para persistência.

`importTokens(data: ExportedTokens): void` — Restaura o estado dos tokens a partir de um objeto exportado anteriormente.

</Accordion>

<Accordion title="new NativeAppAuth({ clientId, redirectUri, ... })">

Autentica usando `authorization_code` + PKCE para aplicações desktop e móveis. Compartilha a mesma API de `SPAAuth`; use um URI de redirecionamento com esquema personalizado (por exemplo, `myapp://callback`).

```typescript title="usage"
import { randomBytes } from "crypto";
import { FrameioClient, NativeAppAuth } from "frameio";

const auth = new NativeAppAuth({
    clientId: "YOUR_CLIENT_ID",
    redirectUri: "myapp://callback",
});
const result = await auth.getAuthorizationUrl({ state: randomBytes(24).toString("hex") });
// open result.url in the system browser, store result.codeVerifier ...
await auth.exchangeCode({ code: "CODE_FROM_CALLBACK", codeVerifier: result.codeVerifier });
const client = new FrameioClient({ token: () => auth.getToken() });
```

**Parâmetros**

`clientId`: `string` — ID do cliente OAuth do Adobe IMS.

`redirectUri`: `string` — URI de redirecionamento registrado (esquema personalizado compatível).

`scopes`: `string` — Escopos separados por espaço (OAuth 2.0 RFC 6749).

`imsBaseUrl`: `string` — URL base do IMS para ambientes de staging/alternativos. O padrão é produção.

`fetch`: `typeof fetch` — Implementação personalizada de fetch (para proxy, TLS etc.).

`onTokenRefreshed`: `OnTokenRefreshed` — Callback opcional disparado após cada renovação de token.

`timeout`: `number` — Tempo limite da solicitação HTTP em milissegundos. O padrão é 30000.

`maxRetries`: `number` — Número máximo de novas tentativas para falhas transitórias. O padrão é 2.

`refreshBuffer`: `number` — Segundos antes da expiração para acionar a renovação proativa. O padrão é 60.

`logger`: `Logger` — Instância de logger para saída de diagnóstico.

**Métodos**

Os mesmos de `SPAAuth`: `getToken()`, `getAuthorizationUrl({ state })`, `exchangeCode({ code, codeVerifier })`, `refresh()`, `revoke()`, `exportTokens()`, `importTokens(data)`.

</Accordion>

<Accordion title="AuthorizationUrlResult">

Objeto retornado por `SPAAuth.getAuthorizationUrl()` e `NativeAppAuth.getAuthorizationUrl()`. Contém a URL de autorização e o verificador de código PKCE.

**Propriedades**

`url`: `string` — A URL de autorização completa para a qual o usuário deve ser redirecionado.

`codeVerifier`: `string` — O verificador de código PKCE a ser armazenado e passado para `exchangeCode()`.

</Accordion>

#### Exceções de autenticação {#auth-exceptions}

Todos os erros de autenticação estendem `FrameioAuthError` e podem ser importados de `frameio`.

| Exceção | Descrição |
| --- | --- |
| `FrameioAuthError` | Erro base para todos os erros do SDK de autenticação. |
| `AuthenticationError` | Falha na troca ou renovação do token. Possui as propriedades `errorCode` e `errorDescription`. |
| `TokenExpiredError` | O refresh token expirou; é necessário autenticar novamente. |
| `NetworkError` | Uma solicitação de rede falhou (tempo limite, erro de conexão etc.). |
| `RateLimitError` | O Adobe IMS retornou 429 e as novas tentativas se esgotaram. Possui a propriedade `retryAfter`. |
| `PKCEError` | Falha na verificação PKCE. |
| `ConfigurationError` | Uma configuração obrigatória está ausente ou é inválida. |
