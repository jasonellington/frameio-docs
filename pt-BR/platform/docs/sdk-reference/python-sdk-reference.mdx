### Uso {#usage}

Instancie e use o cliente da seguinte forma:

```python
from frameio import (
    Frameio,
    SelectDefinitionParamsFieldConfiguration,
    SelectDefinitionParamsFieldConfigurationOptionsItem,
)
from frameio.metadata_fields import CreateFieldDefinitionParamsData_Select

client = Frameio(
    token="YOUR_TOKEN",
)
client.metadata_fields.metadata_field_definitions_create(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    data=CreateFieldDefinitionParamsData_Select(
        field_configuration=SelectDefinitionParamsFieldConfiguration(
            enable_add_new=False,
            options=[
                SelectDefinitionParamsFieldConfigurationOptionsItem(
                    display_name="Option 1",
                ),
                SelectDefinitionParamsFieldConfigurationOptionsItem(
                    display_name="Option 2",
                ),
            ],
        ),
        name="Fields definition name",
    ),
)
```

### Cliente assíncrono {#async-client}

O SDK também exporta um cliente assíncrono para que você possa fazer chamadas não bloqueantes à nossa API. Observe que, se você estiver construindo uma classe de cliente httpx assíncrona para passar a este cliente, use httpx.AsyncClient() em vez de httpx.Client() (por exemplo, para o parâmetro httpx_client deste cliente).

```python
import asyncio

from frameio import (
    AsyncFrameio,
    SelectDefinitionParamsFieldConfiguration,
    SelectDefinitionParamsFieldConfigurationOptionsItem,
)
from frameio.metadata_fields import CreateFieldDefinitionParamsData_Select

client = AsyncFrameio(
    token="YOUR_TOKEN",
)


async def main() -> None:
    await client.metadata_fields.metadata_field_definitions_create(
        account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
        data=CreateFieldDefinitionParamsData_Select(
            field_configuration=SelectDefinitionParamsFieldConfiguration(
                enable_add_new=False,
                options=[
                    SelectDefinitionParamsFieldConfigurationOptionsItem(
                        display_name="Option 1",
                    ),
                    SelectDefinitionParamsFieldConfigurationOptionsItem(
                        display_name="Option 2",
                    ),
                ],
            ),
            name="Fields definition name",
        ),
    )


asyncio.run(main())
```

### Tratamento de exceções {#exception-handling}

Quando a API retorna um código de status de falha (resposta 4xx ou 5xx), uma subclasse do seguinte erro é lançada.

```python
from frameio.core.api_error import ApiError

try:
    client.metadata_fields.metadata_field_definitions_create(...)
except ApiError as e:
    print(e.status_code)
    print(e.body)
```

### Paginação {#pagination}

As solicitações paginadas retornam um SyncPager ou AsyncPager, que podem ser usados como geradores para o objeto subjacente.

```python
from frameio import Frameio

client = Frameio(
    token="YOUR_TOKEN",
)
response = client.project_permissions.index(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    project_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    page_size=10,
    include_total_count=False,
)
for item in response:
    yield item
# alternatively, you can paginate page-by-page
for page in response.iter_pages():
    yield page
```

### Avançado {#advanced}

#### Acessar dados brutos da resposta {#access-raw-response-data}

O SDK fornece acesso aos dados brutos da resposta, incluindo os cabeçalhos, por meio da propriedade .with_raw_response. A propriedade .with_raw_response retorna um cliente “bruto” que pode ser usado para acessar os atributos .headers e .data.

```python
from frameio import Frameio

client = Frameio(
    ...,
)
response = (
    client.metadata_fields.with_raw_response.metadata_field_definitions_create(
        ...
    )
)
print(response.headers)  # access the response headers
print(response.data)  # access the underlying object
pager = client.project_permissions.index(...)
print(pager.response.headers)  # access the response headers for the first page
for item in pager:
    print(item)  # access the underlying object(s)
for page in pager.iter_pages():
    print(page.response.headers)  # access the response headers for each page
    for item in page:
        print(item)  # access the underlying object(s)
```

#### Novas tentativas {#retries}

O SDK conta com novas tentativas automáticas com backoff exponencial. Uma solicitação será repetida desde que seja considerada passível de nova tentativa e que o número de tentativas não tenha ultrapassado o limite configurado (padrão: 2).<br />
Uma solicitação é considerada passível de nova tentativa quando qualquer um dos seguintes códigos de status HTTP é retornado:

- 408 (Tempo limite esgotado)
- 429 (Solicitações em excesso)
- 5XX (Erros internos do servidor)

<br />

Use a opção de solicitação `max_retries` para configurar esse comportamento.

```python
client.metadata_fields.metadata_field_definitions_create(..., request_options={
    "max_retries": 1
})
```

---

#### Tempos limite {#timeouts}

Por padrão, o SDK usa um tempo limite de 60 segundos. Você pode configurá-lo com a opção timeout no nível do cliente ou da solicitação.

```python
from frameio import Frameio

client = Frameio(
    ...,
    timeout=20.0,
)


# Override timeout for a specific method
client.metadata_fields.metadata_field_definitions_create(..., request_options={
    "timeout_in_seconds": 1
})
```

---

#### Cliente personalizado {#custom-client}

Você pode substituir o cliente httpx para personalizá-lo de acordo com seu caso de uso. Alguns casos de uso comuns incluem suporte a proxies e transportes.

```python
import httpx
from frameio import Frameio

client = Frameio(
    ...,
    httpx_client=httpx.Client(
        proxy="http://my.test.proxy.example.com",
        transport=httpx.HTTPTransport(local_address="0.0.0.0"),
    ),
)
```

#### Autenticação {#auth}

<AccordionGroup>

<Accordion title="frameio.auth.ServerToServerAuth(*, client_id, client_secret, ...)" defaultOpen={true}>

Autentica usando a concessão client_credentials do OAuth 2.0. Esse fluxo não envolve um usuário e não retorna um refresh token. Quando o token de acesso expira, o SDK solicita automaticamente um novo usando as credenciais do cliente. Para uso assíncrono, use `AsyncServerToServerAuth`.

```python title="usage"

from frameio import Frameio
from frameio.auth import ServerToServerAuth

auth = ServerToServerAuth(client_id="YOUR_CLIENT_ID", client_secret="YOUR_CLIENT_SECRET")
client = Frameio(token=auth.get_token)
```

**Parâmetros**

`client_id`: `str` — ID do cliente OAuth do Adobe IMS.

`client_secret`: `str` — Client secret OAuth do Adobe IMS.

`scopes`: `str` — Escopos separados por espaço (OAuth 2.0 RFC 6749). O padrão é `openid AdobeID frame.s2s.all`.

`ims_base_url`: `str` — URL base do IMS para ambientes de staging/alternativos. O padrão é produção.

`http_client`: `typing.Optional[httpx.Client]` — httpx.Client opcional para proxy, TLS ou pool de conexões.

`on_token_refreshed`: `typing.Optional[typing.Callable[[dict[str, Any]], None]]` — Callback opcional acionado após cada obtenção de token.

`timeout`: `float` — Tempo limite da solicitação HTTP em segundos. O padrão é 30.

`max_retries`: `int` — Número máximo de novas tentativas em caso de falhas transitórias. O padrão é 2.

`refresh_buffer`: `int` — Segundos antes da expiração para acionar a atualização proativa. O padrão é 60.

**Métodos**

`get_token() -> str` — Retorna um token de acesso válido, atualizando-o se necessário. Passe a referência a este método (não uma chamada) para o SDK: `Frameio(token=auth.get_token)`.

`authenticate() -> dict[str, Any]` — Obtém explicitamente um novo token de acesso. Retorna o dict de resposta do token com `access_token`, `expires_in` etc.

`revoke() -> None` — Revoga ambos os tokens no servidor e limpa o estado local.

`export_tokens() -> dict[str, Any]` — Exporta o estado atual dos tokens para persistência.

`import_tokens(data: dict[str, Any]) -> None` — Restaura o estado dos tokens a partir de um dict exportado anteriormente.

</Accordion>

<Accordion title="frameio.auth.WebAppAuth(*, client_id, client_secret, redirect_uri, ...)">

Autentica usando a concessão authorization_code do OAuth 2.0. Use esta opção para aplicativos do lado do servidor que podem armazenar um client secret com segurança. Para uso assíncrono, use `AsyncWebAppAuth`.

```python title="usage"

import secrets
from frameio import Frameio
from frameio.auth import WebAppAuth

auth = WebAppAuth(
    client_id="YOUR_CLIENT_ID",
    client_secret="YOUR_CLIENT_SECRET",
    redirect_uri="https://myapp.com/callback",
)
url = auth.get_authorization_url(state=secrets.token_urlsafe(32))
# redirect user to url ...
auth.exchange_code(code="CODE_FROM_CALLBACK")
client = Frameio(token=auth.get_token)
```

**Parâmetros**

`client_id`: `str` — ID do cliente OAuth do Adobe IMS.

`client_secret`: `str` — Client secret OAuth do Adobe IMS.

`redirect_uri`: `str` — URI de redirecionamento registrado.

`scopes`: `str` — Escopos separados por espaço (OAuth 2.0 RFC 6749).

`ims_base_url`: `str` — URL base do IMS para ambientes de staging/alternativos. O padrão é produção.

`http_client`: `typing.Optional[httpx.Client]` — httpx.Client opcional para proxy, TLS ou pool de conexões.

`on_token_refreshed`: `typing.Optional[typing.Callable[[dict[str, Any]], None]]` — Callback opcional acionado após cada atualização de token.

`timeout`: `float` — Tempo limite da solicitação HTTP em segundos. O padrão é 30.

`max_retries`: `int` — Número máximo de novas tentativas em caso de falhas transitórias. O padrão é 2.

`refresh_buffer`: `int` — Segundos antes da expiração para acionar a atualização proativa. O padrão é 60.

**Métodos**

`get_token() -> str` — Retorna um token de acesso válido, atualizando-o se necessário. Passe a referência a este método para o SDK: `Frameio(token=auth.get_token)`.

`get_authorization_url(state: str) -> str` — Cria a URL de autorização do Adobe IMS. Passe um valor opaco de CSRF/state que será devolvido.

`revoke() -> None` — Revoga ambos os tokens no servidor e limpa o estado local.

`export_tokens() -> dict[str, Any]` — Exporta o estado atual dos tokens para persistência.

`import_tokens(data: dict[str, Any]) -> None` — Restaura o estado dos tokens a partir de um dict exportado anteriormente.

<Accordion title="frameio.auth.SPAAuth(*, client_id, redirect_uri, ...)">

Autentica usando authorization_code + PKCE (sem client secret). Use esta opção para aplicativos baseados em navegador ou nativos que não podem armazenar um client secret com segurança. Para uso assíncrono, use `AsyncSPAAuth`.

```python title="usage"

import secrets
from frameio import Frameio
from frameio.auth import SPAAuth

auth = SPAAuth(client_id="YOUR_CLIENT_ID", redirect_uri="https://myapp.com/cb")
result = auth.get_authorization_url(state=secrets.token_urlsafe(32))
# redirect user to result.url, store result.code_verifier
auth.exchange_code(code="CODE_FROM_CALLBACK", code_verifier=result.code_verifier)
client = Frameio(token=auth.get_token)
```

**Parâmetros**

`client_id`: `str` — ID do cliente OAuth do Adobe IMS.

`redirect_uri`: `str` — URI de redirecionamento registrado.

`scopes`: `str` — Escopos separados por espaço (OAuth 2.0 RFC 6749).

`ims_base_url`: `str` — URL base do IMS para ambientes de staging/alternativos. O padrão é produção.

`http_client`: `typing.Optional[httpx.Client]` — httpx.Client opcional para proxy, TLS ou pool de conexões.

`on_token_refreshed`: `typing.Optional[typing.Callable[[dict[str, Any]], None]]` — Callback opcional acionado após cada atualização de token.

`timeout`: `float` — Tempo limite da solicitação HTTP em segundos. O padrão é 30.

`max_retries`: `int` — Número máximo de novas tentativas em caso de falhas transitórias. O padrão é 2.

`refresh_buffer`: `int` — Segundos antes da expiração para acionar a atualização proativa. O padrão é 60.

**Métodos**

`get_token() -> str` — Retorna um token de acesso válido, atualizando-o se necessário. Passe a referência a este método para o SDK: `Frameio(token=auth.get_token)`.

`get_authorization_url(state: str) -> AuthorizationUrlResult` — Cria a URL de autorização do Adobe IMS com o desafio PKCE. Retorna um `AuthorizationUrlResult` com os atributos `url` e `code_verifier`.

`exchange_code(code: str, code_verifier: str) -> dict[str, Any]` — Troca um código de autorização + verifier do PKCE por tokens.

`refresh() -> dict[str, Any]` — Aciona manualmente uma atualização de token.

`revoke() -> None` — Revoga ambos os tokens no servidor e limpa o estado local.

`export_tokens() -> dict[str, Any]` — Exporta o estado atual dos tokens para persistência.

`import_tokens(data: dict[str, Any]) -> None` — Restaura o estado dos tokens a partir de um dict exportado anteriormente.

<Accordion title="frameio.auth.AuthorizationUrlResult">

Dataclass imutável (frozen) retornada por `SPAAuth.get_authorization_url()` e `AsyncSPAAuth.get_authorization_url()`. Contém a URL de autorização e o code verifier do PKCE.

**Atributos**

`url`: `str` — A URL de autorização completa para a qual o usuário deve ser redirecionado.

`code_verifier`: `str` — O code verifier do PKCE a ser armazenado e passado para `exchange_code()`.

</Accordion>

#### Exceções de autenticação {#auth-exceptions}

Todas as exceções de autenticação herdam de `FrameioAuthError`.

| Exceção | Descrição |
| --- | --- |
| `FrameioAuthError` | Exceção base para todos os erros de `frameio.auth`. |
| `AuthenticationError` | A troca ou atualização do token falhou. Possui os atributos `error_code` e `error_description`. |
| `TokenExpiredError` | O refresh token expirou; é necessário autenticar novamente. |
| `ConfigurationError` | Uma configuração obrigatória está ausente ou é inválida. |
| `NetworkError` | A solicitação de rede falhou (tempo limite, erro de conexão etc.). |
| `RateLimitError` | A API retornou 429 e as novas tentativas se esgotaram. Possui o atributo `retry_after`. |
| `PKCEError` | A verificação do PKCE falhou. |

Faz o upload de um arquivo local para o Frame.io usando as URLs pré-assinadas retornadas por `client.files.create_local_upload(...)`. `FrameioUploader` é um wrapper leve que lê `upload_urls`, `file_size` e `media_type` da resposta `FileWithUploadUrls` e executa um upload para o S3 em partes e com múltiplas threads.

```python title="usage"

from frameio import Frameio
from frameio.files import FileCreateLocalUploadParamsData
from frameio.upload import FrameioUploader

client = Frameio(
    token="YOUR_TOKEN",
)
response = client.files.create_local_upload(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    folder_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    data=FileCreateLocalUploadParamsData(
        file_size=1137444,
        name="asset.png",
    ),
)
with open("asset.png", "rb") as f:
    FrameioUploader(response.data, f).upload()
```

**Parâmetros**

`asset`: `FileWithUploadUrls` — Uma instância de `FileWithUploadUrls` retornada por `client.files.create_local_upload(...)`.

`file`: `typing.BinaryIO` — Um objeto do tipo arquivo aberto em modo de leitura binária (`"rb"`).

`max_workers`: `int` — Concorrência do pool de threads repassada ao uploader subjacente. O padrão é 5.

`headers`: `typing.Optional[typing.Dict[str, str]]` — Cabeçalhos adicionais mesclados em cada solicitação PUT para o S3. O padrão é `{"x-amz-acl": "private"}`, conforme exigido pelo Frame.io.

`max_retries`: `int` — Número de novas tentativas por parte. O padrão é 3.

`on_progress`: `typing.Optional[typing.Callable[[int, int], None]]` — Callback opcional invocado após cada parte com `(bytes_uploaded_so_far, total_bytes)`.

**Métodos**

`upload() -> None` — Faz o upload do arquivo. Bloqueia até a conclusão ou gera uma exceção em caso de erro.
