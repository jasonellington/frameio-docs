## Acesso para todas as contas {#all-account-access}

Todas as contas do Frame V4 — não apenas as gerenciadas pelo Adobe Admin Console — podem criar tokens e acessar a API V4. Clientes e parceiros podem testar, criar e refinar seus fluxos de trabalho usando os recursos mais recentes da nossa API.

<Steps>

<Step title="Criar um token de autenticação de usuário">

Acesse o Adobe Developer Console para criar um token de autenticação de usuário. O usuário deve usar o mesmo Adobe ID do seu login no Frame para validar o acesso ao token da API.

</Step>

<Step title="Criar credenciais da API">

Depois de obter acesso às APIs, o próximo passo é criar credenciais da API, ou um token de API, para se comunicar com o Frame. Crie suas credenciais da API em developer.adobe.com.

</Step>

</Steps>

![Acesso à conta](/images/platform/docs/guides/accounts-projects-and-workspaces/706a4eb9324bc24a3465388a838455baf58384f128882a185dad2d1900f728a3.webp)

<Info>

Todas as contas V4, sejam gerenciadas pelo Frame (V4F) ou pela Adobe (V4A), podem criar um projeto no Adobe Developer Console e, em seguida, criar credenciais. Depois de obter um conjunto de credenciais (OAuth Client ID/Client Secret), você pode fazer a integração com o fluxo OAuth de três etapas (three-legged) da Adobe Developer Platform. Faça login na sua Adobe Identity para receber um token de autenticação e um token de atualização válidos e fazer solicitações à Developer API V4 do Frame.io!

</Info>

## Projetos e workspaces {#projects-and-workspaces}

### Atualizações dos workspaces {#workspace-updates}

A página inicial do Frame.io é nova e se chama página Workspace. Os usuários podem navegar pelos workspaces e projetos aos quais têm acesso em uma conta. Graças a esse novo design, ficou mais fácil ver quem pertence a um determinado workspace e convidar novas pessoas rapidamente.

<Note>

No Frame V3, os workspaces eram conhecidos como Teams.

</Note>

No V4, os workspaces são configurados como Invite Only (somente por convite), portanto os usuários verão apenas os workspaces para os quais foram explicitamente convidados. Além disso, não há uma página Team Directory nas configurações da conta.

Para gerenciar permissões e operações relacionadas, use os endpoints Create, List, Delete e Update de workspaces.

<Card title="Operações de gerenciamento de workspaces" icon="users" iconType="solid" horizontal={true}>

- Listar as funções de usuário de um determinado workspace.
- Remover um usuário de um determinado workspace.
- Atualizar as funções de usuário do workspace especificado se o usuário já tiver sido adicionado ao workspace. Se o usuário não tiver sido adicionado ao workspace, ele será adicionado com a função especificada.

### Atualizações dos projetos {#project-updates}

O fluxo de criação de projetos mudou no V4. Agora, ao iniciar um novo projeto, você escolhe entre um projeto em branco ou um modelo de projeto (Project Template). Há doze modelos para escolher, desenvolvidos para fluxos de trabalho criativos comuns. Você também pode optar por incluir os assets de demonstração do modelo ou começar apenas com a estrutura do modelo. Escolher um modelo de projeto cria imediatamente um novo projeto no seu workspace.

Para gerenciar permissões e operações relacionadas, use os endpoints Create, List, Delete e Update de projetos.

<Card title="Operações de gerenciamento de projetos" icon="folder" iconType="solid" horizontal={true}>

- Atualizar as funções de usuário do projeto especificado se o usuário já tiver sido adicionado ao projeto. Se o usuário não tiver sido adicionado ao projeto, ele será adicionado com a função especificada.
