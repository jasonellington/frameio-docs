Este guia explica como fazer upload de arquivos para o Frame.io usando o **SDK Python do Frame.io** (`frameio`). O SDK cuida de uploads em várias partes para o S3 por meio de URLs pré-assinadas, com workers paralelos, novas tentativas automáticas e acompanhamento de progresso opcional.

Para os conceitos gerais da API de upload (URLs de upload, cabeçalhos, divisão em partes), consulte [Como funcionam os uploads locais e remotos](/pt-BR/platform/docs/guides/uploading-to-frame-io/how-local-remote-uploads-work).

---

## Pré-requisitos {#prerequisites}

<Steps>

<Step title="Autenticação">

Você tem um cliente `Frameio` funcionando. Consulte o [Guia de autenticação](/pt-BR/platform/docs/guides/authentication/python-sdk) para a configuração.

</Step>

<Step title="Instale o SDK">

```bash
pip install frameio
```

</Step>

<Step title="Pasta de destino">

Você precisa do `account_id` e do `folder_id` para onde o arquivo deve ser enviado. Use o SDK para encontrá-los:

```python
# List your accounts
accounts = client.accounts.index()
account_id = accounts.data[0].id

# List workspaces in the account
workspaces = client.workspaces.index(account_id=account_id)
workspace_id = workspaces.data[0].id

# List projects in the workspace
projects = client.projects.index(account_id=account_id, workspace_id=workspace_id)
project = projects.data[0]

# The project's root folder is the top-level upload target
folder_id = project.root_folder_id

# Or list subfolders to upload into a specific one
folders = client.folders.list(account_id=account_id, folder_id=folder_id)
```

</Step>

</Steps>

## Início rápido {#quick-start}

```python
import os
from frameio import Frameio
from frameio.files import FileCreateLocalUploadParamsData
from frameio.upload import FrameioUploader

client = Frameio(token="YOUR_TOKEN")

file_path = "/path/to/video.mp4"
file_size = os.path.getsize(file_path)

# 1. Create the file resource and get pre-signed upload URLs
response = client.files.create_local_upload(
    account_id="YOUR_ACCOUNT_ID",
    folder_id="YOUR_FOLDER_ID",
    data=FileCreateLocalUploadParamsData(
        name="video.mp4",
        file_size=file_size,
    ),
)

# 2. Upload the file to S3
with open(file_path, "rb") as f:
    FrameioUploader(response.data, f).upload()
```

É só isso. O SDK divide o arquivo em partes com base nas URLs de upload retornadas pela API, faz o upload delas em paralelo e trata as novas tentativas automaticamente.

## Como funciona {#how-it-works}

O upload local é um processo de duas etapas:

<Steps>

<Step title="Crie o recurso de arquivo">

Chame `client.files.create_local_upload()` com o nome e o tamanho do arquivo. A API cria um arquivo placeholder e retorna URLs PUT pré-assinadas do S3 — uma por parte. O número de URLs (e, portanto, de partes) depende do tamanho do arquivo.

</Step>

<Step title="Faça upload para o S3">

`FrameioUploader` lê as URLs de upload da resposta, divide seu arquivo nas partes correspondentes e envia (PUT) cada parte para sua URL em paralelo usando um pool de threads. Cada requisição inclui os cabeçalhos obrigatórios `x-amz-acl: private` e `Content-Type`.

</Step>

</Steps>

<Note>

O upload vai diretamente da sua aplicação para o S3 — ele não passa pelos servidores da API do Frame.io. Esse é o mesmo padrão usado por serviços como YouTube, Vimeo e Dropbox para uploads de arquivos grandes.

</Note>

## Usando o `FrameioUploader` {#using-frameiouploader}

`FrameioUploader` é a forma recomendada de fazer upload de arquivos. Ele encapsula o uploader de partes de nível mais baixo e cuida de todos os detalhes — extrair as URLs de upload da resposta da API, definir os cabeçalhos obrigatórios, dividir o arquivo em partes e fazer o upload em paralelo.

### Acompanhamento de progresso {#progress-tracking}

Use o callback `on_progress` para acompanhar o progresso do upload:

```python
def on_progress(bytes_uploaded: int, total_bytes: int) -> None:
    pct = bytes_uploaded / total_bytes * 100
    print(f"\r{pct:.1f}% ({bytes_uploaded:,} / {total_bytes:,} bytes)", end="", flush=True)

with open(file_path, "rb") as f:
    FrameioUploader(response.data, f, on_progress=on_progress).upload()

print("\nUpload complete!")
```

O callback é chamado uma vez após a conclusão de cada parte, com o total acumulado de bytes enviados até o momento e o tamanho total do arquivo.

#### Barra de progresso com Rich {#rich-progress-bar}

Para uma experiência de terminal mais refinada, use o [Rich](https://github.com/Textualize/rich):

```python
from rich.progress import Progress, BarColumn, DownloadColumn, TransferSpeedColumn, TimeRemainingColumn

with Progress(
    "[progress.description]{task.description}",
    BarColumn(),
    DownloadColumn(),
    TransferSpeedColumn(),
    TimeRemainingColumn(),
) as progress:
    task = progress.add_task("Uploading...", total=file_size)

    with open(file_path, "rb") as f:
        FrameioUploader(
            response.data, f,
            on_progress=lambda done, total: progress.update(task, completed=done),
        ).upload()
```

### Configuração {#configuration}

`FrameioUploader` aceita vários parâmetros opcionais:

| Parâmetro | Padrão | Descrição |
| --- | --- | --- |
| `max_workers` | `5` | Número de threads de upload simultâneas |
| `headers` | `{"x-amz-acl": "private"}` | Cabeçalhos enviados em cada requisição PUT ao S3. Cabeçalhos personalizados são mesclados aos padrões. |
| `max_retries` | `3` | Tentativas por parte (backoff exponencial: 1s, 2s, 4s, …) |
| `on_progress` | `None` | Callback `(bytes_uploaded, total_bytes)` disparado após cada parte |

```python
with open(file_path, "rb") as f:
    FrameioUploader(
        response.data,
        f,
        max_workers=10,       # more parallelism for high-bandwidth connections
        max_retries=5,        # more resilient on flaky networks
        on_progress=on_progress,
    ).upload()
```

### Exemplo completo {#full-example}

Um exemplo completo com autenticação, upload e acompanhamento de progresso:

```python
import os
from frameio import Frameio
from frameio.auth import ServerToServerAuth
from frameio.files import FileCreateLocalUploadParamsData
from frameio.upload import FrameioUploader

# Authenticate
auth = ServerToServerAuth(
    client_id="YOUR_CLIENT_ID",
    client_secret="YOUR_CLIENT_SECRET",
)
client = Frameio(token=auth.get_token)

# Prepare the file
file_path = "/path/to/video.mp4"
file_name = os.path.basename(file_path)
file_size = os.path.getsize(file_path)

# Create the file resource
response = client.files.create_local_upload(
    account_id="YOUR_ACCOUNT_ID",
    folder_id="YOUR_FOLDER_ID",
    data=FileCreateLocalUploadParamsData(
        name=file_name,
        file_size=file_size,
    ),
)

print(f"Uploading {file_name} ({file_size:,} bytes) in {len(response.data.upload_urls)} chunks...")

# Upload with progress
def on_progress(uploaded: int, total: int) -> None:
    print(f"\r{uploaded / total:.0%}", end="", flush=True)

with open(file_path, "rb") as f:
    FrameioUploader(response.data, f, on_progress=on_progress).upload()

print(f"\nDone! View at: {response.data.view_url}")
```

## Upload remoto {#remote-upload}

Se o seu arquivo já estiver acessível por uma URL pública, use o upload remoto. Não é necessário dividir em partes — o Frame.io busca o arquivo diretamente:

```python
from frameio.files import FileCreateRemoteUploadParamsData

response = client.files.create_remote_upload(
    account_id="YOUR_ACCOUNT_ID",
    folder_id="YOUR_FOLDER_ID",
    data=FileCreateRemoteUploadParamsData(
        name="video.mp4",
        source_url="https://example.com/video.mp4",
    ),
)
print(f"File created: {response.data.id}")
```

<Warning>

Atualmente, o upload remoto tem um **limite de tamanho de arquivo de 50 GB**. Para arquivos maiores que 50 GB, use o [upload local](#quick-start).

</Warning>

## Verificando o status do upload {#checking-upload-status}

Após o upload, você pode verificar se o arquivo foi recebido:

```python
status = client.files.show_file_upload_status(
    account_id="YOUR_ACCOUNT_ID",
    file_id=response.data.id,
)
print(f"Upload complete: {status.data.upload_complete}")
```
