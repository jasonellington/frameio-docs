<Note>
  Este é um endpoint de demonstração para a automação Update from code changes do Mintlify. Ele não faz parte da API do Frame.io.
</Note>

Use este endpoint para verificar se um asset terminou de ser processado.

## Obter o status de um asset {#get-an-asset’s-status}

```http
GET /v4/assets/{id}/status
```

### Parâmetros de caminho {#path-parameters}

| Parâmetro | Tipo   | Descrição     |
| --------- | ------ | ------------- |
| `id`      | string | O ID do asset. |

### Campos da resposta {#response-fields}

| Campo         | Tipo   | Descrição                                       |
| ------------- | ------ | ----------------------------------------------- |
| `data.id`     | string | O ID do asset.                                  |
| `data.status` | string | O status de processamento: `processing` ou `ready`. |
| `data.updated_at` | string | Quando o asset foi atualizado pela última vez, como um timestamp UTC no formato ISO 8601. |

### Exemplo {#example}

```bash
curl http://localhost:3001/v4/assets/a1b2c3/status
```

```json
{
  "data": {
    "id": "a1b2c3",
    "status": "ready",
    "updated_at": "2026-11-03T18:22:10Z"
  }
}
```

### Erros {#errors}

| Status | Erro              | Significado                   |
| ------ | ----------------- | ----------------------------- |
| `404`  | `asset_not_found` | Nenhum asset tem este ID.     |
