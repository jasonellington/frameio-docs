## Introduzione {#introduction}

Prima di implementare il tuo dispositivo Camera to Cloud, assicuriamoci che tu abbia tutto il necessario per avere successo.

## Registrati come sviluppatore {#register-as-a-developer}

Per seguire le guide all’implementazione, avrai bisogno di un `client_secret` per il tuo dispositivo. Se non l’hai già fatto, consulta la nostra [guida introduttiva](/it/camera-to-cloud/getting-started-with-cloud-device-integrations) per informazioni su come registrarti come sviluppatore C2C. Il nostro team ti fornirà le credenziali necessarie per interagire con l’API.

## Strumenti per seguire le guide all’implementazione {#tools-for-following-implementation-guides}

Sebbene non siano strettamente necessari, avere a disposizione questi strumenti ti aiuterà a seguire i nostri tutorial e a testare direttamente le interazioni con l’API.

### cURL {#curl}

Questi tutorial mostrano le richieste all’API di Frame.io utilizzando `curl`. Questa libreria molto diffusa offre un’eccellente interfaccia a riga di comando per effettuare richieste HTTP. Quando implementerai il tuo dispositivo, dovrai replicare queste chiamate HTTP nel linguaggio di programmazione che preferisci. L’uso di `curl` in questi esempi ti consente di testare le interazioni con l’API semplicemente copiando i comandi nel terminale.

Per verificare che `curl` sia installato sul tuo sistema, inserisci questo comando nel terminale:

```shell
curl --version
```

Dovresti vedere un output simile a questo:

```text
curl 7.64.1 (x86_64-apple-darwin20.0) libcurl/7.64.1 (SecureTransport) LibreSSL/2.8.3 zlib/1.2.11 nghttp2/1.41.0
Release-Date: 2019-03-27
Protocols: dict file ftp ftps gopher http https imap imaps ldap ldaps pop3 pop3s rtsp smb smbs smtp smtps telnet tftp 
Features: AsynchDNS GSS-API HTTP2 HTTPS-proxy IPv6 Kerberos Largefile libz MultiSSL NTLM NTLM_WB SPNEGO SSL UnixSockets
```

Se non è installato, puoi trovare i programmi di installazione per la maggior parte dei sistemi operativi [qui](https://curl.se/download.html). Gli utenti macOS o Linux possono installarlo tramite [Homebrew](https://brew.sh/):

```shell
brew install curl
```

### Python {#python}

Useremo Python per formattare i payload di risposta JSON, passando i risultati di `curl` tramite pipe:

```shell
curl https://api.frame.io/health | python -m json.tool
```

Per verificare che Python sia installato:

```shell
python --version
```

Output previsto:

```text
Python 2.7.16
```

Se non è installato, puoi [scaricare Python qui](https://www.python.org/downloads/). Per questi esempi vanno bene Python 2.6+ o Python 3.x.

Sebbene Python non sia obbligatorio, aiuta a rendere le risposte più leggibili. In alternativa, strumenti come [jq](https://stedolan.github.io/jq/) offrono funzionalità simili.

## Implementazione di riferimento {#reference-implementation}

Il tuo pacchetto per sviluppatori include un’implementazione di riferimento in Python con un’applicazione CLI di esempio per caricare media su Frame.io come Connessione C2C. Dopo aver completato ogni sezione di queste guide, potrebbe esserti utile esaminare l’implementazione di riferimento per vedere i concetti applicati in codice funzionante.
