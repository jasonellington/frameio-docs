# Panoramica {#overview}

In Frame.io le annotazioni sono rappresentate come un blob JSON serializzato di oggetti di disegno, completi di colori, coordinate e dimensioni. Nel blob, tutte le virgolette tranne la coppia esterna di delimitazione sono precedute da barre di escape (ad es. `\"key\":\"value\"`).

Esistono tre forme di base — **arrow** (freccia), **rect** (rettangolo) e **line** (linea) — oltre al disegno a mano libera, che esula dall'ambito di questa guida ma segue gli stessi principi di base dei dati di coordinate serializzati.

## Il sistema di coordinate {#the-coordinate-system}

Tutte le forme sono posizionate su un sistema di coordinate cartesiane con origine nell'angolo in alto a sinistra e una scala da 0 a 1 su ciascun asse.

![coordinate_plane.png](/images/platform/v2/working-with-annotations/099478340a4f8604fd4389c5d431ec9e9321f509f2d6055b0c92dd62e4e36147.webp)

## Dati di base delle forme {#basic-shape-data}

Tutte le forme sono posizionate sul piano illustrato sopra tramite una combinazione di coordinate e dati di stile. Ogni forma ha alcuni attributi comuni e, in aggiunta, un modo leggermente diverso di fare riferimento al sistema di coordinate.

Tutti gli attributi di distanza/larghezza/altezza utilizzano la stessa scala da 0 a 1 della griglia di coordinate principale, ma in genere sono misurati a partire dal punto di origine della forma.

In altre parole, se un video viene visualizzato in un viewport di 640x480, in quel contesto `x=1` corrisponderà a 640px assoluti. Ciò consente alle annotazioni di ridimensionarsi senza problemi mantenendo la loro posizione relativa al variare di schermo, dimensioni e contesto di visualizzazione.

**Nota**: l'origine di un *rect* è sempre l'angolo in alto a sinistra della forma, indipendentemente dall'origine del disegno.

### Attributi comuni {#common-attributes}

| Attributo | Descrizione |
| --- | --- |
| `tool` | *arrow*, *rect* o *line*. Indica quale forma viene creata. |
| `color` | Colore esadecimale a sei cifre della forma. |
| `size` | Dimensione in pixel della linea della forma. Per le frecce si riferisce solo all'inizio della linea, poiché la larghezza finale è determinata a livello di codice. |

### Arrow {#arrow}

| Attributo | Descrizione |
| :--- | :--- |
| `x` | Coordinata x dell'origine della freccia. |
| `y` | Coordinata y dell'origine della freccia. |
| `w` | Differenza di posizione della freccia sull'asse y dall'inizio alla fine, rispetto all'origine della freccia. |
| `h` | Differenza di posizione della freccia sull'asse x dall'inizio alla fine, rispetto all'origine della freccia. |

### Rect {#rect}

| Attributo | Descrizione |
| :--- | :--- |
| `x` | Coordinata x dell'angolo in alto a sinistra del rettangolo. |
| `y` | Coordinata y dell'angolo in alto a sinistra del rettangolo. |
| `w` | Larghezza del rettangolo, rispetto all'origine in alto a sinistra del rettangolo. |
| `h` | Altezza del rettangolo, rispetto all'origine in alto a sinistra del rettangolo. |
| `ix` | Origine x del disegno del rettangolo. (Non obbligatorio). |
| `iy` | Origine y del disegno del rettangolo. (Non obbligatorio). |
| `radius` | Raggio di arrotondamento degli angoli del rettangolo. Deve essere positivo. I valori superiori a 150 sono visivamente indistinguibili. |

### Line {#line}

| Attributo | Descrizione |
| :--- | :--- |
| `x1` | Coordinata x dell'origine della linea. |
| `y1` | Coordinata y dell'origine della linea. |
| `x2` | Coordinata x del punto finale della linea. Valore assoluto sul piano dell'immagine. |
| `y2` | Coordinata y del punto finale della linea. Valore assoluto sul piano dell'immagine. |
