Ngrok è uno strumento facile da usare che ti consente di creare un tunnel sicuro sulla tua macchina locale insieme a un URL pubblico che puoi usare per testare il tuo progetto locale o per condividere il tuo lavoro per la revisione con un cliente o un collega. Puoi configurare HTTP o HTTPS e, data la popolarità di questo strumento, se qualcosa non funziona esistono tantissimi articoli che descrivono diversi modi per risolvere il problema. Questo articolo illustra un paio di modi semplici per installare ngrok e cosa fare se non riesci a far comunicare la tua applicazione web con ngrok.

## Installare ngrok {#install-ngrok}

Puoi usare ngrok in un paio di modi diversi

### Installare tramite il programma di installazione di ngrok {#install-via-the-ngrok-installer}

1. Vai sul sito web di ngrok e segui le istruzioni riportate: [https://ngrok.com/download](https://ngrok.com/download)
2. Se vuoi le funzionalità offerte dal collegamento di un account, segui queste istruzioni per ottenere un account e un token.

Non è obbligatorio creare un account o aggiungere il token, ma dai sicuramente un'occhiata alla pagina di download per capire se è qualcosa che desideri o di cui hai bisogno.

<Info>

**Nota:**

Se usi questo metodo, ngrok viene eseguito dalla posizione in cui lo salvi, a meno che tu non lo renda disponibile in tutto il sistema.

</Info>

### Installare con Homebrew {#install-with-homebrew}

Questo è il mio metodo preferito per installare ngrok. Se hai Homebrew installato, ti basta digitare `homebrew cask install ngrok`. ngrok viene installato automaticamente e puoi usarlo da qualsiasi posizione! E soprattutto, non devi digitare `./ngrok` nel terminale all'inizio di ogni comando: puoi digitare semplicemente `ngrok`. Puoi leggere di più su questa opzione [qui](https://gist.github.com/wosephjeber/aa174fb851dfe87e644e).

## Usare ngrok {#use-ngrok}

Dopo aver configurato ngrok, scegli una porta come `3000` e avvialo dalla riga di comando del terminale con il comando ngrok http `3000`. Non è obbligatorio usare la porta `3000`, ma è una porta scelta comunemente in fase di configurazione.

Se hai configurato ngrok in modo che venga eseguito da una cartella specifica, devi trovarti nella cartella in cui hai posizionato ngrok e usare il comando `./ngrok http 3000`.

Avvia il server del tuo progetto in ascolto sulla stessa porta e potrai accedere al tuo lavoro usando l'indirizzo pubblico fornito da ngrok.

### Risoluzione dei problemi di ngrok con la tua app web - Barra finale {#troubleshooting-ngrok-with-your-web-app-trailing-slash}

Un problema in cui potresti imbatterti con ngrok è l'impossibilità di connetterti al tuo server quando configuri un URL ngrok da usare con la tua app web. La cosa frustrante di questo problema è che ngrok non registra di aver ricevuto qualcosa. Puoi aprire localhost:4040 per vedere cosa succede, e non ti mostrerà nulla. (localhost:4040 è fornito da ngrok per consentirti di monitorare le richieste in arrivo al tuo server.) Ngrok sembra associare gli indirizzi a /(.*) anziché a (/.*), quindi se non includi una barra finale alla fine del tuo indirizzo e non vedi nulla negli strumenti di monitoraggio di ngrok, è perché ngrok non trova una corrispondenza per l'indirizzo che hai indicato.

Ecco un esempio di aggiunta della barra finale: `http://something.ngrok.io/`

Puoi anche scrivere le tue applicazioni di esempio in modo che puntino a un endpoint che include una barra. Ricorda solo che, affinché l'app Frame.io raggiunga il tuo server, se la tua app di esempio usa l'endpoint `/actions` devi aggiungere l'endpoint /actions alla fine del tuo indirizzo ngrok. Ad esempio, se l'indirizzo ngrok è `http://something.ngrok.io`, dovrai indicarlo nella configurazione della tua Custom Action come `http://something.ngrok.io/actions`. Per altre applicazioni web potrebbe essere diverso, quindi fai qualche prova con la parte finale dell'indirizzo ngrok se non riesci a far funzionare tutto subito.

### Posso usare qualcosa di diverso da ngrok? Prova Glitch! {#can-i-use-something-besides-ngrok-try-glitch}

Glitch è un'alternativa a ngrok davvero interessante e più rapida da configurare. Glitch ti permette di creare un account e poi sviluppare le tue app usando i suoi server con un URL accessibile pubblicamente. Puoi collaborare con altre persone, rendere il tuo codice pubblico o privato e scegliere tra un'ampia varietà di linguaggi e piattaforme. Visita [https://glitch.com/create](https://glitch.com/create) per vedere cosa è disponibile.

Quando configuri il tuo progetto su Glitch, per alcune applicazioni web vale il problema della barra finale. Nel caso di Frame.io, quando configuri una Custom Action su [developer.frame.io](/it/platform/v2) devi includere la barra finale alla fine dell'URL fornito da Glitch. Non devi aggiungere nient'altro, nemmeno per l'endpoint /actions.

### C'è qualcosa di già configurato che potrei provare subito? {#is-there-something-set-up-i-could-try-now}

Sì. Se non vuoi usare ngrok o creare un tuo progetto Glitch, abbiamo configurato un'applicazione di esempio che puoi provare qui: [https://frameio-custom-action.glitch.me](https://frameio-custom-action.glitch.me). Ricorda di includere una barra finale quando aggiungi questo indirizzo nella sezione Custom Actions di \[/).
