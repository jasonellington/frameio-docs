# Navigare tra i dati delle risorse {#navigating-resource-data}

I payload della nostra API sono piuttosto completi! Ciò significa (ad esempio) che, quando intercetti una modifica al campo Status Label di un Asset, potresti ritrovarti a esaminare moltissimi campi, di cui solo pochi saranno immediatamente rilevanti per te.

![Esempi di campi](/images/platform/v2/overview-frame-io-resources-in-zapier/96b556247084aa9ced664a076acc8e22da0c44c5def47b9147b2c0c968964aec.webp)

La buona notizia è che tutti i campi di input dei dati di Zapier dispongono di una funzione di ricerca, grazie alla quale puoi raggiungere rapidamente il campo che ti serve.

![Ricerca rapida di asset approved](/images/platform/v2/overview-frame-io-resources-in-zapier/38f94d317a462a7caf7fdc781713c0040001d99ef441cd25507b215ca373f70e.webp)

Naturalmente, è utile anche sapere cosa cercare.

## Cosa cercare {#what-to-look-for}

La tabella seguente non è esaustiva, ma dovrebbe darti un vantaggio nella creazione di flussi di lavoro con l'integrazione Zapier di Frame.io.

<Info>

**Gli URL degli Asset sono lunghi, ed è normale**

Gli URL degli Asset che vedi nelle risposte dell'API di Frame.io sono link diretti ad Amazon S3. Questi URL possono e devono essere utilizzati in qualsiasi contesto di app Zapier in cui desideri spostare un Asset in un altro sistema. Se puoi scegliere tra "File Attachment" e "File Attachment (URL)", scegli quest'ultimo, poiché i caricamenti tramite URL in Zapier supportano in genere una gamma più ampia di tipi e dimensioni di file.

</Info>

| Tipo di risorsa | Campo in Zapier | Descrizione |
| --- | --- | --- |
| Asset (tutti) | Original | Il video originale caricato, senza modifiche. Nella maggior parte dei casi, sarà la chiave da inviare ad altri sistemi; tuttavia, avrà sempre il tipo di file originale, quindi potrebbe non essere riproducibile in tutti gli altri contesti. |
| Asset (video) | H264 *resolution* | Tutti i proxy h.264 di Frame.io sono disponibili nell'Asset in Zapier. |
| Asset (immagine) | Image *quality* | Analogamente ai proxy video h.264, anche tutti i proxy generati per le immagini sono disponibili in Zapier. |
| Asset (tutti) | Thumb | La miniatura dell'Asset impostata in Frame.io. Questo campo è ottimo per aggiungere elementi visivi ai sistemi di monitoraggio dei progetti come Trello o Airtable. |
| Asset (tutti) | Label | La Status Label. Questo campo viene solitamente abbinato a un'azione "Filter" (come nello screenshot sopra). |
| Asset (tutti) | Creator Email | L'indirizzo email di chi ha caricato originariamente il file. |
| Asset (tutti) | Project ID | L'ID del Project padre dell'Asset. Questo campo è particolarmente utile se abbinato all'azione "Find Project", che puoi utilizzare per recuperare il nome del Project. |
| Asset (tutti) | Parent ID | L'ID del padre di un Asset, che sarà sempre una cartella, un version stack o la root del Project. |
| Comment | Text | Il testo del commento. |
| Comment | Asset ID | L'ID dell'Asset padre del Comment. Utile da passare all'azione Find Asset per ottenere ulteriore contesto, oppure per il collegamento in strumenti di monitoraggio esterni. |
| Comment | Owner Name | Il nome e il cognome dell'utente che ha lasciato il Comment. |
| Comment | Owner Email | L'indirizzo email dell'utente che ha lasciato il Comment. |
| Project | Name | Il nome del Project. |
