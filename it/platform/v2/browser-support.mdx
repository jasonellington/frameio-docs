# Supporto multi-browser per l’accesso a Frame.io {#cross-browser-support-for-frame-io-login}

Anche se non sarà rilevante per le applicazioni interamente basate sull’API, il supporto multi-browser di Frame.io entra in gioco quando viene caricata la nostra [app Accounts](https://accounts.frame.io/) durante un flusso di concessione delle credenziali OAuth.

Quando sviluppi applicazioni OAuth per Frame.io, tieni presente che la pagina di accesso mostrata nel flusso OAuth segue lo stesso supporto dei browser della nostra applicazione web principale. Ai fini della tabella seguente, un supporto “Parziale” significa che tutte le funzionalità principali dovrebbero funzionare senza ostacoli, ma potrebbero presentarsi alcuni problemi minori di layout. Un supporto “Minimo” significa che potrebbe funzionare, ma non lo testiamo né lo supportiamo più esplicitamente.

| Browser | Supporto |
| --- | --- |
| Chrome (ultima versione) | Completo |
| Safari (ultima versione) | Completo |
| Firefox (ultima versione) | Completo |
| Opera (ultima versione) | Completo |
| Edge (ultima versione) | Completo |
| IE (11+) | Minimo |
| IE (&lt;=10) | Nessuno |
| Mobile Safari (ultima versione) | Parziale |
| Chrome per iOS (ultima versione) | Parziale |
| Chrome per Android (ultima versione) | Parziale |
| Browser Android (ultima versione) | Parziale |
