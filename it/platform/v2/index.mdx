## Informazioni su Frame.io {#about-frame-io}

[Frame.io](https://frame.io) è lo strumento di collaborazione cloud per i team video professionali: tutto ciò che serve per far avanzare il processo creativo, in un unico ambiente di lavoro, accessibile da qualsiasi luogo. Con Frame.io puoi caricare, condividere e revisionare in modo sicuro i progetti cinematografici, consentendo all'intera operazione di muoversi alla velocità della creatività.

### Frame.io Developer Platform {#frame-io-developer-platform}

Non tutti i team creativi, i processi o gli stack software sono uguali. È qui che entra in gioco la nostra Developer Platform. La Frame.io Developer Platform ti consente di gestire le attività comuni utilizzando la nostra API. Tra i casi d'uso più diffusi per cui gli sviluppatori hanno utilizzato la nostra API ci sono l'aggiunta automatica di file o cartelle esistenti all'app Frame.io, il caricamento di nuovi contenuti e la gestione dei team.

## Programma Camera to Cloud (C2C) {#camera-to-cloud-c2c-program}

Camera to Cloud è un tipo di integrazione unico. Queste integrazioni sono progettate appositamente per qualsiasi dispositivo o applicazione che genera dati. Se stai sviluppando un'integrazione C2C, dovrai utilizzare le [guide all'integrazione C2C](/it/camera-to-cloud/getting-started-with-cloud-device-integrations). Lì troverai tutte le informazioni necessarie per iniziare a connetterti al cloud con Frame.io!

## Guida rapida {#quick-start-guide}

Se vuoi iniziare subito, fai clic su questo pulsante per importare la nostra API in Postman!

[![Run in Postman](/images/platform/v2/index/button.svg)](https://www.getpostman.com/collections/c2dfffb88990a9dc34c2)

Altrimenti, continua a leggere. Come punto di partenza, assicurati di avere un account Frame.io con cui effettuare l'accesso.

Da lì:

- [Accedi al Developer Portal](/it/platform/v2) utilizzando le tue credenziali Frame.io
- [Crea un Developer Token](/it/platform/v2/authentication#developer-tokens)

Per verificare che il token funzioni, effettua una chiamata di prova utilizzando un linguaggio, uno strumento o un proxy a tua scelta:

<CodeGroup>

```bash title="cURL"
curl --request GET \
  --url https://api.frame.io/v2/me \
  --header 'authorization: Bearer <DEV_TOKEN>'
```

```python title="Python"
import requests

url = "https://api.frame.io/v2/me"
headers = {
 "Authorization": "Bearer <DEV_TOKEN>"
}

requests.GET(url,headers=headers)
```

</CodeGroup>

Nella risposta dovresti vedere le informazioni del tuo utente.

## Flussi di lavoro basati su eventi {#event-based-workflows}

La Developer Platform di Frame.io offre alcune opzioni che puoi utilizzare per estendere i tuoi flussi di lavoro ad altri strumenti o per creare funzionalità completamente nuove.

### Webhook {#webhooks}

I webhook consentono di trasformare gli eventi che si verificano all'interno di Frame.io in notifiche che possono essere inviate a sistemi esterni per l'elaborazione, le callback API e l'automazione dei flussi di lavoro.

Esistono diversi modi per utilizzare i nostri webhook. Puoi sviluppare qualcosa da solo oppure sfruttare uno strumento di automazione no-code come [Zapier](https://zapier.com), [Integromat](https://www.integromat.com), [Pabbly Connect](https://www.pabbly.com/) o [Pipedream](https://pipedream.com).

- [Webhook](/it/platform/v2/webhooks-overview) - I webhook espongono gli eventi di Frame.io a URL esterni per l'utilizzo e l'elaborazione.
- [Zapier](/it/platform/v2/get-started-with-zapier)  - Uno strumento di automazione online che consente di collegare oltre 1.000 app e strumenti comuni senza scrivere codice.

Su Github è disponibile una [Webhooks Example App](https://github.com/Frameio/webhooks-example-app) che puoi utilizzare come punto di partenza se desideri sviluppare un tuo ricevitore.

### Custom Actions {#custom-actions}

Le [Custom Actions](/it/platform/v2/custom-actions-overview) ti consentono di creare integrazioni direttamente in Frame.io sotto forma di componenti UI programmabili. Dal punto di vista tecnico sono molto simili ai webhook e sono un ottimo modo per estendere i tuoi flussi di lavoro in Frame.io.
