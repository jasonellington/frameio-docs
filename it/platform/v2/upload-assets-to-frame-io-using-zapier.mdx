## Panoramica {#overview}

Se desideri caricare file su Frame.io da app cloud esistenti o da un URL che fornisce asset, Zapier è in genere una buona soluzione, poiché il suo prodotto risolve molte delle divergenze di progettazione delle API che rendono complicata l'interazione con le app cloud.  Questa guida chiarisce gli attributi chiave del servizio di caricamento di Zapier, in modo che tu sappia esattamente cosa accade nella tua integrazione.

## Impostare il metodo di caricamento dei file {#setting-the-file-upload-method}

Zapier tenta di individuare automaticamente il metodo di caricamento dei file più flessibile per ciascuna API a cui si connette.  Ad esempio, Zapier tenterà di convertire i link con restrizioni, a cui non è possibile accedere al di fuori del dominio di un'app, in link di download disponibili pubblicamente:

Link originale non leggibile:
`https://www.dropbox.com/s/hriinb9w3a2107m/iPad%20intro.pdf`

Link convertito, utilizzabile dall'Uploader API di Frame.io:
`https://dl.dropboxusercontent.com/s/hriinb9w3a2107m/iPad%20intro.pdf`

### Limitazioni sui file di Zapier {#zapier’s-file-limitations}

È importante sottolineare che, se Zapier **non riesce** a individuare un URL di download statico da passare all'API di Frame.io, il servizio di Zapier scaricherà i file al volo e li passerà a Frame.io.  Zapier limita questo metodo ai file **[inferiori a 100MB](https://zapier.com/help/doc/common-problems-dropbox)**.

Tieni presente che l'interfaccia di Zapier potrebbe avvisarti delle limitazioni sulla dimensione dei file anche quando passi un URL diretto (ossia quando non c'è alcuna limitazione). Ecco perché vale la pena capire come funziona File URL.

## Metodi di caricamento per app e servizi comuni {#upload-methods-for-common-apps-and-services}

**Nota:** le integrazioni di tipo **File Upload** sono soggette ai limiti di dimensione dei file indicati nell'interfaccia di Zapier. I link diretti sono preferibili, poiché non sono soggetti a limitazioni di dimensione e vengono elaborati in modo più rapido e affidabile.

| App | Tipo | Suggerimenti e riferimenti |
| --- | --- | --- |
| Gmail | File Upload | [Documentazione di supporto di Zapier](https://zapier.com/help/doc/common-problems-gmail#how-can-i-attach-a-file-to-my-email-that39s-not-in-my-trigger) |
| Google Drive | Direct Link | Devi incollare `webContentLink` nel selettore File.  Questo funziona per i file caricati su Google Drive, ma non per i documenti o le presentazioni creati all'interno di Drive. [Documentazione di supporto di Zapier](https://zapier.com/help/doc/common-problems-google-drive#unable-to-get-a-value-when-looking-for-quotfilequot-is-it-missing), [Google Drive V3 API](https://developers.google.com/drive/api/v3/manage-downloads) |
| Dropbox | Direct Link | Caricare automaticamente i file di Dropbox su Frame.io |
| Box | Direct Link | Usa `Info Shared Link Download URL` [Guide alle API di Box](https://developer.box.com/guides/downloads/shared-link/) |
| S3 | Direct Link | Guida di Zapier: problemi comuni con S3 |
