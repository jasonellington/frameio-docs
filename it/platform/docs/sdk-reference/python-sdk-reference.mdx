### Utilizzo {#usage}

Crea un'istanza del client e utilizzalo come segue:

```python
from frameio import (
    Frameio,
    SelectDefinitionParamsFieldConfiguration,
    SelectDefinitionParamsFieldConfigurationOptionsItem,
)
from frameio.metadata_fields import CreateFieldDefinitionParamsData_Select

client = Frameio(
    token="YOUR_TOKEN",
)
client.metadata_fields.metadata_field_definitions_create(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    data=CreateFieldDefinitionParamsData_Select(
        field_configuration=SelectDefinitionParamsFieldConfiguration(
            enable_add_new=False,
            options=[
                SelectDefinitionParamsFieldConfigurationOptionsItem(
                    display_name="Option 1",
                ),
                SelectDefinitionParamsFieldConfigurationOptionsItem(
                    display_name="Option 2",
                ),
            ],
        ),
        name="Fields definition name",
    ),
)
```

### Client asincrono {#async-client}

L'SDK esporta anche un client asincrono che consente di effettuare chiamate non bloccanti alla nostra API. Se stai creando una classe client httpx asincrona da passare a questo client, utilizza httpx.AsyncClient() invece di httpx.Client() (ad es. per il parametro httpx_client di questo client).

```python
import asyncio

from frameio import (
    AsyncFrameio,
    SelectDefinitionParamsFieldConfiguration,
    SelectDefinitionParamsFieldConfigurationOptionsItem,
)
from frameio.metadata_fields import CreateFieldDefinitionParamsData_Select

client = AsyncFrameio(
    token="YOUR_TOKEN",
)


async def main() -> None:
    await client.metadata_fields.metadata_field_definitions_create(
        account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
        data=CreateFieldDefinitionParamsData_Select(
            field_configuration=SelectDefinitionParamsFieldConfiguration(
                enable_add_new=False,
                options=[
                    SelectDefinitionParamsFieldConfigurationOptionsItem(
                        display_name="Option 1",
                    ),
                    SelectDefinitionParamsFieldConfigurationOptionsItem(
                        display_name="Option 2",
                    ),
                ],
            ),
            name="Fields definition name",
        ),
    )


asyncio.run(main())
```

### Gestione delle eccezioni {#exception-handling}

Quando l'API restituisce un codice di stato di errore (risposta 4xx o 5xx), viene generata una sottoclasse del seguente errore.

```python
from frameio.core.api_error import ApiError

try:
    client.metadata_fields.metadata_field_definitions_create(...)
except ApiError as e:
    print(e.status_code)
    print(e.body)
```

### Paginazione {#pagination}

Le richieste paginate restituiscono un SyncPager o un AsyncPager, che possono essere utilizzati come generatori per l'oggetto sottostante.

```python
from frameio import Frameio

client = Frameio(
    token="YOUR_TOKEN",
)
response = client.project_permissions.index(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    project_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    page_size=10,
    include_total_count=False,
)
for item in response:
    yield item
# alternatively, you can paginate page-by-page
for page in response.iter_pages():
    yield page
```

### Avanzate {#advanced}

#### Accedere ai dati grezzi della risposta {#access-raw-response-data}

L'SDK fornisce l'accesso ai dati grezzi della risposta, incluse le intestazioni, tramite la proprietà .with_raw_response. La proprietà .with_raw_response restituisce un client “grezzo” che può essere utilizzato per accedere agli attributi .headers e .data.

```python
from frameio import Frameio

client = Frameio(
    ...,
)
response = (
    client.metadata_fields.with_raw_response.metadata_field_definitions_create(
        ...
    )
)
print(response.headers)  # access the response headers
print(response.data)  # access the underlying object
pager = client.project_permissions.index(...)
print(pager.response.headers)  # access the response headers for the first page
for item in pager:
    print(item)  # access the underlying object(s)
for page in pager.iter_pages():
    print(page.response.headers)  # access the response headers for each page
    for item in page:
        print(item)  # access the underlying object(s)
```

#### Tentativi ripetuti {#retries}

L'SDK è dotato di tentativi ripetuti automatici con backoff esponenziale. Una richiesta viene ripetuta purché sia considerata ripetibile e il numero di tentativi non abbia superato il limite configurato (valore predefinito: 2).<br />
Una richiesta è considerata ripetibile quando viene restituito uno dei seguenti codici di stato HTTP:

- 408 (Timeout)
- 429 (Troppe richieste)
- 5XX (Errori interni del server)

<br />

Utilizza l'opzione di richiesta `max_retries` per configurare questo comportamento.

```python
client.metadata_fields.metadata_field_definitions_create(..., request_options={
    "max_retries": 1
})
```

---

#### Timeout {#timeouts}

L'SDK utilizza un timeout predefinito di 60 secondi. Puoi configurarlo con un'opzione di timeout a livello di client o di richiesta.

```python
from frameio import Frameio

client = Frameio(
    ...,
    timeout=20.0,
)


# Override timeout for a specific method
client.metadata_fields.metadata_field_definitions_create(..., request_options={
    "timeout_in_seconds": 1
})
```

---

#### Client personalizzato {#custom-client}

Puoi sostituire il client httpx per personalizzarlo in base al tuo caso d'uso. Alcuni casi d'uso comuni includono il supporto per proxy e trasporti.

```python
import httpx
from frameio import Frameio

client = Frameio(
    ...,
    httpx_client=httpx.Client(
        proxy="http://my.test.proxy.example.com",
        transport=httpx.HTTPTransport(local_address="0.0.0.0"),
    ),
)
```

#### Autenticazione {#auth}

<AccordionGroup>

<Accordion title="frameio.auth.ServerToServerAuth(*, client_id, client_secret, ...)" defaultOpen={true}>

Esegue l'autenticazione tramite il grant client_credentials di OAuth 2.0. Questo flusso non coinvolge un utente e non restituisce un token di aggiornamento. Quando il token di accesso scade, l'SDK ne richiede automaticamente uno nuovo utilizzando le credenziali del client. Per l'utilizzo asincrono, usa `AsyncServerToServerAuth`.

```python title="usage"

from frameio import Frameio
from frameio.auth import ServerToServerAuth

auth = ServerToServerAuth(client_id="YOUR_CLIENT_ID", client_secret="YOUR_CLIENT_SECRET")
client = Frameio(token=auth.get_token)
```

**Parametri**

`client_id`: `str` — ID client OAuth di Adobe IMS.

`client_secret`: `str` — Segreto client OAuth di Adobe IMS.

`scopes`: `str` — Ambiti separati da spazi (OAuth 2.0 RFC 6749). Il valore predefinito è `openid AdobeID frame.s2s.all`.

`ims_base_url`: `str` — URL di base di IMS per ambienti di staging/alternativi. Il valore predefinito è l'ambiente di produzione.

`http_client`: `typing.Optional[httpx.Client]` — httpx.Client facoltativo per proxy, TLS o pool di connessioni.

`on_token_refreshed`: `typing.Optional[typing.Callable[[dict[str, Any]], None]]` — Callback facoltativo attivato dopo ogni recupero del token.

`timeout`: `float` — Timeout della richiesta HTTP in secondi. Il valore predefinito è 30.

`max_retries`: `int` — Numero massimo di tentativi ripetuti per errori temporanei. Il valore predefinito è 2.

`refresh_buffer`: `int` — Secondi prima della scadenza in cui attivare l'aggiornamento proattivo. Il valore predefinito è 60.

**Metodi**

`get_token() -> str` — Restituisce un token di accesso valido, aggiornandolo se necessario. Passa all'SDK il riferimento a questo metodo (non una chiamata): `Frameio(token=auth.get_token)`.

`authenticate() -> dict[str, Any]` — Recupera esplicitamente un nuovo token di accesso. Restituisce il dizionario della risposta del token con `access_token`, `expires_in` e così via.

`revoke() -> None` — Revoca entrambi i token lato server e cancella lo stato locale.

`export_tokens() -> dict[str, Any]` — Esporta lo stato corrente dei token per la persistenza.

`import_tokens(data: dict[str, Any]) -> None` — Ripristina lo stato dei token da un dizionario esportato in precedenza.

</Accordion>

<Accordion title="frameio.auth.WebAppAuth(*, client_id, client_secret, redirect_uri, ...)">

Esegue l'autenticazione tramite il grant authorization_code di OAuth 2.0. Utilizzalo per le applicazioni lato server in grado di memorizzare in modo sicuro un segreto client. Per l'utilizzo asincrono, usa `AsyncWebAppAuth`.

```python title="usage"

import secrets
from frameio import Frameio
from frameio.auth import WebAppAuth

auth = WebAppAuth(
    client_id="YOUR_CLIENT_ID",
    client_secret="YOUR_CLIENT_SECRET",
    redirect_uri="https://myapp.com/callback",
)
url = auth.get_authorization_url(state=secrets.token_urlsafe(32))
# redirect user to url ...
auth.exchange_code(code="CODE_FROM_CALLBACK")
client = Frameio(token=auth.get_token)
```

**Parametri**

`client_id`: `str` — ID client OAuth di Adobe IMS.

`client_secret`: `str` — Segreto client OAuth di Adobe IMS.

`redirect_uri`: `str` — URI di reindirizzamento registrato.

`scopes`: `str` — Ambiti separati da spazi (OAuth 2.0 RFC 6749).

`ims_base_url`: `str` — URL di base di IMS per ambienti di staging/alternativi. Il valore predefinito è l'ambiente di produzione.

`http_client`: `typing.Optional[httpx.Client]` — httpx.Client facoltativo per proxy, TLS o pool di connessioni.

`on_token_refreshed`: `typing.Optional[typing.Callable[[dict[str, Any]], None]]` — Callback facoltativo attivato dopo ogni aggiornamento del token.

`timeout`: `float` — Timeout della richiesta HTTP in secondi. Il valore predefinito è 30.

`max_retries`: `int` — Numero massimo di tentativi ripetuti per errori temporanei. Il valore predefinito è 2.

`refresh_buffer`: `int` — Secondi prima della scadenza in cui attivare l'aggiornamento proattivo. Il valore predefinito è 60.

**Metodi**

`get_token() -> str` — Restituisce un token di accesso valido, aggiornandolo se necessario. Passa all'SDK il riferimento a questo metodo: `Frameio(token=auth.get_token)`.

`get_authorization_url(state: str) -> str` — Crea l'URL di autorizzazione di Adobe IMS. Passa un valore CSRF/state opaco che verrà restituito invariato.

`exchange_code(code: str) -> dict[str, Any]` — Scambia un codice di autorizzazione con token di accesso e di aggiornamento.

`refresh() -> dict[str, Any]` — Attiva manualmente un aggiornamento del token.

`revoke() -> None` — Revoca entrambi i token lato server e cancella lo stato locale.

`export_tokens() -> dict[str, Any]` — Esporta lo stato corrente dei token per la persistenza.

`import_tokens(data: dict[str, Any]) -> None` — Ripristina lo stato dei token da un dizionario esportato in precedenza.

<Accordion title="frameio.auth.SPAAuth(*, client_id, redirect_uri, ...)">

Esegue l'autenticazione tramite authorization_code + PKCE (senza segreto client). Utilizzalo per app basate su browser o native che non possono memorizzare in modo sicuro un segreto client. Per l'utilizzo asincrono, usa `AsyncSPAAuth`.

```python title="usage"

import secrets
from frameio import Frameio
from frameio.auth import SPAAuth

auth = SPAAuth(client_id="YOUR_CLIENT_ID", redirect_uri="https://myapp.com/cb")
result = auth.get_authorization_url(state=secrets.token_urlsafe(32))
# redirect user to result.url, store result.code_verifier
auth.exchange_code(code="CODE_FROM_CALLBACK", code_verifier=result.code_verifier)
client = Frameio(token=auth.get_token)
```

**Parametri**

`client_id`: `str` — ID client OAuth di Adobe IMS.

`redirect_uri`: `str` — URI di reindirizzamento registrato.

`scopes`: `str` — Ambiti separati da spazi (OAuth 2.0 RFC 6749).

`ims_base_url`: `str` — URL di base di IMS per ambienti di staging/alternativi. Il valore predefinito è l'ambiente di produzione.

`http_client`: `typing.Optional[httpx.Client]` — httpx.Client facoltativo per proxy, TLS o pool di connessioni.

`on_token_refreshed`: `typing.Optional[typing.Callable[[dict[str, Any]], None]]` — Callback facoltativo attivato dopo ogni aggiornamento del token.

`timeout`: `float` — Timeout della richiesta HTTP in secondi. Il valore predefinito è 30.

`max_retries`: `int` — Numero massimo di tentativi ripetuti per errori temporanei. Il valore predefinito è 2.

`refresh_buffer`: `int` — Secondi prima della scadenza in cui attivare l'aggiornamento proattivo. Il valore predefinito è 60.

**Metodi**

`get_token() -> str` — Restituisce un token di accesso valido, aggiornandolo se necessario. Passa all'SDK il riferimento a questo metodo: `Frameio(token=auth.get_token)`.

`get_authorization_url(state: str) -> AuthorizationUrlResult` — Crea l'URL di autorizzazione di Adobe IMS con challenge PKCE. Restituisce un `AuthorizationUrlResult` con gli attributi `url` e `code_verifier`.

`exchange_code(code: str, code_verifier: str) -> dict[str, Any]` — Scambia un codice di autorizzazione + verificatore PKCE con i token.

`refresh() -> dict[str, Any]` — Attiva manualmente un aggiornamento del token.

`revoke() -> None` — Revoca entrambi i token lato server e cancella lo stato locale.

`export_tokens() -> dict[str, Any]` — Esporta lo stato corrente dei token per la persistenza.

`import_tokens(data: dict[str, Any]) -> None` — Ripristina lo stato dei token da un dizionario esportato in precedenza.

</Accordion>

Dataclass immutabile restituita da `SPAAuth.get_authorization_url()` e `AsyncSPAAuth.get_authorization_url()`. Contiene l'URL di autorizzazione e il verificatore del codice PKCE.

#### Eccezioni di autenticazione {#auth-exceptions}

Tutte le eccezioni di autenticazione ereditano da `FrameioAuthError`.

| Eccezione | Descrizione |
| --- | --- |
| `FrameioAuthError` | Eccezione di base per tutti gli errori di `frameio.auth`. |
| `AuthenticationError` | Scambio o aggiornamento del token non riuscito. Ha gli attributi `error_code` e `error_description`. |
| `TokenExpiredError` | Il token di aggiornamento è scaduto; è necessario ripetere l'autenticazione. |
| `ConfigurationError` | La configurazione richiesta è mancante o non valida. |
| `NetworkError` | Richiesta di rete non riuscita (timeout, errore di connessione e così via). |
| `RateLimitError` | L'API ha restituito 429 e i tentativi ripetuti sono esauriti. Ha l'attributo `retry_after`. |
| `PKCEError` | Verifica PKCE non riuscita. |

#### Caricamento {#upload}

<AccordionGroup>

<Accordion title="frameio.upload.FrameioUploader(asset, file, ...)" defaultOpen={true}>

Carica un file locale su Frame.io utilizzando gli URL prefirmati restituiti da `client.files.create_local_upload(...)`. `FrameioUploader` è un wrapper leggero che legge `upload_urls`, `file_size` e `media_type` dalla risposta `FileWithUploadUrls` ed esegue un caricamento S3 a blocchi e multithread.

```python title="usage"

from frameio import Frameio
from frameio.files import FileCreateLocalUploadParamsData
from frameio.upload import FrameioUploader

client = Frameio(
    token="YOUR_TOKEN",
)
response = client.files.create_local_upload(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    folder_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    data=FileCreateLocalUploadParamsData(
        file_size=1137444,
        name="asset.png",
    ),
)
with open("asset.png", "rb") as f:
    FrameioUploader(response.data, f).upload()
```

**Parametri**

`asset`: `FileWithUploadUrls` — Un'istanza di `FileWithUploadUrls` restituita da `client.files.create_local_upload(...)`.

`file`: `typing.BinaryIO` — Un oggetto di tipo file aperto in modalità di lettura binaria (`"rb"`).

`max_workers`: `int` — Concorrenza del pool di thread passata all'uploader sottostante. Il valore predefinito è 5.

`headers`: `typing.Optional[typing.Dict[str, str]]` — Intestazioni aggiuntive unite a ogni richiesta PUT S3. Il valore predefinito è `{"x-amz-acl": "private"}`, come richiesto da Frame.io.

`max_retries`: `int` — Numero di tentativi ripetuti per blocco. Il valore predefinito è 3.

`on_progress`: `typing.Optional[typing.Callable[[int, int], None]]` — Callback facoltativo richiamato dopo ogni blocco con `(bytes_uploaded_so_far, total_bytes)`.

**Metodi**

`upload() -> None` — Carica il file. Si blocca fino al completamento o genera un'eccezione in caso di errore.
