<Note>
  Questo è un endpoint dimostrativo per l'automazione Update from code changes di Mintlify. Non fa parte dell'API di Frame.io.
</Note>

Usa questo endpoint per verificare se un asset ha terminato l'elaborazione.

## Ottenere lo stato di un asset {#get-an-asset’s-status}

```http
GET /v4/assets/{id}/status
```

### Parametri del percorso {#path-parameters}

| Parametro | Tipo   | Descrizione   |
| --------- | ------ | ------------- |
| `id`      | string | L'ID dell'asset. |

### Campi della risposta {#response-fields}

| Campo         | Tipo   | Descrizione                                     |
| ------------- | ------ | ----------------------------------------------- |
| `data.id`     | string | L'ID dell'asset.                                |
| `data.status` | string | Lo stato di elaborazione: `processing` o `ready`. |
| `data.updated_at` | string | Quando l'asset è stato aggiornato l'ultima volta, come timestamp UTC in formato ISO 8601. |

### Esempio {#example}

```bash
curl http://localhost:3001/v4/assets/a1b2c3/status
```

```json
{
  "data": {
    "id": "a1b2c3",
    "status": "ready",
    "updated_at": "2026-11-03T18:22:10Z"
  }
}
```

### Errori {#errors}

| Stato  | Errore            | Significato           |
| ------ | ----------------- | --------------------- |
| `404`  | `asset_not_found` | Nessun asset ha questo ID. |
