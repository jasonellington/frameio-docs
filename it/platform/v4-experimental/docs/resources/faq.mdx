## Domande sulla compatibilità {#compatibility-questions}

<AccordionGroup>

<Accordion title="L'API Frame.io V4 è retrocompatibile?">

<Warning>

No. Il prodotto Frame.io presentato ad Adobe MAX funziona in modo sostanzialmente diverso e privilegia flussi di lavoro diversi rispetto alla versione legacy. A causa di queste differenze, la nuova API non è retrocompatibile.

</Warning>

</Accordion>

<Accordion title="Come verrà gestita la retrocompatibilità in futuro?">

Consapevoli che la retrocompatibilità è una preoccupazione importante per i clienti che gestiscono integrazioni di livello produttivo con requisiti di uptime elevati, stiamo progettando l'API V4 in modo che supporti un ulteriore livello di controllo delle versioni tramite un header HTTP personalizzato. Ciò consentirà ai client di scegliere di utilizzare endpoint sperimentali, di evitare modifiche che causano incompatibilità e di fornire garanzie di retrocompatibilità all'interno del namespace API `/v4`.

</Accordion>

<Accordion title="Quando l'API V4 sarà disponibile per tutti, le automazioni che ho configurato con il prodotto legacy continueranno a funzionare? In altre parole, verranno migrate automaticamente a V4?">

<Warning>

Tutte le automazioni che utilizzano token sviluppatore legacy non funzioneranno più per gli account V4. **Non** disponiamo di alcun modo per migrarle a V4.

</Warning>

</Accordion>

</AccordionGroup>

## Contenuti multimediali e file {#media-&-files}

<AccordionGroup>

<Accordion title="Per quanto tempo sono validi gli URL dei link multimediali?">

Gli URL restituiti in `media_links` (come `download_url`, `inline_url` e `url`) sono **URL firmati temporanei**: scadono e non possono essere riutilizzati all'infinito.

| Tipo di URL | Scadenza |
| --- | --- |
| URL di download e inline (`original`, `high_quality`, `efficient`, `video_h264_180`) | Fino a 24 ore |
| URL di miniature e anteprime (`thumbnail`) | Fino a 24 ore |

In pratica, la scadenza è allineata a mezzogiorno o mezzanotte UTC, quindi il tempo effettivamente rimanente quando ricevi un URL può variare da pochi minuti a 24 ore, a seconda di quando viene effettuata la richiesta.

**Non memorizzare questi URL né conservarli nella cache.** Richiedi sempre un nuovo set di `media_links` ogni volta che devi distribuire un file o accedervi. Il tentativo di utilizzare un URL scaduto genererà un errore `403` dalla CDN.

</Accordion>

</AccordionGroup>
