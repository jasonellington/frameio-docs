## 简介 {#introduction}

在实施您的 Camera to Cloud 设备之前，请先确保您已准备好成功所需的一切。

## 注册为开发者 {#register-as-a-developer}

您需要为设备准备一个 `client_secret`，才能按照实施指南进行操作。如果您还没有阅读，请查看我们的 [入门指南](/cn/camera-to-cloud/getting-started-with-cloud-device-integrations)，了解如何注册为 C2C 开发者。我们的团队会为您提供与 API 交互所需的凭据。

## 跟随实施指南所需的工具 {#tools-for-following-implementation-guides}

虽然并非严格必需，但准备好以下工具将有助于您跟随我们的教程，并直接测试 API 交互。

### cURL {#curl}

这些教程使用 `curl` 演示 Frame.io API 请求。这个广泛使用的库为发起 HTTP 请求提供了出色的命令行界面。在实施设备时，您需要使用自己偏好的编程语言复现这些 HTTP 调用。在示例中使用 `curl`，您只需将命令复制到终端即可测试 API 交互。

要验证系统中是否已安装 `curl`，请在终端中输入以下命令：

```shell
curl --version
```

您应该会看到类似如下的输出：

```text
curl 7.64.1 (x86_64-apple-darwin20.0) libcurl/7.64.1 (SecureTransport) LibreSSL/2.8.3 zlib/1.2.11 nghttp2/1.41.0
Release-Date: 2019-03-27
Protocols: dict file ftp ftps gopher http https imap imaps ldap ldaps pop3 pop3s rtsp smb smbs smtp smtps telnet tftp 
Features: AsynchDNS GSS-API HTTP2 HTTPS-proxy IPv6 Kerberos Largefile libz MultiSSL NTLM NTLM_WB SPNEGO SSL UnixSockets
```

如果尚未安装，您可以 [在这里](https://curl.se/download.html) 找到适用于大多数操作系统的安装程序。MacOS 或 Linux 用户可以通过 [Homebrew](https://brew.sh/) 安装：

```shell
brew install curl
```

### Python {#python}

我们将通过管道把 `curl` 的结果传给 Python，以格式化 JSON 响应负载：

```shell
curl https://api.frame.io/health | python -m json.tool
```

检查是否已安装 Python：

```shell
python --version
```

预期输出：

```text
Python 2.7.16
```

如果尚未安装，您可以 [在这里下载 Python](https://www.python.org/downloads/)。Python 2.6+ 或 Python 3.x 均可用于这些示例。

虽然 Python 并非必需，但它有助于提高响应的可读性。此外，[jq](https://stedolan.github.io/jq/) 等工具也能提供类似的功能。
