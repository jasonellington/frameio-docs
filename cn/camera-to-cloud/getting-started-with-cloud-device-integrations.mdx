## Camera To Cloud {#camera-to-cloud}

Camera to Cloud API 提供了一种简单直接的认证协议，专为显示功能有限的设备而设计。完成认证后，您的设备即可将拍摄现场的数据直接上传到云端。该系统支持视频、音频、LUT/CDL 和时间码数据的大多数标准文件格式。如需了解有关 C2C 认证连接的更多详情，请访问我们的[信息页面](https://frame.io/c2c/certified)。

## 快速入门 {#getting-started}

请在我们的[开发者网站](/cn/#start-building)上注册，我们会与您联系，指导您完成 Cloud Devices 集成流程。

在评估您的设备后，我们将建立一个共享的 Slack 频道，并与您一起制定集成计划和时间表。您将收到一个开发包，其中包含构建成功集成所需的全部材料。

## 开发者工具包 {#developer-package}

您的开发包将包括：

**1. Client Secret**

Frame.io 将在我们的后端为您的设备创建一个配置模型。完成后，您将收到设备的 `client_secret`，通常称为设备型号标识符。

**2. 参考实现**

您将收到一个 Python 参考实现，其中包含通过 CLI 工具模拟硬件设备的框架代码。其中包括带注释的代码以及概述关键集成步骤的文档。

**3. 验证流程**

在发布之前，您将与 Frame.io 工程师一起参与质量保证流程，以确保您的设备按预期运行。我们的目标是帮助所有集成方达到一致的质量标准，为使用您的云连接设备的最终用户提供良好体验。这可以让您在公开发布之前获得宝贵的反馈。我们会提供一份审核项目清单，您也可以参阅我们的 [C2C 集成检查清单](/cn/camera-to-cloud/integrator-checklist)，了解成功集成需要具备哪些条件。

**4. 支持材料**

您将收到帮助您的团队了解 Frame.io 价值主张和演示技巧的材料，并可使用专门的 Slack 频道与我们的团队协作。如果您需要更多支持——例如 Frame.io 平台演示或集成最佳实践研讨会——请告诉我们，我们将安排相应的会议。

## 规划您的集成 {#planning-your-integration}

在与我们团队沟通之前或沟通期间，需要解决若干技术细节。您不必在联系我们之前准备好所有这些信息——本概述旨在帮助您开始思考这些方面。

### 设备信息 {#device-information}

我们需要一些关于您设备的基本信息：

* 您设备的确切名称
* SVG 格式的徽标，最好是单色的

### 认证方式 {#authentication-method}

我们现在仅支持 6 位数代码认证流程。对于应用程序，我们提供了一种增强方法：在请求设备代码时使用一个特殊的标头参数，以启用我们的 URL 配对流程。该方法会返回 `verification_uri_complete` 或 `verification_uri` 参数，您可以使用它们生成超链接形式的 URL 或二维码，供用户点击或扫描。这将启动一个简化的配对流程，直接连接到用户所选的项目。有关实现细节，请参阅[启用二维码配对指南](/cn/camera-to-cloud/implementing-c2c-authentication-and-authorization#h3-section-enabling-qr-code-pairing)。
