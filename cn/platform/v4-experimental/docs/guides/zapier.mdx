## 什么是 Zapier？ {#what-is-zapier}

**Zapier 是您的数字助理，可以自动连接您喜爱的各种应用。** 您可以把它看作一座桥梁，让您的应用彼此“对话”，而无需您进行任何手动操作。

其神奇之处在于名为 [**Zap**](https://help.zapier.com/hc/en-us/articles/8496309697421-What-is-a-Zap) 的简单“如果发生这个，就执行那个”规则。例如：“当有新视频上传到 Frame.io 时，自动创建一个分享链接发送给我的团队。”就是这么简单——无需编码，无需复杂设置，只需点击操作即可。

Zapier 支持[超过 7,000 个应用](https://zapier.com/apps)，可将重复、繁琐的任务转化为自动化工作流，让您和您的团队有更多时间专注于最重要的工作。

## 为什么要将 Frame.io 与 Zapier 结合使用？ {#why-use-frame-io-with-zapier}

Frame.io 的 [Zapier 集成](https://zapier.com/apps/frameio-v4/integrations)将自动化的强大功能带入您的文件工作流。您无需手动检查新上传的内容、复制链接或发送状态更新，而是可以设置自动化工作流来为您处理这些任务。

**常见的自动化示例：**

- **新上传通知**：当有人上传新视频时，自动在 Slack 中通知您的团队
- **项目管理同步**：创建新的 Frame.io 项目时，在 Airtable 中创建任务
- **客户沟通**：当客户的审阅准备就绪时，向客户发送电子邮件更新
- **文件整理**：自动将已批准的资产保存到 Google Drive 或 Dropbox
- **状态跟踪**：当评论被解决时，在您的 CRM 中更新项目状态

## 设置 Zapier {#setting-up-zapier}

快速开始使用我们的 Zapier 集成，将 Frame.io 连接到数百个应用。

### 设置 {#setup}

<Steps>

<Step title="注册 Zapier">

注册一个[免费的 Zapier 账户](https://zapier.com/apps/frameio-v4/integrations)

</Step>

<Step title="连接 Frame.io">

登录 Zapier，创建一个 Zap 并将 Frame.io 应用添加到您的 Zap 中。完成后，系统将提示您将 Zapier 与您的 Frame.io 账户连接。

</Step>

</Steps>

### 探索 {#explore}

- 浏览 [Zapier 的示例和模板](https://zapier.com/apps/frameio-v4/integrations)
- 如果您希望我们的 Zapier 集成提供更多功能，请在我们的[社区聊天](https://forum.frame.io/)中告诉我们您的需求。我们像维护其他原生集成一样维护 Zapier 集成，并一直在寻找改进它的方法。

### 与我们合作 {#partner-with-us}

- 如果您公司的软件需要直接集成到 Frame.io 中，而无需 Zapier 作为中间件，请[成为 Frame.io 合作伙伴](https://frame.io/integrations)。

## Zapier 中的 Frame.io 资源字段 {#frame-io-resource-fields-in-zapier}

在使用“File Created”或“Comment Created”等触发器时，您会看到许多字段，它们提供了有关事件和资源的丰富上下文。

### 文件字段 {#file-fields}

<Info>

**文件 URL 安全且直接**：V4 集成提供指向 Frame.io 资产存储的直接链接。当您在其他应用中可以在“File Attachment”和“File Attachment (URL)”之间进行选择时，请选择 URL 选项，因为它通常支持更大的文件和更多的文件类型。

</Info>

主要的文件字段包括：

- `Original Download URL` - 原始上传文件的直接下载链接
- `High Quality Download URL` - 高质量代理版本的下载链接
- `Thumbnail Download URL` - 文件缩略图的下载链接
- `File Name` - 包含扩展名的完整文件名
- `File Type Category` - 分类类型：“video”、“image”、“audio”、“document”或“other”
- `Creator Name` 和 `Creator Email` - 有关文件上传者的信息
- `Project Name` 和 `Project ID` - 项目上下文信息

### 评论字段 {#comment-fields}

主要的评论字段包括：

- `Comment Text` - 评论的文本内容
- `Comment Author Name` 和 `Comment Author Email` - 发表评论的人
- `Timestamp` - 基于时间的评论的帧编号（适用于视频）
- `File ID` - 评论所在文件的 ID
- `Project Name` 和 `Project ID` - 项目上下文

### 项目字段 {#project-fields}

主要的项目字段包括：

- `Project Name` 和 `Project ID` - 基本项目信息
- `Root Folder ID` - 项目根文件夹的 ID
- `Storage Usage` - 项目使用的存储空间（以字节为单位）
- `View URL` - 在 Frame.io 中查看项目的直接链接
- `Workspace ID` 和 `Account ID` - 组织上下文

## 从旧版迁移到 V4 {#migrating-from-legacy-to-v4}

Frame.io 的 V4 Zapier 集成在保持与旧版功能对等的同时，带来了显著的改进。

### 进行切换 {#making-the-switch}

<Warning>

**对于现有用户**：如果您目前正在使用旧版 Frame.io Zapier 集成，您现有的 Zap 将只能与旧版 Frame.io 配合使用。将 Frame.io 账户升级到 V4 后，您需要使用 Frame.io V4 Zapier 集成重新构建您的集成。

</Warning>

<Info>

**对于新用户**：创建新 Zap 时，请始终选择 **Frame.io V4** 集成。这是当前积极维护的版本，包含所有最新改进。

</Info>

### 主要术语变更 {#key-terminology-changes}

最明显的变化在于我们在内容组织方面使用的术语：

| 旧版术语 | V4 术语 |
| --- | --- |
| ”Asset" | "File” 或 “File & Folder" |
| "Asset Created" | "File Created" |
| "Asset Ready" | "File Ready" |
| "Asset Upload Completed" | "File Upload Completed” |

**为什么要做出这一变更？** “File”（文件）一词更通俗易懂，并且能准确描述您正在处理的内容——无论是视频、图像、文档还是任何其他文件类型。
