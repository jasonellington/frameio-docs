## 所有账户均可访问 {#all-account-access}

所有 Frame V4 账户——不仅仅是通过 Adobe Admin Console 管理的账户——都可以创建令牌并访问 V4 API。客户和合作伙伴可以使用我们最新的 API 功能来测试、构建和完善他们的工作流。

<Steps>

<Step title="创建用户身份验证令牌">

访问 Adobe Developer Console 创建用户身份验证令牌。用户必须使用与其 Frame 登录相同的 Adobe ID，才能验证 API 令牌访问权限。

</Step>

<Step title="创建 API 凭据">

获得 API 访问权限后，下一步是创建 API 凭据（即 API 令牌），用于与 Frame 通信。请在 developer.adobe.com 上创建您的 API 凭据。

</Step>

</Steps>

![账户访问](/images/platform/docs/guides/accounts-projects-and-workspaces/706a4eb9324bc24a3465388a838455baf58384f128882a185dad2d1900f728a3.webp)

<Info>

所有 V4 账户，无论是由 Frame 管理（V4F）还是由 Adobe 管理（V4A），都可以在 Adobe Developer Console 中创建项目，然后创建凭据。获得一组凭据（OAuth Client ID/Client Secret）后，您就可以集成 Adobe Developer Platform 的三方 OAuth 流程。登录您的 Adobe Identity，即可获得有效的身份验证令牌和刷新令牌，用于向 Frame.io V4 Developer API 发出请求！

</Info>

## 项目和工作区 {#projects-and-workspaces}

### 工作区更新 {#workspace-updates}

Frame.io 的着陆页焕然一新，现称为工作区（Workspace）页面。用户可以浏览自己在账户中有权访问的工作区和项目。得益于这一新设计，现在可以更轻松地查看谁属于某个工作区，并快速邀请新成员。

<Note>

在 Frame V3 中，工作区被称为 Team。

</Note>

在 V4 中，工作区被设置为仅限邀请，因此用户只能看到自己被明确邀请加入的工作区。此外，账户设置中不再有 Team Directory 页面。

要管理权限及相关操作，请使用创建、列出、删除和更新工作区的端点。

<CardGroup cols={1}>

<Card title="工作区管理操作" icon="users" iconType="solid" horizontal={true}>

- 列出给定工作区的用户角色。
- 从给定工作区中移除用户。
- 如果用户已被添加到工作区，则更新其在该工作区中的用户角色。如果用户尚未被添加到工作区，则会以给定的角色添加该用户。

</Card>

</CardGroup>

### 项目更新 {#project-updates}

V4 中的项目创建流程已发生变化。现在，当您新建项目时，可以选择空白项目或项目模板。共有十二个模板可供选择，专为常见的创意工作流而设计。您还可以选择是否包含模板的演示资产，或者仅从模板结构开始。选择项目模板后，会立即在您的工作区中创建一个新项目。

要管理权限及相关操作，请使用创建、列出、删除和更新项目的端点。

<CardGroup cols={1}>

<Card title="项目管理操作" icon="folder" iconType="solid" horizontal={true}>

- 列出给定项目的用户角色。
- 从给定项目中移除用户。
- 如果用户已被添加到项目，则更新其在该项目中的用户角色。如果用户尚未被添加到项目，则会以给定的角色添加该用户。

</Card>

</CardGroup>
