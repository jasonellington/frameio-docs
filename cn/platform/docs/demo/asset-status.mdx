  这是一个用于 Mintlify "根据代码变更更新"自动化功能的演示端点，并不属于 Frame.io API。
</Note>

使用此端点检查资产是否已完成处理。

## 获取资产状态 {#get-an-asset’s-status}

```http
GET /v4/assets/{id}/status
```

### 路径参数 {#path-parameters}

| 参数 | 类型   | 描述   |
| --------- | ------ | ------------- |
| `id`      | string | 资产 ID。 |

### 响应字段 {#response-fields}

| 字段         | 类型   | 描述                                     |
| ------------- | ------ | ----------------------------------------------- |
| `data.id`     | string | 资产 ID。                                   |
| `data.status` | string | 处理状态：`processing` 或 `ready`。 |
| `data.updated_at` | string | 资产最后一次更新的时间，格式为 ISO 8601 UTC 时间戳。 |

### 示例 {#example}

```bash
curl http://localhost:3001/v4/assets/a1b2c3/status
```

```json
{
  "data": {
    "id": "a1b2c3",
    "status": "ready",
    "updated_at": "2026-11-03T18:22:10Z"
  }
}
```

### 错误 {#errors}

| 状态 | 错误             | 含义               |
| ------ | ----------------- | --------------------- |
| `404`  | `asset_not_found` | 不存在具有此 ID 的资产。 |
