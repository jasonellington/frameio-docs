### 关于 Frame.io {#about-frame-io}

Frame.io 提供灵活、快速且直观的平台，帮助创意团队及其利益相关者组织、审阅和管理制作中的素材，并协调支持这些工作的人员与流程。依托强大的元数据框架，团队现在可以使用 Frame.io 自定义任何以媒体素材为中心的创意工作流。

### 关于 Frame.io V4 开发者平台 {#about-frame-io-v4-developer-platform}

Frame.io 开发者平台经过全面重新设计，让创意协作变得清晰而简单。一系列让您的创意工作更轻松的新概念包括：基于关系的访问控制、贴合团队工作方式的自定义字段，以及简化的 Shares。我们设计了全新的 API，供您交互和构建，以最好地满足客户和合作伙伴的需求。

在本文档中，您会找到一份全面的入门指南，带您了解核心概念并详细介绍完整的 V4 API，同时特别说明从旧版 API 迁移时的各项差异。我们还提供了人类和机器均可读取的 *API 参考*。该参考基于 OpenAPI 规范生成，开发者可以通过 Frame.io *API 参考* 查看所有受支持端点的完整列表，以及示例请求和响应（包括错误信息）。网站顶部导航栏可用于访问正在积极开发中的新端点。有兴趣探索这些*实验性*版本的开发者可以在此切换版本。本部分中的端点仅供方向性参考，因为在以受支持的版本标头正式发布之前，其路由和响应体可能会发生变化。
