### 安装 {#installation}

```bash
npm i -s frameio
```

---

### 用法 {#usage}

按如下方式实例化并使用客户端：

```typescript
import { FrameioClient } from "frameio";

const client = new FrameioClient({ token: "YOUR_TOKEN" });
await client.metadataFields.metadataFieldDefinitionsCreate("b2702c44-c6da-4bb6-8bbd-be6e547ccf1b", {
    data: {
        field_type: "select",
        field_configuration: {
            enable_add_new: false,
            options: [
                {
                    display_name: "Option 1",
                },
                {
                    display_name: "Option 2",
                },
            ],
        },
        name: "Fields definition name",
    },
});
```

---

### 请求和响应类型 {#request-and-response-types}

SDK 将所有请求和响应类型导出为 TypeScript 接口。只需通过以下命名空间导入即可：

```typescript
import { Frameio } from "frameio";

const request: Frameio.UpdateFieldDefinitionParams = {
    ...
};
```

---

### 异常处理 {#exception-handling}

当 API 返回非成功状态码（4xx 或 5xx 响应）时，将抛出以下错误的子类。

```typescript
import { FrameioError } from "frameio";

try {
    await client.metadataFields.metadataFieldDefinitionsCreate(...);
} catch (err) {
    if (err instanceof FrameioError) {
        console.log(err.statusCode);
        console.log(err.message);
        console.log(err.body);
        console.log(err.rawResponse);
    }
}
```

### 高级用法 {#advanced}

#### 附加请求头 {#additional-headers}

如果希望在请求中发送附加请求头，请使用 headers 请求选项。

```typescript
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    headers: {
        'X-Custom-Header': 'custom value'
    }
});
```

#### 附加查询字符串参数 {#additional-query-string-parameters}

如果希望在请求中发送附加查询字符串参数，请使用 queryParams 请求选项。

```typescript
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    queryParams: {
        'customQueryParamKey': 'custom query param value'
    }
});
```

---

#### 重试 {#retries}

SDK 内置了采用指数退避的自动重试机制。只要请求被判定为可重试，且重试次数未超过配置的重试上限（默认值：2），请求就会被重试。

当返回以下任一 HTTP 状态码时，请求被判定为可重试：

- 408（超时）
- 429（请求过多）
- 5XX（服务器内部错误）

<br />

使用 `maxRetries` 请求选项配置此行为。

```typescript
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    maxRetries: 0 // override maxRetries at the request level
});
```

---

#### 超时 {#timeouts}

SDK 默认超时时间为 60 秒。使用 timeoutInSeconds 选项配置此行为。

```typescript
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    timeoutInSeconds: 30 // override timeout to 30s
});
```

#### 中止请求 {#aborting-requests}

SDK 允许用户通过传入中止信号，随时中止请求。

```typescript
const controller = new AbortController();
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    abortSignal: controller.signal
});
controller.abort(); // aborts the request
```

---

#### 访问原始响应数据 {#access-raw-response-data}

SDK 通过 `.withRawResponse()` 方法提供对原始响应数据（包括响应头）的访问。`.withRawResponse()` 方法返回一个 promise，其解析结果为包含 `data` 和 `rawResponse` 属性的对象。

```typescript
const { data, rawResponse } = await client.metadataFields.metadataFieldDefinitionsCreate(...).withRawResponse();

console.log(data);
console.log(rawResponse.headers['X-My-Header']);
```

#### 运行时兼容性 {#runtime-compatibility}

SDK 可在以下运行时中使用：

- Node.js 18+
- Vercel
- Cloudflare Workers
- Deno v1.25+
- Bun 1.0+
- React Native

---

#### 自定义 Fetch 客户端 {#customizing-fetch-client}

SDK 允许你自定义底层的 HTTP 客户端 / Fetch 函数。如果你在不受支持的环境中运行，可以借此作为应急手段，确保 SDK 正常工作。

```typescript
import { FrameioClient } from "frameio";

const client = new FrameioClient({
    ...
    fetcher: // provide your implementation here
});
```

#### 身份验证 {#auth}

<AccordionGroup>

<Accordion title="new ServerToServerAuth({ clientId, clientSecret, ... })">

使用 OAuth 2.0 `client_credentials` 授权方式进行身份验证。此流程不涉及用户，也不会返回刷新令牌。访问令牌过期时，SDK 会使用客户端凭据自动请求新的令牌。

```typescript title="usage"
import { FrameioClient, ServerToServerAuth } from "frameio";

const auth = new ServerToServerAuth({
    clientId: "YOUR_CLIENT_ID",
    clientSecret: "YOUR_CLIENT_SECRET",
});
const client = new FrameioClient({ token: () => auth.getToken() });
```

**参数**

`clientId`: `string` — Adobe IMS OAuth 客户端 ID。

`clientSecret`: `string` — Adobe IMS OAuth 客户端密钥。

`scopes`: `string` — 以空格分隔的作用域（OAuth 2.0 RFC 6749）。默认为服务器到服务器作用域。

`imsBaseUrl`: `string` — 用于预发布/其他环境的 IMS 基础 URL。默认为生产环境。

`fetch`: `typeof fetch` — 自定义 fetch 实现（用于代理、TLS 等）。

`onTokenRefreshed`: `OnTokenRefreshed` — 可选回调，在每次获取令牌后触发。

`timeout`: `number` — HTTP 请求超时时间（毫秒）。默认值为 30000。

`maxRetries`: `number` — 临时性故障的最大重试次数。默认值为 2。

`refreshBuffer`: `number` — 在过期前多少秒触发主动刷新。默认值为 60。

`logger`: `Logger` — 用于输出诊断信息的日志记录器实例。

**方法**

`getToken(): Promise<string>` — 返回有效的访问令牌，必要时进行刷新。将其传递给客户端：`new FrameioClient({ token: () => auth.getToken() })`。

`authenticate(): Promise<TokenResponse>` — 显式获取新的访问令牌。

`revoke(): Promise<void>` — 在服务器端吊销令牌并清除本地状态。

`exportTokens(): ExportedTokens` — 导出当前令牌状态以便持久化。

`importTokens(data: ExportedTokens): void` — 从之前导出的对象恢复令牌状态。

</Accordion>

<Accordion title="new WebAppAuth({ clientId, clientSecret, redirectUri, ... })">

使用 OAuth 2.0 `authorization_code` 授权方式进行身份验证。适用于能够安全存储客户端密钥的服务器端应用。

```typescript title="usage"
import { randomBytes } from "crypto";
import { FrameioClient, WebAppAuth } from "frameio";

const auth = new WebAppAuth({
    clientId: "YOUR_CLIENT_ID",
    clientSecret: "YOUR_CLIENT_SECRET",
    redirectUri: "https://myapp.com/callback",
});
const url = auth.getAuthorizationUrl({ state: randomBytes(24).toString("hex") });
// redirect the user to url ...
await auth.exchangeCode("CODE_FROM_CALLBACK");
const client = new FrameioClient({ token: () => auth.getToken() });
```

**参数**

`clientId`: `string` — Adobe IMS OAuth 客户端 ID。

`clientSecret`: `string` — Adobe IMS OAuth 客户端密钥。

`redirectUri`: `string` — 已注册的重定向 URI。

`scopes`: `string` — 以空格分隔的作用域（OAuth 2.0 RFC 6749）。

`imsBaseUrl`: `string` — 用于预发布/其他环境的 IMS 基础 URL。默认为生产环境。

`fetch`: `typeof fetch` — 自定义 fetch 实现（用于代理、TLS 等）。

`onTokenRefreshed`: `OnTokenRefreshed` — 可选回调，在每次刷新令牌后触发。

`timeout`: `number` — HTTP 请求超时时间（毫秒）。默认值为 30000。

`maxRetries`: `number` — 临时性故障的最大重试次数。默认值为 2。

`refreshBuffer`: `number` — 在过期前多少秒触发主动刷新。默认值为 60。

`logger`: `Logger` — 用于输出诊断信息的日志记录器实例。

**方法**

`getToken(): Promise<string>` — 返回有效的访问令牌，必要时进行刷新。

`getAuthorizationUrl({ state }): string` — 构建 Adobe IMS 授权 URL。传入一个不透明的 CSRF/state 值，该值将被原样返回。

`exchangeCode(code: string): Promise<TokenResponse>` — 用授权码换取访问令牌和刷新令牌。

`refresh(): Promise<TokenResponse>` — 手动触发令牌刷新。

`revoke(): Promise<void>` — 在服务器端吊销令牌并清除本地状态。

`exportTokens(): ExportedTokens` — 导出当前令牌状态以便持久化。

`importTokens(data: ExportedTokens): void` — 从之前导出的对象恢复令牌状态。

</Accordion>

<Accordion title="new SPAAuth({ clientId, redirectUri, ... })">

使用 `authorization_code` + PKCE（无需客户端密钥）进行身份验证。适用于无法安全存储客户端密钥的基于浏览器的单页应用。

```typescript title="usage"
import { randomBytes } from "crypto";
import { FrameioClient, SPAAuth } from "frameio";

const auth = new SPAAuth({
    clientId: "YOUR_CLIENT_ID",
    redirectUri: "https://myapp.com/cb",
});
const result = await auth.getAuthorizationUrl({ state: randomBytes(24).toString("hex") });
// redirect the user to result.url, store result.codeVerifier ...
await auth.exchangeCode({ code: "CODE_FROM_CALLBACK", codeVerifier: result.codeVerifier });
const client = new FrameioClient({ token: () => auth.getToken() });
```

**参数**

`clientId`: `string` — Adobe IMS OAuth 客户端 ID。

`redirectUri`: `string` — 已注册的重定向 URI。

`scopes`: `string` — 以空格分隔的作用域（OAuth 2.0 RFC 6749）。

`imsBaseUrl`: `string` — 用于预发布/其他环境的 IMS 基础 URL。默认为生产环境。

`fetch`: `typeof fetch` — 自定义 fetch 实现（用于代理、TLS 等）。

`onTokenRefreshed`: `OnTokenRefreshed` — 可选回调，在每次刷新令牌后触发。

`timeout`: `number` — HTTP 请求超时时间（毫秒）。默认值为 30000。

`maxRetries`: `number` — 临时性故障的最大重试次数。默认值为 2。

`refreshBuffer`: `number` — 在过期前多少秒触发主动刷新。默认值为 60。

`logger`: `Logger` — 用于输出诊断信息的日志记录器实例。

**方法**

`getToken(): Promise<string>` — 返回有效的访问令牌，必要时进行刷新。

`getAuthorizationUrl({ state }): Promise<AuthorizationUrlResult>` — 构建带有 PKCE 质询的 Adobe IMS 授权 URL。返回包含 `url` 和 `codeVerifier` 的 `AuthorizationUrlResult`。

`exchangeCode({ code, codeVerifier }): Promise<TokenResponse>` — 用授权码 + PKCE 验证码换取令牌。

`refresh(): Promise<TokenResponse>` — 手动触发令牌刷新。

`revoke(): Promise<void>` — 在服务器端吊销令牌并清除本地状态。

`exportTokens(): ExportedTokens` — 导出当前令牌状态以便持久化。

`importTokens(data: ExportedTokens): void` — 从之前导出的对象恢复令牌状态。

<Accordion title="new NativeAppAuth({ clientId, redirectUri, ... })">

```typescript title="usage"

// open result.url in the system browser, store result.codeVerifier ...

const client = new FrameioClient({ token: () => auth.getToken() });
```

**参数**

`redirectUri`: `string` — 已注册的重定向 URI（支持自定义 scheme）。

`scopes`: `string` — 以空格分隔的作用域（OAuth 2.0 RFC 6749）。

`imsBaseUrl`: `string` — 用于预发布/其他环境的 IMS 基础 URL。默认为生产环境。

`fetch`: `typeof fetch` — 自定义 fetch 实现（用于代理、TLS 等）。

`onTokenRefreshed`: `OnTokenRefreshed` — 可选回调，在每次刷新令牌后触发。

`timeout`: `number` — HTTP 请求超时时间（毫秒）。默认值为 30000。

`maxRetries`: `number` — 临时性故障的最大重试次数。默认值为 2。

`refreshBuffer`: `number` — 在过期前多少秒触发主动刷新。默认值为 60。

`logger`: `Logger` — 用于输出诊断信息的日志记录器实例。

#### 身份验证异常 {#auth-exceptions}

所有身份验证错误均继承自 `FrameioAuthError`，并可从 `frameio` 导入。

| 异常 | 说明 |
| --- | --- |
| `FrameioAuthError` | 所有身份验证 SDK 错误的基础错误类。 |
| `AuthenticationError` | 令牌交换或刷新失败。具有 `errorCode` 和 `errorDescription` 属性。 |
| `TokenExpiredError` | 刷新令牌已过期，需要重新进行身份验证。 |
| `NetworkError` | 网络请求失败（超时、连接错误等）。 |
| `RateLimitError` | Adobe IMS 返回 429 且重试次数已用尽。具有 `retryAfter` 属性。 |
| `PKCEError` | PKCE 验证失败。 |
| `ConfigurationError` | 必需的配置缺失或无效。 |
