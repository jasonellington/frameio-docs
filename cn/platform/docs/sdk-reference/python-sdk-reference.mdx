### 用法 {#usage}

按如下方式实例化并使用客户端：

```python
from frameio import (
    Frameio,
    SelectDefinitionParamsFieldConfiguration,
    SelectDefinitionParamsFieldConfigurationOptionsItem,
)
from frameio.metadata_fields import CreateFieldDefinitionParamsData_Select

client = Frameio(
    token="YOUR_TOKEN",
)
client.metadata_fields.metadata_field_definitions_create(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    data=CreateFieldDefinitionParamsData_Select(
        field_configuration=SelectDefinitionParamsFieldConfiguration(
            enable_add_new=False,
            options=[
                SelectDefinitionParamsFieldConfigurationOptionsItem(
                    display_name="Option 1",
                ),
                SelectDefinitionParamsFieldConfigurationOptionsItem(
                    display_name="Option 2",
                ),
            ],
        ),
        name="Fields definition name",
    ),
)
```

### 异步客户端 {#async-client}

SDK 还导出了一个异步客户端，以便您对我们的 API 进行非阻塞调用。请注意，如果您要构造一个异步 httpx 客户端类并传入此客户端，请使用 httpx.AsyncClient() 而不是 httpx.Client()（例如，用于此客户端的 httpx_client 参数）。

```python
import asyncio

from frameio import (
    AsyncFrameio,
    SelectDefinitionParamsFieldConfiguration,
    SelectDefinitionParamsFieldConfigurationOptionsItem,
)
from frameio.metadata_fields import CreateFieldDefinitionParamsData_Select

client = AsyncFrameio(
    token="YOUR_TOKEN",
)


async def main() -> None:
    await client.metadata_fields.metadata_field_definitions_create(
        account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
        data=CreateFieldDefinitionParamsData_Select(
            field_configuration=SelectDefinitionParamsFieldConfiguration(
                enable_add_new=False,
                options=[
                    SelectDefinitionParamsFieldConfigurationOptionsItem(
                        display_name="Option 1",
                    ),
                    SelectDefinitionParamsFieldConfigurationOptionsItem(
                        display_name="Option 2",
                    ),
                ],
            ),
            name="Fields definition name",
        ),
    )


asyncio.run(main())
```

### 异常处理 {#exception-handling}

当 API 返回非成功状态码（4xx 或 5xx 响应）时，将抛出以下错误的子类。

```python
from frameio.core.api_error import ApiError

try:
    client.metadata_fields.metadata_field_definitions_create(...)
except ApiError as e:
    print(e.status_code)
    print(e.body)
```

### 分页 {#pagination}

分页请求将返回 SyncPager 或 AsyncPager，可用作底层对象的生成器。

```python
from frameio import Frameio

client = Frameio(
    token="YOUR_TOKEN",
)
response = client.project_permissions.index(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    project_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    page_size=10,
    include_total_count=False,
)
for item in response:
    yield item
# alternatively, you can paginate page-by-page
for page in response.iter_pages():
    yield page
```

### 高级 {#advanced}

#### 访问原始响应数据 {#access-raw-response-data}

SDK 通过 .with_raw_response 属性提供对原始响应数据（包括标头）的访问。.with_raw_response 属性返回一个“原始”客户端，可用于访问 .headers 和 .data 属性。

```python
from frameio import Frameio

client = Frameio(
    ...,
)
response = (
    client.metadata_fields.with_raw_response.metadata_field_definitions_create(
        ...
    )
)
print(response.headers)  # access the response headers
print(response.data)  # access the underlying object
pager = client.project_permissions.index(...)
print(pager.response.headers)  # access the response headers for the first page
for item in pager:
    print(item)  # access the underlying object(s)
for page in pager.iter_pages():
    print(page.response.headers)  # access the response headers for each page
    for item in page:
        print(item)  # access the underlying object(s)
```

#### 重试 {#retries}

SDK 内置了带指数退避的自动重试机制。只要请求被判定为可重试，且重试次数未超过配置的重试上限（默认：2），请求就会被重试。<br />
当返回以下任一 HTTP 状态码时，请求被判定为可重试：

- 408（超时）
- 429（请求过多）
- 5XX（内部服务器错误）

<br />

使用 `max_retries` 请求选项来配置此行为。

```python
client.metadata_fields.metadata_field_definitions_create(..., request_options={
    "max_retries": 1
})
```

---

#### 超时 {#timeouts}

SDK 默认超时时间为 60 秒。您可以在客户端或请求级别通过 timeout 选项进行配置。

```python
from frameio import Frameio

client = Frameio(
    ...,
    timeout=20.0,
)


# Override timeout for a specific method
client.metadata_fields.metadata_field_definitions_create(..., request_options={
    "timeout_in_seconds": 1
})
```

---

#### 自定义客户端 {#custom-client}

您可以覆盖 httpx 客户端，以根据您的使用场景进行自定义。一些常见的使用场景包括支持代理和传输层。

```python
import httpx
from frameio import Frameio

client = Frameio(
    ...,
    httpx_client=httpx.Client(
        proxy="http://my.test.proxy.example.com",
        transport=httpx.HTTPTransport(local_address="0.0.0.0"),
    ),
)
```

#### 认证 {#auth}

<AccordionGroup>

<Accordion title="frameio.auth.ServerToServerAuth(*, client_id, client_secret, ...)" defaultOpen={true}>

使用 OAuth 2.0 client_credentials 授权方式进行认证。此流程不涉及用户，也不会返回刷新令牌。访问令牌过期时，SDK 会使用客户端凭据自动请求新的令牌。如需异步使用，请使用 `AsyncServerToServerAuth`。

```python title="usage"

from frameio import Frameio
from frameio.auth import ServerToServerAuth

auth = ServerToServerAuth(client_id="YOUR_CLIENT_ID", client_secret="YOUR_CLIENT_SECRET")
client = Frameio(token=auth.get_token)
```

**参数**

`client_id`: `str` — Adobe IMS OAuth 客户端 ID。

`client_secret`: `str` — Adobe IMS OAuth 客户端密钥。

`scopes`: `str` — 以空格分隔的作用域（OAuth 2.0 RFC 6749）。默认为 `openid AdobeID frame.s2s.all`。

`ims_base_url`: `str` — 用于预发布/其他环境的 IMS 基础 URL。默认为生产环境。

`http_client`: `typing.Optional[httpx.Client]` — 用于代理、TLS 或连接池的可选 httpx.Client。

`on_token_refreshed`: `typing.Optional[typing.Callable[[dict[str, Any]], None]]` — 每次获取令牌后触发的可选回调。

`timeout`: `float` — HTTP 请求超时时间（秒）。默认为 30。

`max_retries`: `int` — 暂时性故障的最大重试次数。默认为 2。

`refresh_buffer`: `int` — 在过期前多少秒触发主动刷新。默认为 60。

**方法**

`get_token() -> str` — 返回有效的访问令牌，必要时进行刷新。将此方法引用（而非调用结果）传递给 SDK：`Frameio(token=auth.get_token)`。

`authenticate() -> dict[str, Any]` — 显式获取新的访问令牌。返回包含 `access_token`、`expires_in` 等字段的令牌响应字典。

`revoke() -> None` — 在服务器端吊销两个令牌并清除本地状态。

`export_tokens() -> dict[str, Any]` — 导出当前令牌状态以便持久化。

`import_tokens(data: dict[str, Any]) -> None` — 从先前导出的字典中恢复令牌状态。

</Accordion>

<Accordion title="frameio.auth.WebAppAuth(*, client_id, client_secret, redirect_uri, ...)">

`timeout`: `float` — HTTP 请求超时时间（秒）。默认为 30。

`max_retries`: `int` — 暂时性故障的最大重试次数。默认为 2。

`refresh_buffer`: `int` — 在过期前多少秒触发主动刷新。默认为 60。

**方法**

`refresh() -> dict[str, Any]` — 手动触发令牌刷新。

`revoke() -> None` — 在服务器端吊销两个令牌并清除本地状态。

<Accordion title="frameio.auth.SPAAuth(*, client_id, redirect_uri, ...)">

使用 authorization_code + PKCE（无客户端密钥）进行认证。适用于无法安全存储客户端密钥的基于浏览器的应用或原生应用。如需异步使用，请使用 `AsyncSPAAuth`。

```python title="usage"
result = auth.get_authorization_url(state=secrets.token_urlsafe(32))
# redirect user to result.url, store result.code_verifier
auth.exchange_code(code="CODE_FROM_CALLBACK", code_verifier=result.code_verifier)
client = Frameio(token=auth.get_token)
```

`client_id`: `str` — Adobe IMS OAuth 客户端 ID。

`redirect_uri`: `str` — 已注册的重定向 URI。

`scopes`: `str` — 以空格分隔的作用域（OAuth 2.0 RFC 6749）。

`http_client`: `typing.Optional[httpx.Client]` — 用于代理、TLS 或连接池的可选 httpx.Client。

`on_token_refreshed`: `typing.Optional[typing.Callable[[dict[str, Any]], None]]` — 每次刷新令牌后触发的可选回调。

`timeout`: `float` — HTTP 请求超时时间（秒）。默认为 30。

`max_retries`: `int` — 暂时性故障的最大重试次数。默认为 2。

`refresh_buffer`: `int` — 在过期前多少秒触发主动刷新。默认为 60。

**方法**

`get_token() -> str` — 返回有效的访问令牌，必要时进行刷新。将此方法引用传递给 SDK：`Frameio(token=auth.get_token)`。

`get_authorization_url(state: str) -> AuthorizationUrlResult` — 构建带有 PKCE 质询的 Adobe IMS 授权 URL。返回包含 `url` 和 `code_verifier` 属性的 `AuthorizationUrlResult`。

`exchange_code(code: str, code_verifier: str) -> dict[str, Any]` — 使用授权码和 PKCE 验证码换取令牌。

`refresh() -> dict[str, Any]` — 手动触发令牌刷新。

`revoke() -> None` — 在服务器端吊销两个令牌并清除本地状态。

`export_tokens() -> dict[str, Any]` — 导出当前令牌状态以便持久化。

</Accordion>

#### 认证异常 {#auth-exceptions}

所有认证异常均继承自 `FrameioAuthError`。

| 异常 | 描述 |
| --- | --- |
| `FrameioAuthError` | 所有 `frameio.auth` 错误的基础异常。 |
| `AuthenticationError` | 令牌交换或刷新失败。具有 `error_code` 和 `error_description` 属性。 |
| `TokenExpiredError` | 刷新令牌已过期，需要重新认证。 |
| `ConfigurationError` | 必需的配置缺失或无效。 |
| `NetworkError` | 网络请求失败（超时、连接错误等）。 |
| `RateLimitError` | API 返回 429 且重试次数已用尽。具有 `retry_after` 属性。 |
| `PKCEError` | PKCE 验证失败。 |
