## 概述 {#overview}

如果您想从现有的云端应用或提供 assets 的 URL 将文件上传到 Frame.io，Zapier 通常是一个不错的解决方案，因为它的产品解决了许多 API 设计上的差异，而正是这些差异让与云端应用的交互变得令人头疼。本指南将阐明 Zapier 上传服务的关键特性，让您确切了解集成中发生了什么。

## 设置文件上传方式 {#setting-the-file-upload-method}

Zapier 会尝试为其连接的每个 API 自动找到最灵活的文件上传方式。例如，Zapier 会尝试将无法在应用域之外访问的受限链接转换为公开可用的下载链接：

原始的不可读链接：
`https://www.dropbox.com/s/hriinb9w3a2107m/iPad%20intro.pdf`

转换后的链接，可供 Frame.io 的 Uploader API 使用：
`https://dl.dropboxusercontent.com/s/hriinb9w3a2107m/iPad%20intro.pdf`

### Zapier 的文件限制 {#zapier’s-file-limitations}

重要的是，如果 Zapier **无法**找到可传递给 Frame.io API 的静态下载 URL，Zapier 自己的服务会即时下载文件并将其传递给 Frame.io。Zapier 将此方式限制为**[小于 100MB](https://zapier.com/help/doc/common-problems-dropbox)** 的文件。

请注意，即使在传递 Direct URL 时（即不存在限制时），Zapier 的 UI 也可能会提示文件大小限制警告。因此，了解 File URL 的工作原理很有必要。

## 常见应用和服务的上传方式 {#upload-methods-for-common-apps-and-services}

**注意：** 类型为 **File Upload** 的集成受 Zapier UI 中所示的文件大小限制约束。Direct Link 更为可取，因为它们不受大小限制，并且处理速度更快、更可靠。

| Google Drive | Direct Link | 您需要将 `webContentLink` 粘贴到 File 选择器中。这适用于您上传到 Google Drive 的文件，但不适用于在 Drive 中创建的文档或演示文稿。[Zapier 帮助文档](https://zapier.com/help/doc/common-problems-google-drive#unable-to-get-a-value-when-looking-for-quotfilequot-is-it-missing)，[Google Drive V3 API](https://developers.google.com/drive/api/v3/manage-downloads) |
