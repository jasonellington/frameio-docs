# 浏览资源数据 {#navigating-resource-data}

我们的 API payload 内容非常全面！这意味着（举例来说），当您捕获某个 Asset 的 Status Label 字段的变更时，可能会看到大量字段，而其中真正与您直接相关的却寥寥无几。

![Field examples](/images/platform/v2/overview-frame-io-resources-in-zapier/96b556247084aa9ced664a076acc8e22da0c44c5def47b9147b2c0c968964aec.webp)

好消息是，Zapier 的数据输入字段都具有搜索功能，借助它，您可以快速找到所需的字段。

![Quick-search for asset approved](/images/platform/v2/overview-frame-io-resources-in-zapier/38f94d317a462a7caf7fdc781713c0040001d99ef441cd25507b215ca373f70e.webp)

当然，如果您知道要找什么，也会很有帮助。

## 要查找的内容 {#what-to-look-for}

下表并不详尽，但应能帮助您快速开始使用 Frame.io 的 Zapier 集成构建工作流。

<Info>

**Asset URL 很长，这没关系**

您在 Frame.io API 响应中看到的 Asset URL 是指向 Amazon S3 的直接链接。在任何需要将 Asset 移入其他系统的 Zapier 应用环境中，都可以并且应该使用这些 URL。如果您可以在“File Attachment”和“File Attachment (URL)”之间进行选择，请选择后者，因为 Zapier 中的 URL 上传通常支持更广泛的文件类型和大小。

</Info>

| 资源类型 | Zapier 中的字段 | 描述 |
| --- | --- | --- |
| Asset（全部） | Original | 原始上传的视频，未经任何处理。在大多数情况下，这是您希望推送到其他系统的键；但它始终是原始文件类型，因此可能无法在所有其他环境中播放。 |
| Asset（视频） | H264 *resolution* | Frame.io 的所有 h.264 代理文件都可以在 Zapier 中的 Asset 上获取。 |
| Asset（图片） | Image *quality* | 与 h.264 视频代理文件类似，为图片生成的所有代理文件也都可以在 Zapier 中获取。 |
| Asset（全部） | Thumb | 在 Frame.io 中设置的 Asset 缩略图。该字段非常适合为 Trello 或 Airtable 等项目跟踪系统添加视觉效果。 |
| Asset（全部） | Label | Status Label。该字段通常与“Filter”操作搭配使用（类似于上面的截图）。 |
| Asset（全部） | Creator Email | 原始上传者的电子邮件地址。 |
| Asset（全部） | Project ID | Asset 所属父级 Project 的 ID。该字段在与“Find Project”操作搭配使用时最有用，您可以借助该操作获取 Project 的名称。 |
| Asset（全部） | Parent ID | Asset 父级的 ID，父级始终是文件夹、version stack 或 Project 根目录之一。 |
| Comment | Text | 评论的文本。 |
| Comment | Asset ID | Comment 所属父级 Asset 的 ID。可将其传递给 Find Asset 操作以获取更多上下文，或在外部跟踪工具中用于链接。 |
| Comment | Owner Name | 留下该 Comment 的用户的名字和姓氏。 |
| Comment | Owner Email | 留下该 Comment 的用户的电子邮件地址。 |
| Project | Name | Project 的名称。 |
