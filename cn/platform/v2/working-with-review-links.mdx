---
title: "使用 Review Link"
---

## 概述 {#overview}

Review Link 是 Frame.io 的一项核心功能，用于收集 Asset，并通过单个 URL 将其分发以征集反馈，而无需授予明确的 Team 或 Project 访问权限。从根本上说，Review Link 代表的是单个 Project 内的 Asset，因此本指南假定：

1. 您手头已有 Asset，或者熟悉[通过 API 上传 Asset](/cn/platform/v2/uploading-assets)。
2. 您知道要在其中创建 Review Link 的 Project 的 ID。
3. 您的目标是获得一个可以在 Frame.io 之外分发的 URL（例如通过电子邮件、聊天或其他方式）。

### 核心概念 {#core-concepts}

Review Link 严格隶属于 Project，而 Review Link 中的 Asset 则以一种名为 **Review Link Item** 的特殊资源类型表示。它始终包含其所关联的 `review_link_id` 和 `asset_id`，以及关联 Asset 的完整负载。

虽然无需单独跟踪或管理 Review Link Item，但了解这一结构有助于理解本指南所涵盖的完整工作流。因此，Review Link 的层级结构如下所示：

Project > Review Link > Review Link Item > Asset 引用

### 所需的 scope {#required-scopes}

在开始本指南之前，您需要确保所使用的令牌至少包含以下 scope：

| Scope | 原因 |
| --- | --- |
| **Projects:** Read | 并非严格必需，但获取 Project 的 `root_asset_id` 时需要。 |
| **Assets:** Read | 并非严格必需，但通过 API 导航到 `asset_ids` 时需要。 |
| **Review Links:** Create, Read, Update | 创建 Review Link、添加 Asset 以及获取信息（尤其是在其他系统中进行跟踪时）。 |

## 1. 收集 ID {#1-gather-your-ids}

要创建 Review Link，您需要收集：

1. 一个 Project ID
2. 该 Project 中一个或多个 Asset 的 ID

如果您手头没有 Project ID，但可以访问 Frame.io 并且知道要使用哪个 Project，可以在导航到该项目时从地址栏中看到 ID：`https://app.frame.io/projects/<project-id>`。

同样，如果您手头没有 Asset ID，可以导航到所需的 Asset，并从浏览器地址栏中获取 ID：`https://app.frame.io/player/<asset-id>`。

## 2. 创建 Review Link {#2-create-the-review-link}

要创建链接的基础，您需要确定所需的 Review Link 选项，并将其构建为 JSON 负载。至少需要提供一个 `name`。

以下是一个示例负载——为方便起见，它展示了仅提供 `name` 时各字段的默认值：

```json
{    
    "name": "New Review Link",
    "allow_approvals": true,
    "current_version_only": false,
    "enable_downloading": true,
    "expires_at": null,
    "has_password": false
}
```

现在，使用该负载作为请求体，发起一个经过授权的 `POST` `https://api.frame.io/v2/projects/:id/review_links` 请求。

恭喜！您刚刚创建了一个 Review Link。在响应体中，您会看到两个重要的属性：

- **`id`**：这是对您的链接容器的引用。请妥善保存，因为在下一步添加 Asset 时需要用到它。
- **`short_url`**：这是您最终要分发的 Review Link URL，看起来类似于 `https://f.io/_aBcDeF`

## 3. 将 Asset 添加到 Review Link {#3-add-the-assets-to-the-review-link}

有了 Review Link 之后，就可以向其中添加一些 Asset 了。首先准备一个 JSON 负载，其中包含由您的 Asset `id` 组成的字符串数组：

```json
{
    "asset_ids":[
        "<asset-id-1>",
        "<asset-id-2>",
        "<asset-id-3>"
    ]
}
```

现在，向 `https://api.frame.io/v2/review_links/:id/assets` 发起一个经过授权的 `POST` 请求，在路径中使用第 2 步获得的 Review Link `id`，并在请求体中包含您的 Asset `id`。

全部完成！现在您可以分发您的 `short_url` 了。
