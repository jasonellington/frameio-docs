# 概述 {#overview}

Frame.io 中的标注以序列化的绘图对象 JSON blob 形式表示，其中包含颜色、坐标和尺寸。在该 blob 中，除最外层的一对引号外，所有引号都会用斜杠进行转义（例如 `\"key\":\"value\"`）。

共有三种基本形状——**arrow**、**rect** 和 **line**——以及手绘图形。手绘图形不在本指南的讨论范围内，但它遵循相同的序列化坐标数据基本原理。

## 坐标系 {#the-coordinate-system}

所有形状都放置在一个原点位于左上角、每个坐标轴取值范围为 0 到 1 的笛卡尔坐标系上。

![coordinate_plane.png](/images/platform/v2/working-with-annotations/099478340a4f8604fd4389c5d431ec9e9321f509f2d6055b0c92dd62e4e36147.webp)

## 基本形状数据 {#basic-shape-data}

所有形状都通过坐标与样式数据的组合放置在上述平面上。每种形状都有一些通用属性，此外每种形状定位坐标系的方式也略有不同。

所有表示距离/宽度/高度的属性都使用与主坐标网格本身相同的 0 到 1 比例，但通常是从形状的原点开始计算。

换句话说，如果视频显示在 640x480 的视口中，那么在该上下文中 `x=1` 就等于绝对值 640px。这使得标注能够在观看屏幕、尺寸和上下文发生变化时无缝缩放，同时保持其相对位置。

**注意**：无论绘制起点在哪里，*rect* 的原点始终是该形状的左上角。

### 通用属性 {#common-attributes}

| 属性 | 描述 |
| --- | --- |
| `tool` | *arrow*、*rect* 或 *line*。指明要创建的形状。 |
| `color` | 形状的六位十六进制颜色值。 |
| `size` | 形状线条的像素尺寸。对于箭头，此值仅指线条起点处的宽度，因为终点宽度由程序自动确定。 |

### Arrow {#arrow}

| 属性 | 描述 |
| :--- | :--- |
| `x` | 箭头原点的 x 坐标。 |
| `y` | 箭头原点的 y 坐标。 |
| `w` | 箭头从起点到终点在 y 轴上的位置差，相对于箭头原点。 |
| `h` | 箭头从起点到终点在 x 轴上的位置差，相对于箭头原点。 |

### Rect {#rect}

| 属性 | 描述 |
| :--- | :--- |
| `x` | 矩形左上角的 x 坐标。 |
| `y` | 矩形左上角的 y 坐标。 |
| `w` | 矩形的宽度，相对于矩形左上角原点。 |
| `h` | 矩形的高度，相对于矩形左上角原点。 |
| `ix` | 矩形的绘制起点 x 坐标。（非必需）。 |
| `iy` | 矩形的绘制起点 y 坐标。（非必需）。 |
| `radius` | 矩形圆角的半径。必须为正数。大于 150 的值在视觉上没有区别。 |

### Line {#line}

| 属性 | 描述 |
| :--- | :--- |
| `x1` | 线条原点的 x 坐标。 |
| `y1` | 线条原点的 y 坐标。 |
| `x2` | 线条终点的 x 坐标。为图像平面上的绝对值。 |
| `y2` | 线条终点的 y 坐标。为图像平面上的绝对值。 |
