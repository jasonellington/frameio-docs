# Frame.io 登录的跨浏览器支持 {#cross-browser-support-for-frame-io-login}

虽然这与完全由 API 驱动的应用程序无关，但在 OAuth 凭据授权流程中加载我们的 [Accounts 应用](https://accounts.frame.io/)时，Frame.io 的跨浏览器支持就会发挥作用。

为 Frame.io 编写 OAuth 应用程序时，请注意我们在 OAuth 流程中显示的登录页面与我们的主 Web 应用程序遵循相同的浏览器支持范围。在下表中，"部分"支持表示所有主要功能应可正常使用，但可能存在一些轻微的布局问题。"最低"支持表示可能可以使用，但我们不再明确测试或支持。

| 浏览器 | 支持程度 |
| --- | --- |
| Chrome（最新版） | 完全 |
| Safari（最新版） | 完全 |
| Firefox（最新版） | 完全 |
| Opera（最新版） | 完全 |
| Edge（最新版） | 完全 |
| IE (11+) | 最低 |
| IE (&lt;=10) | 不支持 |
| Mobile Safari（最新版） | 部分 |
| Chrome for iOS（最新版） | 部分 |
| Chrome for Android（最新版） | 部分 |
| Android 浏览器（最新版） | 部分 |
