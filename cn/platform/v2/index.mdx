## 关于 Frame.io {#about-frame-io}

[Frame.io](https://frame.io) 是面向专业视频团队的云端协作工具——让创意流程持续推进所需的一切都集中在一个工作台中，随时随地均可访问。借助 Frame.io，您可以安全地上传、分享和审阅影视项目，让整个团队以创意的速度运转。

### Frame.io 开发者平台 {#frame-io-developer-platform}

并非每个创意团队、流程或软件栈都完全相同。这正是我们的开发者平台的用武之地。Frame.io 开发者平台让您可以使用我们的 API 处理常见任务。开发者使用我们 API 的一些热门场景包括：自动将现有文件或文件夹添加到 Frame.io 应用、上传新内容以及管理团队。

## Camera to Cloud (C2C) 计划 {#camera-to-cloud-c2c-program}

Camera to Cloud 是一种独特的集成类型。这类集成专为任何生成数据的设备或应用而打造。如果您正在构建 C2C 集成，请参阅 [C2C 集成指南](/cn/camera-to-cloud/getting-started-with-cloud-device-integrations)。在那里，您可以找到开始通过 Frame.io 连接云端所需的全部信息！

## 快速入门指南 {#quick-start-guide}

如果您想立即开始，只需点击此按钮，即可将我们的 API 导入 Postman！

[![Run in Postman](/images/platform/v2/index/button.svg)](https://www.getpostman.com/collections/c2dfffb88990a9dc34c2)

否则，请继续阅读。首先，您需要确保拥有一个可以登录的 Frame.io 账户。

接下来：

- 使用您的 Frame.io 凭据[登录开发者门户](/cn/platform/v2)
- [创建 Developer Token](/cn/platform/v2/authentication#developer-tokens)

要确认您的 token 是否有效，请使用您选择的语言、工具或代理发起一次测试调用：

<CodeGroup>

```bash title="cURL"
curl --request GET \
  --url https://api.frame.io/v2/me \
  --header 'authorization: Bearer <DEV_TOKEN>'
```

```python title="Python"
import requests

url = "https://api.frame.io/v2/me"
headers = {
 "Authorization": "Bearer <DEV_TOKEN>"
}

requests.GET(url,headers=headers)
```

</CodeGroup>

在响应中，您应该会看到您的用户信息。

## 基于事件的工作流 {#event-based-workflows}

Frame.io 开发者平台提供了多种选项，您可以借此将工作流扩展到其他工具中，或创建全新的功能。

### Webhooks {#webhooks}

Webhooks 提供了一种方式，可将 Frame.io 内发生的事件转化为通知，发送到外部系统进行处理、API 回调和工作流自动化。

使用我们的 webhooks 有多种方式。您可以自行构建，也可以利用无代码自动化工具，例如 [Zapier](https://zapier.com)、[Integromat](https://www.integromat.com)、[Pabbly Connect](https://www.pabbly.com/) 或 [Pipedream](https://pipedream.com)。

- [Webhooks](/cn/platform/v2/webhooks-overview) - Webhooks 将 Frame.io 事件暴露给外部 URL，以供使用和处理。
- [Zapier](/cn/platform/v2/get-started-with-zapier)  - 一款在线自动化工具，无需编写代码即可连接 1,000 多个常用应用和工具。

我们在 Github 上提供了一个 [Webhooks 示例应用](https://github.com/Frameio/webhooks-example-app)，如果您想构建自己的接收器，可以以此为起点。

### Custom Actions {#custom-actions}

[Custom Actions](/cn/platform/v2/custom-actions-overview) 让您可以将集成作为可编程 UI 组件直接构建到 Frame.io 中。它们在技术上与 Webhooks 非常相似，是扩展 Frame.io 工作流的绝佳方式。
