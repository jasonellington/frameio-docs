Frame.io API 可能会返回以下常见错误：

| 代码 | 详情 | 原因 |
| --- | --- | --- |
| `401` | **Unauthorized（未授权）**——API 令牌无效。请确认您使用的是 Bearer Token 身份验证，并通过 Authorization 标头传递令牌。 |  |
| `402` | **Usage exceeded（超出用量）**——您已超出 Frame.io 套餐限制。 |  |
| `403` | **Forbidden（禁止访问）**——您无权访问该资源。用户访问权限和令牌 scope 不足时均会返回此错误。 |  |
| `404` | **Not Found（未找到）**——未找到资源。 | 资源已被移动或删除。 |
| `422` | **Invalid arguments（参数无效）**——提供的一个或多个参数无效。 |  |
| `429` | **Rate Limited（速率受限）**——您已达到 API 的速率限制。 |  |
| `500` | **Server Error（服务器错误）**——我们的服务器无法解析您的请求，或无法在可用时间范围（30 秒）内完成您的请求。 | 请求 URL 或请求体格式错误，或由于其他原因无法完成。 |

# 常见错误排查 {#troubleshooting-common-errors}

使用有效的 API 令牌执行常见任务时，最常见的错误是 `403`、`404` 和 `500`。

**403** 错误通常表示以下三种情况之一：

1. 请求中使用的令牌和/或该令牌所属的用户，对 Frame.io 账户中所请求资源所在的区域没有足够的访问权限。
2. 令牌不具备所请求资源所需的 Scopes。例如：在没有 `comments.read` scope 的情况下调用 `GET /comments/`。
3. 网络流量问题导致 Frame.io API 无法处理该请求。*如果您怀疑请求因网络流量问题而被阻止，请联系客户支持。*

**404** 错误通常表示资源已不存在——它已被移动或删除。

**500** 错误通常表示请求 URL 或请求体格式错误，但也可能是因为我们无法在可用时间范围（30 秒）内完成请求。

# 速率限制 {#rate-limiting}

Frame.io API 按令牌实施速率限制。每个令牌的默认限制为每秒 50 次调用。某些方法的限制更低（例如 POST `/assets/:id/children` 的速率限制为每秒 5 个资源）。

所有限制都可能发生变化，达到限制时将返回 429 HTTP 错误。我们建议使用指数退避方法来处理速率限制。

请查看我们关于速率限制的[指南](/cn/platform/v2/rate-limits)以了解更多信息。
