---
title: "使用 Glitch"
---

Glitch 是一款可以让您快速轻松地创建 Web 应用的工具。您可以使用 Glitch 运行这些应用进行测试，而无需费力搭建具有公共网址的自有服务器。

本指南提供了一些使用 Glitch 的基本提示和技巧。

## 如何注册 Glitch？ {#how-do-i-sign-up-for-glitch}
点击 **Sign In** 并选择提供的其中一种方式。Glitch 支持通过 Facebook、GitHub、Google 和电子邮件登录。您可以从这里开始：[https://glitch.com](https://glitch.com)。

## 如何在 Glitch 上处理项目？ {#how-do-i-work-with-a-project-on-glitch}
要在 Glitch 上处理项目，请执行以下操作：

1. 前往该项目的项目页面，其结构为 `https://glitch.com/~word-otherword`

2. 点击 **View Source**

3. 在屏幕右上方，点击 **Remix to Edit**。然后您就可以随意修改该项目了。

如果您想处理一个新项目，也可以登录后点击右上角的 **New Project**。

## 如何在 Glitch 上查看日志或控制台？ {#how-do-i-see-logs-or-the-console-on-glitch}
您可以点击页面底部的 **Tools**，从终端查看您的项目。您可以选择查看审计日志（Logs）和全页控制台（Full Page Console）。

## 我可以使用哪些语言？ {#what-languages-can-i-use}
Glitch 官方仅支持 javascript。但您可以非官方地使用许多其他语言。Glitch 可以配合以下语言使用：
* C/C++
* Haskell
* OCaml
* Perl
* Erlang
* Elixir
* Lua 5.2
* PHP 
* Ruby
* Java
* Python
* Go 
* Rust
* Racket 

## Glitch 与 Python {#glitch-and-python}
您可以在 Glitch 上的 Python 项目中添加一个 **requirements.txt** 文件，在其中列出要导入的模块，从而为项目添加依赖项。

有时您想导入的模块可能无法导入。您可以使用 Glitch 的控制台添加它，但请务必使用 `--user` 标记将其安装到您的用户区域。

`pip install --user module_name`
