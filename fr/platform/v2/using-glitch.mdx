---
title: "Utiliser Glitch"
---

Glitch est un outil qui vous permet de créer rapidement et facilement des applications web. Vous pouvez les exécuter avec Glitch pour les tester sans avoir à configurer votre propre serveur avec une adresse web publique. 

Ce guide fournit quelques conseils et astuces de base pour travailler avec Glitch. 

## Comment m’inscrire sur Glitch ? {#how-do-i-sign-up-for-glitch}
Cliquez sur **Sign In** et choisissez l’une des méthodes proposées. Glitch prend en charge la connexion via Facebook, GitHub, Google et e-mail. Vous pouvez commencer ici : [https://glitch.com](https://glitch.com).

## Comment travailler sur un projet dans Glitch ? {#how-do-i-work-with-a-project-on-glitch}
Pour travailler sur un projet dans Glitch, procédez comme suit :

1. Accédez à la page du projet, dont l’adresse a la structure `https://glitch.com/~word-otherword`

2. Cliquez sur **View Source**

3. En haut à droite de l’écran, cliquez sur **Remix to Edit**. Vous pourrez alors modifier le projet comme vous le souhaitez. 

Si vous souhaitez travailler sur un nouveau projet, vous pouvez également vous connecter puis cliquer sur **New Project** en haut à droite. 

## Comment consulter les logs ou la console dans Glitch ? {#how-do-i-see-logs-or-the-console-on-glitch}
Vous pouvez suivre votre projet depuis un terminal en cliquant sur **Tools** en bas de la page. Vous pourrez choisir d’afficher un journal d’audit (Logs) et une console pleine page (Full Page Console). 

## Quels langages puis-je utiliser ? {#what-languages-can-i-use}
Officiellement, Glitch ne prend en charge que JavaScript. Mais vous pouvez utiliser officieusement de nombreux autres langages. Glitch peut fonctionner avec : 
* C/C++
* Haskell
* OCaml
* Perl
* Erlang
* Elixir
* Lua 5.2
* PHP 
* Ruby
* Java
* Python
* Go 
* Rust
* Racket 

## Glitch et Python {#glitch-and-python}
Vous pouvez ajouter des dépendances à votre projet Python sur Glitch en incluant un fichier **requirements.txt** contenant les modules que vous souhaitez importer. 

Il arrive qu’un module que vous souhaitez importer ne s’importe pas. Vous pouvez l’ajouter à l’aide de la console de Glitch, mais veillez à l’installer dans votre espace utilisateur avec l’option `--user`. 

`pip install --user module_name`
