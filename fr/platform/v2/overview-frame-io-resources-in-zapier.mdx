# Parcourir les données des ressources {#navigating-resource-data}

Nos payloads d'API sont très complets ! Cela signifie, par exemple, que lorsque vous interceptez une modification du champ Status Label d'un Asset, vous risquez de vous retrouver face à un grand nombre de champs, dont très peu vous seront immédiatement utiles.

![Exemples de champs](/images/platform/v2/overview-frame-io-resources-in-zapier/96b556247084aa9ced664a076acc8e22da0c44c5def47b9147b2c0c968964aec.webp)

La bonne nouvelle, c'est que tous les champs de saisie de données de Zapier disposent d'une fonction de recherche, qui vous permet d'accéder rapidement au champ dont vous avez besoin.

![Recherche rapide de l'asset approuvé](/images/platform/v2/overview-frame-io-resources-in-zapier/38f94d317a462a7caf7fdc781713c0040001d99ef441cd25507b215ca373f70e.webp)

Bien sûr, il est également utile de savoir ce que l'on cherche.

## Ce qu'il faut rechercher {#what-to-look-for}

Le tableau suivant n'est pas exhaustif, mais il devrait vous donner une longueur d'avance pour créer des workflows avec l'intégration Zapier de Frame.io.

<Info>

**Les URL des Assets sont longues, et c'est normal**

Les URL des Assets que vous voyez dans les réponses de l'API de Frame.io sont des liens directs vers Amazon S3. Ces URL peuvent et doivent être utilisées dans n'importe quel contexte d'application Zapier où vous souhaitez transférer un Asset vers un autre système. Si vous avez le choix entre « File Attachment » et « File Attachment (URL) », choisissez la seconde option, car les téléversements par URL dans Zapier prennent généralement en charge un plus large éventail de types et de tailles de fichiers.

</Info>

| Type de ressource | Champ dans Zapier | Description |
| --- | --- | --- |
| Asset (tous) | Original | La vidéo originale téléversée, intacte. Dans la plupart des cas, c'est la clé que vous voudrez transmettre à d'autres systèmes ; mais il s'agira toujours du type de fichier d'origine, qui pourrait donc ne pas être lisible dans tous les autres contextes. |
| Asset (vidéos) | H264 *résolution* | Tous les proxys h.264 de Frame.io sont disponibles sur l'Asset dans Zapier. |
| Asset (image) | Image *qualité* | Comme pour les proxys vidéo h.264, tous les proxys générés pour les images sont également disponibles dans Zapier. |
| Asset (tous) | Thumb | La miniature de l'Asset telle que définie dans Frame.io. Ce champ est idéal pour ajouter des visuels à des outils de suivi de projet comme Trello ou Airtable. |
| Asset (tous) | Label | Le Status Label. Ce champ sera généralement associé à une action « Filter » (comme dans la capture d'écran ci-dessus). |
| Asset (tous) | Creator Email | L'adresse e-mail de la personne ayant téléversé le fichier à l'origine. |
| Asset (tous) | Project ID | L'ID du Project parent de l'Asset. Ce champ est surtout utile associé à l'action « Find Project », qui permet de récupérer le nom du Project. |
| Asset (tous) | Parent ID | L'ID du parent d'un Asset, qui sera toujours un dossier, une pile de versions ou la racine d'un Project. |
| Comment | Text | Le texte du commentaire. |
| Comment | Asset ID | L'ID de l'Asset parent du Comment. Utile à transmettre à l'action Find Asset pour obtenir plus de contexte, ou pour créer des liens dans des outils de suivi externes. |
| Comment | Owner Name | Le prénom et le nom de l'utilisateur ayant laissé le Comment. |
| Comment | Owner Email | L'adresse e-mail de l'utilisateur ayant laissé le Comment. |
| Project | Name | Le nom du Project. |
