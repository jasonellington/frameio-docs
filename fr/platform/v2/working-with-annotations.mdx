# Vue d’ensemble {#overview}

Dans Frame.io, les annotations sont représentées sous la forme d’un blob JSON sérialisé d’objets de dessin, avec leurs couleurs, coordonnées et tailles. Dans ce blob, tous les guillemets, à l’exception de la paire extérieure, sont échappés avec des barres obliques (par ex. `\"key\":\"value\"`).

Il existe trois formes de base — **arrow**, **rect** et **line** — ainsi que le dessin à main levée, qui sort du cadre de ce guide mais suit les mêmes principes de base de données de coordonnées sérialisées.

## Le système de coordonnées {#the-coordinate-system}

Toutes les formes sont placées dans un repère cartésien dont l’origine se trouve en haut à gauche, avec une échelle de 0 à 1 sur chaque axe.

![coordinate_plane.png](/images/platform/v2/working-with-annotations/099478340a4f8604fd4389c5d431ec9e9321f509f2d6055b0c92dd62e4e36147.webp)

## Données de base des formes {#basic-shape-data}

Toutes les formes sont placées sur le plan ci-dessus à l’aide d’une combinaison de coordonnées et de données de style. Chaque forme possède des attributs communs, puis chacune utilise le système de coordonnées d’une manière légèrement différente.

Tous les attributs de distance/largeur/hauteur utilisent la même échelle de 0 à 1 que la grille de coordonnées principale, mais sont généralement mesurés à partir du point d’origine de la forme.

Autrement dit, si une vidéo est affichée dans une zone d’affichage de 640x480, `x=1` équivaudra à 640 px en valeur absolue dans ce contexte. Cela permet aux annotations de s’adapter sans accroc tout en conservant leur position relative lorsque l’écran, la taille et le contexte d’affichage changent.

**Remarque** : l’origine d’un *rect* est toujours le coin supérieur gauche de la forme, quelle que soit l’origine du dessin.

### Attributs communs {#common-attributes}

| Attribut | Description |
| --- | --- |
| `tool` | *arrow*, *rect* ou *line*. Indique la forme créée. |
| `color` | Couleur hexadécimale à six chiffres de la forme. |
| `size` | Taille en pixels du trait de la forme. Pour les flèches, cela ne concerne que le début du trait, la largeur de fin étant déterminée par programmation. |

### Arrow {#arrow}

| Attribut | Description |
| :--- | :--- |
| `x` | Coordonnée x de l’origine de la flèche. |
| `y` | Coordonnée y de l’origine de la flèche. |
| `w` | Différence de position de la flèche sur l’axe y entre le début et la fin, par rapport à l’origine de la flèche. |
| `h` | Différence de position de la flèche sur l’axe x entre le début et la fin, par rapport à l’origine de la flèche. |

### Rect {#rect}

| Attribut | Description |
| :--- | :--- |
| `x` | Coordonnée x du coin supérieur gauche du rectangle. |
| `y` | Coordonnée y du coin supérieur gauche du rectangle. |
| `w` | Largeur du rectangle, par rapport à l’origine supérieure gauche du rectangle. |
| `h` | Hauteur du rectangle, par rapport à l’origine supérieure gauche du rectangle. |
| `ix` | Origine x du dessin du rectangle. (Facultatif). |
| `iy` | Origine y du dessin du rectangle. (Facultatif). |
| `radius` | Rayon d’arrondi des coins du rectangle. Doit être positif. Les valeurs supérieures à 150 sont visuellement indiscernables. |

### Line {#line}

| Attribut | Description |
| :--- | :--- |
| `x1` | Coordonnée x de l’origine de la ligne. |
| `y1` | Coordonnée y de l’origine de la ligne. |
| `x2` | Coordonnée x de l’extrémité de la ligne. Valeur absolue sur le plan de l’image. |
| `y2` | Coordonnée y de l’extrémité de la ligne. Valeur absolue sur le plan de l’image. |
