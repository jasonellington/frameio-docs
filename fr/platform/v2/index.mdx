## À propos de Frame.io {#about-frame-io}

[Frame.io](https://frame.io) est l’outil de collaboration cloud destiné aux équipes vidéo professionnelles : tout ce dont vous avez besoin pour faire avancer le processus créatif, réuni dans un seul espace de travail, accessible de partout. Avec Frame.io, vous pouvez envoyer, partager et réviser vos projets de film en toute sécurité, pour que l’ensemble de votre activité avance au rythme de la créativité.

### Plateforme de développement Frame.io {#frame-io-developer-platform}

Chaque équipe créative, chaque processus et chaque ensemble de logiciels est différent. C’est là qu’intervient notre plateforme de développement. La plateforme de développement Frame.io vous permet d’effectuer des tâches courantes à l’aide de notre API. Parmi les cas d’usage populaires de notre API figurent l’ajout automatique de fichiers ou de dossiers existants à l’application Frame.io, l’envoi de nouveaux contenus et la gestion des équipes.

## Programme Camera to Cloud (C2C) {#camera-to-cloud-c2c-program}

Camera to Cloud est un type d’intégration unique. Ces intégrations sont conçues spécifiquement pour tout appareil ou application qui génère des données. Si vous développez une intégration C2C, vous devrez utiliser les [guides d’intégration C2C](/fr/camera-to-cloud/getting-started-with-cloud-device-integrations). Vous y trouverez toutes les informations nécessaires pour commencer à vous connecter au cloud avec Frame.io !

## Guide de démarrage rapide {#quick-start-guide}

Si vous voulez commencer tout de suite, cliquez simplement sur ce bouton pour importer notre API dans Postman !

[![Run in Postman](/images/platform/v2/index/button.svg)](https://www.getpostman.com/collections/c2dfffb88990a9dc34c2)

Sinon, poursuivez votre lecture. Pour commencer, vous devez disposer d’un compte Frame.io avec lequel vous pouvez vous connecter.

Ensuite :

- [Connectez-vous au portail développeur](/fr/platform/v2) avec vos identifiants Frame.io
- [Créez un jeton développeur](/fr/platform/v2/authentication#developer-tokens)

Pour vérifier que votre jeton fonctionne, effectuez un appel de test avec le langage, l’outil ou le proxy de votre choix :

<CodeGroup>

```bash title="cURL"
curl --request GET \
  --url https://api.frame.io/v2/me \
  --header 'authorization: Bearer <DEV_TOKEN>'
```

```python title="Python"
import requests

url = "https://api.frame.io/v2/me"
headers = {
 "Authorization": "Bearer <DEV_TOKEN>"
}

requests.GET(url,headers=headers)
```

</CodeGroup>

En réponse, vous devriez voir vos informations d’utilisateur.

## Workflows basés sur les événements {#event-based-workflows}

La plateforme de développement Frame.io propose plusieurs options pour étendre vos workflows à d’autres outils ou pour créer de toutes nouvelles fonctionnalités.

### Webhooks {#webhooks}

Les webhooks permettent de transformer les événements qui se produisent dans Frame.io en notifications envoyées à des systèmes externes pour traitement, rappel d’API et automatisation de workflows.

Il existe plusieurs façons d’utiliser nos webhooks. Vous pouvez développer votre propre solution ou tirer parti d’un outil d’automatisation sans code comme [Zapier](https://zapier.com), [Integromat](https://www.integromat.com), [Pabbly Connect](https://www.pabbly.com/) ou [Pipedream](https://pipedream.com).

- [Webhooks](/fr/platform/v2/webhooks-overview) - Les webhooks exposent les événements Frame.io à des URL externes pour leur consommation et leur traitement.
- [Zapier](/fr/platform/v2/get-started-with-zapier)  - Un outil d’automatisation en ligne qui permet de connecter plus de 1 000 applications et outils courants sans écrire de code.

Nous proposons une [application d’exemple pour les webhooks](https://github.com/Frameio/webhooks-example-app) sur Github, que vous pouvez utiliser comme point de départ si vous souhaitez créer votre propre récepteur.

### Actions personnalisées {#custom-actions}

Les [actions personnalisées](/fr/platform/v2/custom-actions-overview) vous permettent de créer des intégrations directement dans Frame.io sous forme de composants d’interface programmables. Sur le plan technique, elles sont très proches des webhooks et constituent un excellent moyen d’étendre vos workflows Frame.io.
