# Prise en charge multinavigateur pour la connexion à Frame.io {#cross-browser-support-for-frame-io-login}

Bien que cela ne concerne pas les applications entièrement pilotées par l’API, la prise en charge multinavigateur de Frame.io entre en jeu lors du chargement de notre [application Accounts](https://accounts.frame.io/) au cours d’un flux d’octroi d’identifiants OAuth.

Lorsque vous développez des applications OAuth pour Frame.io, sachez que la page de connexion présentée dans le flux OAuth bénéficie de la même prise en charge des navigateurs que notre application web principale. Dans le tableau ci-dessous, une prise en charge « Partielle » signifie que toutes les fonctionnalités majeures devraient fonctionner sans entrave, mais que quelques problèmes mineurs de mise en page peuvent survenir. Une prise en charge « Minimale » signifie que cela peut fonctionner, mais que nous ne le testons ni ne le prenons plus explicitement en charge.

| Navigateur | Prise en charge |
| --- | --- |
| Chrome (dernière version) | Complète |
| Safari (dernière version) | Complète |
| Firefox (dernière version) | Complète |
| Opera (dernière version) | Complète |
| Edge (dernière version) | Complète |
| IE (11+) | Minimale |
| IE (&lt;=10) | Aucune |
| Safari Mobile (dernière version) | Partielle |
| Chrome pour iOS (dernière version) | Partielle |
| Chrome pour Android (dernière version) | Partielle |
| Navigateur Android (dernière version) | Partielle |
