## Vue d'ensemble {#overview}
Frame.io maintient une [application Zapier](https://github.com/Frameio/zapier-app) qui étend les fonctionnalités principales de notre API à l'interface « cliquer et créer » de Zapier.  Vous pouvez utiliser Zapier pour exploiter Frame.io dans des workflows où vous devez travailler ou collaborer dans d'autres applications.  Parmi les fonctionnalités Frame.io couramment utilisées dans les Zaps (c'est-à-dire les tâches automatisées) figurent les commentaires, le téléversement et le téléchargement d'éléments, ainsi que la création d'équipes ou de projets.  Les applications les plus populaires connectées à Frame.io sont visibles sur notre page d'accueil sur le [site web de Zapier](https://zapier.com/apps/frameio/integrations).

Notre application Zapier facilite la connexion à des applications de workflow, bien plus que si vous écriviez votre propre code d'intégration personnalisé.

## Configuration {#setup}
1. Créez un [compte Zapier gratuit](https://zapier.com/apps/frameio/integrations)
2. Connectez-vous à Zapier, créez un Zap et ajoutez-y l'application Frame.io. Vous serez alors invité à connecter Zapier à votre compte Frame.io.
