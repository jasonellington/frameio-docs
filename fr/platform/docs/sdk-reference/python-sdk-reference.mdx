### Utilisation {#usage}

Instanciez et utilisez le client comme suit :

```python
from frameio import (
    Frameio,
    SelectDefinitionParamsFieldConfiguration,
    SelectDefinitionParamsFieldConfigurationOptionsItem,
)
from frameio.metadata_fields import CreateFieldDefinitionParamsData_Select

client = Frameio(
    token="YOUR_TOKEN",
)
client.metadata_fields.metadata_field_definitions_create(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    data=CreateFieldDefinitionParamsData_Select(
        field_configuration=SelectDefinitionParamsFieldConfiguration(
            enable_add_new=False,
            options=[
                SelectDefinitionParamsFieldConfigurationOptionsItem(
                    display_name="Option 1",
                ),
                SelectDefinitionParamsFieldConfigurationOptionsItem(
                    display_name="Option 2",
                ),
            ],
        ),
        name="Fields definition name",
    ),
)
```

### Client asynchrone {#async-client}

Le SDK exporte également un client asynchrone qui vous permet d'effectuer des appels non bloquants vers notre API. Notez que si vous construisez une classe de client httpx asynchrone à transmettre à ce client, utilisez httpx.AsyncClient() au lieu de httpx.Client() (par exemple pour le paramètre httpx_client de ce client).

```python
import asyncio

from frameio import (
    AsyncFrameio,
    SelectDefinitionParamsFieldConfiguration,
    SelectDefinitionParamsFieldConfigurationOptionsItem,
)
from frameio.metadata_fields import CreateFieldDefinitionParamsData_Select

client = AsyncFrameio(
    token="YOUR_TOKEN",
)


async def main() -> None:
    await client.metadata_fields.metadata_field_definitions_create(
        account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
        data=CreateFieldDefinitionParamsData_Select(
            field_configuration=SelectDefinitionParamsFieldConfiguration(
                enable_add_new=False,
                options=[
                    SelectDefinitionParamsFieldConfigurationOptionsItem(
                        display_name="Option 1",
                    ),
                    SelectDefinitionParamsFieldConfigurationOptionsItem(
                        display_name="Option 2",
                    ),
                ],
            ),
            name="Fields definition name",
        ),
    )


asyncio.run(main())
```

### Gestion des exceptions {#exception-handling}

Lorsque l'API renvoie un code de statut d'échec (réponse 4xx ou 5xx), une sous-classe de l'erreur suivante est levée.

```python
from frameio.core.api_error import ApiError

try:
    client.metadata_fields.metadata_field_definitions_create(...)
except ApiError as e:
    print(e.status_code)
    print(e.body)
```

### Pagination {#pagination}

Les requêtes paginées renvoient un SyncPager ou un AsyncPager, qui peuvent être utilisés comme générateurs pour l'objet sous-jacent.

```python
from frameio import Frameio

client = Frameio(
    token="YOUR_TOKEN",
)
response = client.project_permissions.index(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    project_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    page_size=10,
    include_total_count=False,
)
for item in response:
    yield item
# alternatively, you can paginate page-by-page
for page in response.iter_pages():
    yield page
```

### Avancé {#advanced}

#### Accéder aux données brutes de la réponse {#access-raw-response-data}

Le SDK donne accès aux données brutes de la réponse, y compris les en-têtes, via la propriété .with_raw_response. La propriété .with_raw_response renvoie un client « brut » qui permet d'accéder aux attributs .headers et .data.

```python
from frameio import Frameio

client = Frameio(
    ...,
)
response = (
    client.metadata_fields.with_raw_response.metadata_field_definitions_create(
        ...
    )
)
print(response.headers)  # access the response headers
print(response.data)  # access the underlying object
pager = client.project_permissions.index(...)
print(pager.response.headers)  # access the response headers for the first page
for item in pager:
    print(item)  # access the underlying object(s)
for page in pager.iter_pages():
    print(page.response.headers)  # access the response headers for each page
    for item in page:
        print(item)  # access the underlying object(s)
```

#### Nouvelles tentatives {#retries}

Le SDK intègre des nouvelles tentatives automatiques avec un délai d'attente exponentiel (exponential backoff). Une requête est relancée tant qu'elle est jugée réessayable et que le nombre de tentatives n'a pas dépassé la limite configurée (par défaut : 2).<br />
Une requête est jugée réessayable lorsque l'un des codes de statut HTTP suivants est renvoyé :

- 408 (Délai d'expiration dépassé)
- 429 (Trop de requêtes)
- 5XX (Erreurs internes du serveur)

<br />

Utilisez l'option de requête `max_retries` pour configurer ce comportement.

```python
client.metadata_fields.metadata_field_definitions_create(..., request_options={
    "max_retries": 1
})
```

---

#### Délais d'expiration {#timeouts}

Le SDK utilise par défaut un délai d'expiration de 60 secondes. Vous pouvez le configurer avec l'option timeout au niveau du client ou de la requête.

```python
from frameio import Frameio

client = Frameio(
    ...,
    timeout=20.0,
)


# Override timeout for a specific method
client.metadata_fields.metadata_field_definitions_create(..., request_options={
    "timeout_in_seconds": 1
})
```

---

#### Client personnalisé {#custom-client}

Vous pouvez remplacer le client httpx pour l'adapter à votre cas d'usage. Parmi les cas d'usage courants figurent la prise en charge des proxys et des transports.

```python
import httpx
from frameio import Frameio

client = Frameio(
    ...,
    httpx_client=httpx.Client(
        proxy="http://my.test.proxy.example.com",
        transport=httpx.HTTPTransport(local_address="0.0.0.0"),
    ),
)
```

#### Authentification {#auth}

<AccordionGroup>

<Accordion title="frameio.auth.ServerToServerAuth(*, client_id, client_secret, ...)" defaultOpen={true}>

Authentifiez-vous à l'aide de l'octroi OAuth 2.0 client_credentials. Ce flux n'implique aucun utilisateur et ne renvoie pas de jeton d'actualisation. Lorsque le jeton d'accès expire, le SDK en demande automatiquement un nouveau à l'aide des identifiants client. Pour une utilisation asynchrone, utilisez `AsyncServerToServerAuth`.

```python title="usage"

from frameio import Frameio
from frameio.auth import ServerToServerAuth

auth = ServerToServerAuth(client_id="YOUR_CLIENT_ID", client_secret="YOUR_CLIENT_SECRET")
client = Frameio(token=auth.get_token)
```

**Paramètres**

`client_id`: `str` — ID client OAuth Adobe IMS.

`client_secret`: `str` — Secret client OAuth Adobe IMS.

`scopes`: `str` — Portées séparées par des espaces (OAuth 2.0 RFC 6749). Valeur par défaut : `openid AdobeID frame.s2s.all`.

`ims_base_url`: `str` — URL de base IMS pour les environnements de préproduction ou alternatifs. Valeur par défaut : production.

`http_client`: `typing.Optional[httpx.Client]` — httpx.Client facultatif pour la gestion des proxys, du TLS ou du pool de connexions.

`on_token_refreshed`: `typing.Optional[typing.Callable[[dict[str, Any]], None]]` — Callback facultatif déclenché après chaque obtention de jeton.

`timeout`: `float` — Délai d'expiration des requêtes HTTP, en secondes. Valeur par défaut : 30.

`max_retries`: `int` — Nombre maximal de nouvelles tentatives en cas d'échecs temporaires. Valeur par défaut : 2.

`refresh_buffer`: `int` — Nombre de secondes avant l'expiration pour déclencher une actualisation proactive. Valeur par défaut : 60.

**Méthodes**

`get_token() -> str` — Renvoie un jeton d'accès valide, en l'actualisant si nécessaire. Transmettez la référence de cette méthode (et non un appel) au SDK : `Frameio(token=auth.get_token)`.

`authenticate() -> dict[str, Any]` — Obtient explicitement un nouveau jeton d'accès. Renvoie le dictionnaire de réponse du jeton avec `access_token`, `expires_in`, etc.

`revoke() -> None` — Révoque les deux jetons côté serveur et efface l'état local.

`export_tokens() -> dict[str, Any]` — Exporte l'état actuel des jetons à des fins de persistance.

`import_tokens(data: dict[str, Any]) -> None` — Restaure l'état des jetons à partir d'un dictionnaire exporté précédemment.

</Accordion>

<Accordion title="frameio.auth.SPAAuth(*, client_id, redirect_uri, ...)">

Authentifiez-vous à l'aide d'authorization_code + PKCE (sans secret client). Utilisez-le pour les applications basées sur un navigateur ou les applications natives qui ne peuvent pas stocker un secret client en toute sécurité. Pour une utilisation asynchrone, utilisez `AsyncSPAAuth`.

```python title="usage"

import secrets
from frameio import Frameio
from frameio.auth import SPAAuth

auth = SPAAuth(client_id="YOUR_CLIENT_ID", redirect_uri="https://myapp.com/cb")
result = auth.get_authorization_url(state=secrets.token_urlsafe(32))
# redirect user to result.url, store result.code_verifier
auth.exchange_code(code="CODE_FROM_CALLBACK", code_verifier=result.code_verifier)
client = Frameio(token=auth.get_token)
```

**Paramètres**

`client_id`: `str` — ID client OAuth Adobe IMS.

`redirect_uri`: `str` — URI de redirection enregistrée.

`scopes`: `str` — Portées séparées par des espaces (OAuth 2.0 RFC 6749).

`ims_base_url`: `str` — URL de base IMS pour les environnements de préproduction ou alternatifs. Valeur par défaut : production.

`http_client`: `typing.Optional[httpx.Client]` — httpx.Client facultatif pour la gestion des proxys, du TLS ou du pool de connexions.

`on_token_refreshed`: `typing.Optional[typing.Callable[[dict[str, Any]], None]]` — Callback facultatif déclenché après chaque actualisation du jeton.

`timeout`: `float` — Délai d'expiration des requêtes HTTP, en secondes. Valeur par défaut : 30.

`max_retries`: `int` — Nombre maximal de nouvelles tentatives en cas d'échecs temporaires. Valeur par défaut : 2.

`refresh_buffer`: `int` — Nombre de secondes avant l'expiration pour déclencher une actualisation proactive. Valeur par défaut : 60.

**Méthodes**

`get_token() -> str` — Renvoie un jeton d'accès valide, en l'actualisant si nécessaire. Transmettez la référence de cette méthode au SDK : `Frameio(token=auth.get_token)`.

`get_authorization_url(state: str) -> AuthorizationUrlResult` — Construit l'URL d'autorisation Adobe IMS avec un challenge PKCE. Renvoie un `AuthorizationUrlResult` avec les attributs `url` et `code_verifier`.

`exchange_code(code: str, code_verifier: str) -> dict[str, Any]` — Échange un code d'autorisation et un vérificateur PKCE contre des jetons.

`refresh() -> dict[str, Any]` — Déclenche manuellement une actualisation du jeton.

`revoke() -> None` — Révoque les deux jetons côté serveur et efface l'état local.

`export_tokens() -> dict[str, Any]` — Exporte l'état actuel des jetons à des fins de persistance.

</Accordion>

<Accordion title="frameio.auth.AuthorizationUrlResult">

Dataclass figée renvoyée par `SPAAuth.get_authorization_url()` et `AsyncSPAAuth.get_authorization_url()`. Contient l'URL d'autorisation et le vérificateur de code PKCE.

**Attributs**

`url`: `str` — L'URL d'autorisation complète vers laquelle rediriger l'utilisateur.

`code_verifier`: `str` — Le vérificateur de code PKCE à stocker et à transmettre à `exchange_code()`.

</Accordion>

#### Exceptions d'authentification {#auth-exceptions}

Toutes les exceptions d'authentification héritent de `FrameioAuthError`.

| Exception | Description |
| --- | --- |
| `FrameioAuthError` | Exception de base pour toutes les erreurs `frameio.auth`. |
| `AuthenticationError` | L'échange ou l'actualisation du jeton a échoué. Possède les attributs `error_code` et `error_description`. |
| `TokenExpiredError` | Le jeton d'actualisation a expiré ; une nouvelle authentification est requise. |
| `ConfigurationError` | Une configuration requise est manquante ou invalide. |
| `NetworkError` | La requête réseau a échoué (délai d'expiration, erreur de connexion, etc.). |
| `RateLimitError` | L'API a renvoyé 429 et les nouvelles tentatives sont épuisées. Possède l'attribut `retry_after`. |
| `PKCEError` | La vérification PKCE a échoué. |

#### Téléversement {#upload}

<AccordionGroup>

<Accordion title="frameio.upload.FrameioUploader(asset, file, ...)" defaultOpen={true}>

Téléversez un fichier local vers Frame.io à l'aide des URL présignées renvoyées par `client.files.create_local_upload(...)`. `FrameioUploader` est une fine surcouche qui lit `upload_urls`, `file_size` et `media_type` à partir de la réponse `FileWithUploadUrls` et effectue un téléversement S3 multithread par blocs.

```python title="usage"

from frameio import Frameio
from frameio.files import FileCreateLocalUploadParamsData
from frameio.upload import FrameioUploader

client = Frameio(
    token="YOUR_TOKEN",
)
response = client.files.create_local_upload(
    account_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    folder_id="b2702c44-c6da-4bb6-8bbd-be6e547ccf1b",
    data=FileCreateLocalUploadParamsData(
        file_size=1137444,
        name="asset.png",
    ),
)
with open("asset.png", "rb") as f:
    FrameioUploader(response.data, f).upload()
```

**Paramètres**

`asset`: `FileWithUploadUrls` — Une instance `FileWithUploadUrls` renvoyée par `client.files.create_local_upload(...)`.

`file`: `typing.BinaryIO` — Un objet de type fichier ouvert en mode lecture binaire (`"rb"`).

`max_workers`: `int` — Niveau de concurrence du pool de threads transmis à l'outil de téléversement sous-jacent. Valeur par défaut : 5.

`headers`: `typing.Optional[typing.Dict[str, str]]` — En-têtes supplémentaires fusionnés dans chaque requête S3 PUT. Valeur par défaut : `{"x-amz-acl": "private"}`, comme l'exige Frame.io.

`max_retries`: `int` — Nombre de nouvelles tentatives par bloc. Valeur par défaut : 3.

`on_progress`: `typing.Optional[typing.Callable[[int, int], None]]` — Callback facultatif appelé après chaque bloc avec `(bytes_uploaded_so_far, total_bytes)`.

**Méthodes**

`upload() -> None` — Téléverse le fichier. Bloque jusqu'à la fin de l'opération ou lève une exception en cas d'erreur.
