### Installation {#installation}

```bash
npm i -s frameio
```

---

### Utilisation {#usage}

Instanciez et utilisez le client comme suit :

```typescript
import { FrameioClient } from "frameio";

const client = new FrameioClient({ token: "YOUR_TOKEN" });
await client.metadataFields.metadataFieldDefinitionsCreate("b2702c44-c6da-4bb6-8bbd-be6e547ccf1b", {
    data: {
        field_type: "select",
        field_configuration: {
            enable_add_new: false,
            options: [
                {
                    display_name: "Option 1",
                },
                {
                    display_name: "Option 2",
                },
            ],
        },
        name: "Fields definition name",
    },
});
```

---

### Types de requête et de réponse {#request-and-response-types}

Le SDK exporte tous les types de requête et de réponse sous forme d’interfaces TypeScript. Il suffit de les importer avec l’espace de noms suivant :

```typescript
import { Frameio } from "frameio";

const request: Frameio.UpdateFieldDefinitionParams = {
    ...
};
```

---

### Gestion des exceptions {#exception-handling}

Lorsque l’API renvoie un code de statut d’échec (réponse 4xx ou 5xx), une sous-classe de l’erreur suivante est levée.

```typescript
import { FrameioError } from "frameio";

try {
    await client.metadataFields.metadataFieldDefinitionsCreate(...);
} catch (err) {
    if (err instanceof FrameioError) {
        console.log(err.statusCode);
        console.log(err.message);
        console.log(err.body);
        console.log(err.rawResponse);
    }
}
```

### Avancé {#advanced}

#### En-têtes supplémentaires {#additional-headers}

Si vous souhaitez envoyer des en-têtes supplémentaires avec la requête, utilisez l’option de requête headers.

```typescript
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    headers: {
        'X-Custom-Header': 'custom value'
    }
});
```

#### Paramètres de chaîne de requête supplémentaires {#additional-query-string-parameters}

Si vous souhaitez envoyer des paramètres de chaîne de requête supplémentaires avec la requête, utilisez l’option de requête queryParams.

```typescript
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    queryParams: {
        'customQueryParamKey': 'custom query param value'
    }
});
```

---

#### Nouvelles tentatives {#retries}

Le SDK intègre des nouvelles tentatives automatiques avec backoff exponentiel. Une requête est relancée tant qu’elle est considérée comme pouvant être relancée et que le nombre de tentatives n’a pas dépassé la limite configurée (par défaut : 2).

Une requête est considérée comme pouvant être relancée lorsque l’un des codes de statut HTTP suivants est renvoyé :

- 408 (Délai d’expiration dépassé)
- 429 (Trop de requêtes)
- 5XX (Erreurs internes du serveur)

<br />

Utilisez l’option de requête `maxRetries` pour configurer ce comportement.

```typescript
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    maxRetries: 0 // override maxRetries at the request level
});
```

---

#### Délais d’expiration {#timeouts}

Par défaut, le SDK utilise un délai d’expiration de 60 secondes. Utilisez l’option timeoutInSeconds pour configurer ce comportement.

```typescript
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    timeoutInSeconds: 30 // override timeout to 30s
});
```

#### Annulation des requêtes {#aborting-requests}

Le SDK permet aux utilisateurs d’annuler des requêtes à tout moment en transmettant un signal d’annulation.

```typescript
const controller = new AbortController();
const response = await client.metadataFields.metadataFieldDefinitionsCreate(..., {
    abortSignal: controller.signal
});
controller.abort(); // aborts the request
```

---

#### Accéder aux données brutes de la réponse {#access-raw-response-data}

Le SDK donne accès aux données brutes de la réponse, y compris les en-têtes, via la méthode `.withRawResponse()`. La méthode `.withRawResponse()` renvoie une promesse qui se résout en un objet doté des propriétés `data` et `rawResponse`.

```typescript
const { data, rawResponse } = await client.metadataFields.metadataFieldDefinitionsCreate(...).withRawResponse();

console.log(data);
console.log(rawResponse.headers['X-My-Header']);
```

#### Compatibilité des environnements d’exécution {#runtime-compatibility}

Le SDK fonctionne dans les environnements d’exécution suivants :

- Node.js 18+
- Vercel
- Cloudflare Workers
- Deno v1.25+
- Bun 1.0+
- React Native

#### Personnaliser le client Fetch {#customizing-fetch-client}

Le SDK vous permet de personnaliser le client HTTP / la fonction Fetch sous-jacents. Si vous travaillez dans un environnement non pris en charge, c’est une solution de dernier recours pour garantir le fonctionnement du SDK.

```typescript
import { FrameioClient } from "frameio";

const client = new FrameioClient({
    ...
    fetcher: // provide your implementation here
});
```

#### Authentification {#auth}

<AccordionGroup>

<Accordion title="new ServerToServerAuth({ clientId, clientSecret, ... })">

S’authentifier à l’aide de l’octroi OAuth 2.0 `client_credentials`. Ce flux n’implique aucun utilisateur et ne renvoie pas de jeton d’actualisation. Lorsque le jeton d’accès expire, le SDK en demande automatiquement un nouveau à l’aide des identifiants client.

```typescript title="usage"
import { FrameioClient, ServerToServerAuth } from "frameio";

const auth = new ServerToServerAuth({
    clientId: "YOUR_CLIENT_ID",
    clientSecret: "YOUR_CLIENT_SECRET",
});
const client = new FrameioClient({ token: () => auth.getToken() });
```

**Paramètres**

`clientId`: `string` — ID client OAuth Adobe IMS.

`clientSecret`: `string` — Secret client OAuth Adobe IMS.

`scopes`: `string` — Portées séparées par des espaces (OAuth 2.0 RFC 6749). Par défaut : les portées serveur à serveur.

`imsBaseUrl`: `string` — URL de base IMS pour les environnements de préproduction ou alternatifs. Par défaut : production.

`fetch`: `typeof fetch` — Implémentation personnalisée de fetch (pour un proxy, TLS, etc.).

`onTokenRefreshed`: `OnTokenRefreshed` — Callback facultatif déclenché après chaque récupération de jeton.

`timeout`: `number` — Délai d’expiration des requêtes HTTP en millisecondes. Par défaut : 30000.

`maxRetries`: `number` — Nombre maximal de nouvelles tentatives en cas d’échecs temporaires. Par défaut : 2.

`refreshBuffer`: `number` — Nombre de secondes avant l’expiration pour déclencher une actualisation proactive. Par défaut : 60.

`logger`: `Logger` — Instance de logger pour la sortie de diagnostic.

**Méthodes**

`getToken(): Promise<string>` — Renvoie un jeton d’accès valide, en l’actualisant si nécessaire. Transmettez-le au client : `new FrameioClient({ token: () => auth.getToken() })`.

`authenticate(): Promise<TokenResponse>` — Récupère explicitement un nouveau jeton d’accès.

`revoke(): Promise<void>` — Révoque les jetons côté serveur et efface l’état local.

`exportTokens(): ExportedTokens` — Exporte l’état actuel des jetons pour le conserver.

`importTokens(data: ExportedTokens): void` — Restaure l’état des jetons à partir d’un objet exporté précédemment.

</Accordion>

<Accordion title="new WebAppAuth({ clientId, clientSecret, redirectUri, ... })">

S’authentifier à l’aide de l’octroi OAuth 2.0 `authorization_code`. Utilisez cette méthode pour les applications côté serveur capables de stocker un secret client de manière sécurisée.

```typescript title="usage"
import { randomBytes } from "crypto";
import { FrameioClient, WebAppAuth } from "frameio";

const auth = new WebAppAuth({
    clientId: "YOUR_CLIENT_ID",
    clientSecret: "YOUR_CLIENT_SECRET",
    redirectUri: "https://myapp.com/callback",
});
const url = auth.getAuthorizationUrl({ state: randomBytes(24).toString("hex") });
// redirect the user to url ...
await auth.exchangeCode("CODE_FROM_CALLBACK");
const client = new FrameioClient({ token: () => auth.getToken() });
```

**Paramètres**

`clientId`: `string` — ID client OAuth Adobe IMS.

`clientSecret`: `string` — Secret client OAuth Adobe IMS.

`redirectUri`: `string` — URI de redirection enregistré.

`scopes`: `string` — Portées séparées par des espaces (OAuth 2.0 RFC 6749).

`imsBaseUrl`: `string` — URL de base IMS pour les environnements de préproduction ou alternatifs. Par défaut : production.

`fetch`: `typeof fetch` — Implémentation personnalisée de fetch (pour un proxy, TLS, etc.).

`onTokenRefreshed`: `OnTokenRefreshed` — Callback facultatif déclenché après chaque actualisation de jeton.

`timeout`: `number` — Délai d’expiration des requêtes HTTP en millisecondes. Par défaut : 30000.

`maxRetries`: `number` — Nombre maximal de nouvelles tentatives en cas d’échecs temporaires. Par défaut : 2.

`refreshBuffer`: `number` — Nombre de secondes avant l’expiration pour déclencher une actualisation proactive. Par défaut : 60.

`logger`: `Logger` — Instance de logger pour la sortie de diagnostic.

**Méthodes**

`getToken(): Promise<string>` — Renvoie un jeton d’accès valide, en l’actualisant si nécessaire.

`getAuthorizationUrl({ state }): string` — Construit l’URL d’autorisation Adobe IMS. Transmettez une valeur CSRF/state opaque qui vous sera renvoyée.

`exchangeCode(code: string): Promise<TokenResponse>` — Échange un code d’autorisation contre des jetons d’accès et d’actualisation.

`refresh(): Promise<TokenResponse>` — Déclenche manuellement une actualisation du jeton.

`revoke(): Promise<void>` — Révoque les jetons côté serveur et efface l’état local.

`exportTokens(): ExportedTokens` — Exporte l’état actuel des jetons pour le conserver.

`importTokens(data: ExportedTokens): void` — Restaure l’état des jetons à partir d’un objet exporté précédemment.

<Accordion title="new SPAAuth({ clientId, redirectUri, ... })">

S’authentifier à l’aide de `authorization_code` + PKCE (sans secret client). Utilisez cette méthode pour les applications monopages exécutées dans le navigateur qui ne peuvent pas stocker un secret client de manière sécurisée.

```typescript title="usage"
import { randomBytes } from "crypto";
import { FrameioClient, SPAAuth } from "frameio";

const auth = new SPAAuth({
    clientId: "YOUR_CLIENT_ID",
    redirectUri: "https://myapp.com/cb",
});
const result = await auth.getAuthorizationUrl({ state: randomBytes(24).toString("hex") });
// redirect the user to result.url, store result.codeVerifier ...
await auth.exchangeCode({ code: "CODE_FROM_CALLBACK", codeVerifier: result.codeVerifier });
const client = new FrameioClient({ token: () => auth.getToken() });
```

**Paramètres**

`clientId`: `string` — ID client OAuth Adobe IMS.

`redirectUri`: `string` — URI de redirection enregistré.

`scopes`: `string` — Portées séparées par des espaces (OAuth 2.0 RFC 6749).

`imsBaseUrl`: `string` — URL de base IMS pour les environnements de préproduction ou alternatifs. Par défaut : production.

`fetch`: `typeof fetch` — Implémentation personnalisée de fetch (pour un proxy, TLS, etc.).

`onTokenRefreshed`: `OnTokenRefreshed` — Callback facultatif déclenché après chaque actualisation de jeton.

`timeout`: `number` — Délai d’expiration des requêtes HTTP en millisecondes. Par défaut : 30000.

`maxRetries`: `number` — Nombre maximal de nouvelles tentatives en cas d’échecs temporaires. Par défaut : 2.

`refreshBuffer`: `number` — Nombre de secondes avant l’expiration pour déclencher une actualisation proactive. Par défaut : 60.

`logger`: `Logger` — Instance de logger pour la sortie de diagnostic.

**Méthodes**

`getToken(): Promise<string>` — Renvoie un jeton d’accès valide, en l’actualisant si nécessaire.

`getAuthorizationUrl({ state }): Promise<AuthorizationUrlResult>` — Construit l’URL d’autorisation Adobe IMS avec un challenge PKCE. Renvoie un `AuthorizationUrlResult` contenant `url` et `codeVerifier`.

`exchangeCode({ code, codeVerifier }): Promise<TokenResponse>` — Échange un code d’autorisation + un vérificateur PKCE contre des jetons.

`refresh(): Promise<TokenResponse>` — Déclenche manuellement une actualisation du jeton.

`revoke(): Promise<void>` — Révoque les jetons côté serveur et efface l’état local.

`exportTokens(): ExportedTokens` — Exporte l’état actuel des jetons pour le conserver.

`importTokens(data: ExportedTokens): void` — Restaure l’état des jetons à partir d’un objet exporté précédemment.

</Accordion>

<Accordion title="new NativeAppAuth({ clientId, redirectUri, ... })">

S’authentifier à l’aide de `authorization_code` + PKCE pour les applications de bureau et mobiles. Partage la même API que `SPAAuth` ; utilisez un URI de redirection avec un schéma personnalisé (par ex. `myapp://callback`).

```typescript title="usage"
import { randomBytes } from "crypto";

    clientId: "YOUR_CLIENT_ID",
    redirectUri: "myapp://callback",
});
const result = await auth.getAuthorizationUrl({ state: randomBytes(24).toString("hex") });
// open result.url in the system browser, store result.codeVerifier ...
await auth.exchangeCode({ code: "CODE_FROM_CALLBACK", codeVerifier: result.codeVerifier });
const client = new FrameioClient({ token: () => auth.getToken() });
```

**Paramètres**

`clientId`: `string` — ID client OAuth Adobe IMS.

`redirectUri`: `string` — URI de redirection enregistré (schéma personnalisé pris en charge).

`scopes`: `string` — Portées séparées par des espaces (OAuth 2.0 RFC 6749).

`imsBaseUrl`: `string` — URL de base IMS pour les environnements de préproduction ou alternatifs. Par défaut : production.

`fetch`: `typeof fetch` — Implémentation personnalisée de fetch (pour un proxy, TLS, etc.).

`onTokenRefreshed`: `OnTokenRefreshed` — Callback facultatif déclenché après chaque actualisation de jeton.

`timeout`: `number` — Délai d’expiration des requêtes HTTP en millisecondes. Par défaut : 30000.

`maxRetries`: `number` — Nombre maximal de nouvelles tentatives en cas d’échecs temporaires. Par défaut : 2.

`refreshBuffer`: `number` — Nombre de secondes avant l’expiration pour déclencher une actualisation proactive. Par défaut : 60.

`logger`: `Logger` — Instance de logger pour la sortie de diagnostic.

**Méthodes**

Identiques à `SPAAuth` : `getToken()`, `getAuthorizationUrl({ state })`, `exchangeCode({ code, codeVerifier })`, `refresh()`, `revoke()`, `exportTokens()`, `importTokens(data)`.

</Accordion>

<Accordion title="AuthorizationUrlResult">

Objet renvoyé par `SPAAuth.getAuthorizationUrl()` et `NativeAppAuth.getAuthorizationUrl()`. Contient l’URL d’autorisation et le vérificateur de code PKCE.

**Propriétés**

`url`: `string` — L’URL d’autorisation complète vers laquelle rediriger l’utilisateur.

#### Exceptions d’authentification {#auth-exceptions}

Toutes les erreurs d’authentification étendent `FrameioAuthError` et peuvent être importées depuis `frameio`.

| Exception | Description |
| --- | --- |
| `FrameioAuthError` | Erreur de base pour toutes les erreurs du SDK d’authentification. |
| `AuthenticationError` | L’échange ou l’actualisation du jeton a échoué. Possède les propriétés `errorCode` et `errorDescription`. |
| `TokenExpiredError` | Le jeton d’actualisation a expiré ; une nouvelle authentification est requise. |
| `NetworkError` | Une requête réseau a échoué (délai d’expiration, erreur de connexion, etc.). |
| `RateLimitError` | Adobe IMS a renvoyé une erreur 429 et les nouvelles tentatives sont épuisées. Possède une propriété `retryAfter`. |
| `PKCEError` | La vérification PKCE a échoué. |
| `ConfigurationError` | Une configuration requise est manquante ou non valide. |

Si le contenu est inaccessible parce qu’un filigrane est requis pour cet utilisateur et n’est pas pris en charge par les media_links demandés, la requête aboutira, mais les liens média non pris en charge seront définis sur null.
