<Note>
  Il s'agit d'un endpoint de démonstration pour l'automatisation Update from code changes de Mintlify. Il ne fait pas partie de l'API Frame.io.
</Note>

Utilisez cet endpoint pour vérifier si un asset a terminé son traitement.

## Obtenir le statut d'un asset {#get-an-asset’s-status}

```http
GET /v4/assets/{id}/status
```

### Paramètres de chemin {#path-parameters}

| Paramètre | Type   | Description         |
| --------- | ------ | ------------------- |
| `id`      | string | L'ID de l'asset.    |

### Champs de réponse {#response-fields}

| Champ         | Type   | Description                                              |
| ------------- | ------ | -------------------------------------------------------- |
| `data.id`     | string | L'ID de l'asset.                                         |
| `data.status` | string | Le statut de traitement : `processing` ou `ready`.       |
| `data.updated_at` | string | La date de dernière mise à jour de l'asset, sous forme d'horodatage UTC ISO 8601. |

### Exemple {#example}

```bash
curl http://localhost:3001/v4/assets/a1b2c3/status
```

```json
{
  "data": {
    "id": "a1b2c3",
    "status": "ready",
    "updated_at": "2026-11-03T18:22:10Z"
  }
}
```

### Erreurs {#errors}

| Statut | Erreur            | Signification                     |
| ------ | ----------------- | --------------------------------- |
| `404`  | `asset_not_found` | Aucun asset ne possède cet ID.    |
