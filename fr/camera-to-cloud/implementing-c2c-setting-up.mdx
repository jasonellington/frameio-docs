## Introduction {#introduction}

Avant d’implémenter votre appareil Camera to Cloud, assurons-nous que vous disposez de tout le nécessaire pour réussir.

## S’inscrire en tant que développeur {#register-as-a-developer}

Vous aurez besoin d’un `client_secret` pour votre appareil afin de suivre les guides d’implémentation. Si ce n’est pas déjà fait, consultez notre [guide de démarrage](/fr/camera-to-cloud/getting-started-with-cloud-device-integrations) pour savoir comment vous inscrire en tant que développeur C2C. Notre équipe vous fournira les identifiants nécessaires pour interagir avec l’API.

## Outils pour suivre les guides d’implémentation {#tools-for-following-implementation-guides}

Bien qu’ils ne soient pas strictement nécessaires, ces outils vous aideront à suivre nos tutoriels et à tester directement les interactions avec l’API.

### cURL {#curl}

Ces tutoriels présentent les requêtes de l’API Frame.io à l’aide de `curl`. Cette bibliothèque très répandue offre une excellente interface en ligne de commande pour effectuer des requêtes HTTP. Lors de l’implémentation de votre appareil, vous devrez reproduire ces appels HTTP dans le langage de programmation de votre choix. L’utilisation de `curl` dans ces exemples vous permet de tester les interactions avec l’API en copiant simplement les commandes dans votre terminal.

Pour vérifier que `curl` est installé sur votre système, saisissez cette commande dans votre terminal :

```shell
curl --version
```

Vous devriez obtenir un résultat semblable à celui-ci :

```text
curl 7.64.1 (x86_64-apple-darwin20.0) libcurl/7.64.1 (SecureTransport) LibreSSL/2.8.3 zlib/1.2.11 nghttp2/1.41.0
Release-Date: 2019-03-27
Protocols: dict file ftp ftps gopher http https imap imaps ldap ldaps pop3 pop3s rtsp smb smbs smtp smtps telnet tftp 
Features: AsynchDNS GSS-API HTTP2 HTTPS-proxy IPv6 Kerberos Largefile libz MultiSSL NTLM NTLM_WB SPNEGO SSL UnixSockets
```

S’il n’est pas installé, vous trouverez des programmes d’installation pour la plupart des systèmes d’exploitation [ici](https://curl.se/download.html). Les utilisateurs de macOS ou de Linux peuvent l’installer via [Homebrew](https://brew.sh/) :

```shell
brew install curl
```

### Python {#python}

Nous utiliserons Python pour formater les charges utiles JSON des réponses en redirigeant les résultats de `curl` :

```shell
curl https://api.frame.io/health | python -m json.tool
```

Pour vérifier que Python est installé :

```shell
python --version
```

Résultat attendu :

```text
Python 2.7.16
```

S’il n’est pas installé, vous pouvez [télécharger Python ici](https://www.python.org/downloads/). Python 2.6+ ou Python 3.x conviennent pour ces exemples.

Bien que Python ne soit pas obligatoire, il permet de rendre les réponses plus lisibles. Vous pouvez également utiliser des outils comme [jq](https://stedolan.github.io/jq/), qui offrent des fonctionnalités similaires.
