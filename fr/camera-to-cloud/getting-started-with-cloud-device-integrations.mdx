## Camera To Cloud {#camera-to-cloud}

L'API Camera to Cloud fournit un protocole d'authentification simple, conçu pour les appareils dotés de capacités d'affichage limitées. Une fois authentifié, votre appareil peut téléverser les données du plateau directement vers le cloud. Le système prend en charge la plupart des formats de fichiers standard pour la vidéo, l'audio, les LUT/CDL et les données de timecode. Pour plus de détails sur les connexions certifiées C2C, consultez notre [page d'information](https://frame.io/c2c/certified).

## Kit développeur {#developer-package}

Votre kit de développement comprendra :

**1. Client Secret**

Frame.io créera un modèle de configuration pour votre appareil dans notre backend. Une fois cette étape terminée, vous recevrez un `client_secret` pour votre appareil, communément appelé identifiant de modèle d'appareil.

**2. Implémentation de référence**

Vous recevrez une implémentation de référence en Python avec un code squelette qui émule des appareils matériels via un outil CLI. Elle comprend du code commenté et une documentation décrivant les étapes clés de l'intégration.

**3. Processus de validation**

Avant le lancement, vous participerez à un processus d'assurance qualité avec les ingénieurs de Frame.io afin de vérifier que votre appareil fonctionne comme prévu. Notre objectif est d'aider tous les intégrateurs à atteindre des normes de qualité homogènes pour les utilisateurs finaux de votre appareil connecté au cloud. Cela vous fournit de précieux retours avant la sortie publique. Nous vous fournirons une liste de points à vérifier, mais vous pouvez également consulter notre [liste de contrôle d'intégration C2C](/fr/camera-to-cloud/integrator-checklist) pour comprendre ce qui fait une intégration réussie.

**4. Supports d'accompagnement**

Vous recevrez des supports pour aider votre équipe à comprendre la proposition de valeur de Frame.io et les techniques de démonstration, ainsi qu'un accès à un canal Slack dédié pour travailler avec notre équipe. Si vous avez besoin d'une assistance supplémentaire, comme une démo de la plateforme Frame.io ou un atelier sur les bonnes pratiques d'intégration, faites-le-nous savoir et nous organiserons les sessions appropriées.

### Informations sur l'appareil {#device-information}

Nous aurons besoin de quelques informations de base sur votre appareil :

* Le nom exact de votre appareil
* Un logo au format SVG, de préférence monochrome

### Méthode d'authentification {#authentication-method}

Nous prenons désormais exclusivement en charge le flux d'authentification par code à 6 chiffres. Pour les applications, nous proposons une méthode améliorée utilisant un paramètre d'en-tête spécial lors de la demande d'un code d'appareil, afin d'activer notre flux d'appairage par URL. Celui-ci renvoie les paramètres `verification_uri_complete` ou `verification_uri`, que vous pouvez utiliser pour générer une URL sous forme de lien hypertexte ou de QR code que les utilisateurs peuvent toucher ou scanner. Cela lance un processus d'appairage simplifié qui se connecte directement au projet sélectionné par l'utilisateur. Pour les détails d'implémentation, consultez le [guide d'activation de l'appairage par QR code](/fr/camera-to-cloud/implementing-c2c-authentication-and-authorization#h3-section-enabling-qr-code-pairing).
